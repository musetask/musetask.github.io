☰ 4. LayerNorm 与 GELU 的数学推导

4.2–4.6 LayerNorm、GELU、残差连接与参数量：完整数学推导

这一章的公式密度不高，但每一处都有容易被跳过却必须理解的细节：为什么方差除以 \(n\) 而不是 \(n-1\)、GELU 那个奇怪的 0.044715 从哪来、残差连接到底怎么救梯度、以及 163,009,536 这个数字是怎么加出来的。

最后一部分是本章最有价值的部分：把 1.63 亿参数逐项加出来，原书只给结果。

一、LayerNorm：为什么是 0 均值 1 方差

1.1 定义

对某个 token 的 \(d\) 维激活向量 \(a=(a_1,\dots,a_d)\)，LayerNorm 把它标准化：

\[ \mu = \frac{1}{d}\sum_{i=1}^{d} a_i, \qquad \sigma^2 = \frac{1}{d}\sum_{i=1}^{d}(a_i - \mu)^2 \] \[ \mathrm{LayerNorm}(a)_i = \gamma \cdot \frac{a_i - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta \]
预备知识：求和符号的线性性质

\(\sum_{i=1}^{d}(a_i-c)=\sum_{i=1}^{d}a_i-d\cdot c\)（常数 \(c\) 求和 \(d\) 次就是 \(dc\)）；\(\sum_{i=1}^{d}c\cdot a_i=c\sum_{i=1}^{d}a_i\)（常数因子可提出求和号）。

推导：归一化后均值恰为 0、方差恰为 1

记 \(z_i=(a_i-\mu)/\sigma\)（先忽略 \(\epsilon\)）。求均值：

\[ \frac1d\sum_{i=1}^{d}z_i=\frac1{d\sigma}\sum_{i=1}^{d}(a_i-\mu)=\frac1{d\sigma}\left(\sum_{i=1}^{d}a_i-d\mu\right)=\frac1{d\sigma}(d\mu-d\mu)=0 \]

其中用了 \(\sum_i a_i=d\mu\)（这正是 \(\mu\) 的定义移项）。求方差：

\[ \frac1d\sum_{i=1}^{d}z_i^2=\frac1{d\sigma^2}\sum_{i=1}^{d}(a_i-\mu)^2=\frac{1}{\sigma^2}\cdot\underbrace{\frac1d\sum_{i=1}^{d}(a_i-\mu)^2}_{\sigma^2\text{ 的定义}}=1 \]

所以无论输入是什么分布，\(\gamma=1,\beta=0\) 时输出恒为 0 均值、1 方差——这正是正文手算例子得到均值 0.0000、方差 1.0000 的原因。

其中 \(\gamma,\beta\in\mathbb{R}^d\) 是可学习的缩放和平移参数，\(\epsilon\) 是防除零的小常数（PyTorch 默认 1e-5）。

标准化之后为什么还要 \(\gamma,\beta\)

如果只标准化，输出被强行限制在均值 0、方差 1 里，层就失去了表达任意变换的能力——后续层无论怎么加权，得到的分布形状都差不多。加上 \(\gamma,\beta\) 后，网络可以自己学回「要不要标准化」：把 \(\gamma\) 学到接近 0 就等于关掉这一层的归一化。这是 LayerNorm 相对 BatchNorm 的一个优势——它不依赖 batch 统计量，所以训练和推理行为一致。

GPT-2 的 nn.LayerNorm 默认 elementwise_affine=True，即 \(\gamma,\beta\) 存在且可训练，768 维就是 1536 个参数。这解释了后面参数量表里的 2,048 或 1,536。

1.3 有偏方差：unbiased=False 的含义

原书特意用了一个 callout 解释这个参数。样本方差有两个版本：

\[ \sigma^2_{\text{biased}} = \frac{1}{d}\sum (a_i-\mu)^2 \qquad \sigma^2_{\text{unbiased}} = \frac{1}{d-1}\sum (a_i-\mu)^2 \]
预备知识：样本均值的方差

设 \(a_1,\dots,a_d\) 独立同分布，均值 \(\mu\)、方差 \(\sigma^2\)。样本均值 \(\bar a=\frac1d\sum_i a_i\) 的方差为 \(\mathrm{Var}(\bar a)=\frac1{d^2}\sum_i\mathrm{Var}(a_i)=\frac{d\sigma^2}{d^2}=\frac{\sigma^2}{d}\)——平均 \(d\) 个独立样本，方差缩小为 \(1/d\)。另需期望的线性：\(\mathrm{E}[\sum_i X_i]=\sum_i\mathrm{E}[X_i]\)。

推导：为什么除以 \(d-1\) 才是无偏的

先把平方和拆开（下式中的 \(\mu\) 即样本均值 \(\bar a\)）：

\[ \sum_{i=1}^{d}(a_i-\bar a)^2=\sum_{i=1}^{d}a_i^2-2\bar a\sum_{i=1}^{d}a_i+d\bar a^2=\sum_{i=1}^{d}a_i^2-d\bar a^2 \]

（第二步用了 \(\sum_i a_i=d\bar a\)。）两边取期望。\(\mathrm{E}[a_i^2]=\sigma^2+\mu^2\)（方差定义 \(\mathrm{Var}(X)=\mathrm{E}[X^2]-(\mathrm{E}X)^2\) 移项），故 \(\mathrm{E}[\sum_i a_i^2]=d(\sigma^2+\mu^2)\)；\(\mathrm{E}[\bar a^2]=\mathrm{Var}(\bar a)+(\mathrm{E}[\bar a])^2=\sigma^2/d+\mu^2\)。相减：

\[ \mathrm{E}\left[\sum_{i=1}^{d}(a_i-\bar a)^2\right]=d(\sigma^2+\mu^2)-d\left(\frac{\sigma^2}{d}+\mu^2\right)=(d-1)\sigma^2 \]

所以平方和的期望是 \((d-1)\sigma^2\) 而非 \(d\sigma^2\)——除以 \(d\) 会系统性低估，除以 \(d-1\) 才无偏。这就是 Bessel 修正。两版本比值恒为 \(\frac{1/(d-1)}{1/d}=\frac{d}{d-1}\)，与正文表格一致（\(d=6\) 时 \(6/5=1.2\)，即 20% 的差异）。

无偏版本（除以 \(d-1\)）叫 Bessel 修正，修正的是「用有限样本估计总体方差时系统性偏低」这个统计偏差。两者比值恒为 \(d/(d-1)\)。

真正的原因是兼容性，不是数学

二、GELU：0.044715 从哪来

2.1 精确定义

原书给出：GELU(x) = x · Φ(x)，其中 \(\Phi\) 是标准正态分布的累积分布函数：

\[ \Phi(x) = \int_{-\infty}^{x} \frac{1}{\sqrt{2\pi}}e^{-t^2/2}\,dt \]

写成显式形式：

\[ \mathrm{GELU}(x) = x \cdot \frac{1}{2}\left(1 + \mathrm{erf}\!\left(\frac{x}{\sqrt{2}}\right)\right) \]
预备知识：erf、高斯积分与换元积分

误差函数 \(\mathrm{erf}(z)=\frac{2}{\sqrt\pi}\int_0^{z}e^{-t^2}dt\)。高斯积分 \(\int_{-\infty}^{+\infty}e^{-t^2}dt=\sqrt\pi\)（结论；被积函数偶对称，故 \(\int_{-\infty}^{0}e^{-t^2}dt=\sqrt\pi/2\)）。换元积分：令 \(u=t/\sqrt2\)，则 \(dt=\sqrt2\,du\)，积分限 \(t\in(-\infty,x]\) 对应 \(u\in(-\infty,x/\sqrt2]\)。

推导：\(\Phi(x)=\tfrac12\left(1+\mathrm{erf}(x/\sqrt2)\right)\)

对 \(\Phi(x)\) 做换元 \(u=t/\sqrt2\)：

\[ \begin{aligned} \Phi(x)&=\int_{-\infty}^{x}\frac{1}{\sqrt{2\pi}}e^{-t^2/2}\,dt\\ &=\int_{-\infty}^{x/\sqrt2}\frac{1}{\sqrt{2\pi}}e^{-u^2}\sqrt2\,du =\frac{1}{\sqrt\pi}\int_{-\infty}^{x/\sqrt2}e^{-u^2}\,du\\ &=\frac{1}{\sqrt\pi}\left(\int_{-\infty}^{0}e^{-u^2}du+\int_{0}^{x/\sqrt2}e^{-u^2}du\right)\\ &=\frac{1}{\sqrt\pi}\left(\frac{\sqrt\pi}{2}+\frac{\sqrt\pi}{2}\mathrm{erf}\!\left(\frac{x}{\sqrt2}\right)\right) =\frac12\left(1+\mathrm{erf}\!\left(\frac{x}{\sqrt2}\right)\right) \end{aligned} \]

第三步把积分拆成两段：\((-\infty,0]\) 段用高斯积分得 \(\sqrt\pi/2\)；\([0,x/\sqrt2]\) 段正是 erf 定义式的 \(\frac{\sqrt\pi}{2}\mathrm{erf}(x/\sqrt2)\)。于是 \(\mathrm{GELU}(x)=x\Phi(x)\) 化为正文的显式形式。

GELU 是一个「软开关」

\(\Phi(x)\) 可以读作「一个标准正态随机变量小于 \(x\) 的概率」。所以 GELU(x) = x × P(小于 x)。

从行为看：

x 很大（+3）：\(\Phi(3)=0.9987\)，输出 \(\approx 0.999x\)，几乎原样通过。

x 很小（−3）：\(\Phi(-3)=0.0013\)，输出 \(\approx -0.004\)，几乎被压成 0。

x = 0：\(\Phi(0)=0.5\)，但 \(x=0\)，所以输出 0。

和 ReLU 对比的关键差异：ReLU 在 0 处有不可导的尖角，GELU 在 0 处光滑，且在 x 略小于 0 时输出小负值而非硬截断。这让梯度在 0 附近仍然连续。

\[ \mathrm{GELU}(x) \approx \frac{x}{2}\left(1 + \tanh\!\left[\sqrt{\tfrac{2}{\pi}}\,(x + 0.044715\,x^3)\right]\right) \]

对应代码：

三、残差连接：怎么把 2e-4 变成 0.22

原书 4.4 节用五层网络演示梯度消失。数字非常有说服力，值得完整看一遍。

3.1 梯度怎么走的

没有残差时，梯度要串行穿过全部 5 层：

\[ \frac{\partial \mathcal{L}}{\partial W_1} = \frac{\partial \mathcal{L}}{\partial y} \prod_{l=5}^{2} \frac{\partial y}{\partial h_l}\frac{\partial h_l}{\partial W_l}\frac{\partial h_l}{\partial h_{l-1}} \]

每一项都带一个小于 1 的雅可比因子（Linear 的雅可比是权重矩阵，ReLU/GELU 的导数 \(\le 1\)）。5 层相乘，指数级衰减。

加了残差后，前向是 \(\mathbf{x}_{l+1} = \mathbf{x}_l + f(\mathbf{x}_l)\)，反向求导时 backward() 会把梯度同时分两路：一路经过 \(f\)，一路直接穿过加号（因为 \(\partial(\mathbf{x}_l + f)/\partial \mathbf{x}_l = I + f'\)，单位矩阵项保证了梯度原封不动地传下去）。

预备知识：链式法则与雅可比矩阵

若 \(y=f(u),\,u=g(x)\)，则 \(\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}\)。向量情形：\(\mathbf{y}=F(\mathbf{x})\)（\(\mathbf{x},\mathbf{y}\in\mathbb{R}^d\)）的雅可比矩阵 \(J\) 的 \((i,j)\) 元为 \(\partial y_i/\partial x_j\)，梯度反向传播时要乘上它。恒等映射 \(\mathbf{y}=\mathbf{x}\) 的雅可比是单位矩阵 \(I\)。

推导：残差的梯度为什么能「直达」

残差块前向：\(\mathbf{x}_{l+1}=\mathbf{x}_l+f(\mathbf{x}_l)\)。对 \(\mathbf{x}_l\) 求雅可比（加号求导：\(\mathbf{x}_l\) 对自己导数是 \(I\)，\(f(\mathbf{x}_l)\) 的导数记为 \(J_f\)）：

\[ \frac{\partial\mathbf{x}_{l+1}}{\partial\mathbf{x}_l}=I+\underbrace{\frac{\partial f}{\partial\mathbf{x}_l}}_{J_f} \]

记 \(\boldsymbol{\delta}_{l+1}=\partial\mathcal{L}/\partial\mathbf{x}_{l+1}\)，链式法则给出：

\[ \boldsymbol{\delta}_{l}=\boldsymbol{\delta}_{l+1}\,(I+J_f)=\boldsymbol{\delta}_{l+1}+\boldsymbol{\delta}_{l+1}J_f \]

关键在第一项 \(\boldsymbol{\delta}_{l+1}\)：它完全不经过 \(f\)，原封不动传给上一层。把 \(L\) 层串起来，总梯度里永远包含一项 \(\boldsymbol{\delta}_{L}\)（从 loss 直达的恒等路径），其余项才经过各层的 \(J_f\)。没有残差时（如正文公式），梯度是 \(\prod_l J_l\) 的连乘，每层雅可比的谱范数 \(<1\) 就指数衰减；有残差时连乘的是 \(\prod_l(I+J_l)\)，展开后恒含 \(I\) 项——这就是正文表格里 layer 0 梯度从 0.000202 变成 0.221698（1099 倍）的数学原因。

残差连接是架构的必需品，不是优化技巧

原书 4.5 节的 TransformerBlock 里每个子层都有残差：

residual = x; x = self.norm1(x); x, _ = self.att(x, x, x); x = self.dropout(x); x = x + residual

注意代码里的 residual = x 是在 norm 之前保存的。这不是随意写的——残差路径上不插入任何非线性或归一化，梯度才能干净地直达。LayerNorm 和 Dropout 都只在残差分支内部生效。

值得注意的是：两个 embedding 层合计占掉模型的 47.4%，而「Transformer 的计算主体」（注意力 + 前馈）只占 52.2%。词表大小对参数量有压倒性影响——这也是后来 LLaMA 把词表缩到 32k 的原因之一。

4.3 习题 4.1：前馈 vs 注意力

原书习题问「前馈模块和注意力模块各有多少参数」。从上表：

\[ \frac{4{,}722{,}432}{2{,}360{,}064} \approx 2.001 \]

恰好 2 倍。这不是巧合：前馈是 768 → 3072 → 768，两个矩阵各约 236 万；注意力是四个 768×768，也约 236 万。GPT-2 的 4 × d 中间维度让两者参数量精确相等。

参数量相等但计算量与作用完全不同：前馈是逐位置（position-wise）的非线性变换，注意力是 token 间的信息交换。这也是为什么 GPT-2 的 n_layers=12、n_heads=12 被设成相等——一层一个头，纯粹是工程惯例。

4.4 内存占用

原书最后算内存：假设 fp32（每参数 4 字节）：

\[ \frac{163{,}009{,}536 \times 4}{1024^2} = 621.83\ \text{MB} \]

✓ 与原书的 Total size of the model: 621.83 MB 一致。

几个推论：

精度字节/参数124M（weight tying 后）备注
fp324474.59 MB默认，训练用
fp16 / bf162237.30 MB推理常用
int81118.65 MB量化

训练时显存占用远不止模型大小：还要存 AdamW 的两个动量（m 和 v，各一份 fp32），加上梯度。粗算 参数量 × 4 字节 × 4 ≈ 模型权重的 4 倍，即 124M 模型训练要约 1.9 GB 只用于状态，激活值和临时缓冲还要另算。这就是原书 5.2 节提醒「预训练很贵」、以及第 6、7 章改用 lr=5e-5 做微调（而非预训练的 4e-4）的原因。

五、一句话串起本章

四个数学细节如何互相咬合

LayerNorm（有偏方差）让每层输出分布稳定，防止激活值随深度漂移。

GELU（平滑软开关）提供非线性，且在 0 附近梯度连续，不会制造断崖。

残差连接（梯度旁路）让梯度有了一条不经过任何非线性的直达路径，深度才能堆到 12 层甚至 96 层。

参数量（47% 在 embedding）决定了词表大小是模型设计的一个前置约束，而不是纯数据问题。

A.3–A.4 链式法则与自动微分：完整数学推导

原书在 A.4 节明确说："a deep mathematical understanding of gradients is not required to follow the contents of this book." 这个态度是对的——但它也意味着全书唯一一次手算梯度的地方（−0.0898 和 −0.0817）没有推导。

这一页把那两个数字算出来。原书的 logistic regression 例子足够小，可以逐项手算并完全对上，这是理解 PyTorch 训练循环最好的入口。

一、计算图：把公式画成图

原书 A.3 节的例子是逻辑回归（单层神经网络）：

y  = torch.tensor([1.0])     # 真实标签
x1 = torch.tensor([1.1])     # 输入特征
w1 = torch.tensor([2.2])     # 权重参数
b  = torch.tensor([0.0])     # 偏置

z = x1 * w1 + b       # 线性层
a = torch.sigmoid(z)  # 激活
loss = F.binary_cross_entropy(a, y)   # 损失

用公式写就是三层：

\[ z = x_1 w_1 + b, \qquad a = \sigma(z), \qquad \mathcal{L} = -\left[y\log a + (1-y)\log(1-a)\right] \]

其中 sigmoid 是 \(\sigma(z) = \dfrac{1}{1+e^{-z}}\)。

为什么要引入计算图

因为求偏导数的手工过程是机械且易错的：4 个节点要写 4 条局部导数链，还要处理重复路径（如 \(w_1\) 同时出现在 \(z\) 的乘法和链上）。层数一多，手算完全不现实。

PyTorch 的做法：前向时记录每一步操作，反向时按链式法则从 loss 往回走。这就是 autograd 引擎的全部职责。原书把它称为 "reverse-mode automatic differentiation"——反向模式，指从输出往输入求导。

二、链式法则：手算两个梯度

2.1 逐步求局部导数

反向传播只需要三个局部导数：

① 损失对 \(a\) 的导数。二元交叉熵对预测值的导数：

\[ \frac{\partial \mathcal{L}}{\partial a} = -\frac{y}{a} + \frac{1-y}{1-a} \]
预备知识：两条求导法则

① \((\log x)'=1/x\)（\(x>0\)）；② 链式法则：复合函数 \(f(g(x))\) 的导数是 \(f'(g(x))\cdot g'(x)\)——「外层导数乘以内层导数」。下面两处推导只用这两条。

推导：二元交叉熵对 \(a\) 求导

\(\mathcal{L}=-[y\log a+(1-y)\log(1-a)]\)，逐项求导。第一项：\((-y\log a)'=-y\cdot\frac1a\)。第二项是复合函数 \(\log(1-a)\)，用链式法则——外层 \((\log u)'=1/u\)（其中 \(u=1-a\)），内层 \((1-a)'=-1\)：

\[ \frac{d}{da}\big[-(1-y)\log(1-a)\big]=-(1-y)\cdot\frac{1}{1-a}\cdot(-1)=+\frac{1-y}{1-a} \]

两项相加即得 \(\frac{\partial\mathcal{L}}{\partial a}=-\frac{y}{a}+\frac{1-y}{1-a}\)。注意那个关键的负负得正：内层导数 \(-1\) 与外面的负号相消。代入 \(y=1,\ a=0.91834\)：\(-1/0.91834+0=-1.08892\)，与正文 2.2 节第 4 步一致。

② sigmoid 的导数。这是最值得记的一个：

\[ \sigma'(z) = \sigma(z)\,(1-\sigma(z)) = a(1-a) \]
推导：\(\sigma'(z)=\sigma(z)(1-\sigma(z))\) 完整版

把 \(\sigma(z)=\dfrac{1}{1+e^{-z}}\) 写成 \((1+e^{-z})^{-1}\)，用链式法则（外层 \((u^{-1})'=-u^{-2}\)，内层 \((e^{-z})'=-e^{-z}\)）：

\[ \sigma'(z)=-(1+e^{-z})^{-2}\cdot(-e^{-z})=\frac{e^{-z}}{(1+e^{-z})^2} \]

现在做因式分解，把分式拆成两项之积：

\[ \frac{e^{-z}}{(1+e^{-z})^2} =\underbrace{\frac{1}{1+e^{-z}}}_{\sigma(z)}\cdot\underbrace{\frac{e^{-z}}{1+e^{-z}}}_{1-\sigma(z)} \]

第二项化简：\(\dfrac{e^{-z}}{1+e^{-z}}=\dfrac{(1+e^{-z})-1}{1+e^{-z}}=1-\dfrac{1}{1+e^{-z}}=1-\sigma(z)\)。于是 \(\sigma'(z)=\sigma(z)(1-\sigma(z))\)。这个形式的价值：求导不需要重新算指数——前向时已经算出 \(a=\sigma(z)\)，反向直接用 \(a(1-a)\)，一次乘法搞定。这也是 PyTorch 里 sigmoid backward 的实现方式。

③ 线性层的导数。\(z = x_1w_1+b\)，所以

\[ \frac{\partial z}{\partial w_1} = x_1, \qquad \frac{\partial z}{\partial b} = 1 \]

2.2 代入数字

  1. 前向：算 \(z\)：\(z = 1.1 \times 2.2 + 0 = 2.42\)
  2. 前向：算 \(a\)：\(\sigma(2.42) = \dfrac{1}{1+e^{-2.42}} = \dfrac{1}{1+0.08892} = 0.91834\)
  3. 前向：算 loss：\(-\log(0.91834) = 0.08519\)（因为 \(y=1\)，只有第一项）
  4. ∂𝓛/∂a：\(-1/0.91834 + 0/0.08166 = -1.08892\)
  5. σ′(z)：\(0.91834 \times 0.08166 = 0.074992\)
  6. 链式法则：∂𝓛/∂z：\(-1.08892 \times 0.074992 = -0.081660\)
  7. ∂𝓛/∂w₁：\(-0.081660 \times 1.1 = -0.089826\)
  8. ∂𝓛/∂b：\(-0.081660 \times 1 = -0.081660\)

原书打印的结果是 grad_L_w1 = tensor([-0.0898]) 和 grad_L_b = tensor([-0.0817])。完全吻合。 ✓

2.3 一个值得验证的恒等式

注意第 7、8 步的关系：

\[ \frac{\partial \mathcal{L}}{\partial w_1} = \frac{\partial \mathcal{L}}{\partial b} \times x_1 \]

代入：\(-0.081660 \times 1.1 = -0.089826\)。✓ 因为 \(\partial z/\partial w_1 = x_1\) 而 \(\partial z/\partial b = 1\)，两个梯度必然相差一个 \(x_1\) 的倍数。这是个很好的自查手段——两个梯度比例对不上就说明算错了。

符号的物理含义

两个梯度都是负数，意味着增大 \(w_1\) 或 \(b\) 会让 loss 下降。梯度下降的更新是 \(\theta \leftarrow \theta - \eta\nabla_\theta\mathcal{L}\)，减去一个负数就是增大参数。

这是合理的：\(a=0.918\) 而 \(y=1\)，模型已经正确预测且很自信。真实标签是 1，而模型说「有 91.8% 概率是 spam」——这其实是「过度自信」了。

但直觉上「过度自信」应该让 loss 变大才对。这里要小心：二元交叉熵对「自信且正确」的惩罚是 -log 0.918 = 0.085，不是零。模型可以更自信（趋近 1）来把 loss 降到 0。减小 \(a\) 反而会让 loss 上升，所以梯度为负，指向增大。

这个例子的巧妙之处：它说明「loss 小」不等于「概率对」，只说明「概率与标签的匹配程度好」。模型答对了，但它对这个答案的置信度并不完美。

三、sigmoid 导数的两种形式

直接对 \(\sigma(z) = \frac{1}{1+e^{-z}}\) 求导会得到一个看似复杂的结果：

\[ \sigma'(z) = \frac{e^{-z}}{(1+e^{-z})^2} \]

但代入 \(\sigma(z)\) 化简，注意分母：

\[ \frac{e^{-z}}{(1+e^{-z})^2} = \frac{1}{\left(\dfrac{1+e^{-z}}{e^{-z}}\right)^2} \cdot \frac{1}{e^{-z}} = \frac{1}{(1+e^{z})^2}\cdot e^{z} = \frac{e^{z}}{(1+e^{z})^2} \]

再验证它等于 \(\sigma(1-\sigma)\)：\(\sigma = \frac{1}{1+e^z}\)，\(1-\sigma = \frac{e^z}{1+e^z}\)，两者相乘 \(\frac{e^z}{(1+e^z)^2}\)。✓ 两者相同。

这个形式为什么重要：它是「饱和」的

\(\sigma'(z) = \sigma(1-\sigma)\)，最大值在 \(\sigma=0.5\) 处为 0.25，且两端都趋于 0：

\(z\)\(\sigma(z)\)\(\sigma'(z)=\sigma(1-\sigma)\)相对 0.25

原书这个例子里 \(z=2.42\)，梯度已经衰减到最大值的 30%。这就是深度网络里 sigmoid 作为激活函数的致命弱点——每过一层梯度就乘一次小于 0.25 的因子，十几层后彻底归零（梯度消失）。

这正是第 4 章用 GELU 代替 ReLU/sigmoid 的原因之一。GELU 的导数在负半轴也接近 1（不像 sigmoid 那样指数衰减），残差连接（第 4 章）再提供一条梯度旁路，两条措施一起让 12 层甚至 96 层的网络可训练。

四、为什么 PyTorch 不让你手写 backward

原书说完手算梯度后转向 loss.backward()。差别在于谁来组织那 8 步：

手算（A.4 节）loss.backward()（A.5 节起）
链式法则人手写 8 步autograd 引擎自动完成
通用性换网络就要重写任意拓扑通用
中间量保存自己记（易漏）前向时自动记录
反向图生命周期—默认算完即释放（retain_graph=True 可保留）

原书在 grad(loss, w1, retain_graph=True) 里显式传了 retain_graph=True，注释说 "By default, PyTorch destroys the computation graph after calculating the gradients to free memory."——因为它紧接着还要调一次 grad(loss, b)。这个参数在实战中很少用到，但解释了为什么会有它。

4.1 训练循环的三行

把 A.7 节的训练循环拆开，三行就是完整的手工流程：

logits = model(features)              # 前向（含所有中间量的记录）
loss = F.cross_entropy(logits, labels) # 前向最后一步：算损失
optimizer.zero_grad()                   # 清空上一轮的梯度
loss.backward()                         # 反向：链式法则，一次算完所有参数
optimizer.step()                        # 更新：θ ← θ − η·∇
zero_grad() 为什么必须调用

PyTorch 的梯度是累加（+=）而非覆盖。这是 loss.backward() 而非 grad.zero() 的设计带来的灵活性：可以在多个 loss 上分别 backward 然后一次性更新。

但代价是——忘了清零就会把历史梯度一起加进来，训练直接发散。这是 PyTorch 新手最常见的 bug。

4.2 学习率 0.5 的效果

原书 A.7 节用 lr=0.5 训练 3 个 epoch，loss 从 0.75 降到 0.00。观察更新量：

\[ \theta_{\text{new}} = \theta - \eta \cdot \frac{\partial \mathcal{L}}{\partial\theta} \]
预备知识：一阶泰勒展开

光滑函数在 \(x\) 附近可用切线近似：\(f(x+\Delta x)\approx f(x)+f'(x)\,\Delta x\)（\(\Delta x\) 很小时）。多元版本：\(\mathcal{L}(\theta+\Delta\theta)\approx\mathcal{L}(\theta)+\nabla\mathcal{L}\cdot\Delta\theta\)，其中 \(\nabla\mathcal{L}\cdot\Delta\theta\) 是梯度向量与位移向量的点积。

推导：为什么更新 \(\theta-\eta\nabla\mathcal{L}\) 能让 loss 下降

把位移 \(\Delta\theta=-\eta\,\nabla\mathcal{L}\) 代入一阶泰勒展开：

\[ \mathcal{L}(\theta-\eta\nabla\mathcal{L}) \approx \mathcal{L}(\theta) + \nabla\mathcal{L}\cdot(-\eta\nabla\mathcal{L}) = \mathcal{L}(\theta) - \eta\,\|\nabla\mathcal{L}\|^2 \]

因为 \(\|\nabla\mathcal{L}\|^2\ge 0\) 且 \(\eta>0\)，只要 \(\eta\) 足够小（泰勒近似成立），新 loss 一定比旧 loss 小，下降量约为 \(\eta\|\nabla\mathcal{L}\|^2\)。这就是「沿负梯度方向走」的全部数学依据——负梯度是局部下降最快的方向（在所有单位位移中，它让点积 \(\nabla\mathcal{L}\cdot\Delta\theta\) 最小）。\(\eta\) 太大则泰勒近似失效，loss 反而可能上升——这就是学习率需要调参的原因。

在附录 A 的两个输入两个输出的小网络上，初始梯度量级约 0.1–0.5，乘以 \(\eta=0.5\) 后单步更新约 0.05–0.25。这个学习率相对于参数量级是很大的，所以收敛极快（3 个 epoch 就到 0）。

0.5 不能照搬到 LLM 上

附录 A 的网络只有几十个参数，梯度稳定。LLM 用 lr=4e-4（预训练）或 5e-5（微调），小了三个数量级。

原因是深层网络（96 层、768 维）的参数和梯度尺度完全不同，而且需要用 AdamW 而不是 SGD——AdamW 会按每个参数的历史梯度幅度做归一化，学习率的意义与 SGD 完全不同。

原书 A.7 节的注释说得很准确："The learning rate is a hyperparameter, meaning it's a tunable setting that we must experiment with based on observing the loss." 它不是有推导的物理量，是必须实测的超参数。

附录 A 说 sigmoid 导数会饱和；第 3 章说大 logits 让 softmax 梯度归零；第 4 章说残差连接提供梯度旁路。这三处是同一个问题的三个侧面：如何让梯度在几十层内不消失。

答案是三管齐下：缩放 logits（3.4） + 用导数不饱和的激活函数（4.3） + 加残差旁路（4.4）。理解了这一条，就理解了现代 LLM 架构里大半的「非标准」设计。

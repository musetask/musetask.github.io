数学推导详解

原书用代码驱动的方式讲数学：给一段 PyTorch 代码，打印出一个张量，然后说「这就完成了归一化」。这种方式对动手复现很友好，但跳过了公式本身的推导——读者知道每个数字是什么，却不一定知道为什么是这个公式。

这一组补充页面把中间步骤补上：公式用 KaTeX 排版，所有数字用原书给出的输入手算复核过，可以逐个对回原文。建议用法：先跑通原文代码，再回来看推导，看每个打印值是怎么来的。

建议的阅读顺序

如果你的目标是真正读懂 LLM 的数学（而不是跑通代码），按这个顺序：

  1. 第 5 章 — 先建立交叉熵和困惑度的直觉。这是全书的度量基础，后面每一章都在最小化它。务必理解「困惑度 = 等效词表大小」这句话，它让 48,726 这种数字变得可解释。
  2. 第 3 章 — 缩放点积是全书最值得反复看的一节。除以 \(\sqrt{d_k}\) 的方差推导，和第 5 章 softmax 的指数放大效应是同一个问题的两面，对照着看收获最大。
  3. 附录 A — 补上链式法则。这两个梯度是全书唯一手算梯度的地方，算通之后「backward 在做什么」就不再是黑箱。
  4. 第 4 章 — 此时你已经知道梯度会消失，LayerNorm / GELU / 残差三个设计就都能对上了。最后的参数量推导是纯粹的手工练习，但能建立对「词表占 47%」这类事实的直觉。
  5. 第 6、7 章 — 最后读。这两章的数学本身很浅，但涉及损失聚合方式这个全书最容易被忽略的决策：5 章用 mean、6 章只取最后一个 token、7 章用 ignore_index 改分母。把这三处放在一起看，才能理解「聚合方式」不是细节而是设计。

五个自查题

能独立答对这五道题，前四章的数学就真的通了。

  1. 为什么除以 \(\sqrt{d_k}\) 而不是 \(d_k\)？
    → 3.1 与 3.4。答不出「方差 vs 标准差」这一层就说明没真懂。
  2. 掩码之后为什么还要归一化？不归一化会怎样？
    → 4.1–4.3。答不出「掩码位置在归一化时被整除抵消」就说明没读懂泄漏问题。
  3. 困惑度 48,726 是什么意思？为什么它约等于词表大小 50,257？
    → 2.2。关键是能自己推出均匀分布的 PPL 正好等于 \(V\)。
  4. 163,009,536 和 124,412,160 差在哪？为什么原书要做两次计算？
    → 4.2。差的是 out_head 的 38,597,376，来源是 weight tying。
  5. targets 里的 -100 是被「加零」还是「整项删掉」？为什么？
    → 2.1。整项删掉（分子分母都变），这正是 loss_1 == loss_3 严格成立的原因。

一条贯穿全书的暗线

梯度必须能流回去

附录 A 说 sigmoid 导数会饱和；第 3 章说 大 logits 让 softmax 梯度归零；第 4 章说 残差连接提供梯度旁路。

这三处是同一个问题的三个侧面：如何让梯度在几十层内不消失。答案是三管齐下——缩放 logits（3.4）+ 用导数不饱和的激活函数（4.3）+ 加残差旁路（4.4）。

现代 LLM 架构里大半的「非标准」设计，都是为了这一条。

投机解码的数学：接受率、期望长度与贪心调度

这一页把 DSpark 依赖的数学从头算一遍。读者假设有大学数学底子、但计算细节忘了——所以每一步都不跳步，链式法则、尾和公式、全变差距离都先用小例子垫一下，再进入正题。

要证明的东西其实只有四条：

  1. 接受率恰好等于 \(1-\operatorname{TV}(p,q)\)（含无损性的完整证明）；
  2. 期望产出长度是一个链式乘积的尾和，i.i.d. 下退化成截断几何级数；
  3. 位置 1 的敏感度天然高于后续位置（求导）；
  4. 调度器的贪心在固定预算下可证最优（交换论证），但依赖单峰假设，且无损性要求非预见性。

记号：\(V\) 词表；\(p\) 目标模型分布、\(q\) 草稿模型分布；\(\gamma\) 草稿块长；\(y_i\) 第 \(i\) 个草稿 token；\(\alpha_i\) 位置 \(i\) 的条件接受概率；\(S_i=\prod_{j\le i}\alpha_j\) 前缀存活概率；\(K\) 被接受的草稿数、\(N=K+1\) 实际产出；\(b_i\) 置信度头输出；\(R\) 活动请求数、\(\ell_r\) 请求 \(r\) 的验证长度、\(B=\sum_r\ell_r\)；\(\mathrm{SPS}(B)\) batch 为 \(B\) 时的每秒步数。

〇、预备知识（带着算一遍）

0.1 指示变量与期望

设事件 \(A\) 的指示变量 \(X=\mathbb{1}\{A\}\)：\(A\) 发生取 1，否则取 0。于是 \(X^2=X\)，且

推导：期望的线性性

\[ \mathbb{E}[X]=\mathbb{P}(A)\cdot 1+\mathbb{P}(A^c)\cdot 0=\mathbb{P}(A) \]

关键在于 \(\mathbb{E}\) 是线性的，不要求被取期望的随机变量互相独立。所以下面求和时可以放心地把一堆相关的事件拆开。

0.2 尾和公式

这是本页用得最多的一条。设 \(X\) 是非负整数且 \(X\le M\)，则

推导：尾和公式

\[ X=\sum_{i=1}^{M}\mathbb{1}\{X\ge i\} \quad\Longrightarrow\quad \boxed{\mathbb{E}[X]=\sum_{i=1}^{M}\mathbb{P}(X\ge i)} \]

左边成立是因为若 \(X=3\)，右边是 \(1+1+1+0+\cdots=3\)。右边只是逐项取期望（用 0.1）。

小例子：骰子点数 \(X\in\{1,\dots,6\}\)。\(\mathbb{P}(X\ge i)=\frac{7-i}{6}\)，于是 \(\mathbb{E}[X]=\sum_{i=1}^{6}\frac{7-i}{6}=\frac{21}{6}=3.5\)。

0.3 全变差距离

两个概率分布 \(p,q\) 都在同一词表 \(V\) 上，各自求和为 1。全变差距离定义为

推导：TV 与重叠质量

\[ \operatorname{TV}(p,q)=\frac12\sum_{y\in V}\left|p(y)-q(y)\right| \]

\[ \Rightarrow\quad \sum_{y\in V}\min\bigl(p(y),q(y)\bigr) =\sum_y\frac{p(y)+q(y)-|p(y)-q(y)|}{2} =\frac{1+1-\sum_y|p(y)-q(y)|}{2} =\boxed{1-\operatorname{TV}(p,q)} \]

第二行是整页最关键的一个恒等式，务必记牢。几何意义：TV 就是两个分布图上"多出来、不重叠"的那部分面积，所以重叠质量 \(=\,1-\operatorname{TV}\)。

基本性质：\(0\le\operatorname{TV}\le 1\)；\(\operatorname{TV}(p,q)=0\iff p=q\)；对称；三角不等式。

0.4 链式法则与鞅

推导：条件概率的链式展开

\[ \mathbb{P}\Bigl(\bigcap_{i=1}^{k}A_i\Bigr) =\mathbb{P}(A_1)\,\mathbb{P}(A_2\mid A_1)\cdots\mathbb{P}(A_k\mid A_1\cap\cdots\cap A_{k-1}) \]

注意这条式子不需要任何独立性假设——这是它最有用的地方。

鞅：随机过程 \((X_t)\) 相对于信息结构 \(\mathcal{F}_t\)（\(\mathcal{F}_t\) 是"截至时刻 \(t\) 已知的一切"），若 \(\mathbb{E}[X_{t+1}\mid\mathcal{F}_t]=X_t\) 则称鞅。第七节要说的"无损性要求"，本质就是要求输出序列相对于自己的自然过滤是一个鞅。

一、接受率 \(=1-\operatorname{TV}(p,q)\)，以及为什么它无损

1.1 单个 token 的接受概率

固定前缀 \(y_{<i}\)，目标模型给出 \(p(\cdot\mid y_{<i})\)，草稿模型给出 \(q(\cdot\mid y_{<i})\)。草稿 token \(y\sim q(\cdot\mid y_{<i})\) 按下式接受：

推导：逐 token 接受概率

\[ M(y)=\min\!\left(1,\ \frac{p(y\mid y_{<i})}{q(y\mid y_{<i})}\right) \]

\[ \mathbb{E}[\text{接受}]=\sum_y q(y)\,M(y)=\sum_y q(y)\min\!\left(1,\frac{p(y)}{q(y)}\right)=\sum_y\min\bigl(q(y),p(y)\bigr)=\boxed{1-\operatorname{TV}(p,q)} \]

第二行的变形是关键一步：\(q(y)\cdot\min(1,p/q)=\min(q,p)\)。当 \(q(y)=0\) 时该 token 根本不会被起草，贡献为 0，与 \(\min(q,p)=0\) 一致，无奇点。

于是接受率只取决于两个分布的重叠程度，与它们各自的参数化无关。

1.2 无损性：为什么必须用残差重采样

只用上面的"接受/拒绝"，整个块的输出分布并不等于 \(p\)——被拒绝的位置总得填个 token 进去。标准做法是：被拒绝时，从残差分布里采一个。定义

推导：残差分布

\[ Z=\sum_v\bigl(p(v)-q(v)\bigr)_+=\tfrac12\sum_v|p(v)-q(v)|=\operatorname{TV}(p,q), \qquad r(y)=\frac{\bigl(p(y)-q(y)\bigr)_+}{Z} \]

（用到了 \(\sum_v(p(v)-q(v))=0\)，故正部之和等于半绝对差之和。）\(r\) 归一化合法因为 \(Z>0\)（除非 \(p=q\)，那时无需投机）。

命题：若草稿 token \(v\sim q\) 以概率 \(M(v)\) 被接受；否则改为从 \(r\) 采一个，则最终发出的 token \(y\) 满足 \(\mathbb{P}(\text{发出 }y)=p(y)\)。

证明：分两种情况

\[ \mathbb{P}(\text{发出 }y)=q(y)M(y)+\sum_v q(v)\bigl(1-M(v)\bigr)r(y) \]

情形 A：\(p(y)>q(y)\)。此时 \(M(y)=1\)，首项 \(=q(y)\)；又因 \(M(v)=1\) 对所有 \(p(v)\ge q(v)\) 的 \(v\) 成立，求和只在 \(p(v)<q(v)\) 上非零：

\[ \sum_{p(v)<q(v)}q(v)\left(1-\frac{p(v)}{q(v)}\right)r(y)=\sum_{p(v)<q(v)}\bigl(q(v)-p(v)\bigr)r(y)=Z\,r(y) \]

合计 \(q(y)+Z\cdot\frac{p(y)-q(y)}{Z}=p(y)\)。✓

情形 B：\(p(y)\le q(y)\)。首项 \(=q(y)\cdot\frac{p(y)}{q(y)}=p(y)\)；而 \(r(y)=0\)，求和项为 \(0\)。合计 \(p(y)\)。✓

这就是无损（lossless）的精确含义：输出分布与直接从 \(p\) 采样完全相同，所以加速不改变模型行为。注意残差项是必须的——它的存在正是为了让 \(p\) 里"草稿没覆盖到"的那部分质量被正确补回来。

二、期望产出长度：链式乘积的尾和

定义条件接受概率（这一步把 1.1 的结论推广到整块）：

定义：条件接受概率与存活概率

\[ \alpha_i=\mathbb{E}\Bigl[M(y_i)\mid y_1,\dots,y_{i-1}\text{ 全部被接受}\Bigr] =\mathbb{E}\Bigl[1-\operatorname{TV}\bigl(q(\cdot\mid y_{<i}),\,p(\cdot\mid y_{<i})\bigr)\ \Big|\ \cdots\Bigr] \]

\[ S_i:=\mathbb{P}(K\ge i)=\mathbb{P}(y_1,\dots,y_i\text{ 全被接受})=\prod_{j=1}^{i}\alpha_j \]

第二行直接用 0.4 的链式法则——没有引入独立性假设。这正是链式法则比"假设独立"更强的地方。

被接受的草稿数 \(K\in\{0,\dots,\gamma\}\)。无论 \(K\) 是多少，目标模型总会补上 1 个 token（要么是被拒位置上由残差采出的那个，要么是整块全中时 \(\gamma+1\) 位置的新 token），所以 \(N=K+1\)。用 0.2 的尾和公式：

推导：期望长度的精确式

\[ \mathbb{E}[N]=1+\mathbb{E}[K]=1+\sum_{i=1}^{\gamma}\mathbb{P}(K\ge i)=\boxed{\sum_{i=0}^{\gamma}S_i},\qquad S_0:=1 \]

\(S_0=1\) 这一项就是那个 bonus token——对应 Algorithm 1 伪代码第 5 行"初值 Expected accepts \(\tau^*\leftarrow R\)"：\(R\) 个请求各贡献 1 个，合计 \(R\)。

2.1 i.i.d. 简化：截断几何级数

若各位置接受率相同（\(\alpha_j\equiv\alpha\)，这是理想化假设，真实系统里 \(\alpha_i\) 随前缀变化），则 \(S_i=\alpha^i\)，于是

推导：等比求和

\[ \mathbb{E}[N]=\sum_{i=0}^{\gamma}\alpha^{\,i} \]

\[ (1-\alpha)\sum_{i=0}^{\gamma}\alpha^{\,i} =\bigl(1+\alpha+\cdots+\alpha^{\gamma}\bigr)-\bigl(\alpha+\alpha^2+\cdots+\alpha^{\gamma+1}\bigr) =1-\alpha^{\gamma+1} \]

\[ \Rightarrow\quad \mathbb{E}[N]=\frac{1-\alpha^{\,\gamma+1}}{1-\alpha}\quad(\alpha\ne1),\qquad \mathbb{E}[N]=\gamma+1\quad(\alpha=1) \]

两个边界（务必和求和下标 \(i\) 从 0 起一起记，否则会算错）：\(\alpha\to1\) 时 \(\mathbb{E}[N]=\gamma+1\)；\(\alpha\to0\) 时 \(\mathbb{E}[N]\to1\)，退化成普通自回归。

敏感性：\(\gamma=8\) 时，\(\alpha:0.7\to0.9\) 使 \(\mathbb{E}[N]\) 从 2.94 跳到 5.22。

三、位置 1 为什么杠杆最高

原文强调"第一个 token 具有最高的杠杆作用，第一个被拒整块作废"。这句话可以精确证明。由 \(\mathbb{E}[N]=\sum_{i=0}^{\gamma}S_i\)，\(S_i=\prod_{j\le i}\alpha_j\)：

推导：逐位置敏感度

\[ \frac{\partial S_i}{\partial\alpha_k}= \begin{cases} 0, & i<k\\[2pt] \dfrac{S_i}{\alpha_k}, & i\ge k \end{cases} \quad\Longrightarrow\quad \frac{\partial\mathbb{E}[N]}{\partial\alpha_k}=\frac{1}{\alpha_k}\sum_{i=k}^{\gamma}S_i \]

\[ \frac{\partial\mathbb{E}[N]}{\partial\alpha_1}=\frac{\mathbb{E}[N]-1}{\alpha_1}, \qquad \frac{\partial\mathbb{E}[N]}{\partial\alpha_k}=\frac{S_{k-1}}{\alpha_k}\sum_{i=k}^{\gamma}S_i \ \le\ \frac{\mathbb{E}[N]-1}{\alpha_k} \]

关键在因子 \(S_{k-1}=\prod_{j<k}\alpha_j\)：位置 \(k\) 的敏感度被"走到这一步之前全部存活"的概率乘了一遍，而位置 1 没有这个折扣（\(S_0=1\)）。因此

结论

\[ \alpha_k\,\frac{\partial\mathbb{E}[N]}{\partial\alpha_k}\;\le\;\alpha_1\,\frac{\partial\mathbb{E}[N]}{\partial\alpha_1} \]

即同样幅度地提升 \(\alpha_k\)，永远不如提升 \(\alpha_1\) 值钱（等号仅在所有 \(\alpha_j=1\) 时成立）。这就把实验观察（DSpark 数学上从 0.93 起步、并靠并行主干的高容量赢下位置 1）变成了架构设计的依据：重容量投在前，轻依赖投在后。

四、训练目标：为什么是分布匹配而非交叉熵

由第一节，\(\alpha_i = 1-\operatorname{TV}(q_i,p_i)\)，而 \(\mathbb{E}[N]\) 对每个 \(\alpha_i\) 单调增。所以

结论：训练目标

\[ \max\ \mathbb{E}[N]\ \iff\ \min\ \sum_i \operatorname{TV}\bigl(q(\cdot\mid y_{<i}),\,p(\cdot\mid y_{<i})\bigr) \]

关键提醒：交叉熵不是这个目标。交叉熵与前向 KL 只差一个与 \(q\) 无关的常数：

推导：CE 与前向 KL 的关系

\[ \operatorname{CE}(q,p)=-\sum_y p(y)\log q(y) =\underbrace{\sum_y p(y)\log\frac{p(y)}{q(y)}}_{=\,\operatorname{KL}(p\|q)} +\underbrace{\sum_y p(y)\log p(y)}_{=\,-H(p)\ \text{，与 }q\text{ 无关}} \]

而接受率依赖的是 TV，不是 KL。两者对"草稿把质量放在错误位置"的惩罚方式不同：前向 KL 在 \(q(y)\to0\) 而 \(p(y)>0\) 处发散，TV 只线性惩罚。所以用 CE 当代理是常见做法，但严格来说优化的不是接受率。

TV 的梯度也有个需要注意的性质：

推导：TV 的梯度

\[ \frac{\partial\,\operatorname{TV}}{\partial q(y)}=\frac{\partial}{\partial q(y)}\cdot\frac12|p(y)-q(y)| =-\frac12\,\operatorname{sign}\bigl(p(y)-q(y)\bigr),\qquad p(y)\ne q(y) \]

即梯度模长恒为 \(\tfrac12\)、只有符号，在 \(p(y)=q(y)\) 处不可微（次梯度取 \([-\tfrac12,\tfrac12]\) 的任意值）。好消息是它不像前向 KL 那样在 \(q\to0\) 时爆炸；代价是它对"错得少"和"错得多"给出的信号强度一样，信息量较低。这也解释了 DSpark 训练时为什么三项损失里同时用了分布匹配项和交叉熵项。

五、校准：ECE、保序性、以及乘积校准

5.1 ECE 的定义

定义：期望校准误差

\[ \operatorname{ECE}=\sum_{m=1}^{M}\frac{|B_m|}{n}\,\bigl|\operatorname{acc}(B_m)-\operatorname{conf}(B_m)\bigr| \]

把 \(n\) 个预测按预测概率分进 \(M\) 个区间 \(B_1,\dots,B_M\)；\(\operatorname{acc}\) 是该区间内"实际被接受"的比例，\(\operatorname{conf}\) 是平均预测概率。完美校准时两项相等，曲线落在对角线上。

5.2 温度缩放是保序变换（证明）

推导：保序性

\[ p_T(y)=\frac{\exp(z_y/T)}{\sum_v\exp(z_v/T)},\qquad T>0 \]

设 \(z_a>z_b\)。则 \(z_a/T>z_b/T\)，故 \(\exp(z_a/T)>\exp(z_b/T)\)。两者同除以同一正数 \(\sum_v\exp(z_v/T)\)：

\[ p_T(a)=\frac{\exp(z_a/T)}{Z}>\frac{\exp(z_b/T)}{Z}=p_T(b) \]

所以 \(z\mapsto p_T(z)\) 严格单调递增。置信度头输出还要过一层 \(\sigma\)，而 \(\sigma\) 也严格单调增，所以复合 \(\sigma(z/T)\) 仍然保序。

这条保序性是 STS 能用的前提：它只纠正概率的绝对值（让阈值剪枝和期望长度算得准），不会打乱置信度头学到的相对草稿排名——而阈值剪枝恰恰只需要排名正确。

5.3 为什么逐位置校准推不出乘积校准

调度器要的是前缀存活概率 \(S_k=\prod_{i\le k}b_i\) 的绝对值，不是各 \(b_i\) 的排名。直觉上"每个位置都校准了，乘起来自然也对"，但这一步并不成立：

  • 误差是乘性累积的。若每个位置的相对误差约 \(\varepsilon\)，则 \(k\) 项乘积的相对误差量级约 \(k\varepsilon\)。所以位置 1 上 5% 的 ECE，到位置 7 已经不可忽略——实测正是这个趋势（ECE 5.7%→3.3%，而 \(\mathrm{AUC}\) 0.818→0.907）。
  • 条件分布会漂移。\(b_i\) 是在"前 \(i-1\) 个都被接受"的训练分布上拟合的；真实运行中到达位置 \(i\) 的前缀分布与之不同。

所以 DSpark 的 STS 直接对累积乘积做校准：逐位置做 1 维网格搜索，最小化 \(\mathbb{E}\bigl[\bigl|S_k^{\text{true}}-S_k^{\text{pred}}\bigr|\bigr]\)，且保持已校准的前序位置固定。

六、调度器：贪心为什么可证最优

设 \(R\) 个活动请求，请求 \(r\) 的草稿块存活概率为 \(a_{r,1}\ge a_{r,2}\ge\cdots\ge a_{r,\gamma_r}\)。单调性来自定义：\(a_{r,j}=\prod_{i\le j}b_{r,i}\)，而每个 \(b\le1\)，故 \(a_{r,j}\) 关于 \(j\) 单调不增。决策 \(\ell=(\ell_1,\dots,\ell_R)\)：

推导：调度目标

\[ B(\ell)=\sum_r\ell_r,\qquad \tau(\ell)=R+\sum_{r}\sum_{j\le\ell_r}a_{r,j},\qquad \Theta(\ell)=\tau(\ell)\cdot\mathrm{SPS}\bigl(B(\ell)\bigr) \]

\(\max_\ell\ \Theta(\ell)\)

（\(R\) 来自 bonus token；\(\mathrm{SPS}\) 只依赖总 batch。目标形式是最大化比值，不是最大化分子或最小化分母。）

6.1 命题：固定预算下，取全局最大的 \(B\) 个值最优

命题与证明（交换论证）

记多重集 \(\mathcal{A}=\{a_{r,j}\}\)，令 \(A(B)\) 为其中最大的 \(B\) 个数之和。则对任意满足 \(B(\ell)=B\) 的可行 \(\ell\)，有 \(\tau(\ell)\le A(B)\)，且存在可行 \(\ell^*\) 取到等号。

可行性：取"最大的 \(B\) 个"得到集合 \(F^*\)。因 \(a_{r,j}\ge a_{r,k}\) 对 \(j\le k\)，若 \(a_{r,k}\in F^*\) 则所有 \(a_{r,j}\,(j<k)\) 的值都不小于它，因而也在前 \(B\) 名内（并列时一致地打破平局即可）。故 \(F^*\) 自动满足"取了位置 \(k\) 就得取 \(1..k-1\)"的前缀约束，\(\ell^*\) 可行。

最优性：任意可行的 \(\ell\) 对应一个大小为 \(B\) 的前缀闭合集合 \(F\)。对任意大小为 \(B\) 的子集（不论是否闭合），其元素和 \(\le A(B)\)——这是"取最大的 \(B\) 个"的定义性质（任何更小的元素换入更大的元素只会让和变大）。故 \(\tau(\ell)\le A(B)\)。∎

于是 6.1 说明：对每一个固定的 \(B\)，分子的最大值都是 \(A(B)\)，因此

推导：降为一维扫描

\[ \max_\ell\Theta(\ell)=\max_{B}\ \underbrace{A(B)\cdot\mathrm{SPS}(B)}_{=:\,f(B)} \]

Algorithm 1 做的事正是增量地扫 \(B\)：每准入一个 token 就让 \(B\) 加一、\(\tau\) 加 \(a_{r,j}\)、查表更新 \(f(B)\)。等价性成立，贪心在固定预算意义下是精确最优的，不是启发式。

6.2 但提前停止需要单峰假设——反例

Algorithm 1 在 \(f(B)\) 不再上升时就 break。若 \(f\) 非单峰，这只会找到局部最优：

反例

\[ A(1)=1,\ A(2)=2,\ A(3)=3;\qquad \mathrm{SPS}(1)=10,\ \mathrm{SPS}(2)=1,\ \mathrm{SPS}(3)=10 \]

\[ f(1)=10,\qquad f(2)=2,\qquad f(3)=30 \]

贪心：\(f\) 从 10 升到 2？——2 < 10，于是在 \(B=2\) 处停止，得 2。而真正最大值是 \(f(3)=30\)，被整个跳过。物理上这对应 batch size 2 撞上硬件悬崖（\(\mathrm{SPS}\) 掉到 1）。

这正是生产部署要去掉 break 的动机。但去掉它会破坏无损性——于是引出下一节。

七、非预见性：无损性的数学边界

7.1 命题：任何位置级判据必须只依赖该位置自身 token 之前的前缀

命题

记 \(\mathcal{F}_{i-1}=\sigma(y_{<i})\) 为"位置 \(i\) 的 token 被采样之前可知的一切"。若验证器额外施加一个判据 \(g:\mathcal{F}_{i-1}\to\{0,1\}\)（\(g=1\) 才保留该位置），则输出分布仍然精确等于 \(p\)。反之若 \(g\) 依赖了 \(y_i\) 本身，则一般不再等于 \(p\)。

证明：由 1.1，\(q(y)M(y)=\min(q(y),p(y))\)。加判据后，条件于 \(\mathcal{F}_{i-1}\) 发出 \(y\) 的概率正比于

\[ q(y)\,M(y)\,g(y)=\min\bigl(q(y),p(y)\bigr)\,g(y) \]

而无损要求它恰为 \(p(y)\)。两者相容，当且仅当 \(g\) 在 \(\{y:\min(q,p)>0\}\) 上取常值——即 \(g\) 不携带关于 \(y\) 的信息，也就是 \(g\) 是 \(\mathcal{F}_{i-1}\)-可测的。∎

直观说法：\(p(y)\cdot g(y)/\sum_v p(v)g(v)\) 是"被 \(g\) 挑中的那部分"在 \(p\) 下的条件分布。只要挑法本身与 \(y\) 相关，输出就被"筛"过了，不再是 \(p\)。这就是选择偏差。

7.2 用鞅重述

无损性等价于输出序列 \((y_i)\) 满足

等价刻画

\[ \mathbb{E}\bigl[y_{i+1}\ \big|\ \mathcal{F}_i\bigr]=p\bigl(y_{i+1}\mid y_{<i+1}\bigr)\qquad\forall i \]

即"下一步的条件期望等于模型自己的条件分布"——这正是 0.4 里鞅定义的离散版本。一旦某个决策条件在 \(y_i\) 上，被条件化的对象就变了，上式左边会额外带上 \(\mathbb{E}[\,\cdot\mid g(y_i)=1\,]\) 这一层，等式破裂。非预见性不是工程洁癖，是正确性的边界。

7.3 落到 DSpark 上

置信度头吃的是"主干隐藏状态 + 前一个草稿 token 的马尔可夫嵌入"，所以 \(b_{i+1}\) 依赖 \(y_i\)。于是：

  • 若在第 \(i\) 步的准入决策里用了 \(S_{i+1}\)（需要先实例化 \(y_i\)），判据就不再是 \(\mathcal{F}_i\)-可测的，7.1 的结论失效。所以 Algorithm 1 的 break 不是性能优化，是把决策限制在"截至当前步已处理的前缀"上的正确性护栏。

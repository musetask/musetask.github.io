注意力机制的数学：MHA → MLA

这一页把 DeepSeek 注意力演进路线上的每个关键公式算清楚：缩放因子 \(\sqrt{d_k}\) 的来历、MHA/MQA/GQA 的 KV cache 精确核算、MLA 为什么敢把 KV 压成 576 维（解耦 RoPE + 注意力折叠），最后是 V4 的 mHC。

记号：\(h_t\in\mathbb{R}^{d}\) 是第 \(t\) 个 token 的 hidden state；\(n\) 为头数，\(d_h\) 为每头维度；\(L\) 为上下文长度。

一、\(\mathrm{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}+M\right)V\)：缩放因子哪来的

设 query 和 key 的每个分量独立、均值 0、方差 1。点积 \(s=\sum_{i=1}^{d_k} q_i k_i\) 的方差是：

推导：点积的方差

\[ \begin{aligned} \mathbb{E}[q_i k_i] &= \mathbb{E}[q_i]\,\mathbb{E}[k_i] = 0 \qquad\text{（独立）}\\ \mathrm{Var}(q_i k_i) &= \mathbb{E}[(q_i k_i)^2] - 0 = \mathbb{E}[q_i^2]\,\mathbb{E}[k_i^2] = 1\\ \mathrm{Var}(s) &= \sum_{i=1}^{d_k}\mathrm{Var}(q_i k_i) = d_k \qquad\text{（独立项方差相加）} \end{aligned} \]

于是 \(s\) 的标准差是 \(\sqrt{d_k}\)。\(d_k=128\) 时点积的典型幅度是 ±11 左右——直接喂给 softmax 会让它饱和（一个 logit 比其他大几十，softmax 输出 ≈ one-hot，梯度 ≈ 0）。除以 \(\sqrt{d_k}\) 把方差拉回 1，softmax 才能工作在有梯度的区间。\(M\) 是因果掩码：未来位置填 \(-\infty\)，softmax 后权重为 0。

二、Q、K、V 为什么是三份

直觉

同一个 \(X\) 既要"提问"又要"被匹配"还要"搬运内容"，三个角色需要的几何空间不一样：\(Q\) 是"找什么"的天线，\(K\) 是" 我是谁"的名牌，\(V\) 是真正要搬给下一层的行李。硬拿 \(XX^T\) 做相似度，只能匹配到语义相近的词（apple→banana），抓不住"apple 找它的动词 ate"这种结构关系。三套可学习的投影就是把三个角色投影到三个不同的向量空间。

三、MHA → MQA → GQA：KV cache 核算

推理时每个 token、每层要缓存当下及历史所有 token 的 K 和 V。设 KV 头数为 \(n_{kv}\)（MHA 里 \(n_{kv}=n\)，MQA 里 \(n_{kv}=1\)，GQA 里 \(n_{kv}=\) 组数），则：

\[ \text{每 token 每层元素数} = 2 \cdot n_{kv} \cdot d_h, \qquad \text{总元素数} = 2 \cdot n_{\text{layers}} \cdot n_{kv} \cdot d_h \cdot L \]

系数 2 是因为 K 和 V 各存一份。乘上每元素的字节数（bf16=2B，FP8=1B）即得字节数。

算例：80 层、\(d_h=128\)、\(L=128\mathrm{K}=131072\)、bf16

\[ \begin{aligned} \text{MHA（64 个 KV 头）}&: 2\cdot80\cdot64\cdot128\cdot131072\cdot2\mathrm{B} \approx 343.6\,\mathrm{GB}\\ \text{GQA-8（8 个 KV 头）}&: 2\cdot80\cdot8\cdot128\cdot131072\cdot2\mathrm{B} \approx 42.9\,\mathrm{GB}\\ \text{MLA（见下节）}&: 576\cdot80\cdot131072\cdot2\mathrm{B} \approx 12.1\,\mathrm{GB}\;\;(\text{FP8 下约 }6\,\mathrm{GB}) \end{aligned} \]

GQA 相对 MHA 恰好是 \(64/8 = 8\) 倍的差距——"KV cache 降到 1/4～1/8"就是这么来的。MLA 一行里的 576 是下一节的结论。

四、MLA：把 KV 压成 576 维

MLA 不存各头的 K/V 全量，只存一个低维隐向量。设隐维度 \(d_c = 512\)：

\[ c_t^{KV} = h_t W_{DKV} \in \mathbb{R}^{512}, \qquad k_{t,i} = c_t^{KV} W_{UK,i},\;\; v_{t,i} = c_t^{KV} W_{UV,i} \]

\(W_{DKV}\) 是下投影（压缩），\(W_{UK,i}\)、\(W_{UV,i}\) 是第 \(i\) 个头的上投影（重建）。cache 里只躺 \(c_t^{KV}\)，K/V 在推理时按需重建。

为什么 RoPE 必须解耦

推导：旋转破坏线性的位置

RoPE 给第 \(m\) 个位置的 key 施加一个位置相关的正交旋转 \(R_m\)。如果直接对压缩向量做旋转再重建：

\[ (R_m\, c_t^{KV})\, W_{UK} \;\neq\; R_m\, (c_t^{KV} W_{UK}) \]

因为一般的 \(W_{UK}\) 与 \(R_m\) 不对易。而先重建再旋转 \(R_m(c_t^{KV}W_{UK})\) 又要求把全量 K 物化出来——压缩的意义就没了。DeepSeek 的解法是解耦：内容键 \(K^C\) 从隐向量重建（不带位置，保持线性），另设一条 64 维的纯位置键 \(K^R\) 专管 RoPE、各头共享。cache 内容变为：

\[ \underbrace{c_t^{KV}}_{512\text{ 维}} + \underbrace{k_t^{R}}_{64\text{ 维}} = 576\text{ 维/token/层} \]

注意力折叠：连 K 都不用物化

推导：结合律 \(A(BC)=(AB)C\)

第 \(i\) 个头的 attention 打分是：

\[ \begin{aligned} \mathrm{score}_{t,i} &= q_{t,i}\, k_{t,i}^T = q_{t,i}\, (c_t^{KV} W_{UK,i})^T \\ &= q_{t,i}\, W_{UK,i}^T\, (c_t^{KV})^T = \underbrace{(q_{t,i}\, W_{UK,i}^T)}_{\tilde{q}_{t,i}\in\mathbb{R}^{512}}\, (c_t^{KV})^T \end{aligned} \]

即直接拿吸收了 \(W_{UK,i}^T\) 的 query \(\tilde{q}\) 去和 512 维隐向量 \(c_t^{KV}\) 做点积，全程不物化 \(k_{t,i}\)。\(W_{UK,i}^T\) 可以离线折叠进 Q 的投影矩阵，推理零开销。这就是 MLA 敢把 cache 压到每 token 每层 576 个元素的底气：存得少，算得也不多。

五、压缩比对照

以每 token 每层存的元素数计（MHA：\(2\cdot64\cdot128 = 16384\) 为 100%）：

  • MHA：16384 —— 基准 100%
  • GQA-8：\(2\cdot8\cdot128 = 2048\) —— 12.5%
  • MLA：\(512 + 64 = 576\) —— 约 3.5%，不到 GQA 的三分之一

六、mHC：残差从单车道变四车道

经典残差 \(y = x + F(x)\) 只是朴素相加。mHC 给每个 token 维护 \(n_s = 4\) 条并行残差流，流之间的混合系数矩阵 \(A\in\mathbb{R}^{4\times4}\) 经 20 轮 Sinkhorn 迭代约束为近似双随机矩阵（每行每列之和都 ≈1）。

预备知识：为什么双随机

双随机矩阵作用在向量上是凸组合（系数非负、和为 1），输出被钳在输入的凸包里——信号既不会被放大也不会被湮灭，前向/反向的数值稳定性就有了数学保证。这正是深层（万亿参数量级）网络最怕的"层间通信失稳"的解药。

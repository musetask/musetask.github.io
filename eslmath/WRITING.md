# eslmath 写作规范（给章节作者 / subagent 看）

本目录 `eslmath/` 是《The Elements of Statistical Learning》(2nd ed.) 的**公式推导手册**。
目标读者：有大学数学（微积分 / 线性代数 / 概率统计）基础，但**计算细节忘了**，需要把书里
印成一行结论的公式重新推一遍。

## 0. 你要产出的唯一文件

`eslmath/src/NN-slug.md`，例如 `eslmath/src/03-linear-regression.md`。
**不要**直接写 HTML。构建脚本 `eslmath/build_site.py` 会把它转成 HTML。

front matter 必须完整（字段顺序照抄，值按本章修改）：

```
---
id: m03
n: "3"
title: 线性回归方法
title_en: Linear Methods for Regression
desc: 一句话描述本章推了哪些公式
prev: m02
next: m04
prev_title: 第 2 章 监督学习概述
next_title: 第 4 章 线性分类方法
---
```

`id` 决定输出文件名（`m03` → `eslmath/m03.html`）。`n` 是章节号，目录页用它排序。

## 1. 章节 id 命名（重要）

- 一级标题：`# 3 线性回归方法 {#s-3}`
- 二级标题：`## 3.2 最小二乘的正规方程 {#s-3-2}`（对应原书 §3.2）
- 三级标题：`### 3.2.1 高斯误差模型 {#s-3-2-1}`

id 必须是 `s-<原书节号>`，因为 `index.html` 的卡片链接直接指向这些锚点。

## 2. 支持的 Markdown 子集（只有这些！）

| 写法 | 结果 |
|---|---|
| `# ## ### #### 标题` | 标题；**必须**手写 `{#id}` |
| 空行分隔的连续行 | 一个段落 |
| `- 项目` / `1. 项目` | 列表（可缩进嵌套） |
| `\| a \| b \|` + `\|---\|---\|` | 表格（渲染成 `.fx` 表） |
| ` ``` ` 围栏 | 代码块 |
| `> 引用块` | 提示框（见下） |
| `$$ ... $$` | 独立公式（可跨行） |
| `$...$` | 行内公式，**原样交给 KaTeX** |
| `**粗**` `*斜*` `` `码` `` `[文字](链接)` | 行内标记 |
| `---` | 分隔线 |

**不支持**：HTML 标签、图片、嵌套引用块、latex 环境（`\begin{align}` 之类不要用）。

### 2.1 公式块

独立公式用 `$$` 包起来，**编号写在 `\eqno{}` 里**：

```
$$
\hat\beta = (X^\top X)^{-1}X^\top y \eqno{3.6}
$$
```

- `\eqno{3.6}` 会渲染成公式右侧的小徽标 `(3.6)`，**编号必须用原书编号**。
- 原书没有编号的公式（推导中间量）就不要写 `\eqno`。
- 行内公式不要超过约 40 个字符，太长就提成独立公式块，否则移动端会横向溢出。

### 2.2 提示框（blockquote 的四种用法）

引用块的第一行写 `**标签**`，可选 `· 小标题`：

```
> **基础知识** · 投影定理
> 唯一投影存在：...
> - 要点一
> - 要点二

> **推导** · 为什么正规方程等价于正交投影
> 第一步……

> **结果** · 系数估计量的方差
> $$\mathrm{Var}(\hat\beta)=(X^\top X)^{-1}\sigma^2 \eqno{3.8}$$

> **坑**
> $X^\top X$ 秩亏时 (3.6) 不存在，但 $\hat y$ 仍唯一。
```

允许的标签：**基础知识**、**推导**、**结果**、**坑**、**数值**、**延伸**。
标签后的 `· 小标题` **必须短**（≤24 字）；写长了会被当成正文。

引用块内可以包含列表和 `$$` 公式（公式行前要加 `> `）。
引用块内要用空行分段时，空行写成单独的 `>`。

## 3. 数学写法约定

- 用 `\hat{}` `\tilde{}` 表示估计量，希腊字母直接写 `\beta` `\lambda`。
- 矩阵用大写字母，转置写 `^\top`，逆写 `^{-1}`，逆矩阵写 `X^\dagger`（伪逆时用 `\dagger` 或 `X^+`）。
- 范数写 `\lVert x\rVert_2` 或 `\lVert x\rVert`，矩阵范数写 `\lVert A\rVert`。
- 概率写 `\Pr(A\mid B)`，条件均值写 `E[Y\mid X]`（用 `\mid` 或 `|` 都可以，统一用 `\mid`）。
- 求和下标范围要写全：$\sum_{i=1}^N$，不要偷懒。
- 单位矩阵 `\mathbf{1}` 或 `I`，别用 `1`。
- **不要**在数学里用 `*`（会被当成斜体标记），用 `\cdot` `\times`。
- 上下标不要写 `\hat{\beta}_j`，统一 `\hat\beta_j`。

## 4. 每节的内容要求（这是重点）

一个推导小节按这个骨架写：

1. **问题**：一句话说明这一节要算出什么，书里对应哪个公式编号。
2. **`> **基础知识**`**：这一步依赖的定义/定理，给出可复核的公式。
3. **推导步骤**：用编号列表，每步说清「这一步做了什么、用了什么」。
   ESL 的风格是跳步的，你要把跳掉的那一步补出来，但不要写成教科书式长篇。
4. **公式块**：结果公式，带原书编号。
5. **`> **结果**`**：这个公式的含义（几何意义 / 概率含义 / 算法含义）。
6. **`> **坑**`**：原文省略的条件（秩、可识别性、无偏前提、正则性……）。
   没有明显坑时可以省略，但**不要写「无坑」**。

推导要求：

- **每一步都要能算**。不能写「易证」「显然」「整理可得」而不给中间式。
  如果真的省略了一行，必须说明为什么可以省（例如「因为 $X^\top X$ 对称」）。
- 优先给**数值可验证**的形式：能写成矩阵形式就写矩阵形式，并注明维度。
- 如果原书给出多个等价形式，把它们串起来推导（这是最有价值的内容，例如
  最小二乘的 `argmin` → 正规方程 → QR 解 → SVD 解）。
- 关键结论标出**推导依赖的假设**，删掉任何一条结论都会不成立。

## 5. 篇幅要求

- 每个 `##` 小节至少 400 字中文 + 3 个公式块，重要的推导（如 EM、SVM 对偶、
  PCA、bootstrap 方差）至少 800 字。
- 每章覆盖原书该章**所有出现编号的公式**（编号在 `.eqs` 清单里，见第 6 节）。
  允许合并推导相近的公式，但每个编号都要在文中被提及（作为 `\eqno` 或正文引用）。
- 章节开头写一段导语（普通段落，不要 `>`），说明本章在全书中的位置。

## 6. 公式编号清单

每章的公式编号清单在（只读，不要修改）：

```
/private/var/folders/_h/hcgnzw6d0lb4lltt1d21klmm0000gn/T/opencode/eslmath/chNN-<slug>.eqs
```

格式是 `编号<TAB>PDF 里抽取的 alt 文本`。alt 文本很乱（PDF 抽取的乱序碎片），
**只能当作「有哪些编号」的清单**，不能照抄它的内容。公式的正确形式要靠你自己的
ESL 知识 + 上下文写出来。

对应的原文 HTML 在 `eslmath/../esl/chNN-<slug>.html`，公式是 PNG 图片，
alt 文本同样很乱，但**周围的正文段落是可读的**，读完能确定每个公式在讲什么。
建议流程：先读 `.eqs` 拿到编号清单 → 再读原文 HTML 找每个编号附近的文字 →
然后凭数学知识写出正确公式与推导。

链接到原文的写法（在 `src/*.md` 里，相对路径从 `eslmath/` 出发）：

```
<a class="src" href="../esl/ch03-linear-methods-for-regression.html#s-3-2">原文 §3.2</a>
```

`<a class="src">` 是原样透传的 HTML（转换脚本不动它）。每章用它链接 5–15 个即可，
不用每个公式都链。

## 7. 引用预备知识

`eslmath/src/00-prereq.md` 里有五组编号：`L*`（线性代数）、`C*`（微积分）、
`P*`（概率统计）、`O*`（优化）、`N*`（数值）。引用时写「（见预备知识 L2）」，
不要重复解释一遍基础内容。预备知识里**没有**的东西（如谱聚类的拉普拉斯矩阵分解）
在正文里就地补一句定义。

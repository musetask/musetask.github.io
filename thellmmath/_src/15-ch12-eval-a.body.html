(12.1)序列概率的自回归分解#

出处第 12 章 12.1.1 节 Metrics for Language Modeling　对照原文

原书公式 12.1

① 公式

\[ P(\boldsymbol u)=\prod_{t=1}^{T}P\big(u_t\mid \boldsymbol u_{<t}\big), \]

② 符号

符号含义形状 / 量纲
\(\boldsymbol u\)参考文本序列\(\mathcal V^{T}\)
\(u_t\)第 \(t\) 个 token\(\mathcal V\)
\(\boldsymbol u_{<t}\)前 \(t-1\) 个 token 的前缀\(\mathcal V^{t-1}\)；\(u_{<1}=\emptyset\)
\(P(\cdot)\)真实文本分布（数据分布）\(\Delta(\mathcal V^T)\)
\(P(u_t\mid\boldsymbol u_{<t})\)给定前缀后的下一个 token 分布\(\Delta(\mathcal V)\)
\(p_\Theta(u_t\mid\boldsymbol u_{<t})\)模型的对应估计（softmax 输出）\(\Delta(\mathcal V)\)，\(|p_\Theta-p|\le1\)

③ 推导

公式 (12.1) 不是定理，而是定义的展开——但展开过程必须会写，因为后面每一步都要在这个乘积上做变换。

  1. 工具：边际化与全概率公式。对联合分布 \(P(u,v)\)，定义边缘 \(P(u)=\sum_{v\in\mathcal V}P(u,v)\)（求和即离散积分）。两边同除 \(P(u)>0\)，立刻得到
    \[ P(u,v)=\underbrace{P(u)}_{\text{前缀}}\cdot\underbrace{P(v\mid u)}_{\text{条件}} \]
    这就是二元链式法则。
  2. 三元情形。把 \((u,v)\) 当作整体再展开一次：
    \[ P(u,v,w)=P(u,v)\,P(w\mid u,v)=P(u)\,P(v\mid u)\,P(w\mid u,v) \]
    注意第二项的条件是 \((u,v)\) 而不是 \((v)\)。
  3. 一般情形：对 \(T\) 归纳。命题：对任意联合分布，\(P(u_1,\dots,u_T)=\prod_{t=1}^{T}P(u_t\mid u_1,\dots,u_{t-1})\)。
    • \(T=1\)：\(P(u_1)=P(u_1\mid\emptyset)\)，而空前缀的条件分布就是边缘分布，成立。
    • 归纳步：设 \(T-1\) 时成立。把 \((u_1,\dots,u_{T-1})\) 打包为单一随机变量 \(\boldsymbol u_{<T}\)，用二元链式法则： \(P(\boldsymbol u_{<T},u_T)=P(\boldsymbol u_{<T})P(u_T\mid\boldsymbol u_{<T})\)。再对 \(P(\boldsymbol u_{<T})\) 用归纳假设展开。∎
    符号上把 \(\boldsymbol u_{<t}\) 直接写进 \(P(u_t\mid\boldsymbol u_{<t})\)，就是在说"条件里只保留前缀"——这不是额外假设，而是"把所有条件都显式列出"的诚实写法。
  4. 数值例子。设 \(T=4\)，模型给出的四个条件分布分别把真实 token 排在概率 0.4 / 0.3 / 0.2 / 0.5：
    \[ P(\boldsymbol u)=0.4\times0.3\times0.2\times0.5=0.012 \]
    \(\log 0.012=-4.423\)。记住这组数字，后面 12.2 / 12.3 全部用它。
  5. 为什么这条式子是"能算"的前提。联合分布有 \(|\mathcal V|^{T}\) 个概率，无法存储；而右侧只有 \(T\) 个 \(|\mathcal V|\)-维向量。自回归分解把指数级的联合表压缩成 \(T\) 个小表，这正是所有自回归语言模型的结构来源。
    易错点：两处极易混淆
    • \(P(\boldsymbol u)\) 与 \(P_\Theta(\boldsymbol u)\) 不是一回事。评测时我们假设真实分布无法计算，于是用模型在参考文本上的似然 \(p_\Theta(\boldsymbol u)=\prod_t p_\Theta(u_t\mid\boldsymbol u_{<t})\) 作为 \(P(\boldsymbol u)\) 的代理估计量。这一步是 MLE，不是恒等式。
    • 条件独立性不是假设。因果掩码是结构保证：位置 \(t\) 的计算图里根本不存在位置 \(t\) 之后的节点，所以 \(u_{>t}\) 无法影响 \(u_t\)。这与朴素贝叶斯的"特征条件独立假设"是完全不同的两件事。
直觉 12.1 就是"整句概率 = 每个词的接龙概率连乘"。写一句 4 个词的话，你有多大概率恰好写出来，等于第 1 词猜对的概率 × 在第 1 词已定的前提下第 2 词对的概率 × …… 连乘之后会变得极小——这正是下一条公式要解决的问题。

(12.2)困惑度定义一：建模概率的 \(T\) 次根倒数#

出处第 12 章 12.1.1 节 Perplexity　对照原文

原书公式 12.2

① 公式

\[ \mathrm{PPL}(\boldsymbol u)=P(\boldsymbol u)^{-\frac1T}, \]

② 符号

符号含义形状 / 量纲
\(\mathrm{PPL}\)Perplexity，困惑度标量，\(\ge1\)（因 \(P\le1\)）
\(P(\boldsymbol u)\)整句的（估计）建模概率\(\in(0,1]\)，\(T\) 越大越小
\(T\)token 数。\(-\frac1T\) 就是"开 \(T\) 次方根"正整数

③ 推导

动机是 (12.1) 让 \(P(\boldsymbol u)\) 不可比：写 1000 个 token 必然比写 10 个 token 概率小几个数量级，与模型好坏无关。所以要做长度归一化。归一化有两条路：算术平均（不行）与几何平均（行）。

  1. 为什么不能取算术平均。设 \(p_t=P(u_t\mid\boldsymbol u_{<t})\)。若用 \(\frac1T\sum_t p_t\)，那么"前 \(T-1\) 个词全猜对（\(p_t\approx1\)）、最后一个词完全猜错（\(p_T\approx0\)）"这种灾难性句子，仍能拿到接近 \(1\) 的平均分。而连乘形式 (12.1) 会诚实地把它压到接近 0。平均抹掉了最坏的那一步。
  2. 选几何平均。几何平均数（geometric mean）的定义是 \(G(a_1,\dots,a_T)=\big(\prod_{t}a_t\big)^{1/T}\)。要"拉回来"，就要乘它的倒数：
    \[ P(\boldsymbol u)^{-\frac1T}=\left(\prod_{t=1}^{T}p_t\right)^{-1/T}=\left(\prod_{t=1}^{T}\frac{1}{p_t}\right)^{1/T}=G\!\left(\frac1{p_1},\frac1{p_2},\dots,\frac1{p_T}\right) \]
    这一步用到两条初等运算法则：\((ab)^{c}=a^cb^{c}\) 与 \(\prod_t x_t^{1/T}=(\prod_t x_t)^{1/T}\)。所以
    \[ \boxed{\ \mathrm{PPL}=\text{各步"倒数条件概率"的几何平均数}\ } \]
    另外注意 \(P(\boldsymbol u)\le1\Rightarrow P^{-1/T}\ge1\)，所以 PPL 的下界是 1（模型给真实 token 概率 1），没有 0。
  3. 数值例子（用 12.1 的四个概率）。
    \[ \mathrm{PPL}=0.012^{-\frac14}=\left(\frac1{0.012}\right)^{1/4}=(83.333)^{1/4}=\exp\!\Big(\tfrac14\ln 83.333\Big)=\exp(1.1057)\approx\mathbf{3.02} \]
    用倒数验证：\(\big(\tfrac1{0.4}\cdot\tfrac1{0.3}\cdot\tfrac1{0.2}\cdot\tfrac1{0.5}\big)^{1/4}=(2.5\times3.333\times5\times2)^{1/4}=(83.333)^{1/4}\approx3.02\)。两者一致。
  4. 为什么它是"有效分支因子"。设词表大小为 \(|\mathcal V|=V\)。取最简单的均匀分布基线：\(p_t=1/V\) 对所有 \(t\)。代入 (12.1) 得 \(P(\boldsymbol u)=V^{-T}\)，代入 (12.2)：
    \[ \mathrm{PPL}=\big(V^{-T}\big)^{-1/T}=\big(V^{T}\big)^{1/T}=V \]
    模型"完全没学会"时 PPL 正好等于词表大小。所以 PPL 的正确读法是："模型在每一步的实际上有效的候选个数"。若 \(\mathrm{PPL}=3\)，意思不是"猜了 3 次"，而是"每一步的真实 token 在模型的等效概率分布里，大约和另外 2 个干扰项一样有竞争力"。\(3.02\) 说明这个模型的语言知识比"在 32000 个词里瞎猜"好 4 个数量级。
  5. 为什么 \(-\frac1T\) 这个指数是唯一合理的选择。要让指标与 \(T\) 无关，必须消掉连乘带来的 \(T\) 次幂增长。设用 \(\mathrm{PPL}=P^{-a}\)，则均匀基线处 \(\mathrm{PPL}=V^{aT}\)——只有 \(a=1/T\) 才能让它与 \(T\) 无关。所以 (12.2) 里的指数不是随便取的，它由"长度归一化"这个要求唯一确定。
直觉 "困惑"这个名字来自一个信息论式的解读：\(H=-\frac1T\sum\ln p_t\) 是每个 token 的平均不确定性（熵），而 \(\mathrm{PPL}=e^{H}\) 把它换算回"候选数"的单位。熵的单位是 bit/nat（对数刻度），指数把刻度变回线性刻度，于是可以和 \(V\) 直接比较。
易错点 (12.2) 这个形式实际上算不出来。它要求先有 \(P(\boldsymbol u)\) 这个整体概率，而 \(P(\boldsymbol u)\le1\) 且随 \(T\) 指数衰减，几百个 token 就会下溢。历史上 GPT-2 时代真的这么算过，得到的困惑度会有数值误差。实际必须用 12.3 的对数形式。见下。

(12.3)困惑度定义二：平均负对数似然的指数（\(=e^{\mathrm{CE}}\)）#

出处第 12 章 12.1.1 节 Perplexity（数值稳定形式）　对照原文

原书公式 12.3

① 公式

\[ \mathrm{PPL}(\boldsymbol u)=\exp\!\left(-\frac{1}{T}\sum_{t=1}^{T}\log P\big(u_t\mid \boldsymbol u_{<t}\big)\right), \]

② 符号

符号含义形状 / 量纲
\(-\frac1T\sum_t\log p_t\)平均负对数似然 = 平均交叉熵 \( \mathrm{CE} \)标量，单位 nat
\(\exp(\cdot)\)自然指数单调函数，\(\mathbb R\to\mathbb R_{>0}\)
\(\mathrm{PPL}\)困惑度\(\in[1,\infty)\)

③ 推导：12.2 与 12.3 恒等

  1. 第一步：代入 (12.1)。
    \[ \mathrm{PPL}=\left(\prod_{t=1}^{T}p_t\right)^{-1/T} \]
    这一步就是把 12.1 的乘积塞进 12.2 的根号里。
  2. 第二步：拆开根号（对数运算法则 \(\ln\prod x_t=\sum\ln x_t\)、\(\ln x^c=c\ln x\)）。
    \[ \ln\mathrm{PPL}=-\frac1T\ln\Big(\prod_{t=1}^{T}p_t\Big)=-\frac1T\sum_{t=1}^{T}\ln p_t \]
    第一个等号两边取 \(\ln\)（合法，因 \(\mathrm{PPL}>0\)，且 \(\ln\) 在正数上单射）。第二个等号用了 \(\ln(ab)=\ln a+\ln b\) 对有限乘积的推广。
  3. 第三步：两边取指数。由 \(\ln x=-A\iff x=e^{-A}\)：
    \[ \mathrm{PPL}=\exp\!\left(-\frac1T\sum_{t=1}^{T}\log p_t\right) \]
    这正是 12.3。∎
  4. 关于"两者何时相等"的准确说法。网上（以及不少中文教材）常说"12.2 只在所有 \(p_t\) 相同时才等于 12.3"。这个说法是错的。上面三步只用了 \(\ln\prod=\sum\ln\) 和 12.1，对 \(p_1,\dots,p_T\) 没有任何等值要求——只要 12.1 成立，两个定义恒等。真正的适用条件是：
    • 12.2 需要整体概率 \(P(\boldsymbol u)\) 作为输入；12.3 需要逐 token 的对数概率。如果你手上只有 \(P(\boldsymbol u)\) 这一个数（比如某个第三方只给了句概率），就算不出 12.3——反之亦然。
    • 如果模型给的 \(p_t\) 不是归一化概率（例如被温度缩放、被 top-\(p\) 截断后未重归一、或用启发式评分代替概率），那么"整体概率"与"逐 token 乘积"不再是同一个对象，12.2 与 12.3 就会给出不同的数。
  5. 数值例子 1（接 12.1）。四个 \(p_t\) 为 \(0.4,0.3,0.2,0.5\)：
    \[ \ln \mathrm{PPL}=-\tfrac14\big(\ln0.4+\ln0.3+\ln0.2+\ln0.5\big)=-\tfrac14(-0.9163-1.2040-1.6094-0.6931)=1.1057 \]
    \(\mathrm{PPL}=e^{1.1057}\approx3.02\)，与 12.2 的结果一致。 顺带得到交叉熵：\(\mathrm{CE}=1.1057\ \text{nat}\)。而 \(\ln 3.02\approx1.1057\)——这不是巧合，因为定义就是 \(\ln\mathrm{PPL}=\mathrm{CE}\)。
  6. 数值例子 2（演示为什么必须用对数形式）。设 \(T=100\)，每个 \(p_t=0.3\)。
    • 整体概率：\(P(\boldsymbol u)=0.3^{100}=5.15\times10^{-53}\)。float32 的最小正规数是 \(1.18\times10^{-38}\)，所以单精度下这个值直接下溢成 0；即使双精度勉强存下，\(0^{-1/100}=\infty\)，结果彻底失效。
    • 对数形式：\(\ln\mathrm{PPL}=-\frac1{100}\cdot100\ln0.3=-\ln0.3=1.204\)，\(\mathrm{PPL}=e^{1.204}=3.33\)。每一步的中间量 \(\ln p_t\in(-1.6,\,0)\) 有界，绝不下溢。
    这就是原书说的"为避免数值下溢，通常用对数概率求和"。工程上应当逐 token 累加 log-prob（用 logsumexp 或直接取 log_softmax），绝不能先乘后取幂。
  7. 数值例子 3（有效分支因子的读数）。均匀分布基线 \(\mathrm{CE}=\ln V\)。取 \(V=32000\)：\(\ln 32000=10.373\)，\(\mathrm{PPL}=32000\)。若某模型 PPL=8.0，则 \(\mathrm{CE}=\ln8=2.079\) nat，每步等效候选约 8 个。

交叉熵与困惑度的关系，以及在分类任务上的读法

  1. 恒等式。把 (12.3) 与交叉熵的定义对齐：
    \[ \mathrm{CE}(\boldsymbol u,p)=-\frac1T\sum_{t=1}^{T}\log p_\Theta(u_t\mid\boldsymbol u_{<t})\quad\Longrightarrow\quad \boxed{\mathrm{PPL}=e^{\mathrm{CE}}} \]
    所以"困惑度"就是"交叉熵换底"：\(e\) 进制 vs \(2\) 进制的类比不完全精确（换底要乘 \(\ln2\)），但 exp 把 nat 变回线性刻度这件事是精确的。
  2. 这正是训练目标与评测指标的同一个量。预训练最小化的 \(\mathrm{CE}\) 就是上式这个量；评测时报的 PPL 是训练损失的指数。两者单调对应，所以"训练 loss 降了"和"PPL 降了"是同一件事。
  3. 推广到 \(K\) 类分类。把 \(\boldsymbol u\) 缩成一个标签，模型给出真实标签的概率 \(p_{\text{true}}\in(0,1]\)，则
    \[ \mathrm{CE}=-\log p_{\text{true}},\qquad \mathrm{PPL}=\frac{1}{p_{\text{true}}} \]
    于是 PPL 在分类里就是"倒数真实类概率"，同一个"有效分支因子"读法：PPL=2 意味着模型对真实标签只有一半把握（等价于瞎猜）；PPL=1.05 意味着几乎确定。两个边界：
    • \(p_{\text{true}}\le1\Rightarrow \mathrm{CE}\ge0\Rightarrow\mathrm{PPL}\ge1\)。
    • 完全无信息的模型 \(p_{\text{true}}=1/K\Rightarrow \mathrm{CE}=\ln K,\ \mathrm{PPL}=K\)。和语言模型情形一模一样。
  4. 数值例子（1000 样本二分类）。真实标签概率 0.8：\(\mathrm{CE}=-\ln0.8=0.223\) nat，\(\mathrm{PPL}=e^{0.223}=1.25\)。概率 0.5（瞎猜）：\(\mathrm{CE}=0.693\)，\(\mathrm{PPL}=2.00\)。概率 0.95：\(\mathrm{CE}=0.0513\)，\(\mathrm{PPL}=1.053\)。注意分类任务里 PPL 只能落在 \([1,2]\)，精度不够、要在更细的刻度上比较时必须同时报 CE 或概率本身。
直觉 12.2 与 12.3 是同一个数的两种"读法"：12.2 说"整句概率的均摊"，12.3 说"平均每一位有多惊讶"。数学上是恒等，工程上只有后者能用，因为前者会下溢——这是"数学上的定义"和"能算出来的定义"分开的典型案例。
易错点：PPL 跨模型比较的三个前提
  • tokenizer 必须一致。PPL 对 \(T\) 归一化，但 \(T\) 由分词器决定。一个 Unicode 字符被切成 1 个还是 3 个 token，直接改变 \(\frac1T\sum\ln p_t\)。不同分词器的 PPL 不可比（这也是为什么 instruct 模型报的 PPL 常常比 base 模型"低"却不代表更强——它们的模板让每个 token 更好预测）。
  • 语料必须一致。PPL 是逐句平均再平均，长句权重会被放大；不同评测集的分词平均长度不同。
  • 不要用 PPL 跨任务比较。它是似然度量，与"输出对不对"没有因果联系。一个 PPL 很低的模型可能生成语法完美但内容错误的文本（重复、套话都是高概率续写）。PPL 只测语言建模，不测任务能力。

原书公式 12.4

① 公式

\[ \mathrm{Precision}=\frac{TP}{TP+FP}, \]

② 符号：混淆矩阵（原书 Table 12.2）

预测类别（Predicted Class）
正 Positive负 Negative
真实类别
（Actual Class）		正 Positive\(TP\)　真阳性\(FN\)　假阴性
负 Negative\(FP\)　假阳性\(TN\)　真阴性
  • \(TP\)：实际为正、预测为正（猜对的正例）
  • \(FP\)：实际为负、预测为正（误报 / 假警报）
  • \(FN\)：实际为正、预测为负（漏报）
  • \(TN\)：实际为负、预测为负（猜对的负例）

③ 推导

  1. 精确定义：它是一个条件概率。把预测器当作一个划分：\(\{\text{预测为正的样本}\}\subseteq\) 全部样本。在"预测为正"这个子集里，有多大比例真的为正？
    \[ \mathrm{Precision}=\frac{TP}{TP+FP}=P\big(\text{真实为正}\mid\text{预测为正}\big) \]
    用条件概率的计数定义即可：\(P(A\mid B)=n(A\cap B)/n(B)\)。分子 \(TP=n(\text{正}\cap\text{预测正})\)，分母 \(n(\text{预测正})=TP+FP\)（分母里必须有 \(FP\)，因为误报的样本也被算进了"预测为正"）。
  2. 为什么分母不含 FN。FN 的样本根本没有被"预测为正"，它们对精确率没有任何影响。精确率只回答"我报出来的有多准"，完全不管"我漏了多少"。这个信息缺失正是 12.5 存在的理由。
  3. 数值例子。取 \(TP=80,\ FP=20,\ FN=40,\ TN=860\)（共 1000 个样本，其中真实正例 120 个）：
    \[ \mathrm{Precision}=\frac{80}{80+20}=\frac{80}{100}=0.80 \] "报出的 100 条警报里，80 条是真的。"
  4. 精确率可以被"少报"刷高。极端情形：模型只输出它最有把握的 1 条，且恰好正确，则 \(TP=1,FP=0\)：
    \[ \mathrm{Precision}=\frac{1}{1+0}=1.00,\qquad \mathrm{Recall}=\frac{1}{120}=0.0083 \]
    精确率满分，但 120 个真实正例里只找出了 1 个。所以精确率绝不能单独报告。至少要配一个召回率。
  5. 精确率的阈值依赖性。LLM 输出的是连续分数 \(z\)（正类概率或 logit），需要阈值 \(\tau\) 才能变成 0/1 决策：\(\hat y=\mathbf 1[z>\tau]\)。\(\tau\) 提高 → \(FP\) 减少、\(FN\) 增加 → \(\mathcal P\) 上升、\(\mathcal R\) 下降。报一个"精确率 0.9"而不报阈值，等于什么都没说。
直觉 精确率 = 告警准确率。火灾报警器响了 100 次，其中 80 次真有火：精确率 80%。它衡量"报警器值不值得信任"，代价是对"漏报"完全无感。
(12.5) 召回率　(12.6) \(F_1\)

(12.5)召回率 Recall#

出处第 12 章 12.1.1 节 Recall　对照原文

原书公式 12.5

① 公式

\[ \mathrm{Recall}=\frac{TP}{TP+FN}, \]

② 符号

符号含义量纲
\(TP\)被找出来的真实正例计数 \(\ge0\)
\(FN\)被漏掉的真实正例计数 \(\ge0\)
\(TP+FN\)真实正例总数（与阈值无关）计数
\(\mathrm{Recall}\)召回率\([0,1]\)

③ 推导

  1. 它也是一个条件概率，但方向相反。这次把条件放在"真实类别"上：
    \[ \mathrm{Recall}=\frac{TP}{TP+FN}=P\big(\text{预测为正}\mid\text{真实为正}\big) \]
    在全部真实正例这个集合里，有多大比例被找了出来？分母 \(TP+FN\) 是真实正例的总数：\(TP\) 是被找出的，\(FN\) 是被漏掉的。
  2. 关键差异：分母不含 \(FP\)。误报的样本不影响召回率——它们本来就不是真实正例，不在分母里。所以精确率和召回率的分母是两组不同的样本。这是两个指标能同时低的根本原因（大量误报 \(\Rightarrow\mathcal P\) 低；大量漏报 \(\Rightarrow\mathcal R\) 低）。
  3. 数值例子。用 12.4 的混淆矩阵，真实正例 \(TP+FN=80+40=120\)：
    \[ \mathrm{Recall}=\frac{80}{120}=0.6667 \] "120 个真实正例里找出了 80 个。"
  4. 精确率与召回率的精确反比关系（工程上极有用）。由定义，
    \[ \frac{\mathcal P}{\mathcal R}=\frac{TP/(TP+FP)}{TP/(TP+FN)}=\frac{TP+FN}{TP+FP}=\frac{\text{真实正例数}}{\text{预测正例数}} \]
    （约定 \(TP>0\)；\(TP=0\) 时两者都为 0。） 推论：设正例总数 \(P_{\text{tot}}\) 固定、\(\mathcal P=0.80\)、\(\mathcal R=0.6667\)，则预测正例数是 \(\frac{120}{0.80}=150\)。这条关系把三个数字绑在一起，很多"精确率高所以可靠"的错误结论都出在忽略了它。
  5. 召回率是"集合层面"的量，不是单样本的量。单看一个样本，说它"对不对"只有 0/1 两种可能；但"召回"要求先有一个决策集合（哪些被判为正）。所以 \(\mathcal P,\mathcal R,F_1\) 都不是逐样本可加的量，评测时不能"先算每条的准确率再平均"，必须先在全集上算混淆矩阵再取比值（macro 除外，见下）。
  6. 多类/长文本场景。实体抽取、QA 的"答案是否包含"判定等都产出二值混淆矩阵。多个类别时通常按类别分别算 \(\mathcal P,\mathcal R\) 再取宏平均（macro）或按真实例数加权（micro）；两种算法的结果不同，报告时必须说明。
直觉 召回率 = 覆盖率 / 查全率。100 个病人里有 20 个真的生病，模型只诊断出 8 个，召回率就是 \(8/20=0.4\)。它衡量"该抓的人有没有都被抓到"，代价是对"误抓"完全无感。
(12.4) 精确率　(12.6) \(F_1\) 把两者调和平均

(12.6)\(F_1\) 分数：精确率与召回率的调和平均#

出处第 12 章 12.1.1 节 F1 Score　对照原文

原书公式 12.6

① 公式

\[ F_1=2\times\frac{\mathrm{Precision}\times\mathrm{Recall}}{\mathrm{Precision}+\mathrm{Recall}}, \]

② 符号

符号含义量纲
\(\mathcal P,\mathcal R\)精确率、召回率（见 12.4 / 12.5）\([0,1]\)，且非同时为 0
\(F_1\)精确率与召回率的调和平均\([0,1]\)
\(F_\beta\)加权版，\(\beta>1\) 偏重召回\([0,1]\)

③ 推导 A：它确实是调和平均

  1. 工具：调和平均的定义。两个正数 \(a,b\) 的调和平均定义为"倒数的算术平均，再取倒数"：
    \[ H(a,b)=\left(\frac{1}{a}+\frac{1}{b}\right)^{-1} \]
    这是三种"平均数"里唯一的倒数形式；几何平均 \(\sqrt{ab}\) 则是"对数的算术平均，再取指数"。
  2. 化成 \(\frac{2PR}{P+R}\)。用分式通分与倒数：\(\frac{1}{a}+\frac{1}{b}=\frac{a+b}{ab}\)，故
    \[ H(a,b)=\left(\frac{a+b}{ab}\right)^{-1}=\frac{ab}{a+b}=\frac{2ab}{a+b} \]
    代入 \(a=\mathcal P,\ b=\mathcal R\) 即得 \(F_1=\frac{2\mathcal P\mathcal R}{\mathcal P+\mathcal R}\)。这就是原书那句"the harmonic mean of precision and recall"的全部数学内容。
  3. 边界检查。\(\mathcal P=0\) 或 \(\mathcal R=0\) 时 \(F_1=0\)（正确：一条都没抓到或全是误报，判 0 分）；\(\mathcal P=\mathcal R=1\) 时 \(F_1=1\)。

③ 推导 B：为什么用调和平均而不是算术平均（严格版）

  1. 精确的差值恒等式。记算术平均为 \(A=\frac{\mathcal P+\mathcal R}{2}\)。做通分：
    \[ A-F_1=\frac{(\mathcal P+\mathcal R)}{2}-\frac{2\mathcal P\mathcal R}{\mathcal P+\mathcal R}=\frac{(\mathcal P+\mathcal R)^2-4\mathcal P\mathcal R}{2(\mathcal P+\mathcal R)}=\frac{(\mathcal P-\mathcal R)^2}{2(\mathcal P+\mathcal R)}\ \ge\ 0 \]
    最后一步用平方非负。所以：\(F_1\) 恰好等于算术平均减去一个"不平衡惩罚项"，且惩罚以偏差的平方计。等号仅当 \(\mathcal P=\mathcal R\)。
  2. 调和平均被"小的那个"支配。记 \(m=\min(\mathcal P,\mathcal R),\ M=\max(\mathcal P,\mathcal R)\)。由 \(\frac1m+\frac1M\le\frac2m\) 得 \(H\ge m\)；由 \(\frac1m+\frac1M\ge\frac2M\) 得 \(H\le M\)。所以
    \[ \min(\mathcal P,\mathcal R)\;\le\;F_1\;\le\;2\min(\mathcal P,\mathcal R) \]
    推论：只要有一个指标塌了，\(F_1\) 最多是那个塌掉的值的两倍。若 \(\mathcal R=0.1\)，则 \(F_1\le0.2\)，无论 \(\mathcal P\) 多高。
  3. 数值例子：差距有多大。取 \(\mathcal P=0.9,\ \mathcal R=0.1\)：
    \[ A=0.50,\qquad F_1=\frac{2\cdot0.09}{1.0}=0.18,\qquad A-F_1=\frac{(0.8)^2}{2}=0.32 \]
    算术平均给出 0.50（听起来"还行"），调和平均只有 0.18（诚实地反映出召回几乎为零）。差异 2.8 倍。
  4. 更极端的情形说明"平方惩罚"的必要性。取 \(\mathcal P=1.0,\ \mathcal R=0.01\)：算术平均 \(0.505\)（！）而 \(F_1=\frac{0.02}{1.01}=0.0198\)。若用算术平均，一个"只报 1 条且报对了"的模型能拿 0.505 分，几乎与均衡模型持平——这显然是错的。调和平均的"倒数形式"自动把低的那一项按全额计入。
  5. 用"精确率固定"写出精确的量化结论。这是最能体现 \(F_1\) 设计意图的表述。把 12.6 与 \(\mathcal R\) 视为关于 \(\mathcal R\) 的方程（视 \(\mathcal P=p\) 为已知常数）：
    \[ F_1(p+R)=2pR\quad\Longrightarrow\quad F_1p+R\,F_1=2pR\quad\Longrightarrow\quad R\,(2p-F_1)=F_1p\quad\Longrightarrow\quad \boxed{\,R=\frac{F_1\,p}{2p-F_1}\,}\ \]
    （分母 \(2p-F_1>0\)，因为 \(\mathcal R\le1\) 时 \(F_1=\frac{2p\mathcal R}{p+\mathcal R}\le2p\)。）读法：精确率被钉在 \(p\) 时，要让 \(F_1\) 达到 \(f\)，召回率必须至少是 \(\frac{fp}{2p-f}\)。
    • 取目标 \(f=0.8\)：\(\mathcal P=0.9\Rightarrow \mathcal R\ge\frac{0.72}{1.8-0.8}=0.720\)；\(\mathcal P=0.8\Rightarrow\mathcal R\ge\frac{0.64}{0.8}=0.800\)。
    • 该下界关于 \(p\) 单调递减（\(g(p)=\frac{fp}{2p-f}\)，\(g'(p)=\frac{-f^2}{(2p-f)^2}<0\)），故最宽松的乐观情形是 \(p=1\)：此时 \(F_1=\frac{2\mathcal R}{1+\mathcal R}\)，反解得 \(\mathcal R\ge\frac{f}{2-f}\)。取 \(f=0.8\)：\(\mathcal R\ge\frac{0.8}{1.2}=0.667\)。
    • 验证：\(\mathcal P=1,\mathcal R=0.667\Rightarrow F_1=\frac{2\cdot0.667}{1.667}=0.800\) ✓。这就是 \(F_1\ge0.8\) 时召回率的绝对下界——"哪怕精确率 100%，召回率也不能低于 67%"。
    易错点：一条常见的错误说法 "\(F_1\) 等于精确率固定为 \(p\)、召回率为 \(\frac{p}{2-p}\) 时的某个准确率"——这不是恒等式。代入检验：\(p=0.8,\ \mathcal R=\frac{0.8}{1.2}=0.667\)，则 \(F_1=\frac{2\cdot0.8\cdot0.667}{1.467}=0.727\neq0.8\)。正确的关系是上面那个反解 \(\mathcal R=\frac{F_1p}{2p-F_1}\)（等价地，固定 \(\mathcal R\) 时 \(\mathcal P=\frac{F_1\mathcal R}{2\mathcal R-F_1}\)）。另外注意 \(\frac{f}{2-f}\) 这个形式对应的是"精确率完美时"的最乐观下界，容易被误记成通用公式。

③ 推导 C：为什么 \(F_1\) 优于准确率，以及加权推广

  1. 准确率与 \(F_1\) 会严重脱节。用 12.4 的混淆矩阵（\(TP=80,FP=20,FN=40,TN=860\)）：
    \[ \mathrm{Accuracy}=\frac{TP+TN}{TP+FP+FN+TN}=\frac{940}{1000}=0.94,\qquad F_1=0.727 \]
    94% 的准确率听起来很好，但它被 860 个 \(TN\) 撑起来了。更糟的是：在正例只占 10% 的数据上，"全部预测为负"的平凡基线准确率就有 0.90，却有 \(F_1=0\)。所以类别不平衡时必须用 \(F_1\)（或 \(PR\) 曲线下面积 AUC-PR）。
    直觉准确率是"平均每 100 个判断对几个"，被多数类淹没；\(F_1\) 是"在正例这个困难子集上做对多少"，只看困难部分。两者的分母根本不同。
  2. 为什么 \(F_1\) 还不够：\(\mathcal P\) 与 \(\mathcal R\) 常常天秤不等。安全场景要召回，翻译要精确。所以定义加权调和平均 \(F_\beta\)：
    \[ F_\beta=\frac{(1+\beta^2)\mathcal P\mathcal R}{\beta^2\mathcal P+\mathcal R}=\left(\frac{\beta^2/\mathcal P+1/\mathcal R}{\beta^2+1}\right)^{-1} \]
    推导同 ③A（对倒数做加权平均再取倒数）。性质：\(\beta\to0\Rightarrow F_\beta\to\mathcal P\)；\(\beta\to\infty\Rightarrow F_\beta\to\mathcal R\)；\(\beta=1\) 就是 12.6。\(F_2\)（召回加权）在医疗/安全评测里是常用默认值。
  3. 为什么"集合层面"这件事不是缺陷。\(F_1\) 是四个计数的比值，无法分解成"每个样本的贡献之和"。所以不能把 \(F_1\) 拿来做逐样本的早停判据或损失（那是训练时用交叉熵的原因，见 12.3）。\(F_1\) 的角色只在评测：在固定阈值下对一批预测算一次。
直觉 调和平均是"两个都要好才算好"的平均：把 \(1/\mathcal P\) 和 \(1/\mathcal R\) 平均再取倒数，等价于先算"错的比例"再平均。错误率高的那一边被完整地计入，没有折扣。所以 \(F_1\) 是"不允许任何一边偷懒"的分数。
(12.7) 生成任务：BLEU

(12.7)BLEU：长度惩罚 × \(n\)-gram 精确率的加权几何平均#

出处第 12 章 12.1.1 节 BLEU　对照原文

原书公式 12.7

① 公式

\[ \mathrm{BLEU}=\mathrm{BP}\times\exp\!\left(\sum_{n=1}^{N}w_n\times\log p_n\right), \]

实践中取 \(N=4\)，\(w_n=\frac1N=\frac14\)（均匀分布）——也就是 BLEU-4。

② 符号

符号含义量纲 / 取值
\(\mathcal C\)候选译文（candidate，模型输出）字符串，长度 \(l_c\)
\(\mathcal R\)参考译文集合（可能有多个参考）集合，最短者长度 \(l_r\)
\(N\)最高的 \(n\)-gram 阶数（通常 4）正整数
\(w_n\)\(n\)-gram 阶的权重，实践中 \(\sum_{n=1}^Nw_n=1\)\([0,1]\)
\(p_n\)\(n\)-gram 精确率（截断计数，见下 ④）\([0,1]\)
\(\mathrm{BP}\)长度惩罚（brevity penalty），公式 (12.8)\(\in(0,1]\)
\(\mathrm{BLEU}\)双语评估替补分数\([0,1]\)

③ 推导

  1. 指数形式 = 加权几何平均。用 \(e^{x+y}=e^xe^y\) 与 \(\prod x^{w}=\exp(w\ln x)\)：
    \[ \exp\!\left(\sum_{n=1}^{N}w_n\log p_n\right)=\prod_{n=1}^{N}p_n^{\,w_n} \]
    若 \(\sum_n w_n=1\)，右边就是 \(p_1,\dots,p_N\) 的加权几何平均数（权重和为 1 的加权几何平均才有"平均"的资格）。
  2. 为什么是几何平均而不是算术平均。用 Jensen 不等式（\(\ln\) 是凹函数，故 \(\ln(\mathbb E[X])\ge\mathbb E[\ln X]\)）：
    \[ \sum_{n}w_n\ln p_n\ \le\ \ln\!\Big(\sum_{n}w_n p_n\Big)\quad\Longrightarrow\quad \prod_{n}p_n^{w_n}\ \le\ \sum_{n}w_np_n \]
    所以几何平均 \(\le\) 算术平均。但真正决定性的理由是"零传播"性质：BLEU 的语义是"译文整体正确"，只要有一阶 \(n\)-gram 完全对不上（如 \(p_3=0\)，出现一个机器翻译标志性的错译），几何平均立刻变 0，总分归零；算术平均却会给出 \(\frac13\times\text{(其余两阶)}>0\) 的部分分。BLEU 的取对数写法正是为了让"对数域求和"这件事在数值上好算（\(\prod\) 可能下溢，\(\sum\ln\) 不会）。
  3. 为什么 BP 可以乘在外面。长度惩罚与 \(n\)-gram 匹配是两个独立的影响因素（候选是否覆盖了参考的长度、候选的词序片段是否出现）。相乘对应"两个条件都要满足"的逻辑（\(\mathrm{BLEU}\le1\) 需要两者同时合格）。而几何平均保证"每一阶都要合格"。
  4. 数值例子（N=2, \(w_1=w_2=\frac12\)）。候选 \(\mathcal C=\)"the cat sat"，参考 \(\mathcal R=\)"the cat sat on"。
    • 一元：候选 3 个 unigram 全部在参考中各出现 1 次，故 \(p_1=\frac{3}{3}=1\)。
    • 二元：候选含 "the cat"、"cat sat" 共 \(l_c-n+1=3-2+1=2\) 个二元组，全部命中，故 \(p_2=\frac22=1\)。
    • 长度：\(l_c=3\le l_r=4\Rightarrow \mathrm{BP}=\exp(1-\frac43)=0.7165\)（见 12.8）。
    • \(\mathrm{BLEU}=0.7165\times\exp(\frac12\ln1+\frac12\ln1)=0.7165\)。
    这是一个"前缀完全正确"却只得 0.72 的句子——BLEU 对短句的惩罚非常重，这也是实际使用中采用语料级 BLEU（把多句拼起来算、用最接近的参考长度）的原因。
  5. 反面例子：截断计数的作用。候选 \(\mathcal C=\)"the the the the"，参考 \(\mathcal R=\)"the cat sat on"。
    • 若不截断：\(count_{\mathcal C}(\text{the})=4\)，取 min 或不取都会算成 \(4/4=1\)，得满分——一条毫无意义的译文拿了 \(\mathrm{PPL}=1\) 级的分数。
    • 截断后：\(\min(count_{\mathcal C},count_{\mathcal R})=\min(4,1)=1\)，故 \(p_1=\frac{1}{4}=0.25\)。
    • 二元组：候选的 "the the" 出现 3 次，参考里出现 0 次，\(\min(3,0)=0\Rightarrow p_2=0\Rightarrow\mathrm{BLEU}=0\)。
    截断计数是 BLEU 防止"堆词刷分"的唯一机制。

④ 补充推导：\(p_n\) 的截断计数定义与"截断后的有效长度"

原书把这条写成 12.9（在第 12 章 · 评测（2/2）页正式展开），但 12.7 用到了它，所以这里把推导做完。

原书公式 12.9（补充推导）
\[ p_n=\frac{\sum_{n\text{-gram}\in\mathcal C}\min\big(\mathrm{count}_{\mathcal C}(n\text{-gram}),\ \max_{R\in\mathcal R}\mathrm{count}_{R}(n\text{-gram})\big)}{\sum_{n\text{-gram}\in\mathcal C}\mathrm{count}_{\mathcal C}(n\text{-gram})}, \]
  1. 先算分母：截断后的有效长度。设候选串有 \(l_c\) 个 token，则它包含的 \(n\)-gram 个数恰为
    \[ (l_c-n+1)+(l_c-n)+\cdots+1\ \text{（逐起点计数）}\ \Longrightarrow\ \max(0,\ l_c-n+1) \]
    更直接地：每个起点位置 \(i=1,\dots,l_c-n+1\) 产生一个 \(n\)-gram，所以 \(n\)-gram 总数是 \(l_c-n+1\)。而 \(\sum_{n\text{-gram}\in\mathcal C}\mathrm{count}_{\mathcal C}(n\text{-gram})\) 正是"把所有 \(n\)-gram 的出现次数加起来"，等于总数。因此
    \[ \boxed{\ \sum_{n\text{-gram}\in\mathcal C}\mathrm{count}_{\mathcal C}(n\text{-gram})=\max(0,\ l_c-n+1)=:\ l_c^{\text{eff}}(n)\ } \]
    这就是"截断后的有效长度"：不是 \(l_c\)（词数），也不是 \(l_c\cdot n\)（字符数），而是去掉所有不完整的 \(n\)-gram 后剩下的个数。同理参考侧为 \(l_r^{\text{eff}}(n)=\max(0,l_r-n+1)\)。
  2. 算分子的上界。对任意 \(n\)-gram \(g\)，匹配数 \(\min(\mathrm{count}_{\mathcal C}(g),\max_R\mathrm{count}_{R}(g))\le\max_R\mathrm{count}_{R}(g)\le\max_{R}(l_r^{\text{eff}}(n))\)。把所有 \(n\)-gram 的上界求和，得
    \[ \text{分子}\ \le\ l_r^{\text{eff}}(n)=\max(0,\ l_r-n+1) \]
  3. 于是得到精确率的上界：
    \[ p_n\ \le\ \frac{l_r^{\text{eff}}(n)}{l_c^{\text{eff}}(n)}=\frac{\max(0,l_r-n+1)}{\max(0,l_c-n+1)} \]
    这一步解释了两件事：
    • 为什么必须截断。不截断时分子可以超过分母（例如重复堆词），\(p_n>1\)，"精确率"就失去了"比率"的含义。取 \(\min\) 保证 \(\text{匹配数}\le\mathrm{count}_{\mathcal C}(g)\)，从而 \(p_n\le1\)。
    • 为什么必须乘 BP。若 \(l_c>l_r\)，上式严格小于 1，说明即使每个词都对，长度不够也会扣分——但这只是"扣一点"；真正的问题是若 \(l_c<l_r\)（候选太短），每个 \(p_n\) 都可能等于 1（短句的所有 \(n\)-gram 都命中），总分 \(\to1\)，这显然荒谬。BP 就是为了纠正后者，见 12.8。
  4. 为什么高阶惩罚更重。固定 \(l_c>l_r>0\)，令 \(g(n)=\frac{l_r-n+1}{l_c-n+1}\)。求导：
    \[ g'(n)=\frac{-(l_c-n+1)+(l_r-n+1)}{(l_c-n+1)^2}=\frac{l_r-l_c}{(l_c-n+1)^2}<0 \]
    即 \(n\) 越大，"覆盖率"上界越紧。直观理由：长 \(n\)-gram 很少重复，参考里的长片段一旦对不上就彻底失分——这正是 BLEU 能捕捉词序的原因。
  5. 多参考的处理：取 \(\max_R\)。人写参考译文往往有好几版，不同版本用词不同。取 \(\max_R\) 表示"只要任一参考命中就算数"，这是把 BLEU 从"对某一个参考"放宽成"对某个参考集合的最佳匹配"，是对多参考语料的标准做法。
直觉 BLEU 就是一张"逐级通关表"：1-gram、2-gram、3-gram、4-gram 每一级问"你猜中的比例是多少"，四级用几何平均合成总分，任何一级为 0 则全灭；再用长度惩罚防止"只翻前三句"骗满分。整句完全正确时，\(\mathrm{PPL}\)-式的乘积会趋近 1。
易错点：BLEU 的四条适用边界
  • BLEU 与语义/语序近似无关。"the cat sat on the mat" 与 "mat the on sat cat the" 的 \(n\)-gram 统计几乎相同（4-gram 会有差异，但可被模板化绕过），BLEU 却都给高分。BLEU 只能用于有参考译文的窄域任务，不能用来评测开放生成。
  • tokenizer 会改变 BLEU。分词不同 → \(n\)-gram 边界不同 → 数值不同。比较不同系统必须用同一套分词与同一参考。
  • 语料级 vs 句级。句级 BLEU（尤其有 BP 的情况下）对短句惩罚过重（见 ③第 4 步的例子），所以 SOTA 报告的是 corpus-level BLEU：把候选串与参考串按句对齐后累加匹配计数再取比值，此时 \(l_c,l_r\) 是总和，短句问题被平均掉。
  • BLEU 只算精确率方向。参考里的内容候选完全没译出来时 \(p_n\) 仍可能不小（因为分母只看候选），必须靠 BP 间接兜底。ROUGE 走的是相反方向（召回），两者互补。
(12.8) 长度惩罚 BP　(12.6) \(F_1\)

(12.8)BLEU 的长度惩罚因子 BP#

出处第 12 章 12.1.1 节 BLEU（Brevity Penalty）　对照原文

原书公式 12.8

① 公式

\[ \mathrm{BP}=\begin{cases} 1, & \text{if } l_c>l_r,\\[4pt] \exp\!\left(1-\dfrac{l_r}{l_c}\right), & \text{if } l_c\le l_r. \end{cases} \]

② 符号

符号含义量纲
\(l_c\)候选译文的 token 长度正整数
\(l_r\)最短参考译文的 token 长度（多参考时取最短）正整数
\(\mathrm{BP}\)长度惩罚因子\((0,1]\)

③ 推导

  1. 第一件事：验证 \(\mathrm{BP}\in(0,1]\)。两分支分别检查：
    • 分支一 \(l_c>l_r\)：\(\mathrm{BP}=1\le1\)。
    • 分支二 \(l_c\le l_r\)：令 \(x=\dfrac{l_r}{l_c}\ge1\)，则指数 \(1-x\le0\)，故 \(\mathrm{BP}=e^{1-x}\le e^0=1\)；且 \(x\) 有限故 \(\mathrm{BP}>0\)。∎
    候选不短于参考时一点都不罚——多出来的长度不该扣分（可能是合理的展开）。
  2. 第二件事：验证在 \(l_c=l_r\) 处连续。两分支在边界给出 \(\mathrm{BP}=1\) 与 \(\mathrm{BP}=\exp(1-1)=1\)，完全一致。这一点很关键：如果短的那支写成 \(l_r/l_c\)，边界处会给出 \(1\)，但斜率跳变；写成指数形式则两侧行为一致，长度轻微变化时分数不会突变。连续性是选指数形式的首要理由。
  3. 第三件事：验证单调性（候选越短，分越低）。在分支二上对 \(l_c\) 求导（复合函数链式法则：\(\frac{d}{dl_c}e^{g(l_c)}=e^{g(l_c)}g'(l_c)\)，其中 \(g(l_c)=1-l_r/l_c\)，\(g'(l_c)=+\frac{l_r}{l_c^2}>0\)）：
    \[ \frac{\partial \mathrm{BP}}{\partial l_c}=e^{\,1-l_r/l_c}\cdot\frac{l_r}{l_c^2}>0 \]
    即 \(\mathrm{BP}\) 随 \(l_c\) 递增——候选越短，惩罚越重。✓
  4. 第四件事（最关键）：为什么 \(\mathrm{BP}\) 恰好能保证 BLEU \(\le1\)。从 12.7 的 ④ 得到 \(p_n\le\frac{l_r-n+1}{l_c-n+1}\)。因为权重和为 1，几何平均不超过各阶比值的几何平均；当 \(l_c,l_r\) 都远大于 \(N\) 时
    \[ \frac{l_r-n+1}{l_c-n+1}\approx\frac{l_r}{l_c}=x\quad(\text{对每个 }n),\quad\Longrightarrow\quad \prod_{n=1}^{N}p_n^{\,1/N}\ \lesssim\ x^{\sum_n w_n}=x \]
    把这个"未补偿的长度亏欠" \(x\) 与 \(\mathrm{BP}=e^{1-x}\) 相乘，得到总分上界 \(xe^{1-x}\)。而由 \(\ln x\le x-1\)（\(\ln\) 凹、切线在 \(x=1\)）有
    \[ x\,e^{1-x}=\exp\big(\ln x+1-x\big)\le\exp\big((x-1)+1-x\big)=1 \]
    等号仅在 \(x=1\)（即 \(l_c=l_r\)）时成立。所以 BLEU 恒 \(\le1\)，且长度惩罚与几何平均的指数形式是"配对"设计的：外侧最多抵消一个长度比（因为权重和是 1 而不是 \(N\)）。这也解释了为什么不是 \(\left(\frac{l_r}{l_c}\right)^N\) 那样的形式——那会抵消 \(N\) 个长度比，罚得重得多。
    说明：这里是设计启发，不是定理 第 4 步中 \(\frac{l_r-n+1}{l_c-n+1}\approx\frac{l_r}{l_c}\) 是大长度近似（严格相等只在 \(l_c=l_r\) 时成立）。所以"BP 保证 BLEU≤1"更准确地说是：指数形式是满足"无跳变 + 单调 + 与几何平均的权重结构自洽"这几个要求的自然选择。\(x e^{1-x}\le1\) 这个不等式本身是严格成立的，但把它当作 BLEU 的定理需要把近似换成"每阶比值都等于 \(x\)"的保守假设。\(e^{1-x}\) 与 \((x)^{1}\) 只差一个常数因子：\(e^{1-x}\approx x\cdot e^{-(x-1)^2/2+\dots}\)，一阶近似就是 \(\mathrm{BP}\approx x^{-1}=l_c/l_r\)——线性地按长度比例罚，与阶数 \(N\) 无关。
  5. 第五件事：数值例子。
    • \(l_c=3,\ l_r=4\)：\(\mathrm{BP}=\exp(1-\frac43)=\exp(-0.3333)=0.7165\)。（这个数已在 12.7 的数值例子 里用到。）
    • \(l_c=19,\ l_r=20\)（差 5%）：\(\mathrm{BP}=\exp(1-\frac{20}{19})=\exp(-0.0526)=0.949\)，即扣 5%——与 \(1-\frac{20-19}{20}=0.95\) 几乎一致。
    • \(l_c=10,\ l_r=20\)（差一半）：\(\mathrm{BP}=\exp(1-2)=e^{-1}=0.368\)。惩罚非常重，而算术平均 \((10+20)/2=15\) 在这个场景下毫无信息量。
    • \(l_c=25,\ l_r=20\)：分支一，\(\mathrm{BP}=1\)。
  6. 第六件事：为什么取"最短参考长度" \(l_r\)。多参考时若取最长的参考作基准，一个本来正确但偏简洁的译文会被无端扣分；取最短参考使 BP 成为最宽松的惩罚——是一种"不冤枉短而正确的译文"的保守选择。代价是模型可以靠"只写最短参考那么长"来规避 BP，这正是 12.7 里 \(l_c<l_r\) 时 \(p_n\) 全为 1 却仍只得 0.72 的漏洞来源（短到极限时 \(p_n\to1\) 而 \(\mathrm{BP}\to0\)，乘积才被拉住；取 \(l_c\to0\) 时 \(\mathrm{BP}=e^{1-l_r/l_c}\to0\)，所以极端情况仍会被压住——这正是第 4 步那个 \(xe^{1-x}\le1\) 的实际价值）。
直觉 BP 就是"交作业不能只写开头"的扣分规则：写够了（\(l_c>l_r\)）不扣；写短了按短的比例指数扣。写成指数而不是线性或幂次，是为了在"刚好写够"这个临界点附近平滑过渡——你少写一个词不会被扣得比少写两个词多出一大截。
(12.7) BLEU 总分

本页小结：8 条公式串成一条线

  1. (12.1) → (12.3) 的推导链条是本页的主干。概率链式法则给出连乘 \(\prod_t p_t\)；(12.2) 取 \(-\frac1T\) 次幂做长度归一化（唯一能消掉 \(T\) 次幂增长的指数）；(12.3) 把同一个数换写成 \(\exp(-\frac1T\sum\ln p_t)\)，从而可计算。二者恒等，差异只在"输入形式"与"数值稳定性"。
  2. \(\mathrm{PPL}=e^{\mathrm{CE}}\)。训练损失与评测指标是同一个量的两种刻度；"有效分支因子"的读法统一了语言建模（\(V\) 词表的均匀基线）与 \(K\) 类分类（均匀基线给 \(K\)）。
  3. (12.4)–(12.6) 是集合层面的两个条件概率 + 调和平均。\(F_1=\frac{2\mathcal P\mathcal R}{\mathcal P+\mathcal R}=\frac{\mathcal P-\mathcal R}{2}-\frac{(\mathcal P-\mathcal R)^2}{2(\mathcal P+\mathcal R)}\) 的第二项解释了一切：不平衡被平方惩罚。
  4. (12.7)–(12.8) 是"几何平均 + 长度惩罚"的两块拼图。\(n\)-gram 截断计数的分母是有效长度 \(l_c^{\text{eff}}(n)=l_c-n+1\)，它给出 \(p_n\) 的上界；BP 在加权几何平均外面最多抵消一个长度比，\(x e^{1-x}\le1\) 保证总分不超过 1。

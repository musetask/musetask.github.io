前置小节：期望、极大似然与数值稳定性

后面每一条公式都会用到这四件事，先一次性推清楚。

C1 期望就是加权求和

随机变量 \(X\sim q\) 与函数 \(f\) 的期望，定义就是把"取值乘概率"加起来：连续情形写成积分，离散情形写成求和。

\[ \mathbb{E}_{X\sim q}\!\left[f(X)\right]=\int q(x)\,f(x)\,\mathrm{d}x \]

三个必须记住的性质（后面反复用）：① 期望是线性的，\(\mathbb{E}[aX+b]=a\mathbb{E}[X]+b\)，无论 \(X\) 与别的东西是否独立；② 期望存在当且仅当 \(\mathbb{E}[|f|]<\infty\)，有正有负的项要能收敛；③ 归一性 \(\int q(x)\,\mathrm{d}x=1\)，这是下面所有恒等变形的支点。

C2 极大似然 = 最小化负对数似然

设参数为 \(\theta\)，观测数据为 \(\{(x_i,\tilde r_i)\}_{i=1}^{N}\) i.i.d. 来自真实分布 \(q\)。极大似然估计（Maximum Likelihood Estimation, MLE）取让数据似然最大的 \(\theta\)：

\[ \hat\theta=\arg\max_\theta\; p_\theta(\text{data})=\arg\max_\theta\prod_{i=1}^{N}p_\theta(x_i,\tilde r_i) \]

连乘会指数下溢，且优化器需要光滑目标，于是取对数（对数是单调递增的，不改变 argmax）。再取负号把极大化变成极小化，得到负对数似然（Negative Log-Likelihood, NLL）：

\[ \mathcal{L}(\theta)=-\sum_{i=1}^{N}\log p_\theta(x_i,\tilde r_i)\;\xrightarrow{\text{期望}}\;\mathcal{L}(\theta)=-\mathbb{E}_{(x,\tilde r)\sim q}\!\left[\log p_\theta(x,\tilde r)\right] \]

最后一步是从样本平均换成期望：\(N\) 很大时样本均值逼近期望，做 SGD 时每个 mini-batch 就是这个期望的一个无偏估计。注意这里把 \(q\) 放在了数学下标里——这正是后面说"MSE 只是 MLE"的关键：损失函数的形式完全由你假设的噪声分布 \(p(\tilde r\mid r)\) 决定。

C3 平方损失 = 高斯噪声下的极大似然

假设标注者给的分数 \(\tilde r\) 围绕真实值 \(r_\theta(x,y)\) 服从方差为 \(\sigma^2\) 的高斯噪声：

\[ p(\tilde r\mid x,y)=\mathcal{N}\!\left(\tilde r;\,r_\theta(x,y),\,\sigma^2\right)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{\left(\tilde r-r_\theta(x,y)\right)^2}{2\sigma^2}\right) \]

取负对数：

\[ -\log p=-\log\frac{1}{\sqrt{2\pi\sigma^2}}+\frac{(\tilde r-r_\theta(x,y))^2}{2\sigma^2}=\text{const}+\frac{1}{2\sigma^2}\underbrace{\left(r_\theta(x,y)-\tilde r\right)^2}_{\text{平方误差}} \]

第一项与 \(\theta\) 无关，\(\sigma\) 是常数，所以"最小化 MSE"与"最小化 NLL"是同一个优化问题。推广一下：噪声分布换成 Laplace 就得到 L1 损失，换成分类分布（\(\tilde r\) 是"好/坏"标签）就得到交叉熵。损失函数不是选出来的，是噪声假设的推论。

易错点说"用 MSE 因为它效果好"是把因果说反了。正确说法是：我们假设标注噪声是零均值高斯的，MSE 是这个假设的结果。换个噪声假设，损失就该换；不换而声称"最优"是没有依据的。

C4 sigmoid 及其导数

\[ \sigma(z)=\frac{1}{1+e^{-z}},\qquad \sigma'(z)=\frac{e^{-z}}{(1+e^{-z})^2}=\sigma(z)\bigl(1-\sigma(z)\bigr)=\sigma(-z)\,\sigma(z) \]
  1. 对 \(z\) 求导：分母 \(1+e^{-z}\) 的导数是 \(-e^{-z}\)，套商的求导法则得 \(\frac{0\cdot(1+e^{-z})-1\cdot(-e^{-z})}{(1+e^{-z})^2}=\frac{e^{-z}}{(1+e^{-z})^2}\)。
  2. 注意 \(1-\sigma(z)=1-\frac{1}{1+e^{-z}}=\frac{e^{-z}}{1+e^{-z}}\)，把它乘进 \(\sigma(z)\) 正好得到上式——这是化简，不是巧合。
  3. 再注意 \(\sigma(-z)=1-\sigma(z)\)，于是 \(\sigma'(z)=\sigma(-z)\sigma(z)\)。
  4. 关键一步：\(\dfrac{\mathrm{d}}{\mathrm{d}z}\log\sigma(z)=\dfrac{\sigma'(z)}{\sigma(z)}=\sigma(-z)\)。log 把 sigmoid 导数里的一个 \(\sigma(z)\) 消掉了。这条会在 8.2 的梯度里直接用到。

C5 数值稳定性：为什么必须写 -logsigmoid

8.2 的损失是 \(-\log\sigma(z)\)。教科书写法是"先算 \(\sigma(z)\)，再取 log"，在实数域上完全正确，但在浮点域上会炸。原因是 \(\sigma(z)\) 在 \(z\) 很负时会下溢到 0，而中间的 \(e^{-z}\) 在 \(z\) 很负时会上溢。改用恒等变形：

\[ \log\sigma(z)=\log\frac{1}{1+e^{-z}}=-\log\!\left(1+e^{-z}\right)=-\operatorname{softplus}(-z),\qquad \operatorname{softplus}(x)\equiv\log(1+e^{x}) \]

于是 \(-\log\sigma(z)=\operatorname{softplus}(-z)=\log(1+e^{-z})\)。注意这个版本永远不需要算 \(\sigma\)。再看两种溢出：

  • 上溢：教科书写法里若 \(z=-800\)，要计算 \(e^{800}\)。float32 的最大有限数约 \(3.4\times10^{38}\)，float64 约 \(1.8\times10^{308}\)，所以 float32 在 \(z<-88.7\)、float64 在 \(z<-709\) 时直接变 inf，整个 batch 的损失变成 nan。而 \(z=-800\) 在训练中并不罕见——两个长文本的奖励差完全可能这么大。
  • 下溢：\(z=+40\) 时真实的 \(\log\sigma(40)\approx-4.2\times10^{-18}\)，但 float32 里 \(\sigma(40)\) 已经被舍入成 1.0，于是 \(\log\sigma=0\)，损失精确等于 0。数值上分不清"损失是 \(4\times10^{-18}\)"和"损失是 0"，梯度信息（\(\sigma(-40)\approx4\times10^{-18}\)）被完全抹掉。

稳定实现的关键是：让指数的自变量永远非正，这样 exp 的结果永远 \(\le 1\)。用恒等式 \(\log(1+e^{x})=\max(x,0)+\log(1+e^{-|x|})\) 分情况即可：

\[ \operatorname{softplus}(x)=\begin{cases} x+\log\left(1+e^{-x}\right), & x>0\\[2pt] \log\left(1+e^{x}\right), & x\le 0\end{cases}=\max(x,0)+\log\left(1+e^{-|x|}\right) \]
  • \(x>0\)：\(e^{x}\) 会爆，但 \(e^{-x}\in(0,1)\) 安全，\(\log(1+e^{x})=x+\log(1+e^{-x})\)（提取公因子 \(e^{x}\)）。此时结果约等于 \(x\)，没有任何精度损失。
  • \(x\le0\)：\(e^{x}\le1\) 天然安全，直接算。
  • 统一写法 \(\max(x,0)+\log(1+e^{-|x|})\)：两个分支合并，自变量恒为 \(-|x|\le0\)，是所有框架 softplus 的实际实现。

把 \(x=-z\) 代进去，损失就有了一个处处安全的表达式：

\[ \mathcal{L}=-\log\sigma(z)=\operatorname{softplus}(-z)=\max(-z,0)+\log\left(1+e^{-|z|}\right)=\min(z,0)-\log\left(1+e^{-|z|}\right) \]

对应的稳定实现（注意用 log1p 而不是 log(1+u)：当 \(u\) 很小时 \(1+u\) 在浮点下会舍入成 1，而 log1p(u) 直接算 \(\log(1+u)\) 的高精度版本）：

import torch
import torch.nn.functional as F

def logsigmoid(z):
    # log(sigmoid(z)) = -softplus(-z)，自变量恒 <= 0，永不上溢
    return F.softplus(-z)          # PyTorch 内部就是 max(x,0)+log1p(exp(-|x|))

def reward_pair_loss(r_pos, r_neg):
    # 8.2：-E[log sigma(r(x,y+) - r(x,y-))]
    z = r_pos - r_neg
    return -F.logsigmoid(z).mean()   # 或者 F.softplus(-z).mean()

# 等价写法：直接用融合算子，不要先 sigmoid 再 log
loss = F.binary_cross_entropy_with_logits(z, torch.ones_like(z), reduction='none')

# 等价写法：reward = beta * log(pi_theta / pi_ref) 时套同一个函数
logits = beta * (logp_pos - logp_ref_pos - logp_neg + logp_ref_neg)   # 这就是 DPO
直觉-logsigmoid 不是"数学家的写法"，而是"数值分析家的写法"。数学上 \(\log\sigma(z)\) 只有一种；计算机里 \(\log\sigma(z)\) 有无数种数值实现，其中绝大多数会在极端输入下失效。写对它的判据是：代码里不应出现 log(sigmoid(...)) 这个组合。看到它就要警惕。
本小节是 8.1、8.2、8.4、8.11、8.13 的公共前置，记住 C1–C5 即可。

(8.1)打分式训练：均方误差损失#

出处第 8 章 8.2.3 节 Reward Model Training · Scoring based method　对照原文

原书公式 8.1

① 公式

\[ \mathcal{L}=\mathbb{E}_{(x,y,\tilde r)\sim\mathcal{D}}\!\left[\left(r_\theta(x,y)-\tilde r\right)^2\right] \]

② 符号

符号含义形状 / 量纲
\(r_\theta(x,y)\)奖励模型的输出：\(r_\theta = \mathbf{w}^\top \mathrm{LM}_\theta(x,y)_{\text{last}} + b\)标量 \(\in\mathbb{R}\)
\(\tilde r\)标注者给的分数（如 0.9 / 0.6）标量，离散或连续
\((x,y,\tilde r)\sim\mathcal{D}\)三元组在数据集 \(\mathcal{D}\) 上独立同分布—
\(\mathcal{L}\)目标函数，取极小标量，单位"奖励"\({}^2\)

③ 推导

这条式子表面是回归，实质是极大似然。按前置小节 C3 展开：

  1. 建模标注噪声。假设 \(\tilde r \mid (x,y)\) 的条件分布是均值 \(r_\theta(x,y)\)、方差 \(\sigma^2\) 的正态分布（零均值噪声是"标注无系统偏差"的假设）。
  2. 写出似然。\(p_\theta(\tilde r\mid x,y)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(\tilde r-r_\theta(x,y))^2}{2\sigma^2}\right)\)。
  3. 取负对数。\(-\log p_\theta = \log\sqrt{2\pi\sigma^2}+\frac{(\tilde r-r_\theta)^2}{2\sigma^2}\)。第一项与 \(\theta\) 无关，求梯度时消失。
  4. 对数据取期望。\(\mathcal{L}(\theta)=-\mathbb{E}_{\mathcal{D}}[\log p_\theta]=\text{const}+\frac{1}{2\sigma^2}\mathbb{E}_{\mathcal{D}}\big[(r_\theta-\tilde r)^2\big]\)。
  5. 结论：\(\frac{1}{2\sigma^2}\) 是正的常数，不改变最优解，所以最小化 MSE \(\equiv\) 最小化高斯似然的 NLL。梯度为 \(\nabla_\theta\mathcal{L}=2\mathbb{E}[(r_\theta-\tilde r)\nabla_\theta r_\theta]\)。
  6. 闭式最优解（线性探针情形）：若 \(r_\theta=\mathbf{w}^\top\boldsymbol\phi(x,y)\)，则最优 \(\mathbf{w}^\ast\) 是 \(\mathbb{E}[\boldsymbol\phi\tilde r^{\top}]\,\mathbb{E}[\boldsymbol\phi\boldsymbol\phi^{\top}]^{-1}\)，即"用 \(\tilde r\) 对特征做最小二乘回归"。这说明它完全是一个监督回归任务。
直觉"让模型打的分和人类打的分一样"。做法非常朴素：把标注者的分数当成 ground truth，训一个回归器去拟合。工程上最简单，也是最早的做法。
为什么后来被放弃了三个结构性问题。
  • 回归到均值（regression to the mean）。最小化 \(\mathbb{E}[(r_\theta-\tilde r)^2]\) 关于 \(r_\theta\) 的一阶条件是 \(\mathbb{E}[r_\theta-\tilde r]=0\)，即 \(r_\theta(x,y)=\mathbb{E}[\tilde r\mid x,y]\)。所以模型拟合的必然是标注者的条件均值，而不是"最好的那个回答该得几分"。而人的打分高度集中在中间区间（大家都打 3 分、4 分），于是模型学到的分数被系统性压缩：好坏回答的差距在特征里被抹平，奖励信号分辨率下降。
  • 离群标注主导梯度。MSE 的梯度是 \(2(r_\theta-\tilde r)\)，误差越大梯度线性增长。一个被误标的样本（\(\tilde r=0\) 但回答其实很好）会持续、稳定地往一个方向拉参数；而对比损失的梯度带 \(\sigma(-\Delta r)\) 权重，饱和后自动衰减（见 8.2）。
  • 要求标注者的绝对刻度一致。宽松的标注者给 0.9，严格的给 0.6（原书举的例子）。MSE 把这两者当作相差 0.3 的真实差异去拟合，于是模型学到的是"标注者偏严程度"的混合，平均化之后谁都不像。
易错点"奖励被钻空子（reward hacking）/ 过度优化"这个坑常被误归到 8.1。其实因果链是：MSE 训练出的 \(r_\theta\) 同样只对训练分布的绝对分数负责，它的绝对刻度没有语义保证；后续 PPO 只管最大化 \(r_\theta\)，不会验证 \(r_\theta\) 在分布外是否还成立。所以只要 \(\max_y r_\theta(x,y)\) 与"人类认为好"有正相关但不完全一致，RL 就会把模型推向 \(r_\theta\) 的最高点——哪怕那里人类评价很差。奖励模型的漏洞一定会被策略优化找到并放大，这是 RLHF 的结构性问题，不是某个损失函数的局部缺陷。

(8.2)对比式训练：Bradley–Terry 负对数似然#

出处第 8 章 8.2.3 节 Reward Model Training · Contrast based method　对照原文

原书公式 8.2

① 公式

\[ \mathcal{L}=-\mathbb{E}_{(x,y^+,y^-)\sim\mathcal{D}}\!\left[\log\left(\sigma\left(r_\theta(x,y^+)-r_\theta(x,y^-)\right)\right)\right] \]

简记 \(\Delta r=r_\theta(x,y^+)-r_\theta(x,y^-)\)，则 \(\mathcal{L}=-\mathbb{E}[\log\sigma(\Delta r)]=\mathbb{E}[\operatorname{softplus}(-\Delta r)]\)。

② 符号

符号含义形状 / 量纲
\(y^+\)，\(y^-\)同一个输入下人类更喜欢 / 更不喜欢的两个输出token 序列
\(P(y^+\succ y^-\mid x)\)随机挑一位标注者，他选 \(y^+\) 的概率\([0,1]\)
\(r_\theta(x,y)\)奖励模型给"输入-输出"对的强度分标量
\(\Delta r\)奖励差，只依赖差值标量
\(\sigma\)sigmoid \(\frac{1}{1+e^{-z}}\)\((0,1)\)

③ 推导

第 1 步：从"人怎么选"到"强度模型"。人类的选择有随机性（同一对回答换个人可能反选），所以只能建模概率。我们为每个"输入-输出"对赋一个实数强度 \(r(x,y)\)，并假设

\[ P(y_w\succ y_l\mid x)=\frac{\exp r(x,y_w)}{\exp r(x,y_w)+\exp r(x,y_l)}=\sigma\!\left(r(x,y_w)-r(x,y_l)\right) \]

为什么是 sigmoid？可以从优势比（odds）倒推。设 \(p=P(y_w\succ y_l)\)。任何二选一模型都必须满足 \(p+(1-p)=1\)，而 Bradley–Terry 额外假设优势比只依赖强度差：

\[ \frac{p}{1-p}=\exp\!\left(r(x,y_w)-r(x,y_l)\right)\;\equiv\;e^{\Delta r} \]

这是一个关于 \(p\) 的一元一次方程，解出来 \(p=\frac{e^{\Delta r}}{1+e^{\Delta r}}=\sigma(\Delta r)\)，与上面的显式形式一致（分子分母同乘 \(e^{-r(x,y_l)}\)）。反过来，代入可验证两种写法恒等。所以 sigmoid 不是"选"出来的，而是"强度差取对数后等于优势比"这一假设的解；它同时保证了 \(r(x,y_w)>r(x,y_l)\iff p>\frac12\)，即奖励的序 = 偏好的序。

第 2 步：可识别性——奖励只能定到常数平移。损失里只出现差 \(\Delta r\)，所以把所有 \(r(x,y)\) 同时加上常数 \(c\)，似然一字不变：

\[ \sigma\big((r(x,y^+)+c)-(r(x,y^-)+c)\big)=\sigma(\Delta r) \]

因此从偏好数据原则上无法确定奖励的绝对零点（若标注者全打 5 分制，\(r\) 平移 5 也不改变任何预测）。更进一步：对固定的单个输入 \(x\)，只有该输入下各输出之间的差可识别（沿该输入的方向再平移也不变）。

怎么消掉这个自由度常见做法：(1) 用无偏置的输出头 \(r_\theta=\mathbf{w}^\top h\)（无 bias 项就没有可平移的自由度），或 (2) 显式约束 \(\mathbb{E}_{y\sim\pi_{\text{ref}}}[\log\text{stuff}]=0\)，或 (3) 干脆不管——因为下游（PPO、DPO、排序）全都只用差值，零点无所谓。这一点在读 DPO 论文里 \(r(x,y)=\beta\log\frac{\pi^*}{\pi_{\text{ref}}}+\beta\log Z(x)\) 那个含 \(\log Z\) 的式子时会再次出现：\(\log Z(x)\) 就是那个无法确定的配分函数。
易错点：还有一层不可识别性若把 sigmoid 换成带温度的形式 \(\sigma(\Delta r/\tau)\)，则 \((r,\tau)\mapsto(cr,c\tau)\) 给出一模一样的似然——尺度和温度同时被混淆。所以"奖励放大 2 倍"必须同时"温度放大 2 倍"才等价。这也解释了为什么 \(\beta\)（DPO 里的 KL 乘子）不是可以随手调的小超参：它和奖励尺度纠缠在一起。

第 3 步：传递性（为什么成对数据可以共存）。真实标注会自相矛盾（A>B、B>C、C>A 都出现过），这时"BT 模型存在"就无解。BT 的强项是：只要存在一个满足传递性的序，似然就非零。用实数直线上的标量 \(r\) 表示序，传递性自动成立。设 \(r_A>r_B\) 且 \(r_B>r_C\)，则

\[ r_A-r_C=\underbrace{(r_A-r_B)}_{>0}+\underbrace{(r_B-r_C)}_{>0}>0\;\Longrightarrow\;\sigma(r_A-r_C)>\frac12 \;\Longrightarrow\;P(A\succ C)>\frac12 \]

三步只用了加法与 \(\sigma\) 的单调性。注意随机性只来自 sigmoid 的 sigmoid 形软化——序本身是确定的。这是 BT 模型的精髓：确定性全序 + 单点随机扰动。

第 3.5 步：Bradley–Terry 定理（三元素条件）。反过来问：什么样的成对概率数据能被某个 \(r\) 复现？答案由三元素子集决定。对三个候选 \(1,2,3\)，记 \(p_{ij}=P(i\succ j)\)，则必要且充分条件是两个循环乘积相等：

\[ p_{12}\,p_{23}\,p_{31}=p_{21}\,p_{32}\,p_{13} \]

验证：代入 \(p_{ij}=\frac{e^{r_i}}{e^{r_i}+e^{r_j}}\)，得 \(\frac{e^{r_1}e^{r_2}e^{r_3}}{(e^{r_1}+e^{r_2})(e^{r_2}+e^{r_3})(e^{r_3}+e^{r_1})}=p_{21}p_{32}p_{13}\)，分子分母完全一样，条件成立。反之若某个三角形的循环乘积不等，则不存在任何 \(r\) 能同时满足这三个概率——这就是"偏好不一致"的形式化定义。

推广到 \(n\) 个候选：记 \(W_{ij}\) 为"j 战胜 i"的次数。BT 的极大似然解满足一阶条件，整理后是线性特征值方程 \(W\mathbf{r}=c\,\mathbf{r}\)，其中 \(c=\sum_j W_{ij}\)。因此 BT 强度 \(\mathbf{r}\) 就是 \(W\) 的主特征向量（Perron–Frobenius 定理：非负不可约矩阵有唯一正的、模最大的特征值）。

这条定理的实践含义做偏好数据清洗时，可以直接检查数据里是否含"三元素循环"，用来定位互相矛盾的标注。它也是 Listwise / Plackett–Luce 排序模型的出发点——如果 BT 假设不成立，可以放松为只要求"无环的部分序"存在，用拓扑排序 + 随机效用模型来拟合。

第 4 步：写出负对数似然。假设各条标注独立，则数据集 \(\mathcal{D}=\{(x_i,y_i^+,y_i^-)\}_{i=1}^{N}\) 的似然是各项相乘：

\[ p(\mathcal{D}\mid\theta)=\prod_{i=1}^{N}\sigma(\Delta r_i)\;\xrightarrow{\text{取负对数}}\;-\sum_{i=1}^{N}\log\sigma(\Delta r_i)\;\xrightarrow{\text{期望}}\;\mathcal{L}=-\mathbb{E}_{\mathcal{D}}\big[\log\sigma(\Delta r)\big] \]

为什么取负号：我们要最大化似然，而优化器只会做梯度下降（极小化），故乘以 \(-1\)。这一步不是"约定"，而是"极大似然 \(\to\) 极小化 NLL"的标准转换（见前置 C2）。

第 5 步：梯度。目标只通过标量 \(z=\Delta r\) 依赖 \(\theta\)，所以用链式法则（\(z=f(\theta)\) 时 \(\nabla_\theta g(z)=g'(z)\nabla_\theta z\)）：

\[ \nabla_\theta\mathcal{L}=-\mathbb{E}_{\mathcal{D}}\!\left[\frac{\mathrm{d}}{\mathrm{d}z}\log\sigma(z)\cdot\nabla_\theta z\right]=-\mathbb{E}_{\mathcal{D}}\!\left[\sigma(-z)\,\nabla_\theta\Delta r\right] \]

代入 \(z=\Delta r\)，并把 \(\nabla_\theta\Delta r=\nabla_\theta r_\theta(x,y^+)-\nabla_\theta r_\theta(x,y^-)\) 展开：

\[ \nabla_\theta\mathcal{L}=-\mathbb{E}_{\mathcal{D}}\!\left[\sigma(-\Delta r)\left(\nabla_\theta r_\theta(x,y^+)-\nabla_\theta r_\theta(x,y^-)\right)\right] \]

其中 \(\frac{\mathrm{d}}{\mathrm{d}z}\log\sigma(z)=\sigma(-z)\) 来自前置 C4 第 4 步。

第 6 步：读懂这个梯度的三重信息。

  • 方向正确。梯度下降 \(\theta\leftarrow\theta-\eta\nabla_\theta\mathcal{L}\) 等价于 \(\theta\leftarrow\theta+\eta\,\sigma(-\Delta r)\,[\nabla r(x,y^+)-\nabla r(x,y^-)]\)：抬高正例奖励、压低负例奖励。目标是"最大化分数差"，不是"抬高分数"——绝对值不动，这正是它对标注者松紧不敏感的原因。
  • 饱和。权重 \(\sigma(-\Delta r)\) 在 \(\Delta r\to+\infty\) 时趋于 0。已经分得很开的一对样本贡献的梯度指数级衰减，自动"毕业"。好处：不怕难负样本、不会被单个错标样本长期带偏；坏处：模型只在还没学会的样本上学习，必须持续注入新数据，否则损失很快不再下降（这被称为"偏好数据耗尽"）。
  • 与 DPO 同构。把 \(z\) 换成 \(z_{\text{DPO}}=\beta\big(\log\frac{\pi_\theta(y^+|x)}{\pi_{\text{ref}}(y^+|x)}-\log\frac{\pi_\theta(y^-|x)}{\pi_{\text{ref}}(y^-|x)}\big)\)，得到的 \(\nabla_\theta\mathcal{L}=-\mathbb{E}[\sigma(-z_{\text{DPO}})\nabla_\theta z_{\text{DPO}}]\) 形式完全相同。所以 DPO 可以理解成"把奖励模型换成策略模型与参考模型的对数比"，从而免掉显式训练 \(r_\theta\)（推导见本页末尾 延伸，编号公式 8.43 在第 11 页）。

第 7 步：凸性与驻点。作为 \(\Delta r\) 的函数，\(\mathcal{L}=\operatorname{softplus}(-\Delta r)\) 是凸的、二阶导 \(\sigma(-z)\sigma(z)>0\)，唯一极小点在 \(z=0\)（即 \(P=\frac12\)，完全不确定）。但作为 \(\theta\) 的函数，\(r_\theta\) 是神经网络，\(\mathcal{L}\) 非凸，一阶条件 \(\nabla_\theta\mathcal{L}=0\) 只是"这个方向上不下坡"，不等于全局最优——和所有深度学习一样。

直觉不需要标注者打出"3 分还是 4 分"，只需要回答"这两个里你更想要哪个"。人的绝对尺度混乱（有人打 4 分是"优秀"，有人打 4 分是"及格"），但同一时刻的两个人对同一对回答的相对判断要一致得多。BT 损失只吃相对判断，扔掉了不可靠的绝对刻度——这是它比 8.1 好的根本原因，不是"它更精巧"。
关于可识别性的第二层：数据不足时更糟如果某个 \(x\) 只被标注了很少几对，甚至只标了一对（\(y^+\succ y^-\)），那么 \(r(x,y^+)-r(x,y^-)\) 的数值大小完全没被约束（只有符号被约束），梯度可以无限把这个差推大。所以实践中要对 \(\Delta r\) 做 clip，或者干脆用 pairwise ranking 的 hinge / margin 损失。

(8.3)排序式训练：对所有有序对取期望#

出处第 8 章 8.2.3 节 Reward Model Training · Ranking based method　对照原文

原书公式 8.3

① 公式

\[ \mathcal{L}=-\mathbb{E}_{(x,y_1,\dots,y_K)\sim\mathcal{D}}\;\mathbb{E}_{(y^+,y^-)\subset\{y_1,\dots,y_K\}}\!\left[\log\left(\sigma\left(r_\theta(x,y^+)-r_\theta(x,y^-)\right)\right)\right] \]

② 符号

符号含义形状 / 量纲
\(K\)同一输入下被标注排序的候选回答数正整数，常取 \(4\sim9\)
\((y^+,y^-)\subset\{y_1,\dots,y_K\}\)从候选集中按序抽一对，\(y^+\) 排在 \(y^-\) 之前共 \(\frac{K(K-1)}{2}\) 种取法
内层 \(\mathbb{E}\)对所有满足偏序的有序对求平均标量

③ 推导

  1. 看清这是嵌套期望。外层对"输入 + \(K\) 个候选 + 排序结果"取期望（数据层面），内层对"这一组候选内部的所有有序对"取期望（组内枚举）。写成求和形式最清楚： \(\mathcal{L}=-\frac{1}{N}\sum_{i=1}^{N}\frac{2}{K(K-1)}\sum_{a=1}^{K}\sum_{b=a+1}^{K}\log\sigma\big(r_\theta(x_i,y_a)-r_\theta(x_i,y_b)\big)\)。
  2. 8.2 是它的特例。取 \(K=2\)，内层只有一对，8.3 逐字退化成 8.2。所以 8.3 不是新损失，而是"把同样的 BT 项在更密的偏序上求平均"。
  3. 为什么内层可以这样平均。因为对固定的候选集，\(\{(y^+,y^-):y^+\succ y^-\}\) 上的均匀平均就是"任取一对符合偏序的有序对"的期望——一个对称性论证，\(K\) 个候选的完全排序下所有 \(\frac{K(K-1)}2\) 对地位平等。
  4. 与 Listwise / Plackett–Luce 的关系。若人类排序本身服从 Plackett–Luce（每次从候选里按 softmax 权重抽一个最优者，重复到排完），则整个排序的概率是 \(\prod_{j=1}^{K}\frac{e^{r_j}}{\sum_{i\ge j}e^{r_i}}\)，其 NLL 可以展开成"逐步 softmax 交叉熵"；而 \(\frac{2}{K(K-1)}\sum_{a<b}\) 这个成对平均正是它的一个无偏、方差更小的等价目标（这是 RRHF 的做法，见 8.36 附近）。
  5. 为什么"排序比成对更好"。两条理由：(a) 信息量：\(K\) 个候选给出 \(\log_2 K!\) 比特的序信息，\(K=2\) 只有 1 比特；(b) 梯度信号密度：每个输入贡献 \(\frac{K(K-1)}2\) 项而不是 1 项，方差小得多，收敛更快。
  6. 代价：\(O(K^2)\) 的枚举开销。\(K=9\) 就是 36 个前向，实践中不可接受。两种补救：(i) 从 \(\frac{K(K-1)}2\) 对里随机抽 \(m\) 对（\(m=2\sim8\)），其余靠无偏性丢弃；(ii) 用 listwise 的 softmax 一次算完，但梯度结构变了（不再有 \(\sigma(-\Delta r)\) 的自动饱和）。
直觉8.2 问"这两句哪句更好"，8.3 问"这五句从好到差怎么排"。人类其实更容易给出后者——排序比两两比较快，而且标注者之间的一致性更高（不用反复做 36 次两两决策）。
易错点内层期望的归一化方式决定了这个损失到底在优化什么。若不除以 \(\frac{K(K-1)}2\)，长列表样本天然获得更大权重，梯度会被"候选多的输入"主导。同时注意 8.3 假设标注给的是全序（无并列）；若允许并列，\(\frac{K(K-1)}2\) 这个归一化就不对了，要改成"有效对数"。

(8.4)对比损失 + 正例语言建模正则项#

出处第 8 章 8.2.3 节 Reward Model Training · Objective function optimization　对照原文

原书公式 8.4

① 公式

\[ \mathcal{L}=-\mathbb{E}_{(x,y^+,y^-)\sim\mathcal{D}}\!\left[\log\left(\sigma\left(r_\theta(x,y^+)-r_\theta(x,y^-)\right)\right)\right]-\beta\,\mathbb{E}_{(x,y^+)\sim\mathcal{D}}\!\left[\sum_{t=1}^{T}\log\left(y^+_t\mid x,y^+_{<t}\right)\right] \]

② 符号

符号含义形状 / 量纲
\(y^+_t\)正例的第 \(t\) 个 token词表中的一个 id
\(y^+_{<t}=(y^+_1,\dots,y^+_{t-1})\)teacher forcing 用的前缀（真值，不是模型采样）长度 \(t-1\)
\(\log p_\theta(y^+_t\mid x,y^+_{<t})\)自回归交叉熵的单项，\(\le0\)标量，单位 nat
\(T\)正例的 token 数正整数
\(\beta\)语言建模项的权重无量纲超参

③ 推导

  1. 看清符号。第二项前面是 负号，而它括号里的求和是 \(\le0\)。所以 \(\mathcal{L}\) 是"对比 NLL + \(\beta\times\)（语言建模 NLL）"，即两项 NLL 的加权和： \(\mathcal{L}=\mathcal{L}_{\text{contrast}}+\beta\,\mathcal{L}_{\text{LM}}\)，其中 \(\mathcal{L}_{\text{LM}}=-\sum_t\log p_\theta(y^+_t\mid x,y^+_{<t})\)。
  2. 为什么加这一项。动机是正则化：偏好数据集通常只有几万到几十万对，奖励模型（几 B 参数）极易过拟合——训练集准确率 95%、验证集 60%。加一项"在正例上做普通 SFT"相当于给共享的 backbone 施加一个强而稠密的监督信号（每条样本贡献 \(T\) 个 token 的梯度，而对比项只贡献 2 个），迫使 backbone 保持语言建模能力，不至于为了区分两个回答而把表征压成一维。
  3. 为什么能一石二鸟。附带的好处是：奖励模型在推理时只输出标量，但共享 backbone 仍记得怎么"写好回答"，于是从初始化好的奖励模型可以直接当作一个可用的生成模型。InstructGPT 的做法正是用 SFT 模型同时初始化策略模型和奖励模型。
  4. 怎么实现。正例的 \(\log p_\theta\) 就是标准交叉熵：把 \([x;y^+]\) 拼成一条序列，过一遍 lm_head 得 logits，与右移一位的 token id 算 CrossEntropyLoss。原书代码片段里的 _forward_lmloss 正是这件事。
class RmHead(nn.Module):
    def forward(self, sent1, sent2, prompt_ids, lm_attn_mask, response_ids):
        h1 = self.model(input_ids=sent1, attention_mask=..., return_dict=True).last_hidden_state
        h2 = self.model(input_ids=sent2, attention_mask=..., return_dict=True).last_hidden_state
        # 只取最后一个非 pad 位置的隐状态，过无偏置线性头
        r_pos = self.reward_head(h1[:, -1]).squeeze(-1)      # [B]
        r_neg = self.reward_head(h2[:, -1]).squeeze(-1)      # [B]
        loss_contrast = F.softplus(-(r_pos - r_neg)).mean()  # 8.2，稳定实现

        out = self.model(input_ids=prompt_ids, attention_mask=lm_attn_mask).logits
        loss_lm = F.cross_entropy(out[:, :-1].reshape(-1, V), response_ids[:, 1:].reshape(-1))
        return loss_contrast + beta * loss_lm                  # 8.4
直觉"既要会打分，也要会写话。"对比项教会模型区分，语言建模项教会模型生成；两者共用一个 backbone，等于用生成任务给判别任务做正则。
易错点：两项的量纲不一致\(\mathcal{L}_{\text{contrast}}\) 的单位是"奖励"，\(\mathcal{L}_{\text{LM}}\) 的单位是"nat"，它们的比值没有物理意义，所以 \(\beta\) 完全依赖调参，换个奖励头初始化就得重调。更隐蔽的坑：语言建模项是对 \(T\) 求和的，所以长回答的权重天然是短回答的若干倍；如果 batch 内长度差异大，梯度会被长样本主导。实现里常见两个变通——改成按 token 平均，或把 \(\beta\) 与平均长度挂钩。

(8.5)多奖励模型的加权合并#

出处第 8 章 8.2.3 节 Reward Model Training · Reward calculation method　对照原文

原书公式 8.5

① 公式

\[ r(x,y)=\sum_{i=1}^{n}\lambda_i\times r_i(x,y) \]

② 符号

符号含义形状 / 量纲
\(n\)专项奖励模型个数（=对齐标准个数）正整数，LLaMA-2 取 2（helpfulness / harmlessness）
\(r_i(x,y)\)第 \(i\) 个标准下的奖励标量，量纲随 \(i\) 而异
\(\lambda_i\)第 \(i\) 个标准的权重（重要程度）标量，常取 \(\lambda_i>0\)，可归一化使 \(\sum\lambda_i=1\)

③ 推导

  1. 这是多目标标量化（scalarization）。我们不是要求每个标准都最优（那多半无解），而是把 \(n\) 个目标折成一个标量。前提是所有 \(r_i\) 已训练好且已固定，只训 \(\lambda\) 或直接手调。
  2. 为什么取加权和而不是其他聚合。几个候选：
    • 加权和（8.5）：线性、可微、梯度 \(\nabla_\theta r=\sum_i\lambda_i\nabla_\theta r_i\)，每个标准都能拿到梯度。缺点是无法表达非互斥目标：两个标准冲突时会给出 0 分，而 0 分可能被误读为"不好"。
    • 加权几何平均 \(\prod_i r_i^{\lambda_i}\)：任一标准为 0 则整体为 0，强制每个标准都达标。对齐里常用（"有害性权重取乘法"）。
    • 硬约束 / gating：LLaMA-2 的实际做法就是这一类——分别训练 helpfulness RM 和 harmlessness RM，用一个二分类的 gating 机制选择用哪个（早期版本取 \(\max(r_{\text{safety}},r_{\text{help}})\)，或 safety 分数超过阈值就拒答），而不是把它们加权成一个标量。
  3. 量纲问题必须处理。\(r_1\) 可能是"1–5 分制"，\(r_2\) 是"0–1 的概率"，直接 \(\lambda_1 r_1+\lambda_2 r_2\) 里 \(\lambda\) 被迫吸收尺度差，"把 helpfulness 权重设为 0.7"这句话就失去了意义。实践做法：先把每个 \(r_i\) 用固定的分位数（如训练集 5% / 95% 分位）归一化到 \([0,1]\)，再调 \(\lambda\)。或者用 softmax 权重 \(\lambda_i=\frac{e^{w_i}}{\sum_j e^{w_j}}\)，这样 \(w\in\mathbb{R}^n\) 可以无约束地梯度下降。
  4. 校验"单一标量够用"。8.5 隐含一个强假设：存在一组固定 \(\lambda\)，使得加权和与人类综合判断同序。可以用 8.2 那套 BT 拟合检验：把 \(r=\sum\lambda_i r_i\) 当成强度，检验三元素循环条件是否成立；不成立说明单一标量表达力不够，得上 Pareto 前沿或分标准训练。
直觉像做菜：一个厨师管"好吃"（helpfulness），一个管"安全"（harmlessness）。8.5 说"总评 = 加权求和"；LLaMA-2 说"先让安全的人把不合格的毙掉，剩下的再让好吃的人打分"——后者更接近现实，因为安全和帮助经常不是可比的量。
易错点加权求和把"无冲突"和"完全抵消"混为一谈：\(\lambda_1 r_1+\lambda_2 r_2=0\) 既可能是"两个都平庸"，也可能是"极安全 + 极不友好"。下游 PPO 看不到区别，会把这两种状态一视同仁地继续优化。若对齐准则之间存在硬性底线（例如"有害性"不可为正），就不该用线性加和。
相关：(8.2) 单奖励模型的 BT 拟合　(8.6) 合并后的 \(r\) 如何进入 RL 目标

(8.6)强化学习目标：最大化期望累积回报#

出处第 8 章 8.2.4 节 Reinforcement Learning for Alignment　对照原文

原书公式 8.6

① 公式

\[ \mathcal{J}(\theta)=\arg\max_\theta\;\mathbb{E}_{\tau\sim P_\theta}\!\left[R(\tau)\right]=\arg\max_\theta\sum_{\tau}R(\tau)P_\theta(\tau) \]

② 符号

符号含义形状 / 量纲
\(\tau=\{a_1,\dots,a_T\}\)轨迹（一整段生成）长度 \(T\) 的动作序列
\(R(\tau)=\sum_{t=1}^{T}r_t\)累积回报（cumulative reward）标量，单位"奖励"
\(P_\theta(\tau)\)策略 \(\pi_\theta\) 走出 \(\tau\) 的概率\([0,1]\)
\(\mathcal{T}_{\text{all}}\)所有可能轨迹的集合，基数 \(=|\mathcal{V}|^{T}\)有限但天文大
\(\mathcal{J}(\theta)\)目标函数值（严格说 \(\mathcal{J}\) 是函数，\(\arg\max\) 的结果是 \(\theta^\ast\)）标量

③ 推导

  1. 从定义出发。策略 \(\pi_\theta(a_t\mid s_t)\) 是马尔可夫的：给定当前状态选动作的概率只依赖状态。轨迹概率按概率的乘法公式连乘： \(P_\theta(\tau)=\Pr(a_1,\dots,a_T\mid\pi_\theta)=\prod_{t=1}^{T}\pi_\theta(a_t\mid s_t)\)。
  2. 语言模型的对应关系。状态是"用户输入 + 已生成的前缀"，动作是"下一个 token"： \(s_t=(x,y_{<t}),\;a_t=y_t,\;\pi_\theta(a_t\mid s_t)=\frac{\exp z_t}{\sum_{v\in\mathcal{V}}\exp z_v}\)（\(z_t\) 是 lm_head 的输出 logit）。轨迹 \(\tau\) 就是一次完整回复 \(y=y_{1:T}\)，长度 \(T\) 是自回归步数。
  3. 期望展开为求和。按前置 C1，\(\mathbb{E}_{\tau\sim P_\theta}[R(\tau)]=\sum_{\tau}P_\theta(\tau)R(\tau)\)（离散轨迹空间；连续时写成积分）。这个恒等变形是整条策略梯度推导的起点：它把"对分布求期望"变成"对每条轨迹按概率加权求和"，从而可以用采样近似。
  4. 轨迹空间有限但不可枚举。词表 \(|\mathcal{V}|\approx10^5\)，生成 512 个 token，总轨迹数 \(10^5{}^{512}\)——所以第二项永远不能直接算，只能采样。这是 8.12 存在的全部理由。
  5. RLHF 里 \(R(\tau)\) 的特殊形式。一般 RL 逐步给 \(r_t\)，但 RLHF 几乎只用终止奖励：\(r_T=r_\phi(x,y)\)，其余 \(r_t=0\)。这就是为什么 PPO 还需要一个 critic（见 8.13）——回报只在末尾出现，信号极稀疏。
  6. 注意没有 KL 约束。（8.6）如果原样优化，\(\max_\theta\mathbb{E}[r_\theta(x,y)]\) 的最优解是"只生成 \(r_\theta\) 最高的那个 token 序列"，模型会立刻坍缩成复读机。实践中必须在目标里加 KL 惩罚 \(\beta\,\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})\)（PPO 的 KL 惩罚形式见 8.21，DPO 把它写进对偶问题里，见本页 延伸）。
直觉语言模型就是策略：状态是已经写下的文字，动作是下一个字，奖励是整段回答末尾由奖励模型给的一个分数。目标只有一句话——让"整段回答的期望得分"尽量高。
易错点：记号不严谨严格来说 \(\mathcal{J}(\theta)=\mathbb{E}[R(\tau)]\) 是一个函数，而 \(\theta^\ast=\arg\max_\theta\mathcal{J}(\theta)\) 才是最优点。原书把 \(\arg\max\) 写在等号左边是简写，读的时候要自己补上这层区分。另外 \(\mathcal{J}\) 关于 \(\theta\) 高度非凸（策略网络的参数空间），所以（8.6）只保证有驻点，不保证找得到——这是所有 RL 算法都需要 KL 约束、重要性采样、裁剪等一系列稳定化手段的根本原因。
相关：(8.5) 合并后的 \(r\) 作为 \(r_T\)　(8.7) 对它求梯度

(8.7)对参数求梯度：策略梯度定理的第一步#

出处第 8 章 8.2.4 节 · Policy gradient　对照原文

原书公式 8.7

① 公式

\[ \nabla\mathcal{J}(\theta)=\sum_{\tau}R(\tau)\,\nabla P_\theta(\tau) \]

② 符号

符号含义形状 / 量纲
\(\nabla P_\theta(\tau)\)概率对参数的梯度，第 \(j\) 分量是 \(\frac{\partial P_\theta(\tau)}{\partial\theta_j}\)向量 \(\in\mathbb{R}^{|\theta|}\)（\(\theta\in\mathbb{R}^d\) 时）
\(R(\tau)\)外部环境给的、与 \(\theta\) 无关的常数标量
\(\nabla\mathcal{J}(\theta)\)目标对参数的梯度向量 \(\in\mathbb{R}^{d}\)

③ 推导

  1. 用和的求导法则。（8.6）右端是有限求和 \(\sum_\tau R(\tau)P_\theta(\tau)\)，对每个 \(\theta_j\) 逐项求导再相加：\(\frac{\partial\mathcal{J}}{\partial\theta_j}=\sum_\tau R(\tau)\frac{\partial P_\theta(\tau)}{\partial\theta_j}\)。因为只有 \(P_\theta\) 依赖 \(\theta\)，其余为常数。
  2. 把分量形式写成向量形式。按"分母布局"约定，\(\nabla_\theta f=\left(\frac{\partial f}{\partial\theta_1},\dots,\frac{\partial f}{\partial\theta_d}\right)^{\top}\)（梯度为行向量/列向量不影响后续内积）。逐分量等式与向量等式 \(\nabla_\theta\mathcal{J}=\sum_\tau R(\tau)\nabla_\theta P_\theta(\tau)\) 完全等价。
  3. \(R(\tau)\) 移到求和号外。因为它与 \(\theta\) 无关（奖励由冻结的奖励模型给出），可以当常数提出：\(\nabla_\theta\mathcal{J}=\nabla_\theta\big[\sum_\tau R(\tau)P_\theta(\tau)\big]\)。这一步是策略梯度能成立的关键——如果 \(R\) 依赖 \(\theta\)，就会多出一项含 \(\nabla_\theta R\) 的项，整个推导要重做。
  4. 为什么这个式子还不可用。它要求对所有轨迹求和（含 \(10^{5}{}^{512}\) 项）。所以接下来三步（8.10–8.12）要把它改写成可用采样估计的形式。
直觉"总分的梯度 = 每条轨迹的分数 × 这条轨迹的概率的梯度。"看起来很自然对吧？但直接实现会遇到两个麻烦：求和项数天文大，以及 \(\nabla P_\theta(\tau)\) 里含 \(\theta\) 的高次幂（因为 \(P_\theta=\prod_t\pi_\theta\)，一阶导就会展开成 \(T\) 个乘积的求和）。8.10–8.11 就是在消掉这两个麻烦。
易错点这一式在数学上完全正确，但不能直接用来写代码：它没有 \(\nabla_\theta R\)，所以看起来"免费"；而且 \(P_\theta(\tau)\) 若在浮点下溢为 0，\(\nabla P_\theta(\tau)\) 也为 0，梯度静默消失。务必走到 8.11 的 score 形式再实现。
相关：(8.6) 被求导的目标　(8.9) 采样场景下的重述　(8.11) 变成可用的 score 形式

(8.8)梯度上升更新规则#

出处第 8 章 8.2.4 节 · Policy gradient　对照原文

原书公式 8.8

① 公式

\[ \theta\leftarrow\theta+\eta\nabla\mathcal{J}(\theta) \]

② 符号

符号含义形状 / 量纲
\(\eta\)学习率（步长）标量超参
\(\theta\leftarrow\cdot\)参数原地更新（in-place update）\(\mathbb{R}^{d}\)
\(+\)梯度上升；若把目标改写成损失 \(\mathcal{L}=-\mathcal{J}\) 再下降，则等价于 \(\theta\leftarrow\theta-\eta\nabla_\theta\mathcal{L}\)—

③ 推导

  1. 来源。把 8.7 的结果代进一阶泰勒展开。设 \(\theta'=\theta+\Delta\)，则 \(\mathcal{J}(\theta')\approx\mathcal{J}(\theta)+\nabla_\theta\mathcal{J}(\theta)^{\top}\Delta\)。要最大化，取 \(\Delta=\eta\nabla_\theta\mathcal{J}\)，得到 \(\mathcal{J}(\theta+\eta\nabla\mathcal{J})=\mathcal{J}(\theta)+\eta\|\nabla\mathcal{J}\|^2\)——只要梯度非零就严格上升。
  2. 符号为什么是加号。因为要极大化回报。如果改写成"极小化损失"，符号翻转：定义 \(\mathcal{L}(\theta)=-\mathcal{J}(\theta)\)，则 \(\nabla\mathcal{L}=-\nabla\mathcal{J}\)，\(\theta\leftarrow\theta-\eta\nabla\mathcal{L}=\theta+\eta\nabla\mathcal{J}\)，完全一样。所以（8.8）和深度学习里的 \(\theta\leftarrow\theta-\eta\nabla\mathcal{L}\) 是同一件事，只是约定不同。
  3. 为什么是"随机"梯度上升。实践里 \(\nabla\mathcal{J}(\theta)\) 用 mini-batch 采样估计（8.12），所以每步只沿估计方向走。这是 SGD/Adam 的标准做法，理论保证是"收敛到驻点集合"，不保证全局最优（8.6 已说明目标非凸）。
  4. 这个式子太朴素，实际不能直接用。三个问题：① 固定步长 \(\eta\) 无法适应梯度尺度的剧变；② 非凸 + 高方差 → 需要动量/自适应学习率；③ 最要紧的：没有稳定化机制，一步更新可能让策略骤变、采样分布立刻失效。PPO 的裁剪目标（8.20）就是给这一步加的护栏。
直觉"朝期望回报上升最快的方向迈一小步。"公式本身只有一句话，难点全在 \(\nabla\mathcal{J}\) 怎么算、步子怎么迈稳——那就是 8.9–8.16 和下一页的 PPO 在做的事。
相关：(8.7) 梯度从哪来　下一页 (8.20) PPO 裁剪目标

(8.9)采样设定下的目标重述#

出处第 8 章 8.2.4 节 · Policy gradient（当在决策空间 \(\mathcal{T}\) 内采样时目标的重述）　对照原文

原书公式 8.9

① 公式

\[ \nabla\mathcal{J}(\theta)=\sum_{\tau}R(\tau)\nabla P_\theta(\tau) \]

形式与（8.7）逐字相同；区别纯粹在求和域：\(\sum_{\tau}\) 现在只遍历采样得到的轨迹集合 \(\mathcal{T}\)，而 \(\mathcal{T}\) 是 \(\mathcal{T}_{\text{all}}\) 的一个子集。

② 符号

符号含义形状 / 量纲
\(\mathcal{T}\)本次迭代采样出的 \(N\) 条轨迹的集合有限集，\(|\mathcal{T}|=N\)
\(\mathcal{T}_{\text{all}}\)所有可能轨迹的集合（\(|\mathcal{V}|^{T}\) 条）不可枚举

③ 推导

  1. 为什么要重述。（8.7）的求和遍历 \(\mathcal{T}_{\text{all}}\)，需要 \(10^{5}{}^{512}\) 次求导，不可行。策略梯度的思路是：既然期望是加权平均，那就采样一批轨迹、只算这批的加权和。
  2. 为什么"照抄原式"就够了。因为从（8.7）到（8.12）的三步恒等变形（乘 \(1\)、换成 \(\nabla\log\)、换成样本均值）对 \(\tau\) 的求和域没有任何要求——它们对 \(\mathcal{T}_{\text{all}}\) 和 \(\mathcal{T}\) 都成立。所以原书在这里只是把 8.7 重新念一遍，读者需要自己记住"求和域变了"这个语义变化。
  3. 把语义写清楚。正确写法是 \(\nabla\mathcal{J}(\theta)\approx\sum_{\tau\in\mathcal{T}}R(\tau)\nabla P_\theta(\tau)\)，其中 \(\approx\) 来自采样。如果误以为这一步是恒等式，就会得出"梯度等于这批样本梯度的无归一化和"，从而丢掉后续的 \(1/N\) 因子，步长被放大 \(N\) 倍——这是策略梯度实现里一个真实会踩的坑。
  4. On-policy 的代价。采样轨迹的分布是 \(P_{\theta_{\text{old}}}\)，而我们在优化 \(P_\theta\)。所以每更新一次参数，旧轨迹就"过期"了，必须重新采样（on-policy），数据利用率极低——一批数据只能用一次。PPO 用重要性采样（8.15–8.18）来缓解。
直觉（8.7）和（8.9）长得一样，就像"对全国求平均"和"对抽样的 1000 人求平均"写的是同一个式子。区别只在"对谁求和"，而这决定了后面所有 \(1/N\)、重要性权重的出现。
相关：(8.7) 全轨迹版本　(8.10) 下一步恒等变形

(8.10)乘上 \(\frac{P_\theta(\tau)}{P_\theta(\tau)}\)，为 score 铺路#

出处第 8 章 8.2.4 节 · Policy gradient（第 2 步）　对照原文

原书公式 8.10

① 公式

\[ =\sum_{\tau}R(\tau)\,\frac{P_\theta(\tau)}{P_\theta(\tau)}\,\nabla P_\theta(\tau) \]

② 符号

符号含义形状 / 量纲
\(\frac{P_\theta(\tau)}{P_\theta(\tau)}\)恒等于 1 的哑因子（dummy factor）无量纲
其作用把 \(P_\theta\) 从"求导对象"变成"被求导对象的因子"，从而造出 \(\log\) 的机会—

③ 推导

  1. 这一步是恒等变形，不是新等式。对 \(P_\theta(\tau)\neq0\) 有 \(\frac{P_\theta(\tau)}{P_\theta(\tau)}=1\)，所以右端与 8.9 完全相等。（\(P_\theta(\tau)=0\) 的轨迹本来对梯度的贡献也是 0，形式上的 \(0/0\) 可以理解为跳过。）
  2. 为什么非做不可。因为下一条恒等式是 \(\nabla P_\theta(\tau)=P_\theta(\tau)\nabla\log P_\theta(\tau)\)。它的左边是"概率的梯度"，不可算——因为 \(P_\theta(\tau)=\prod_{t=1}^{T}\pi_\theta(a_t\mid s_t)\)，对它求导要展开成 \(T\) 项乘积之和，其中每一项都是 \(T-1\) 个概率的乘积，数值上又小又容易下溢。右边的 \(\nabla_\theta\log P_\theta=\sum_t\nabla_\theta\log\pi_\theta\) 是和，每一项只依赖当前一步，稳定且廉价。
  3. 所以这步的唯一目的是"造出因子"：只有先在前面摆一个 \(P_\theta(\tau)\)，才能把它配对到 \(\nabla P_\theta(\tau)\) 上，凑成 \(P\cdot\nabla\log P\)。这是全章最典型的"凑形式"技巧，值得记住套路：想让 \(\nabla f\) 变成 \(f\cdot\nabla\log f\)，就先乘一个 \(f/f\)。
  4. 从链条法则验证这个恒等式。取 \(f=P_\theta(\tau)>0\)，复合函数 \(g(u)=\log u\)，则 \(\nabla_\theta f=f\cdot\nabla_\theta\log f\)（对向量 \(\theta\) 逐分量成立）。等价地 \(\nabla_\theta\log f=\frac{\nabla_\theta f}{f}\)。
  5. 这一步的隐含代价。计算 \(\log P_\theta(\tau)\) 需要前向传播一次策略模型，而 \(\nabla P_\theta(\tau)\) 只需反向传播。所以引入 \(P_\theta\) 不是纯符号操作——它换来了"可实现性"，代价是内存/时间上多一次前向（同一 batch 内所有轨迹共享这次前向）。
直觉这一行什么都没说，是纯代数 gymnastics。但它是整条策略梯度链的枢纽：把"难以计算的导数"换成"对数概率的导数"，正是所谓 score function trick（也叫 REINFORCE 技巧、likelihood ratio trick）。
相关：(8.9) 上一步　(8.11) 恒等式生效处

(8.11)换成 score 形式：策略梯度定理#

出处第 8 章 8.2.4 节 · Policy gradient（第 3 步）　对照原文

原书公式 8.11

① 公式

\[ =\sum_{\tau}P_\theta(\tau)\,R(\tau)\,\nabla\log\left(P_\theta(\tau)\right) \]

利用 \(\sum_\tau P_\theta(\tau)\nabla\log P_\theta(\tau)=\sum_\tau\nabla P_\theta(\tau)=\nabla\sum_\tau P_\theta(\tau)=\nabla1=\mathbf{0}\)，等价地写成期望形式：

\[ \nabla_\theta\mathcal{J}(\theta)=\mathbb{E}_{\tau\sim P_\theta}\!\left[R(\tau)\,\nabla_\theta\log P_\theta(\tau)\right] \]

② 符号

符号含义形状 / 量纲
\(\nabla_\theta\log P_\theta(\tau)\)对数概率的梯度（score）向量 \(\in\mathbb{R}^{d}\)
\(\nabla_\theta\log\pi_\theta(a_t\mid s_t)\)由链式法则拆出的逐步 score向量
\(P_\theta(\tau)R(\tau)\nabla\log P_\theta(\tau)\)每条轨迹对总梯度的贡献向量

③ 推导

  1. 代入 8.10 并用恒等式。把 8.10 里的 \(\frac{P_\theta}{P_\theta}\) 与 \(\nabla P_\theta\) 配对：\(\frac{P_\theta}{P_\theta}\nabla P_\theta=\nabla_\theta\left(P_\theta\log P_\theta-P_\theta\right)\)，验证——\(\frac{\mathrm{d}}{\mathrm{d}\theta}(P\log P-P)=P'\log P+P\frac{P'}{P}-P'=P'\log P+P'-P'=P'\log P\)。取 \(\theta=\log P\) 方向即得 \(P\cdot\nabla\log P=\nabla P\)。这一步用"验证法"比"口诀法"更不容易搞错。
  2. 换成期望形式（把求和读成加权平均）。由前置 C1，\(\sum_\tau P_\theta(\tau)g(\tau)=\mathbb{E}_{\tau\sim P_\theta}[g(\tau)]\)，取 \(g(\tau)=R(\tau)\nabla\log P_\theta(\tau)\) 即得。
  3. 逐步展开 score——这才是能写代码的版本。用链式法则与对数的可加性（\(\log\prod=\sum\log\)）： \(\nabla_\theta\log P_\theta(\tau)=\nabla_\theta\sum_{t=1}^{T}\log\pi_\theta(a_t\mid s_t)=\sum_{t=1}^{T}\nabla_\theta\log\pi_\theta(a_t\mid s_t)\)。 代入得 \(\nabla_\theta\mathcal{J}=\mathbb{E}_\tau\left[R(\tau)\sum_{t=1}^{T}\nabla_\theta\log\pi_\theta(a_t\mid s_t)\right]\)。每一步的 score 只需一次 token 级前向的反向传播，这就是 (8.11) 相对 (8.7) 的全部实用价值。
  4. 为什么能省掉一整类项（reparameterization 视角）。把 \(R(\tau)\nabla\log P_\theta(\tau)\) 看成"把 \(R\) 的梯度从采样分布搬运到 \(\theta\) 上"：对任何 \(f\)，\(\mathbb{E}[f\nabla\log P]=\mathbb{E}[\nabla f]=-\mathbb{E}[f\nabla\log P]\)（对 \(f=P\) 用一次积分分部即得，因 \(\int\nabla P=\int P\nabla\log P=0\)）。所以不需要可微的环境（奖励模型可以完全冻结、甚至是人给的），这正是 RLHF 相对"需要可微奖励"的方法的优势。
直觉梯度 = "回报高的轨迹，把概率往上推；回报低的，往下压"，压/推的力度等于 log 概率的梯度。log 让"往上推"这件事在数值上变得可加、可算。
易错点：无偏 ≠ 低方差（8.11）是精确恒等式，没有近似。但它的估计量（8.12）方差极大：语言任务里一条轨迹的 \(R\) 可能是 0.2 也可能是 0.8，而 \(\|\nabla\log P_\theta\|\) 随序列长度 \(T\) 线性增长（因为是 \(T\) 项之和）。所以实际必须靠优势函数（8.13）降方差，靠重要性采样（8.15–8.18）复用数据。

(8.12)蒙特卡洛采样近似#

出处第 8 章 8.2.4 节 · Policy gradient（第 4 步，采样近似）　对照原文

原书公式 8.12

① 公式

\[ \approx\frac{1}{N}\sum_{\tau\sim\mathcal{T}}R(\tau)\,\nabla\log\left(P_\theta(\tau)\right) \]

② 符号

符号含义形状 / 量纲
\(\tau_1,\dots,\tau_N\overset{\text{i.i.d.}}{\sim}P_{\theta_{\text{old}}}\)从（冻结的）旧策略独立同分布采样的 \(N\) 条轨迹\(N\) 常取 \(512\sim4096\)

\(\approx\)采样近似（不是恒等式）—

③ 推导

  1. 无偏性证明。要说明"用样本均值代替期望不引入系统偏差"。设 \(\tau_i\overset{\text{i.i.d.}}{\sim}P\)，记 \(G_i=R(\tau_i)\nabla\log P_\theta(\tau_i)\)。由期望的线性性 \(\mathbb{E}\big[\frac1N\sum_iG_i\big]=\frac1N\sum_i\mathbb{E}[G_i]=\mathbb{E}[G_i]=\nabla_\theta\mathcal{J}(\theta)\)。对任何 \(N\ge1\) 都成立，包括 \(N=1\)。
  2. 注意无偏的对象是梯度，不是目标值。\(\frac1N\sum_iR(\tau_i)\) 是 \(\mathcal{J}(\theta)\) 的无偏估计，但 \(\frac1N\sum_iR(\tau_i)\nabla\log P_\theta(\tau_i)\) 是 \(\nabla_\theta\mathcal{J}\) 的无偏估计。梯度无偏就足以保证 SGD 的收敛性论证可用。
  3. 方差量级。由独立同分布，\(\mathrm{Var}\big(\frac1N\sum_iG_i\big)=\frac1{N^2}\sum_i\mathrm{Var}(G_i)=\frac{\mathrm{Var}(G)}{N}\)。所以标准差按 \(1/\sqrt N\) 下降。语言任务里 \(\mathrm{Var}(G)\) 很大（回复长度差异 + 奖励稀疏），所以 \(N\) 通常上千。
  4. \(1/N\) 从哪来。8.11 是"加权求和" \(\sum_\tau P_\theta(\tau)(\cdot)\)，权重 \(P_\theta\) 自动隐含了归一化（因 \(\sum_\tau P_\theta=1\)）。8.12 换成普通样本平均后权重没了，就必须显式除以 \(N\) 补回来。上一节提过的"漏掉 \(1/N\)"就是这里。
  5. 真正的目标：估计器形式。代入 \(\nabla_\theta\log P_\theta(\tau)=\sum_{t=1}^{T}\nabla_\theta\log\pi_\theta(a_t\mid s_t)\)，得到实践中真正写的式子： \(\nabla_\theta\mathcal{J}\approx\frac1N\sum_{i=1}^{N}\sum_{t=1}^{T_i}R(\tau_i)\nabla_\theta\log\pi_\theta(a_t^{(i)}\mid s_t^{(i)})\)。逐 token 累加进 loss.backward() 即可。
  6. 为什么要往 \(\nabla_\theta\log P_\theta(\tau)\) 里"插入"一个 \(R\) 之外的量——这就是优势函数。见 8.13。
# REINFORCE：把 8.12 展开成逐 token 累加

易错点常见三错：① 漏 \(1/N\)，等效步长放大 \(N\) 倍，训练直接发散；② 在 adv 上忘记 .detach()，价值函数的梯度会串进策略目标，训练崩溃（PPO 里 .detach() 是必须的）；③ 采样用的策略与求梯度的策略不一致却当 on-policy 处理——正确做法是引入重要性权重（8.18），这正是 PPO 的做法。

(8.13)优势函数：减基线降方差#

出处第 8 章 8.2.4 节 · PPO · Advantage estimation　对照原文

原书公式 8.13

① 公式

\[ \hat{A}_t=Q(s_t,a_t)-V(s_t) \]

② 符号

符号含义形状 / 量纲
\(Q(s_t,a_t)\)动作价值：在 \(s_t\) 采取 \(a_t\) 后的期望累积回报标量，单位"奖励"
\(V(s_t)=\mathbb{E}_{a\sim\pi_\theta(\cdot\mid s_t)}[Q(s_t,a)]\)状态价值：\(s_t\) 下所有动作的平均水平（基线 baseline）标量
\(\hat A_t\)优势：这个动作比"平均水平"好多少标量，可正可负
critic \(V_\phi\)单独训练的价值网络（原书：用奖励模型初始化并动态更新）参数 \(\phi\)

③ 推导

第 1 步：为什么可以随便减一个基线。把 8.12 里的 \(R(\tau)\) 换成 \(R(\tau)-b(s_t)\)：

\[ \mathbb{E}_{a\sim\pi_\theta(\cdot\mid s_t)}\!\left[b(s_t)\nabla_\theta\log\pi_\theta(a\mid s_t)\right]=b(s_t)\sum_{a}\pi_\theta(a\mid s_t)\nabla_\theta\log\pi_\theta(a\mid s_t)=b(s_t)\nabla_\theta\underbrace{\sum_{a}\pi_\theta(a\mid s_t)}_{=1}=\mathbf{0} \]

关键在第 3 个等号：\(\nabla_\theta\sum_a\pi_\theta(a\mid s_t)=\nabla_\theta 1=\mathbf{0}\)（因为对动作求和的结果与 \(\theta\) 无关，恒为 1）。所以任何只依赖状态、不依赖动作的 \(b\) 减掉都不改变梯度的期望。

第 2 步：为什么 \(V\) 是最好的基线。我们要最小化估计量的方差。等价地，在所有状态依赖的基线里最小化 \(\mathbb{E}[(Q-b)^2\mid s_t]\)——把目标函数对 \(b\) 求导并令零：\(\frac{\partial}{\partial b}\mathbb{E}[(Q-b)^2]=2(b-\mathbb{E}[Q])=0\Rightarrow b^\ast=\mathbb{E}[Q]=V(s_t)\)。这就是最小方差基线（Gauss–Markov 不等式在单步情形的特例）。所以"优势"这个定义不是拍脑袋，它就是"最小方差的中心化"。

第 3 步：期望形式的严格表述。在折扣 \(\gamma\) 下 \(\hat A_t=Q(s_t,a_t)-V(s_t)=\mathbb{E}\Big[\sum_{k=t}^{T-1}\gamma^{k-t}r_k\,\Big|\,s_t,a_t\Big]-\mathbb{E}_\pi\Big[\sum_{k=t}^{T-1}\gamma^{k-t}r_k\,\Big|\,s_t\Big]\)。写成 GAE（广义优势估计）就是 \(\hat A_t^{\text{GAE}(\gamma,\lambda)}=\sum_{l=0}^{\infty}(\gamma\lambda)^l\delta_{t+l}\)，其中 \(\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)\)（TD 残差）。\(V\) 越准、\(\lambda\) 越小，方差越小偏差越大——这是偏差–方差旋钮。

第 4 步：RLHF 里的工程细节。RLHF 的奖励只在最后一个 token 给出（\(r_T=r_\phi(x,y)\)，其余为 0），所以 \(Q(s_t,a_t)=r_T\) 对所有 \(t\) 相同，而 \(V(s_t)\) 随 \(t\) 递减（离终点越近，剩余步数越少、方差越小）。这使得靠近终点的步优势判断更准。critic 可以直接用奖励模型初始化（原书做法），因为奖励模型的输出已经大致标定了回报的绝对水平。

第 5 步：为什么用采样估计 \(\hat A_t\)。实践中 \(Q\) 不直接可得（要知道"这个回答最终会得多少分"，得等生成完、算完奖励才知道）。所以实际算 \(\hat A_t\approx r_t+\gamma V(s_{t+1})-V(s_t)\)（单步 TD 残差），这只需 critic 的一次前向。

with torch.no_grad():
    v_old = critic(x, y[:, :-1])            # V(s_t), [N, T-1]
    r     = zeros_like(v_old); r[:, -1] = R # 终止奖励
    delta = r + gamma * v_critic_next - v_old   # TD 残差 δ_t
    adv   = zeros_like(delta)
    last  = 0.0
    for t in reversed(range(T - 1)):        # GAE 反向递推
        last = delta[:, t] + gamma * lam * last
        adv[:, t] = last
ret = adv + v_old                          # 回报估计（GAE(1) 时精确）
直觉"打分"里有绝对值和相对值两部分。8.12 里的 \(R(\tau)\) 是绝对值——哪怕模型已经"及格"了，只要比平均水平高，梯度还会继续推。这就是 baseline 要解决的问题：把"这个状态本身就难/容易"的部分减掉，只保留"这一步选得好不好"。类比考试：把"及格线 60 分"减掉，你关心的是超出 60 分多少，而不是总分。
易错点① 基线必须只依赖状态。若基线里含 \(a_t\)，第 1 步的 \(\nabla_\theta\sum_a\pi_\theta(a\mid s_t)=0\) 就不成立，梯度被改变（这是 actor–critic 里 critic 用 TD 目标独立训练的原因）。② \(\hat A_t\) 在反向传播时必须 detach()，否则 critic 和 actor 的目标纠缠。③ critic 若系统性低估，会让所有优势偏正，策略被过度推动——critic 训练不稳是 RLHF 崩溃的常见原因之一。

(8.14)示例环境：三个动作的 \(Q\) 值递增#

出处第 8 章 8.2.4 节 · Example 8.2　对照原文

原书公式 8.14

① 公式

\[ 0<Q(s_t,a_{t,1})<Q(s_t,a_{t,2})<Q(s_t,a_{t,3}) \]

② 符号

符号含义形状 / 量纲
\(a_{t,1},a_{t,2},a_{t,3}\)状态 \(s_t\) 下的三个候选动作三个不同 token
\(0<\cdot\)关键：所有 \(Q\) 都在正半轴上，最差的那个也是正的—
\(V(s_t)=\sum_i\pi_\theta(a_{t,i}\mid s_t)Q(s_t,a_{t,i})\)三者的加权平均，必落在 \(Q_1\) 与 \(Q_3\) 之间标量

③ 推导

  1. 先算基线。因 \(\pi_\theta(\cdot\mid s_t)\) 是概率分布且和为 1，\(V(s_t)=\sum_i\pi_iQ_i\) 是凸组合，故 \(Q_1\le V\le Q_3\)，严格不等号在分布非退化时成立。这是加权平均的基本性质。
  2. 再算优势。代入 8.13：\(\hat A_1=Q_1-V\le0\)，\(\hat A_3=Q_3-V\ge0\)，中间那个符号不定。三个动作的优势不全为正。
  3. 如果不减基线（只用 8.12 的 \(R\)）。Example 8.2 的场景：采样恰好选中 \(a_{t,1}\)，虽然它的 \(Q\) 最小，但因为 \(Q_1>0\)（8.14 最左边的不等式就是为这个例子准备的），朴素策略梯度算出 \(\nabla\propto Q_1\nabla\log\pi(a_{t,1}\mid s_t)\)，系数为正，于是把概率往上推——最优动作被压下去了。
  4. 用了基线之后。系数变成 \(\hat A_1=Q_1-V\le0\)，梯度下降等价于把 \(\pi(a_{t,1}\mid s_t)\) 往下压，同时 \(\hat A_3>0\) 把最优动作往上拉。采样运气不好被自动纠正。
直觉问题出在"符号"。策略梯度只看系数的符号决定推还是压，所以系数的绝对零点选在哪里至关重要。用绝对 \(Q\) 当系数，等于假设"奖励 0 是及格线"；可 RLHF 的奖励是奖励模型给的连续分（比如 0.2 到 0.9），没有任何理由认为 0 是及格线。\(V\) 就是那把重新校准零点、也即"这把尺子的零点该定在哪"的尺子。
易错点这类"符号偏置"故障非常隐蔽：训练 loss 曲线看起来完全正常（它确实在下降），只是模型在生成上慢慢偏离。诊断方法：打印 \(\hat A\) 的均值。若持续显著偏离 0，说明 critic 的基线不准；若 \(\hat A\) 几乎全为正，说明奖励/基线的零点设错了。

(8.15)期望写成积分#

出处第 8 章 8.2.4 节 · Importance sampling（第 1 步）　对照原文

原书公式 8.15

① 公式

\[ \mathbb{E}_{x\sim q}\!\left[f(x)\right]=\int q(x)\cdot f(x)\,\mathrm{d}x \]

② 符号

符号含义形状 / 量纲
\(q(x)\)目标分布（target distribution）概率密度，\(\int q\,\mathrm{d}x=1\)，\(q\ge0\)
\(f(x)\)被取期望的函数，要求 \(\int q|f|<\infty\)（可积）任意
\(\mathrm{d}x\)勒贝格积分的微分记号（离散情形下换成 \(\sum\)）—

③ 推导

  1. 这是定义，不是定理。期望的加权平均定义在离散情形是 \(\sum_x q(x)f(x)\)；连续情形取"细分区间再求和→取极限"：把支撑集切成小区间 \(I_i\)，每段用 \(q(x_i)f(x_i)\) 代表贡献，求和得 \(\sum_i q(x_i)f(x_i)\Delta x_i\)，令 \(\max\Delta x_i\to0\) 即得积分。所以（8.15）是全章唯一一条"照抄定义"的公式。
  2. 为什么非写不可。因为下一步要做被积函数的代数变形（8.16 插入 \(\frac{p}{p}\)，8.17 再抽出 \(p(x)\)）。求和形式下"从求和号里提出一个公因子"很别扭，积分形式下就是普通的因式分解。所以整条链的动机就是：把 \(\int qf\) 改写成 \(\int (\text{能提出去的东西})\cdot(\text{剩下的东西})\)，好让"从 \(p\) 采样"这件事合法。
  3. 两个必须一直记住的前提。① \(q\ge0\) 且 \(\int q=1\)；② \(f\) 在 \(q\) 下可积。后面推出重要性权 \(q/p\) 时还要加第三个：\(p(x)>0\) 几乎处处（只要 \(q\) 有质量的地方 \(p\) 也要有）。
直觉"目标分布下的平均"就是"用目标分布当权重的加权积分"。接下来三步要证明的是：这个加权积分，可以改成用另一个分布采样、只是把权重换一下。

(8.16)插入 \(\frac{p(x)}{p(x)}=1\)，造出重要性权#

出处第 8 章 8.2.4 节 · Importance sampling（第 2 步）　对照原文

原书公式 8.16

① 公式

\[ =\int\frac{p(x)}{p(x)}\cdot q(x)\cdot f(x)\,\mathrm{d}x \]

下一步（8.17，在下一页）把它整理成 \(\int p(x)\cdot\frac{q(x)}{p(x)}\cdot f(x)\,\mathrm{d}x=\mathbb{E}_{x\sim p}\!\left[\frac{q(x)}{p(x)}f(x)\right]\)。

② 符号

符号含义形状 / 量纲
\(p(x)\)提议分布（proposal / sampling distribution），可采样概率密度，\(\int p\,\mathrm{d}x=1\)
\(\frac{q(x)}{p(x)}\)重要性权（importance weight）无量纲，\(\ge0\)，期望为 1
\(\frac{p(x)}{p(x)}\)恒为 1 的哑因子（要求 \(p(x)>0\)）无量纲

③ 推导

  1. 恒等变形。对 \(p(x)>0\) 的点，\(\frac{p(x)}{p(x)}=1\)，故（8.16）右端 =（8.15）右端。这步和 8.10 一样是纯代数，但目的不同：这里是为了把 \(p(x)\) 放到积分号内、且与 \(q(x)f(x)\) 相邻的位置，好让下一步把它识别成"期望的权重"。
  2. 重排因子。乘法可交换：\(\int p(x)\cdot\frac{q(x)}{p(x)}\cdot f(x)\,\mathrm{d}x\)。用（8.15）把 \(p\) 认作权重，得到 \(\mathbb{E}_{x\sim p}\left[\frac{q(x)}{p(x)}f(x)\right]\)。于是"在 \(q\) 下求期望"被改写成"在 \(p\) 下求期望，再乘一个修正权"。
  3. 权重的归一性可以验证。取 \(f\equiv1\)：\(\mathbb{E}_{p}\!\left[\frac{q}{p}\right]=\int p\cdot\frac{q}{p}\,\mathrm{d}x=\int q\,\mathrm{d}x=1\)。所以重要性权的期望是 1——这正是它"修正了分布但没改变总量"的原因。
  4. 什么时候估计量不存在（\(L^1\) 条件）。要求 \(\int p\left|\frac{q}{p}f\right|\mathrm{d}x=\int|q f|\,\mathrm{d}x=\mathbb{E}_q[|f|]<\infty\)。这由（8.15）的前提自动满足，只要 \(p>0\) 几乎处处。若 \(q\) 在某个区间有质量而 \(p\) 在那里为 0，则 \(\frac{q}{p}=+\infty\)，估计量无定义——这是重要性采样的硬性适用条件。
  5. 什么时候方差爆炸（\(L^2\) 条件）。二阶矩 \(\mathbb{E}_p\left[\left(\frac{q}{p}\right)^2\right]=\int\frac{q(x)^2}{p(x)}\,\mathrm{d}x\)。由柯西–施瓦茨不等式，取 \(u=q/\sqrt p\)、\(v=\sqrt p\)：\(\int\frac{q^2}{p}=\int u^2\cdot1\;\ge\;\big(\int uv\big)^2=\big(\int q\big)^2=1\)。等号成立当且仅当 \(u=cv\)，即 \(q=cp\)，再由两者都积分为 1 得 \(c=1\)，即 \(q=p\)。 所以：估计量的方差 \(\ge0\)，且恰好在 \(p=q\) 时为 0。这就是"离策略下要用重要性采样，就必须让两个分布尽量接近"的严格依据。实践中取 KL 惩罚 \(\beta\,\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})\) 就是主动把 \(p\)（旧策略）和 \(q\)（新策略）拉近（KL 惩罚目标见 8.21，重要性权应用于策略梯度见 8.18）。
# 方差爆炸的直观例子：q 是目标分布，p 采样不到那里
import numpy as np
q = lambda x: np.exp(-x**2/2) / np.sqrt(2*np.pi)      # N(0,1)
p = lambda x: np.exp(-(x-10)**2/2) / np.sqrt(2*np.pi)  # N(10,1)
f = lambda x: x**2
xs = np.random.normal(10, 1, 200000)
w = q(xs) / p(xs)
print(w.mean(), (w*f(xs)).mean(), w.std())
# 期望值确实收敛到 E_q[x^2] = 1（无偏），但 w 的标准差极大：
# w = exp(5x - 50)，在 x 略小于 10 时已远超 float64 范围 -> 采样估计直接失效
直觉"用我方便采的分布去算我真正关心的分布的期望，每个样本乘一个修正系数。"系数在常见区域很小、在罕见区域巨大——所以离得越远，方差越炸。这解释了 PPO 为什么既要限制策略更新幅度（裁剪），又要加 KL 惩罚：两者都是在把 \(p\) 和 \(q\) 摁在一起。
易错点三个高频错误：① 忘了权重，忘了就等于在估计 \(\mathbb{E}_p[f]\) 而非 \(\mathbb{E}_q[f]\)；② 权重没 detach，重要性权含 \(\theta\) 却当常数用，梯度里会多出 \(\nabla_\theta\frac{\pi_\theta}{\pi_{\text{old}}}\) 项，PPO 靠裁剪强行截断它；③ 权重不截断时数值溢出——\(p\) 与 \(q\) 稍微离远一点，\(q/p\) 就可能超过 float64 的 \(1.8\times10^{308}\)。PPO 的 \(\mathrm{clip}(r_t(\theta),1\pm\epsilon)\) 正是把这个权重强行限制在 \([1-\epsilon,1+\epsilon]\)（0.2 附近），用一点偏差换掉整个方差灾难。

延伸：为什么 DPO 只是 8.2 换了个 \(z\)

8.2 的 BT 损失在 RLHF 之后被重新发现了一次——这就是 DPO（Direct Preference Optimization）。它的贡献是把 8.2 里的"强度" \(r_\theta(x,y)\) 换成策略与参考策略的对数比，从而完全消掉显式的奖励模型和采样循环。编号公式 8.43 在 第 3/3 页，这里把推导补齐，因为它是本页两条线（偏好似然 + KL 约束）的交汇点。

  1. 起点：带 KL 约束的奖励最大化。RLHF 的真正目标不是裸的 \(\max_\pi\mathbb{E}_\pi[r]\)，而是"8.6 减去离参考策略太远的惩罚"：\(\max_\pi\;\mathbb{E}_{y\sim\pi(\cdot\mid x)}\big[r(x,y)\big]-\beta\,\mathrm{KL}\big(\pi(\cdot\mid x)\,\|\,\pi_{\text{ref}}(\cdot\mid x)\big)\)，约束为 \(\mathrm{KL}\le\varepsilon\)。
  2. 把约束写成拉格朗日函数（对偶拉格朗日法）。对约束 \(g(\pi)=\mathrm{KL}-\varepsilon\le0\) 引入乘子 \(\lambda\ge0\)。用恒等式 \(\mathrm{KL}(\pi\|\pi_{\text{ref}})=\mathbb{E}_\pi\!\left[\log\frac{\pi}{\pi_{\text{ref}}}\right]-\mathbb{E}_{\pi_{\text{ref}}}\!\left[\log\frac{\pi}{\pi_{\text{ref}}}\right]\)，得到 \(\mathcal{L}(\pi,\lambda)=\mathbb{E}_\pi\big[r(x,y)\big]-\lambda\,\mathbb{E}_\pi\big[\log\tfrac{\pi(y\mid x)}{\pi_{\text{ref}}(y\mid x)}\big]+\lambda\,\mathbb{E}_{\pi_{\text{ref}}}\big[\log\tfrac{\pi(y\mid x)}{\pi_{\text{ref}}(y\mid x)}\big]\)。
  3. 关键一步：最后一项与 \(\pi\) 无关（\(\pi_{\text{ref}}\) 固定，积分用它自己的密度），所以在固定 \(x\) 下只需最大化 \(\mathbb{E}_\pi\big[g(y)\big]\)，其中 \(g(y)=r(x,y)-\lambda\log\frac{\pi(y\mid x)}{\pi_{\text{ref}}(y\mid x)}\)。
  4. 解这个内层问题。\(\mathbb{E}_\pi[g]=\sum_y\pi(y\mid x)g(y)\) 是关于 \(\pi\) 的线性函数，定义在概率单纯形（凸集）上。线性函数在凸紧集上的最大值必在极点取得，而单纯形的极点就是 one-hot 分布，故最优解把所有质量放在 \(g\) 的最大点：\(\pi^\ast(y\mid x)\propto\pi_{\text{ref}}(y\mid x)\exp\!\big(\frac{r(x,y)}{\lambda}\big)\)。归一化即得闭式解 \(\pi^\ast(y\mid x)=\frac{1}{Z(x)}\,\pi_{\text{ref}}(y\mid x)\exp\!\big(\frac{r(x,y)}{\beta}\big)\)，其中把乘子 \(\lambda\) 重新命名为 \(\beta\)，\(Z(x)=\sum_{y}\pi_{\text{ref}}(y\mid x)\exp\frac{r(x,y)}{\beta}\) 是配分函数。
  5. 反解出奖励。由上式直接移项：\(r(x,y)=\beta\log\frac{\pi^\ast(y\mid x)}{\pi_{\text{ref}}(y\mid x)}+\beta\log Z(x)\)。那个 \(\beta\log Z(x)\) 就是 8.2 里说的"只能定到常数平移"——\(Z(x)\) 恰好吸收了这个自由度，而且在同一次比较中 \(x\) 相同，\(Z(x)\) 相互抵消。
  6. 代回 BT 模型。由 8.2 第 1 步，偏好概率是 \(P(y^+\succ y^-\mid x)=\sigma\big(\frac{r(x,y^+)-r(x,y^-)}{\beta}\big)\)（因为最优策略是 \(\pi_{\text{ref}}\) 的指数倾斜，其诱导出的偏好仍是 BT 形式，强度为 \(r/\beta\)）。代入第 5 步，\(Z(x)\) 消去： \(P(y^+\succ y^-\mid x)=\sigma\!\Big(\beta\big[\log\frac{\pi_\theta(y^+\mid x)}{\pi_{\text{ref}}(y^+\mid x)}-\log\frac{\pi_\theta(y^-\mid x)}{\pi_{\text{ref}}(y^-\mid x)}\big]\Big)\)。
  7. 取负对数即得 DPO 目标（8.43）。\(\mathcal{L}_{\text{DPO}}=-\log\sigma(z_{\text{DPO}})\)，\(z_{\text{DPO}}\) 即上式方括号内整体乘 \(\beta\)。形式与 8.2 完全相同，且数值稳定性也用同一个 softplus(-z)（见前置 C5）。
  8. （补充）隐变量边缘化技巧。上面的推导把 \(y\) 当作一次性的"动作"。但自回归生成里动作是 token 而非整段回复。DPO 论文用一个恒等式绕过：在位置 \(j\) 之前的上下文记作 \(x_{<j}\)，有 \(\pi(y\mid x)=\sum_{a_{1:j-1}}\pi(a_{1:j-1}\mid x)\cdot\pi^\ast(a_{j}\mid x,y_{<j})\)，即对"已经生成的前缀"做边缘化。这样 token 级的对数比可以累加成序列级的对数比，\(\log\frac{\pi_\theta(y\mid x)}{\pi_{\text{ref}}(y\mid x)}=\sum_t\log\pi_\theta(y_t\mid x,y_{<t})-\sum_t\log\pi_{\text{ref}}(y_t\mid x,y_{<t})\)，推导得以原封不动地搬到序列层面。
为什么这件事很重要RLHF 需要四个模型（policy、reference、reward、critic）、一个在线采样循环、以及 PPO 的全部稳定化技巧。DPO 只需 policy 和 reference，训练一次前向+反向，复杂度等同 SFT。它没有消除 前置 C5 里的数值稳定性问题，也没有消除 8.2 里"标注者之间的绝对刻度差异"问题——因为 BT 假设它没变。

再往外一步：不成对反馈与 KTO

8.2 假设每个输入都有一条偏好对 \((y^+,y^-)\)。真实场景里更常见的是不成对反馈（unpaired feedback）：只有对单个回答的"点赞/点踩"或 1–5 星评分。这类数据量更大、更便宜，但无法直接构成 BT 的成对比较——没有对手就没有 \(\Delta r\)。

解决思路是把"效用（utility）"和"KL 散度"分开建模。做法与 DPO 第 2 步同源：定义效用

\[ u(x,y)=\beta\log\frac{\pi_\theta(y\mid x)}{\pi_{\text{ref}}(y\mid x)} \]

它是"当前策略比参考策略更偏好这个回答多少"的对数度量（\(u>0\) 说明策略相对参考更倾向于生成 \(y\)）。再用一个 sigmoid 把无界的 \(u\) 压到概率尺度，得到两个可当作概率解读的量：

\[ \lambda_{\mathrm D}(x,y)=\sigma_{\beta}\big(u(x,y)\big)\quad(\text{desirable 的权重}),\qquad \lambda_{\mathrm L}(x,y)=\sigma_{\beta}\big(-u(x,y)\big)=1-\lambda_{\mathrm D}(x,y)\quad(\text{lossy 的权重}) \]

直觉：一个被判定为"好"的回答，训练目标是把 \(\lambda_{\mathrm D}\) 推向 1（即把 \(\pi_\theta/\pi_{\text{ref}}\) 推大）；一个被判定为"差"的回答，目标是把 \(\lambda_{\mathrm L}\) 推向 1（即把比值推小）。因为 \(\lambda_{\mathrm D}+\lambda_{\mathrm L}=1\)，两个方向的梯度天然互相抑制，不会把策略推向 KL 爆炸的方向。

KTO（Kahneman–Tversky Optimization）的损失写成"预测值与目标值 \(v\in\{0,1\}\) 的加权不匹配"形式：对 desirable 样本只惩罚 \(\lambda_{\mathrm L}\)（即"还不够好"），对 undesirable 样本只惩罚 \(\lambda_{\mathrm D}\)（即"还不够差"），并用系数平衡两类样本的先验比例，避免数据里点赞远多于点踩导致的偏置。得到的对偶形式里，desirability 与 lossiness 两支各自带一个由类别先验决定的权重，形状与 8.2 的 \(-\log\sigma\) 一样都落在 softplus 上，因此数值稳定性处理完全复用前置 C5。

一句话对比BT / DPO 需要"谁比谁好"，KTO 只需要"这个好不好"。代价是它无法利用同一输入内多个回答的相对信息（那正是 8.3 排序法想利用的），所以在有高质量成对数据时 BT 家族仍然更强；KTO 的价值在于能廉价地吃下"海量单条评分"这种原本会被丢弃的数据。
说明KTO 不在本手册覆盖的原书公式范围内（原书 8.3.2 节列举的监督对齐算法是 SLiC / RRHF 类，编号公式 8.33–8.46 在 第 3/3 页）。本小节是超出原书的补充说明，用于解释"不成对反馈"这条技术路线的通用套路；其具体损失函数与超参见 KTO 原论文，本手册不逐条推导。

三条线索的收束

把 8.1–8.16 串起来，整章其实只反复在做同一件事：把一个无法直接求导的"人类判断"改写成一个可以梯度下降的标量目标。

  • 8.1–8.5：把判断变成损失。路线一（8.1）把评分当标签做回归，代价是绝对刻度不可靠；路线二（8.2、8.3）把判断当序做 BT 似然，扔掉绝对刻度，换来传递性与自动饱和的梯度；8.4 加正例 SFT 做正则，8.5 把多个标准线性合并。
  • 8.6–8.12：把期望变成梯度。三次恒等变形（展开求和 → 乘 \(P/P\) → 换成 \(\nabla\log P\)）把"不可枚举的期望"变成"可采样的加权和"，代价是方差。
  • 8.13–8.16：用基线降方差、用重要性权复用数据。8.13 的基线是不改变梯度的自由度（因为 \(\nabla_\theta\sum_a\pi_\theta(a\mid s)=0\)），8.15–8.16 的重要性权是把期望从 \(q\) 搬到 \(p\) 的恒等变形，代价由 \(L^2\) 条件（方差在 \(p\ne q\) 时严格大于 0）量化。

三处"免费的午餐"都不存在：去掉绝对刻度换来了不可识别性，换来了饱和与数据耗尽；把导数变成可算形式换来了采样方差；允许离策略换来了重要性权的高方差。PPO 的裁剪与 KL 惩罚（下一页 8.19–8.21）本质上都是在为这三笔账定价。

C.1 RMSNorm：归一化的定义式与手算验证

原文这一节用图 C.2 直观对比了 LayerNorm 与 RMSNorm，并给出「均值 0.77、方差 0.41」这个结果，但没有写出任何一个公式。这一页把两条定义式写出来，把图 C.2 的六个数字逐步手算一遍，并证明 RMSNorm 真正保证的不变量其实既不是零均值也不是单位方差，而是 平方均值为 1。

一、为什么需要归一化

深层网络里，前一层的输出尺度会被后一层的权重放大或缩小。设某层为 \(\mathbf{y} = \mathbf{W}\mathbf{x}\)，如果 \(\mathbf{W}\) 的行和随机变大，\(\|\mathbf{y}\|\) 就随层数指数增长或衰减。前者让激活值冲出浮点表示范围，后者让梯度在反向传播中指数消失。

归一化层的作用就是把每个 token 的特征向量拉回一个固定的尺度，让下一层不必关心上游送来的数有多大。RMSNorm 和 LayerNorm 干的是同一件事，区别只在怎么算这个尺度。

二、LayerNorm 的定义式

给定一个 token 的 \(d\) 维隐藏向量 \(\mathbf{x} = (x_1, \dots, x_d)\)，先算均值和方差：

\[ \mu = \frac{1}{d}\sum_{i=1}^{d} x_i, \qquad \sigma^2 = \frac{1}{d}\sum_{i=1}^{d}(x_i - \mu)^2 \]

然后标准化，再乘一个学到的增益、加一个学到的偏移：

\[ \hat{x}_i = \frac{x_i - \mu}{\sigma}, \qquad y_i = \gamma_i\, \hat{x}_i + \beta_i \]
LayerNorm 的两条硬保证

因为 \(\frac{1}{d}\sum_i \hat{x}_i = 0\) 且 \(\frac{1}{d}\sum_i \hat{x}_i^2 = 1\)，所以输出恰好零均值、单位方差（当 \(\gamma = 1, \beta = 0\) 时）。这正是图 C.2 右侧标注的 "Zero-centered mean and unit variance after normalization"。

推导：为什么标准化后均值恰为 0、平方均值恰为 1

先算均值。把 \(\hat{x}_i = (x_i - \mu)/\sigma\) 代入，\(\sigma\) 与 \(i\) 无关可提出：

\[ \frac{1}{d}\sum_{i=1}^{d}\hat{x}_i = \frac{1}{d\sigma}\sum_{i=1}^{d}(x_i - \mu) = \frac{1}{d\sigma}\left(\sum_{i=1}^{d}x_i - d\mu\right) \]

而 \(\mu\) 的定义就是 \(\mu = \frac{1}{d}\sum_i x_i\)，即 \(\sum_i x_i = d\mu\)，括号里 \(= d\mu - d\mu = 0\)。故均值恒为 0——注意这里没用任何近似，是恒等式。

再算平方均值：

\[ \frac{1}{d}\sum_{i=1}^{d}\hat{x}_i^2 = \frac{1}{d\sigma^2}\sum_{i=1}^{d}(x_i - \mu)^2 \]

而 \(\sigma^2\) 的定义恰是 \(\sigma^2 = \frac{1}{d}\sum_i (x_i-\mu)^2\)，即 \(\sum_i (x_i-\mu)^2 = d\sigma^2\)，代入得 \(\frac{d\sigma^2}{d\sigma^2} = 1\)。证毕。

一句话记忆：LayerNorm 保证的量，恰好就是它减掉和除掉的那两个量——减均值保证零均值，除标准差保证单位方差。下一节会看到，RMSNorm 保证的也是「它除的那个量」。

三、RMSNorm 的定义式：只去掉减均值这一步

RMSNorm 把「减均值」整个删掉，直接除以均方根（root mean square）：

\[ \mathrm{RMS}(\mathbf{x}) = \sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2} = \sqrt{\frac{1}{d}\sum_{i=1}^{d}(x_i - \mu)^2 + \mu^2} = \sqrt{\sigma^2 + \mu^2} \] \[ y_i = \gamma_i \cdot \frac{x_i}{\mathrm{RMS}(\mathbf{x})}, \qquad \text{（默认没有 } \beta \text{）} \]
推导：\(\mathrm{RMS}^2 = \sigma^2 + \mu^2\)

把每个 \(x_i\) 写成「偏离均值的部分」加「均值本身」：\(x_i = (x_i - \mu) + \mu\)，然后平方展开：

\[ \begin{aligned} \frac{1}{d}\sum_{i=1}^{d} x_i^2 &= \frac{1}{d}\sum_{i=1}^{d}\big[(x_i - \mu) + \mu\big]^2 \\ &= \frac{1}{d}\sum_{i=1}^{d}(x_i - \mu)^2 + \frac{2\mu}{d}\underbrace{\sum_{i=1}^{d}(x_i - \mu)}_{=\,0} + \frac{1}{d}\sum_{i=1}^{d}\mu^2 \\ &= \sigma^2 + 0 + \mu^2 \end{aligned} \]

中间那项为 0 的原因：\(\sum_i (x_i - \mu) = \sum_i x_i - d\mu = d\mu - d\mu = 0\)（正是上一节证过的「中心化后求和为 0」）。两边开方即得 \(\mathrm{RMS} = \sqrt{\sigma^2 + \mu^2}\)。

这个恒等式说明：RMS 的平方 = 方差 + 均值的平方，它永远 \(\geq \sigma^2\)，等号只在 \(\mu = 0\) 时成立——这就是 warn 框里「只有当 \(\mu=0\) 时两者才相等」的来源。

最容易算错的一步

RMSNorm 除的是 RMS，不是标准差。很多人拿 \(\sigma\) 去除，结果全错。二者的关系是 \(\mathrm{RMS} = \sqrt{\sigma^2 + \mu^2}\)，只有当 \(\mu = 0\) 时两者才相等。图 C.2 里输入的均值是 17.47（远非 0），所以 \(\sigma = 14.42\) 而 \(\mathrm{RMS} = 22.65\)，差了 57%。

参数个数：LayerNorm 每维 2 个参数（\(\gamma_i, \beta_i\)），RMSNorm 每维 1 个（\(\gamma_i\)）。对 \(d = 1024\) 的 Qwen3 0.6B，一个归一化层从 2048 个参数降到 1024 个。后面会看到，全模型一共 57 个 RMSNorm，共省下 58,368 个参数。

四、手算：图 C.2 的六个数字

图 C.2 的输入（layer outputs）是 \(\mathbf{x} = [5.61,\ 14.32,\ 0.00,\ 34.88,\ 38.70,\ 11.29]\)。按图上标注，先核对统计量：

\[ \mu = \frac{5.61 + 14.32 + 0.00 + 34.88 + 38.70 + 11.29}{6} = \frac{104.80}{6} = 17.4667 \approx 17.47 \] \[ \sigma^2 = \frac{1}{6}\sum (x_i - 17.4667)^2 = \frac{140.58 + 9.90 + 305.08 + 303.22 + 450.86 + 38.15}{6} = \frac{1247.79}{6} = 207.97 \approx 207.91 \]

（图上标 207.91，是先把各数四舍五入到两位再算的，直接用原始值算是 207.97，差异只来自舍入。）

4.1 先算 RMS

\[ \mathrm{RMS}^2 = \frac{1}{6}\sum x_i^2 = \frac{31.4721 + 205.0624 + 0 + 1216.6144 + 1497.69 + 127.4641}{6} = \frac{3078.3030}{6} = 513.0505 \] \[ \mathrm{RMS} = \sqrt{513.0505} = 22.6517 \]

五、RMSNorm 真正保证的不变量：平方均值为 1

既然输出既不是零均值也不是单位方差，那 RMSNorm 到底保证了什么？答案是它保证的量恰好就是它除的那个量：

\[ \frac{1}{d}\sum_{i=1}^{d} y_i^2 = \frac{1}{d}\sum_{i=1}^{d}\left(\frac{x_i}{\mathrm{RMS}}\right)^2 = \frac{1}{\mathrm{RMS}^2}\cdot \frac{1}{d}\sum_{i=1}^{d} x_i^2 = \frac{\mathrm{RMS}^2}{\mathrm{RMS}^2} = 1 \]

即 \(\mathrm{RMS}(\mathbf{y}) = 1\) 恒成立（当增益 \(\gamma = 1\) 时；带增益则是 \(\mathrm{RMS}(\gamma \odot \mathbf{y}) = |\gamma|\)）。用 4.2 的输出验算：

\[ \frac{0.2477^2 + 0.6322^2 + 0^2 + 1.5397^2 + 1.7083^2 + 0.4984^2}{6} = \frac{0.0614 + 0.3997 + 0 + 2.3708 + 2.9190 + 0.2484}{6} = \frac{5.9993}{6} = 0.9999 \approx 1 \]
推导：\(\mathrm{mean}(y) = \mu/\mathrm{RMS}\)，\(\mathrm{var}(y) = \sigma^2/\mathrm{RMS}^2\)

由 \(y_i = x_i / \mathrm{RMS}\)，分母是常数（与 \(i\) 无关），可直接提出求和号：

\[ \mathrm{mean}(y) = \frac{1}{d}\sum_i \frac{x_i}{\mathrm{RMS}} = \frac{1}{\mathrm{RMS}}\cdot\frac{1}{d}\sum_i x_i = \frac{\mu}{\mathrm{RMS}} \]

方差同理。记 \(\bar{y} = \mu/\mathrm{RMS}\)，则 \(y_i - \bar{y} = (x_i - \mu)/\mathrm{RMS}\)，于是

\[ \mathrm{var}(y) = \frac{1}{d}\sum_i (y_i - \bar{y})^2 = \frac{1}{\mathrm{RMS}^2}\cdot\frac{1}{d}\sum_i (x_i - \mu)^2 = \frac{\sigma^2}{\mathrm{RMS}^2} \]

注意这里用的是总体方差（除以 \(d\)），和 LayerNorm 定义里的 \(\sigma^2\) 一致。下面恒等式用的正是这两个关系。

顺带一个漂亮的恒等式

因为 \(\mathrm{var}(y) = \frac{\sigma^2}{\mathrm{RMS}^2}\) 且 \(\mathrm{mean}(y) = \frac{\mu}{\mathrm{RMS}}\)，两者相加有：

\[ \mathrm{mean}(y)^2 + \mathrm{var}(y) = \frac{\mu^2 + \sigma^2}{\mathrm{RMS}^2} = \frac{\mathrm{RMS}^2}{\mathrm{RMS}^2} = 1 \]

用原文的数字验证：\(0.77^2 + 0.41 = 0.5929 + 0.41 = 1.0029 \approx 1\)。所以看到 RMSNorm 的输出均值和方差，只要检查两者平方和是否为 1 就能判断算对了——这也解释了为什么「均值 0.77、方差 0.41」这两个数看起来有点奇怪却又是自洽的。

六、为什么「不减均值」是可以接受的

LayerNorm 的减均值有两个作用：

  1. 数值作用：让输出零均值，梯度分布更对称。
  2. 统计作用：让「偏离」成为唯一的信息源。

RMSNorm 放弃了这两点，但实践上损失很小。理由是：

均值是可以被下一层学回来的

归一化层后面紧跟的是一个线性层 \(W\)。一个常数偏移向量 \(\mu \cdot \mathbf{1}\) 对下一层的贡献是 \(W(\mu\mathbf{1}) = \mu\,(W\mathbf{1})\)，这是一个固定的、可被后续权重吸收的常量方向。换句话说，零均值带来的好处，下游本来就能通过权重自己学到，而减均值本身要付出一次全维 reduction 的代价。

这就是「便宜 vs 精确」的真实取舍：RMSNorm 用一点表达能力，换来大约 7% 的归一化层前向计算量（见下一节）。大规模训练里这笔交易是划算的——这就是为什么 LLaMA、Qwen3、Mistral 现代架构几乎都选了 RMSNorm。

七、参数量与计算量：两次 reduction vs 一次

7.1 reduction 次数

在 GPU 上，一个向量的 reduction 是跨线程的归约操作，需要线程间通信，是归一化层里最慢的部分。

需要的 reduction次数
LayerNorm\(\sum x_i\)、\(\sum x_i^2\)、最后除法 x.sum() / pow(2).mean()2 次跨特征 reduction
RMSNorm只需 pow(2).mean()1 次

这正是原文说的：reduces the number of cross-feature reductions from two to one, which lowers communication overhead on GPUs。

7.2 参数量

按图 C.7 的配置，Qwen3 0.6B 的 \(d = 1024\)，transformer block 重复 28 次，每个 block 含 RMSNorm 1（attention 前）和 RMSNorm 2（feedforward 前），模型末尾还有一个 final RMSNorm：

\[ \text{RMSNorm 层数} = 2 \times 28 + 1 = 57 \]
方案每层参数57 层合计
LayerNorm（\(\gamma,\beta\)）\(2 \times 1024 = 2048\)116,736
RMSNorm（只有 \(\gamma\)）\(1 \times 1024 = 1024\)58,368

相对 6 亿参数，这只是一小部分，但这是零成本的收益：不改结构、不改初始化、少一次通信、省一半归一化参数。这也是为什么 C.4 里的 QKNorm 可以直接「借用」C.1 的 RMSNorm 实现，套在 query 和 key 上。

八、RMSNorm 的梯度（进阶，可跳过）

用 \(r = \mathrm{RMS}(\mathbf{x})\)，\(y_i = \gamma_i x_i / r\)。注意 \(r\) 依赖于所有 \(x_j\)，所以求导时不能只当作常数：

\[ \frac{\partial y_i}{\partial x_j} = \gamma_i\left(\frac{\delta_{ij}}{r} - \frac{x_i}{r^2}\cdot\frac{\partial r}{\partial x_j}\right), \qquad \frac{\partial r}{\partial x_j} = \frac{x_j}{d\,r} \]
推导：\(\partial r / \partial x_j = x_j/(dr)\)（链式法则）

把 \(r\) 写成复合函数：\(r = u^{1/2}\)，其中 \(u = \frac{1}{d}\sum_{k=1}^{d} x_k^2\)。链式法则 \(\frac{\partial r}{\partial x_j} = \frac{dr}{du}\cdot\frac{\partial u}{\partial x_j}\)：

\[ \frac{dr}{du} = \frac{1}{2}u^{-1/2} = \frac{1}{2r}, \qquad \frac{\partial u}{\partial x_j} = \frac{1}{d}\cdot 2x_j = \frac{2x_j}{d} \]

（第二步：求和里只有 \(k = j\) 那一项含 \(x_j\)，\(\frac{\partial}{\partial x_j}x_j^2 = 2x_j\)，其余项导数为 0。）相乘：

\[ \frac{\partial r}{\partial x_j} = \frac{1}{2r}\cdot\frac{2x_j}{d} = \frac{x_j}{d\,r} \]

直观理解：\(r\) 是整体的「尺度」，\(x_j\) 越大，它对尺度的贡献越大，导数 \(\propto x_j\) 正是这个意思。分母的 \(d\) 来自均值里的 \(1/d\)。

于是（\(\gamma_i = 1\) 时）：

\[ \frac{\partial y_i}{\partial x_j} = \frac{1}{r}\left(\delta_{ij} - \frac{x_i x_j}{d\,r^2}\right) = \frac{1}{r}\left(\delta_{ij} - \frac{y_i y_j}{d}\right) \]
怎么读这个式子：对角项 \(\frac{1}{r}\delta_{ij}\) 是「保持自己」；减掉的第二项是把所有输入的贡献沿 \(\mathbf{y}\) 方向投影后拿掉，保证 \(\sum_j x_j \frac{\partial y_i}{\partial x_j} = 0\)，也就是 整体缩放不改变输出。后者正是 RMSNorm 的不变性来源：\(\mathbf{x} \to c\mathbf{x}\) 时 \(\mathbf{y}\) 不变（分子分母同时乘 \(c\)）。LayerNorm 多一层不变性：\(\mathbf{x} \to \mathbf{x} + c\mathbf{1}\) 时 \(\mathbf{y}\) 也不变，而这恰恰是 RMSNorm 放弃的那个。

C.3 旋转位置编码：两种写法为什么等价

原文明确指出 RoPE 有两种「数学上等价」的实现——split-halves（本书与 Hugging Face 用的）和 interleaved（原论文与 Llama 官方代码用的），并说「两者编码相同的相对位置，只是维度配对方式不同」，但没有给出任何证明。这一页补上：先写旋转的数学形式，再证明相对位置性质，最后严格证明两种布局等价。

一、旋转矩阵与相对位置

1.1 二维旋转

最基本的事实是：二维向量乘一个形如

\[ R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} \]

的矩阵，等于把它转 \(\theta\) 角，且长度不变（\(\det R = \cos^2\theta + \sin^2\theta = 1\)，即 \(R\) 是正交矩阵，满足 \(R^\top R = I\)）。这两条性质是后面一切结论的来源。

预备知识：旋转矩阵长什么样

平面上把向量 \(\mathbf{v} = (x, y)\) 逆时针转 \(\theta\) 角，新坐标为 \((x\cos\theta - y\sin\theta,\; x\sin\theta + y\cos\theta)\)。写成矩阵乘法就是 \(\mathbf{v}' = R(\theta)\mathbf{v}\)，其中 \(R(\theta)\) 正是上面那个矩阵——它的两列分别是转后的基向量 \((1,0) \mapsto (\cos\theta, \sin\theta)\) 和 \((0,1) \mapsto (-\sin\theta, \cos\theta)\)。

另需两条三角恒等式（后面反复用）：\(\cos(-\theta) = \cos\theta\)（偶函数），\(\sin(-\theta) = -\sin\theta\)（奇函数）。

推导：\(R(\theta)\) 确实是「转 \(\theta\) 角」且保长

把 \(\mathbf{v}\) 写成极坐标 \(\mathbf{v} = (r\cos\varphi,\; r\sin\varphi)\)（\(r = \|\mathbf{v}\|\)），代入矩阵乘法：

\[ R(\theta)\mathbf{v} = \begin{pmatrix} r\cos\varphi\cos\theta - r\sin\varphi\sin\theta \\ r\cos\varphi\sin\theta + r\sin\varphi\cos\theta \end{pmatrix} \]

用和角公式 \(\cos(\varphi+\theta) = \cos\varphi\cos\theta - \sin\varphi\sin\theta\)、\(\sin(\varphi+\theta) = \sin\varphi\cos\theta + \cos\varphi\sin\theta\)，得

\[ R(\theta)\mathbf{v} = \big(r\cos(\varphi+\theta),\; r\sin(\varphi+\theta)\big) \]

即：模长仍是 \(r\)（长度不变），辐角从 \(\varphi\) 变成 \(\varphi + \theta\)（转了 \(\theta\) 角）。

正交性 \(R^\top R = I\) 直接乘一下验证：

\[ R^\top R = \begin{pmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{pmatrix} \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} = \begin{pmatrix} \cos^2\theta+\sin^2\theta & 0 \\ 0 & \sin^2\theta+\cos^2\theta \end{pmatrix} = I \]

对角元用 \(\cos^2 + \sin^2 = 1\)，非对角元 \(-\cos\theta\sin\theta + \sin\theta\cos\theta = 0\)。正交矩阵保内积：\((R\mathbf{a})^\top(R\mathbf{b}) = \mathbf{a}^\top R^\top R\,\mathbf{b} = \mathbf{a}^\top\mathbf{b}\)——这条性质在 1.3 和第五节都要用。

1.2 把 \(d\) 维向量拆成 \(d/2\) 个二维块

RoPE 的核心构造是：把 \(d\) 维 query/key 向量拆成 \(d/2\) 个二元组，第 \(i\) 个二元组用自己的角度 \(\theta_i\) 转。位置 \(m\) 处，角度是

\[ \theta_i(m) = m \cdot \omega_i, \qquad \omega_i = \theta_{\text{base}}^{-2i/d} = 10000^{-2i/d},\quad i = 0,1,\dots,\tfrac{d}{2}-1 \]

于是 \(d\) 维的旋转是一个分块对角矩阵，每个 \(2\times 2\) 块是不同角度的旋转：

\[ R(m) = \operatorname{diag}\big(R(\theta_0(m)),\, R(\theta_1(m)),\, \dots,\, R(\theta_{d/2-1}(m))\big) \]

RoPE 做的事就一句话：\(\mathbf{q}_m \leftarrow R(m)\,\mathbf{q}\)，\(\mathbf{k}_n \leftarrow R(n)\,\mathbf{k}\)。

1.3 关键定理：注意力分数只依赖相对位置

查询位置 \(m\)、键位置 \(n\) 的 attention 分数是旋转后的内积：

\[ \mathbf{q}_m^\top \mathbf{k}_n = \mathbf{q}^\top R(m)^\top R(n)\, \mathbf{k} \]

关键在于 \(R(m)^\top = R(-m)\)，且两个旋转相乘等于角度相加的旋转：

\[ R(-m)R(n) = R(-m + n) = R(n - m) \]

所以：

\[ \boxed{\;\mathbf{q}_m^\top \mathbf{k}_n \;=\; \mathbf{q}^\top R(n-m)\, \mathbf{k}\;} \]
推导：\(R(m)^\top = R(-m)\) 且 \(R(\alpha)R(\beta) = R(\alpha+\beta)\)

第一步：转置等于反向旋转。直接转置 \(R(m)\)（只含一个角度，记作 \(\theta\)）：

\[ R(\theta)^\top = \begin{pmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{pmatrix} \]

而 \(R(-\theta) = \begin{pmatrix} \cos(-\theta) & -\sin(-\theta) \\ \sin(-\theta) & \cos(-\theta) \end{pmatrix}\)，用预备知识里的奇偶性 \(\cos(-\theta)=\cos\theta\)、\(\sin(-\theta)=-\sin\theta\)，得 \(R(-\theta) = \begin{pmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{pmatrix}\)。两边完全相同，故 \(R(\theta)^\top = R(-\theta)\)。注意这是分块对角矩阵逐块成立，所以对整个 \(R(m)\) 也成立。

第二步：旋转相乘等于角度相加。直接做矩阵乘法，以 \((1,1)\) 元为例：

\[ \big[R(\alpha)R(\beta)\big]_{11} = \cos\alpha\cos\beta + (-\sin\alpha)(\sin\beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta = \cos(\alpha+\beta) \]

其余三元同理（分别对应 \(-\sin(\alpha+\beta)\)、\(\sin(\alpha+\beta)\)、\(\cos(\alpha+\beta)\)），合起来正是 \(R(\alpha+\beta)\)。同样逐块成立。

合起来：\(\mathbf{q}_m^\top\mathbf{k}_n = \mathbf{q}^\top R(m)^\top R(n)\,\mathbf{k} = \mathbf{q}^\top R(-m)R(n)\,\mathbf{k} = \mathbf{q}^\top R(n-m)\,\mathbf{k}\)。绝对位置 \(m, n\) 只以差的形式出现——这就是相对位置性质的全部证明。

绝对位置全部消掉了

右边完全没有 \(m\) 和 \(n\) 的绝对值，只差 \(n - m\)。这就是「RoPE 编码的是相对位置」的严格含义：把整个序列左移若干位，所有 attention 分数不变。

它换来了两个实际好处：(1) 训练时见过的相对距离在推理时自动外推——不像绝对位置嵌入那样超出训练长度就完全失效；(2) 与 KV cache 天然兼容——每个 token 入库时按自己的绝对位置转一次即可，缓存里存的是已旋转的 \(k\)，复用时无需再处理（对应 listing C.4 里的 apply_rope(keys_new, cos, sin, offset=start_pos)）。

相对位置是有方向的

\(n - m\) 而不是 \(|n - m|\)。因为因果掩码下 \(n \le m\)，实际取值都是非正的。也就是说 query 永远「看到自己左边」的距离；如果交换 query 和 key 的位置，分数一般会变（\(f(-(n-m)) \ne f(n-m)\)）。所以 RoPE 不能简单地当成一个对称的句法距离来用。

二、频率 \(\omega_i\) 的设计

为什么要取 \(\omega_i = 10000^{-2i/d}\) 而不是均匀的？关键是每个块能分辨的最小距离：角度每变化 \(\pi\) 才转过半个周期，所以第 \(i\) 个维度的「波长」是

\[ \lambda_i = \frac{2\pi}{\omega_i} = 2\pi \cdot 10000^{2i/d} \]

取 \(d = 64\)（Qwen3 0.6B：emb_dim 1024 ÷ 16 heads = head_dim 64），context_length = 4096（listing C.3 的默认值）：

多尺度的位置编码

高频维度（\(i\) 小）转得飞快，负责局部顺序——相邻两个词的区分；低频维度（\(i\) 大）转得极慢，负责全局顺序——相距几千个 token 的位置区分。整套机制等价于同时使用多个不同尺度的「相对位置特征」，用 \(d/2\) 个正交基把这 \(d/2\) 个尺度装进同一个向量里。

这正是绝对正弦位置编码（Vaswani et al. 2017）的思路，RoPE 的贡献是把它从「加到输入上」变成「旋转 q/k」——而正是这个改变带来了第 1.3 节的相对位置性质。

为什么 theta_base = 10000：它决定了频率梯度的陡峭程度。base 越大，高频维度越少、低频维度越多，模型越善于长程。base 太小则所有维度都转得太快，\(d/2\) 个尺度挤在短距离内。10000 是原论文在 512–8192 长度上选的经验值，Qwen3 把它带到 40,960 的上下文上。

三、手算：listing C.3 的角度表

listing C.3 里最绕的一行是：

inv_freq = 1.0 / (theta_base ** (
    torch.arange(0, head_dim, 2, dtype=dtype)[: (head_dim // 2)].float()
    / head_dim
))

拆开看：torch.arange(0, 64, 2) 得到 [0, 2, 4, ..., 62]，除以 head_dim = 64 得 [0, 1/32, 1/16, ..., 31/32]，取负号再以 10000 为底做幂：

\[ \omega_i = 10000^{-\,2i/64} = 10^{-4\cdot(2i/64)} = 10^{-i/8} \]

用 \(d = 64\) 核对：\(i = 0 \Rightarrow 10^0 = 1\)；\(i = 8 \Rightarrow 10^{-1} = 0.1\)；\(i = 16 \Rightarrow 10^{-2} = 0.01\)；\(i = 31 \Rightarrow 10^{-3.875} \approx 1.334\times 10^{-4}\)。与上表一致。

接下来的 angles = positions[:, None] * inv_freq[None, :] 就是外积，直接给出 \(m\omega_i\)；angles = torch.cat([angles, angles], dim=1) 把 \(d/2\) 列复制成 \(d\) 列——这正是 split-halves 布局的来源：前一半和后一半用完全相同的角度，所以代码里 cos、sin 的长度是 head_dim 而不是 head_dim/2。

四、apply_rope 的三行代码在做什么

x1 = x[..., : head_dim // 2]   # 前一半
x2 = x[..., head_dim // 2:]   # 后一半
rotated = torch.cat((-x2, x1), dim=-1)
x_rotated = (x * cos) + (rotated * sin)

设前半段为 \((x_0, x_1, \dots, x_{d/2-1})\)，后半段为 \((x_{d/2}, \dots, x_{d-1})\)，且 cos、sin 各为 \([c_0,c_1,\dots,c_{d/2-1},c_0,c_1,\dots,c_{d/2-1}]\)。那么输出是：

\[ \begin{aligned} y_i &= x_i c_i + (-x_{i+d/2})\, s_i = x_i\cos\theta_i - x_{i+d/2}\sin\theta_i, && i < \tfrac d2\\ y_{i+d/2} &= x_{i+d/2} c_i + x_i\, s_i = x_{i+d/2}\cos\theta_i + x_i\sin\theta_i \end{aligned} \]

这恰好就是第 1.2 节的分块旋转矩阵 \(R(m)\) 作用在 \(\mathbf{x}\) 上的结果，其中第 \(i\) 个二维块是 \(\binom{x_i}{x_{i+d/2}}\)。所以 split-halves 布局下，被配成一对的是「前半段第 \(i\) 个」和「后半段第 \(i\) 个」。

五、两种布局为什么等价（严格证明）

5.1 两种布局的配对规则

同一个频率列表 \([\omega_0, \omega_1, \dots]\)，两种布局把它挂到维度上的方式不同：

布局第 \(i\) 个频率配到的两个维度\(\cos\) 向量长什么样
interleaved（原论文 / Llama）\((2i,\ 2i+1)\)
相邻维度成对		\([c_0, c_0, c_1, c_1, c_2, c_2, \dots]\)
split-halves（本书 / HF）\((i,\ i + d/2)\)
前后两半对应位置成对		\([c_0, c_1, c_2, \dots, c_0, c_1, c_2, \dots]\)

这就是原文图里 cos cos cos cos sin sin sin sin 与 cos sin cos sin cos sin cos sin 的区别。

5.2 证明

引入置换矩阵 \(P\)，它把 interleaved 的布局重排成分块对角的 split-halves 布局：\(P\) 就是把维度 1 与 \(d/2\) 对调、维度 2 与 \(d/2+1\) 对调……的那个「完美洗牌」。它满足两个性质：

  • \(P^\top = P\)，\(P^\top P = I\)（正交，因此不改变内积）；
  • \(R_{\text{split}} = P\,R_{\text{inter}}\,P^\top\)——两个旋转矩阵只是彼此的重排版本，因为 \(R(\theta)\) 是分块对角的，重排块顺序仍是同类矩阵。

于是对 query 和 key 同时做变换：

\[ R_{\text{split}}\,\mathbf{q} = P R_{\text{inter}} P^\top \mathbf{q}, \qquad R_{\text{split}}\,\mathbf{k} = P R_{\text{inter}} P^\top \mathbf{k} \]

它们的内积为：

\[ \begin{aligned} (R_{\text{split}}\mathbf{q})^\top (R_{\text{split}}\mathbf{k}) &= \mathbf{q}^\top P^\top \underbrace{P R_{\text{inter}}^\top P\,P R_{\text{inter}} P^\top}_{=\,R_{\text{inter}}^\top P^\top P R_{\text{inter}} = R_{\text{inter}}^\top R_{\text{inter}} = I}\mathbf{k}\\ &= \mathbf{q}^\top R_{\text{inter}}^\top R_{\text{inter}}\mathbf{k} = (R_{\text{inter}}\mathbf{q})^\top (R_{\text{inter}}\mathbf{k}) \end{aligned} \]
预备知识：置换矩阵是正交矩阵

置换矩阵 \(P\) 的每一行、每一列恰有一个 1，其余为 0。它作用在向量上就是重排分量顺序。因为重排不改变各分量的平方和，\(\|P\mathbf{x}\|^2 = \|\mathbf{x}\|^2\)，故 \(P^\top P = I\)（正交）。

这里的 \(P\) 还是对合（involution）：它把维度 \(i\) 与 \(i+d/2\) 对调，再做一次就换回来，所以 \(P^2 = I\)，从而 \(P^\top = P^{-1} = P\)。正文里 \(P^\top\) 和 \(P\) 混用，正是这个原因。

推导：把转置一步步展开（不跳步版）

注意 attention 分数是两个不同位置的内积：query 在位置 \(m\)，key 在位置 \(n\)。记 \(R_s(m)=PR_i(m)P^\top\)（\(P\) 与位置无关，是固定的维度重排），直接展开：

\[ \begin{aligned} \big(R_s(m)\mathbf{q}\big)^\top\big(R_s(n)\mathbf{k}\big) &= \mathbf{q}^\top\big(PR_i(m)P^\top\big)^\top\big(PR_i(n)P^\top\big)\mathbf{k} \\ &= \mathbf{q}^\top P\,R_i(m)^\top\underbrace{P^\top P}_{=\,I}\,R_i(n)\,P^\top\mathbf{k} \qquad\text{（用 \((XYZ)^\top=Z^\top Y^\top X^\top\)，且 \(P^\top=P\)）}\\ &= \underbrace{(P^\top\mathbf{q})}_{\tilde{\mathbf{q}}}{}^\top R_i(m)^\top R_i(n)\,\underbrace{(P^\top\mathbf{k})}_{\tilde{\mathbf{k}}} \\ &= \big(R_i(m)\tilde{\mathbf{q}}\big)^\top\big(R_i(n)\tilde{\mathbf{k}}\big) \end{aligned} \]

即：split 布局下 \((\mathbf{q},\mathbf{k})\) 的分数，等于 interleaved 布局下重排后向量 \((\tilde{\mathbf{q}},\tilde{\mathbf{k}})=(P^\top\mathbf{q},P^\top\mathbf{k})\) 的分数——这正是 5.3 节表格"第一列 = 第三列"的由来。反过来读：如果先把 \(W_q,W_k\) 的输出行按 \(P\) 重排（实践中"换实现必须连权重一起重排"），两种布局逐元素给出相同的 logits。

一个容易混淆的点：\((R\mathbf{q})^\top(R\mathbf{k})=\mathbf{q}^\top\mathbf{k}\) 对任何正交矩阵 \(R\) 都成立，但它只讲同一位置的情形，与"两种布局是否等价"无关；真正的等价性是上面这个跨位置 \((m,n)\) 的恒等式。

置换矩阵 \(P\) 在中间以 \(P^\top P=I\) 的形式完全抵消后，剩下 interleaved 布局作用在重排向量上的分数。也就是说：两种布局给出逐元素相同的 attention logits（差一个固定的维度重排），因此逐元素相同的 softmax 权重、逐元素相同的输出。

等价性的真正含义

严格地说，两种实现产生的旋转后向量不同（维度被重排了），等价的是 attention 分数。这个区别很重要：如果你在训练中用 split-halves、在部署时换成 interleaved，而且没有用 P 重排权重（W_query / W_key 的输出行），模型输出会完全错乱——即使数学「等价」。所以实践中换实现必须连权重一起重排。原文只说「数学上等价」不涉及这一点，值得留意。

5.3 手算验证（\(d = 4\)）

取 \(\theta_{\text{base}} = 10000\)、\(d = 4\)，则 \(\omega_0 = 1.0\)，\(\omega_1 = 10000^{-1/2} = 0.01\)。设 query 向量 \(\mathbf{q} = [1, 2, 3, 4]\)，key 向量 \(\mathbf{k} = [0.5, -1, 2, 0.25]\)。先各自验证相对位置性质，再验证「重排后」的等价性：

位置差split-halvesinterleaved（同一 \(\mathbf{q},\mathbf{k}\)）interleaved（作用在 \(P\mathbf{q}, P\mathbf{k}\) 上）
\(m = 0,\ n = 3\)−7.640041+8.981546−7.640041
\(m = 5,\ n = 8\)−7.640041+8.981546−7.640041
\(m = 100,\ n = 103\)−7.640041+8.981546−7.640041

三件事一次看清：

  1. 每一列内部三行相同——相对位置性质成立：序列左移 5 格或 100 格，只要间距仍是 3，分数一动不动。
  2. 前两列不相等——对同一组 \(\mathbf{q},\mathbf{k}\) 直接换布局，分数会变。这不矛盾：两种布局配对的维度不同，旋转作用在不同的二维平面上。
  3. 第一列 = 第三列——先用置换 \(P\) 把向量重排成另一布局的配对（\([x_0,x_1,x_2,x_3]\mapsto[x_0,x_2,x_1,x_3]\)），再做 interleaved 旋转，分数就和 split-halves 逐位相同。这正是 5.2 节证明的内容：等价的是「布局 + 对应的权重重排」，不是「同一向量换个写法」。

六、常见误解

三个容易搞错的地方

1. RoPE 不是「加」到表示上，而是「转」q/k。它作用在 attention 的输入上，不在残差流上，因此不会像绝对位置嵌入那样污染后续层。

2. 不需要外推训练，就自动获得外推能力——但有上限。相对位置性质让长度外推成为可能，可一旦 \(n - m\) 超过训练时见过的最大相对距离，低频维度仍未转过半个周期，注意力会退化。真正的长上下文通常还需要 NTK-aware scaling、YaRN 之类的频率缩放。

3. 频率列表和配对方式是两个独立问题。调 theta_base 改的是频率；换 interleaved / split-halves 改的是配对。原文把它们并排展示，容易让人以为只是写法不同；实际上第 5.2 节的证明说明配对方式只要两边一致就完全不影响，而频率则直接决定模型能分辨多大的距离。

F.4 Elo 评级：公式、逐场手算与 k 值的作用

原文给出了 Elo 的两条公式和最终排行榜，但没有展示这 6 场比赛是怎么一步步推出 1043.7 / 1015.2 / 1000.7 / 940.4 的。这一页把每场比赛的 \(E\)、增量、赛后分数全部列出，并补上原文没展开的三件事：400 这个常数从哪来、\(k = 32\) 意味着什么、为什么顺序会影响结果。

一、两条公式

给定胜者当前评分 \(R_w\) 与败者当前评分 \(R_l\)，先算胜者的预期胜率：

\[ E_w = \frac{1}{1 + 10^{(R_l - R_w)/400}} \]

然后两边同时更新：

\[ R_w' = R_w + k\,(1 - E_w), \qquad R_l' = R_l + k\,(0 - (1 - E_w)) = R_l - k\,(1 - E_w) \]
预备知识：\(E_w + E_l = 1\)（预期胜率互补）

败者的预期胜率是 \(E_l = 1/(1+10^{(R_w-R_l)/400})\)。直接验算 \(1 - E_w = E_l\)：

\[ 1 - E_w = 1 - \frac{1}{1+10^{-\Delta R/400}} = \frac{10^{-\Delta R/400}}{1+10^{-\Delta R/400}} = \frac{1}{10^{\Delta R/400}+1} = E_l \]

（第三步分子分母同除以 \(10^{-\Delta R/400}\)。）所以"胜者预期拿 \(E_w\)"等价于"败者预期拿 \(1-E_w\)"——这正是更新公式里败者增量写成 \(-k(1-E_w)\) 的原因，也是"总量守恒"的概率基础。

一句话概括 Elo 的全部直觉

实际结果 \(S\) 与预期结果 \(E\) 的差，乘以 \(k\)，就是分数增量。

\[ \Delta = k\,(S - E), \qquad S = \begin{cases} 1 & \text{赢}\\ 0 & \text{输}\end{cases} \]

打爆冷门 → \(S - E\) 大 → 涨得多；稳赢送分 → \(S - E \approx 0\) → 几乎不动。这就是「赢强手涨得多，赢弱手涨得少」的全部机制。

二、400 这个常数从哪来

先看这个函数对评分差的形状。设 \(\Delta R = R_w - R_l\)，则

\[ E_w = \frac{1}{1 + 10^{-\Delta R / 400}} \]

这是 logistic 函数（形状和 softmax 里的 exp 归一化是同一族）。两个特例：

评分差 \(\Delta R\)\(E_w\)含义
00.5000势均力敌
1000.6400约 64% 胜率
2000.7597约 76%
4000.9091约 91%
8000.9901约 99%
推导：手算验证表格中的 \(\Delta R = 200\) 一行

\(E_w = 1/(1+10^{-200/400}) = 1/(1+10^{-0.5})\)。先算 \(10^{-0.5} = 1/\sqrt{10}\)：\(\sqrt{10} \approx 3.1623\)，故 \(10^{-0.5} \approx 0.31623\)。于是

\[ E_w = \frac{1}{1 + 0.31623} = \frac{1}{1.31623} \approx 0.7597 \]

与表格一致。同理 \(\Delta R = 100\) 时 \(10^{-0.25} = 1/\sqrt[4]{10} \approx 0.5623\)，\(E_w \approx 0.6400\)；\(\Delta R = 400\) 时 \(10^{-1} = 0.1\)，\(E_w = 1/1.1 \approx 0.9091\)。

所以 400 的含义是：领先 400 分 ≈ 10:1 的赔率。这个「差 400 分胜率九成」的习惯是国际象棋 Elo 的约定，沿用到了所有 Elo 变体里。数学上 400 完全自由（换成 200 或 800 只是让曲线更陡或更缓），它是一个尺度约定而非推导结果。

对比 sigmoid：Logistic 写出来是 \(E = \frac{1}{1+e^{-x/A}}\)，Elo 里 \(A = 400/\ln 10 \approx 173.7\)。理解成 \(A\) 控制「评分差被放大成多大优势」即可。
推导：\(10^{x/400} = e^{x/A}\)，其中 \(A = 400/\ln 10\)

换底恒等式：\(10^{y} = e^{y\ln 10}\)（两边取自然对数都是 \(y\ln 10\)）。取 \(y = x/400\)：

\[ 10^{x/400} = e^{(x/400)\ln 10} = e^{x / (400/\ln 10)} \]

于是 \(A = 400/\ln 10\)。数值：\(\ln 10 \approx 2.30259\)，故 \(A \approx 400/2.30259 \approx 173.72\)。\(A\) 越大，同样的评分差 \(x\) 对应的指数越小，曲线越平缓——这就是它"控制放大倍数"的含义。

三、\(k = 32\) 的作用

\(k\) 是每场比赛的最大分值变动幅度（因为 \(0 \le S - E \le 1\)，所以 \(|\Delta| \le k\)）。原文用 k_factor=32，initial_rating=1000。

\(k\)平局时的变动爆冷时的变动特点
4–16±2 ~ ±8接近上限保守，需要几千场才能收敛
32±16±32本书取值，平衡速度与稳定
64+±32 ~±64反应快，但对单场噪声敏感、易震荡
\(k\) 与「学习率」是同一个角色

\(k\) 越大，排行榜对最近的比赛越敏感（类似大学习率）；越小越稳定但迟钝（类似小学习率）。原始 Elo（\(k=32\)，定级赛用 \(k=10\)）后来演化出 Glicko（按表现方差给每个选手单独定 \(k\)，强手 \(k\) 小、弱手 \(k\) 大）。

在 LLM 场景，模型的数量远少于棋手、每场「对局」样本量大（每次都是成千上万条用户投票），所以 Arena 用 Bradley–Terry 而不是 Elo——见第七节。

4.1 三个关键场次的验算细节

第 1 场（平局）：\(R_l - R_w = 0\Rightarrow E_w = 1/(1+10^0) = 0.5\)，两边各 \(\pm 32 \times 0.5 = \pm 16\)。

第 3 场（弱势方赢了 16 分的落后者）：Claude-3 只有 984，Llama-3 有 1000，所以 ratings[loser] - ratings[winner] 是 正的 16：

\[ E_w = \frac{1}{1 + 10^{16/400}} = \frac{1}{1 + 10^{0.04}} = \frac{1}{1 + 1.0965} = 0.4770 \]

Llama-3 当时被看好（E > 0.5），却输了，所以扣掉 \(32 \times (1 - 0.477) = 16.74\) 分。这就是「爆冷要付出更大代价」——是双向的，冷门方赢时涨得更多。

第 6 场（最悬殊的一场）：GPT-5 此时 1031.3，Llama-3 只有 952.9，差 78.4 分：

\[ E_w = \frac{1}{1 + 10^{-78.4/400}} = \frac{1}{1 + 10^{-0.196}} = \frac{1}{1 + 0.6368} = 0.6109 \]

GPT-5 赢了，但只涨 \(32 \times (1 - 0.6109) = 12.45\) 分。78 分的优势只换来 12 分的涨幅——这就是 Elo 的「防爆冷」机制：它会自动把频率更高的结果吸收成更小的边际变化。

总量守恒的检验：每场比赛双方增量之和恰好为 \(+k(1-E) - k(1-E) = 0\)。整个算法不创造也不销毁分数，只是把分数在模型之间搬运。所以 1000 只是起点，真正有意义的是相对排名。

五、原文提到的顺序效应：为什么会发生

原文说：the same set of outcomes, when presented in a different order, can end with slightly different final scores。原因是 Elo 是逐场在线更新，第 \(k\) 场的 \(E\) 依赖前 \(k-1\) 场的结果，所以整个过程不是 \(S\) 的某个固定函数。

「爆冷发生得越早，影响越大」这一点可以直接看出来：

把 Claude-3 爆冷 Llama-3 放在该场 \(E_w\)Claude-3 涨分
第 1 场（双方都是 1000，势均力敌）0.5000+16.00
第 5 场（Claude-3 已被抬到 1000.7，Llama-3 掉到 967.3）0.5479+14.47

同一场「比赛」，先打涨 16 分后打只涨 14.47 分，差 1.53 分。虽然本例的差异温和（原文原话 usually mild），但在稀疏投票的排行榜上可以累积到足以颠倒名次。

原文给的解法，以及它的代价

原文建议：shuffle the votes pairs, run the elo_ratings function multiple times, and average the resulting ratings。这就是多次随机重排取平均，在数学上是对「不同置换下的终值」取期望，属于蒙特卡洛估计。

它确实能压掉顺序效应，但引入了新问题：\(f\) 是非线性的，\(E[f(x)] \ne f(E[x])\)。平均下来的分数不再对应任何一条真实的对局序列，也不保证满足 Elo 的自洽性条件 \(E_w(R_w, R_l) + E_l(R_l, R_w) = 1\)。所以它是个方便的启发式修正，不是原则性解法。

六、Elo 的三个隐含假设

  1. 零和：分数只在模型间搬运（第二节已验证）。
  2. 单一维度：每个模型只有一个分数，假设所有能力（数学、代码、写作、拒答率）排序一致。现实中不同模型强弱项不同，一个分数必然掩盖取舍——这是 Elo 排行榜最常被批评的地方。
  3. 结果无平局：S 只取 0/1。用户「两个都好」或「两个都差」被强行二选一，引入系统性偏差。

这三条也解释了原文 4.4 节里说的「benchmark 和 leaderboard 都能被 game，用户会按风格而非正确性来选」。

七、Elo → Bradley–Terry：Arena 为什么换掉了它

原文说 Arena 现在改用 Bradley–Terry，优势有两条。可以从上面的分析直接对上：

优势一：能给出置信区间。BT 是对整个数据集做一次联合最大似然拟合，似然曲面有明确的曲率信息，于是能算出 \(\hat{R} \pm \text{SE}\)。Elo 是逐场贪心更新，没有这个结构。两个模型分数只差 0.3 分时，区间会大幅重叠——排行榜上「相邻」其实往往是「分不出来」，而 Elo 的呈现方式掩盖了这一点。

优势二：免疫顺序效应。BT 一次性估计所有评分，是顺序无关的联合估计，而不是逐场递推，所以第三节的置换问题从根上消失。

两者的关系也很清楚： Bradley–Terry 拟合出来的分数，形状上就是第 1.2 节那个 logistic 函数，只是把它从「递推规则」变成了「待估参数」：

\[ P(A \succ B) = \frac{1}{1 + 10^{-(R_A - R_B)/400}} \]

原文因此说：the Bradley-Terry model is fitted to produce values comparable to Elo。所以「Elo」这个名字留下来了，但算的是 BT。

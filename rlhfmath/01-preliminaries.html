#0.1 期望：加权平均的另一种写法

复习 · 期望
离散：Ex∼P[f(x)] ＝ Σx P(x)·f(x)；连续：把 Σ 换成 ∫，P(x) 换成密度 p(x)。线性：E[aX+bY]＝aE[X]+bE[Y]，求导/求和可进期望里面。蒙特卡洛：从 P 中抽 B 个样本 xi，则 (1/B)Σf(xi) ≈ E[f]，B 越大越准——RL 里所有“empirical average”都是它。

例子：骰子点数 X，P＝1/6，则 E[X]＝(1+…+6)/6＝3.5。抽 3 次得 2,5,4，蒙特卡洛估计＝(2+5+4)/3＝3.67，已经接近 3.5。

全书通用
离散 E ＝ Σ P·f，连续 E ＝ ∫ p·f dτ，样本平均 (1/B)Σ f(τi) → E[f]

为什么 RL 总在期望和求和之间横跳？因为状态太多算不完 Σ，只能采样 B 条轨迹取平均（见 Eq 6.4→6.6）。记住：看到 Eτ∼π 就读作“按当前策略多跑几次取平均”。

#0.2 梯度三件套

复习 · 链式法则＋log trick
① 链式：d/dx f(g(x))＝f′(g)·g′(x)。② log-derivative trick：∇p＝p·∇log p，因为 ∇log p＝(∇p)/p。③ sigmoid σ(x)＝1/(1+e−x)，导数 σ′(x)＝σ(x)(1−σ(x))，且 σ(−x)＝1−σ(x)，−log σ(x) 求导得 −(1−σ(x))·x′。
  1. log 为什么能进期望？以后看到 ∇log π(a|s)，把它读作“让这个动作变 fashion 的方向”。log 把乘积变加法（log ab＝log a＋log b），求导后只剩策略项，环境项被消掉——这正是策略梯度 Eq 6.9–6.11 的核心。
  2. sigmoid 速算：σ(0)＝0.5，σ(2)≈0.88，σ(−2)≈0.12。导数在 0 处最大 0.25，往两边迅速变小——这解释了为什么 BT loss 在“已经分得很开”时梯度消失。
  3. 小练习：设 p＝erc/(erc+err)，证明 p＝σ(rc−rr)。提示：分子分母同除 erc，得 1/(1+e−(rc−rr))。这就是 Eq 5.2 / 5.4 的第一步，后面会反复用。

#0.3 KL、交叉熵、softmax：一家三口

复习 · 定义
softmax：把任意实数 ri 变成概率 eri/Σerj。交叉熵 H(P,Q)＝−ΣP log Q（用 Q 去猜 P 的代价）。KL：DKL(P‖Q)＝ΣP log(P/Q)＝H(P,Q)−H(P)，≥0 且仅当 P＝Q 取 0（Gibbs 不等式）。方向很重要：D(P‖Q) 对 Q 覆盖不到 P 的地方罚得很重。
Eq 15.3 / 15.4 同款
DKL(P‖Q) ＝ Σx P(x) log(P(x)/Q(x)) ＝ Ex∼P[log P(x) − log Q(x)]

语言模型里 P 常是“正在训的模型 π”，Q 是“参考模型 πref”。采样写法 Ex∼P[·] 让 KL 只需“从自己采样、查两个模型的 log prob 相减”，不用枚举整个词表（Eq 15.4 的由来）。

易错
KL 不是距离（不对称）！书里 reverse KL ＝ D(π‖πref)（从自己采样，保守、不敢去参考模型没见过的地方）；forward KL ＝ D(πref‖π)（要覆盖参考模型，常用于蒸馏）。RLHF 默认 reverse。

#0.4 MDP：s, a, r, p, γ 五个字母

s 状态 state
你在哪。机器人是位置速度；语言模型是“prompt＋已生成的前缀”。
a 动作 action
你干什么。机器人是推力；语言模型是“下一个 token”，整条回复是动作序列。
r 奖励 reward
干得好不好。RLHF 里是奖励模型打分 rθ(x,y)。
p 转移 transition
干了之后世界怎么变：p(s′|s,a)。语言模型单轮 RLHF 常没有转移（bandit）。
γ 折扣 discount
0–1，越小越短视。LM 的 RLHF 常取 γ＝1（整句只看最终分）。

策略 π(a|s)：给定状态出动作的概率表，就是语言模型本身。轨迹 τ＝(s0,a0,r0,…)。值函数 V(s)＝E[未来折扣回报|从 s 出发]，Q(s,a) 是“在 s 强制先做 a”的版本，优势 A＝Q−V（“比平均好多少”）。这三个字母贯穿 Ch 6。

#0.5 微积分速记：后面推导只用这几行

  • d/dx log x＝1/x；d/dx ex＝ex；d/dx clip(x) 在界内＝1，界外＝0（PPO/B 截断的梯度开关就这么来的）。
  • min(a,b) 求导＝跟随较小者。PPO 的 min(rA, clip(r)A) 本质是“ pessimistic：哪个好就信哪个里更保守的”。
  • Σ 与 ∇ 可交换：∇Σ＝Σ∇；E 与 ∇ 在“采样分布与 θ 无关时”可交换，有关时必须用 log trick（Eq 6.9 的全部难点）。
  • 几何平均 ⇔ 算术平均的 log：(∏pt)1/n＝exp((1/n)Σlog pt)——GSPO Eq 6.34 一行就靠它防溢出。

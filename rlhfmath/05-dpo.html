Ch 8DPO：三段推导全程

This chapter covers
  • Eq 8.1–8.4 DPO loss 长什么样、梯度在干什么
  • Eq 8.5–8.17 RLHF 最优解 π*＝πrefer/β/Z（Gibbs）
  • Eq 8.18–8.26 把 r 代回 BT 得 sigmoid（Z 相消）
  • Eq 8.27–8.29 loss 求导得加权 SFT 梯度

#Eq 8.1–8.3 先看答案

Eq 8.1 RLHF 目标（同 3.4）
maxπ ExEy∼π[r(x,y)] −βDKL(π‖πref)
Eq 8.2 DPO loss
L＝−E[ logσ( βlog(π(yc|x)/πref(yc|x)) −βlog(π(yr|x)/πref(yr|x)) ) ]
Eq 8.3 隐式奖励
r(x,y)＝βlog(πr(y|x)/πref(y|x))

人话：DPO 不训奖励模型，它说“最优策略和最优奖励是一枚硬币两面”（8.3），把 r 用 π 表示后塞进 BT，就得到只含两个模型 log prob 的 8.2。β 还是 KL 价格。

#Eq 8.4 梯度直觉（先记住，证在最后）

Eq 8.4
∇L＝−βE[ σ(r(yr)−r(yc))·(∇logπ(yc|x)−∇logπ(yr|x)) ]
  1. 权重 σ(rr−rc)∈(0,1)：排错了（rr＞rc）权重→1，大力改；排对且拉开，权重→0，几乎不动。
  2. 方向：加 yc 的 log prob，减 yr 的——加权版的 SFT。β 控制步子：β 大更信 KL（贴着 ref），β 小更激进。
  3. 伏笔：只增大 margin（c−r 之差），c、r 各自绝对值都可能掉——preference displacement（图 8.2），-calDPO 等变体为此而生。

#第一段 Eq 8.5–8.17：解出最优策略

Eq 8.5–8.6 展开 KL
max E[r]−βE[log(π/πref)] ＝ max E[ r −βlog(π/πref) ]
Eq 8.7–8.9 除以 β 变 min
＝ min E[ log(π/πref) −r/β ]（提 −1、除 β、max 变 min）
前置 · 配分函数 Z
Z(x)＝Σyπref(y|x)exp(r(x,y)/β)：对所有可能回答求和的归一化常数，只与 x 有关。实际算不出（y 空间巨大），但推导中会被消掉——DPO 巧妙正在此。
Eq 8.10–8.11 配分
Z(x)＝Σyπrefexp(r/β)；目标＝min E[ log( π/( (1/Z)πrefexp(r/β) ) ) −logZ ]
  1. 8.12→8.15（加减 logZ＋合并）：原式 log(π/πref)−r/β，加 (logZ−logZ)＝0 得 [log(π/πref)＋logZ]−logZ−r/β；log a＋log b＝log ab 得 log(πZ/πref)−logZ−r/β；把 r/β 写成 log exp(r/β) 并入分母，即得 8.11 方括号。
  2. 8.16 看成 KL：方括号＝log( π / [ (1/Z)πrefexp(r/β) ] )，对 y∼π 取期望正是 DKL(π‖(1/Z)πrefer/β)。−logZ 与 π 无关，扔掉。
  3. 8.17 Gibbs 不等式：KL≥0，仅当两分布相等取 0，故最优 π*＝(1/Z)πrefexp(r/β)。一句话：最优策略＝参考策略按 er/β 加权再归一化。

#第二段 Eq 8.18–8.26：把 r 换成 π

Eq 8.18 BT
p*(y1≻y2|x)＝er*(x,y1)/(er*1＋er*2)
Eq 8.19–8.22 解 r*
logπ*＝−logZ＋logπref＋r*/β ⇒ r*＝βlog(π*/πref)＋βlogZ
  1. 8.19–8.20：对 8.17 取 log：logπ*＝log(1/Z)＋logπref＋log exp(r*/β)＝−logZ＋logπref＋r*/β（log abc＝和）。
  2. 8.21–8.22：移项 ×β 即得 r* 表达式。注意多出 βlogZ——下一步会被消掉。
  3. 8.23–8.24 代入 BT：p*＝exp(βlog(π*1/πref1)＋βlogZ)/[分母两项同理]。ea+b＝eaeb，每项都带因子 eβlogZ＝Zβ，分子分母约掉（Z 与 y 无关），得 8.24。
  4. 8.25–8.26 化 sigmoid：分子分母同乘 exp(−βlog(π*1/πref1))：＝1/[1＋exp(βlog(π*2/πref2)−βlog(π*1/πref1))]；记 x＝βlog(π*1/πref1)−βlog(π*2/πref2)，分母＝1＋e−x，即 σ(x)。证毕——这就是 8.2（y1＝yc）。
Z 去哪了？
Z(x) 只与 prompt 有关，与 y 无关，在 BT 的比值里分子分母同乘同除被消掉。这就是 DPO 不用估计不可算的 Z 也能训的原因——BT 只关心差值（回看 §5.1“只有差值重要”）。

#第三段 Eq 8.27–8.29：对 loss 求导

Eq 8.27–8.28
∇L＝−∇E[logσ(u)]，u＝βlog(π(yc)/πref)−βlog(π(yr)/πref)；＝−E[ σ′(u)/σ(u)·∇u ]
Eq 8.29 结果
＝−E[ βσ(βlog(π(yr)/πref)−βlog(π(yc)/πref))·(∇logπ(yc)−∇logπ(yr)) ]
前置 · 三个求导
dσ/dx＝σ(1−σ)；dlogx/dx＝1/x；σ(−x)＝1−σ(x)。πref 与 θ 无关，∇ 只打 πθ。
  1. 链式：∇logσ(u)＝(1/σ(u))·σ′(u)·∇u＝(1/σ)·σ(1−σ)·∇u＝(1−σ(u))∇u。
  2. 1−σ(u)＝σ(−u)：−u＝βlog(πr/πref)−βlog(πc/πref)，即 8.29 的 σ 里那串。
  3. ∇u：∇[βlogπ(yc)−βlogπref−βlogπ(yr)＋…]＝β(∇logπ(yc)−∇logπ(yr))（ref 项导数 0）。合起来即 8.29＝8.4。证毕。
  4. 代码：pi＝chosen−rejected；ref＝ref_chosen−ref_rejected；loss＝−logsigmoid(β·(pi−ref))，chosen_rewards＝β·(policy−ref).detach() 供打日志。

记住 DPO 的 tradeoff：简单（无采样、无 value、无 reward 模型）、KL 静态（β 一步到位），但信号来自离线 pair，上限常比在线 RL 低一截（原书 8.5）。

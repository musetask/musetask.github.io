Ch 5奖励模型：从偏好到 loss

This chapter covers
  • Eq 5.1–5.3 Bradley-Terry：pi/(pi+pj) 与 σ(ri−rj) 等价
  • Eq 5.4–5.6 负对数似然：两种写法 −logσ(Δ)＝log(1+e−Δ)
  • Eq 5.7 margin、Eq 5.8 多比较加权、Eq 5.9 Plackett-Luce K-wise
  • Eq 5.10 ORM 与 Eq 5.11 PRM：二分类交叉熵搬到 token/step 上

#Eq 5.1–5.2 BT 模型：强度 → sigmoid

原书 Eq 5.1
P(i≻j) ＝ pi/(pi＋pj)，pi＞0
原书 Eq 5.2
令 pi＝eri，则 P(i≻j) ＝ eri/(eri＋erj) ＝ σ(ri−rj)，σ(z)＝1/(1＋e−z)
  1. 为什么要 pi＞0？把每个物品的“潜在实力”想成正数，i 赢的概率正比于实力占比。实力翻倍，胜率按比例涨——这是 Bradley-Terry 1952 年的原始假设。
  2. 换参：正数不方便优化（梯度要 constrained），令 pi＝eri，ri∈ℝ 无约束。代入得 eri/(eri＋erj)。
  3. 化成 sigmoid：分子分母同除 eri：＝1/(1＋e−(ri−rj))＝σ(ri−rj)。证毕。只有差值重要：全体 r 加常数 C，差不变，概率不变——奖励模型输出整体平移不影响偏好。
  4. 数字：ri−rj＝0→0.5；＝2→σ(2)≈0.88；＝−2→0.12。

#Eq 5.3–5.4 从概率到训练目标

原书 Eq 5.3
P(y1≻y2|x) ＝ exp(rθ(y1|x))/(exp(rθ(y1|x))＋exp(rθ(y2|x)))
原书 Eq 5.4 全程
θ*＝argmaxθ P(yc≻yr|x)＝…＝argmax σ(rθ(yc|x)−rθ(yr|x))＝argmin −logσ(Δ)
前置 · 极大似然
想让模型“说对偏好”，就最大化它给正确偏好 yc≻yr 赋的概率。取 −log 后“最大化概率”变“最小化 loss”（数值更稳），这就是全部机器学习的 MLE 套路。
  1. 记 Δ＝rc−rr。由 5.2，P＝σ(Δ)。
  2. 原书中间 4 行只是在消元：exp(rc)/(exp(rc)＋exp(rr))→ 分母提 exp(rc) →1/(1＋exp(rr)/exp(rc))→1/(1＋exp(−Δ))→σ(Δ)。每一步都是“同除 exp(rc)＋指数相减”。
  3. 取负对数：loss＝−logσ(Δ)。Δ＝3（c 强很多）→σ≈0.953→loss≈0.048；Δ＝−1（排反了）→σ≈0.269→loss≈1.31，梯度会大力纠正。

#Eq 5.5＝Eq 5.6：两种写法等价

Eq 5.5 / 5.6
L ＝ −logσ(rc−rr) ＝ log(1＋err−rc)，记 Δ＝rc−rr
  1. 证：σ(Δ)＝1/(1＋e−Δ)，取 −log：−logσ＝−log1＋log(1＋e−Δ)＝log(1＋e−Δ)。而 −Δ＝rr−rc，即得 5.6。
  2. 代码对应：loss＝-F.logsigmoid(chosen−rejected).mean() 就是 5.5 的 batch 平均；logsigmoid 比先 sigmoid 再 log 稳定（防 e−Δ 溢出）。
  3. 梯度（后面 DPO 还会用）：dL/dΔ＝−(1−σ(Δ))＝σ(Δ)−1≤0。所以 ∂L/∂rc＝σ(Δ)−1（负，增大 rc 降 loss），∂L/∂rr＝1−σ(Δ)（正，减小 rr 降 loss）。分错时 |梯度|≈1，分对且 Δ≫0 时梯度→0。

#Eq 5.7 margin：Likert 分差也要学

原书 Eq 5.7（Llama 2）
L ＝ −logσ(rc−rr − m(yc,yr))，如 5 分 vs 2 分则 m＝3

人话：原来只要求 rc＞rr（赢 0.01 也行）；现在要求赢 至少 m 分：rc−rr＞m。m 大＝“碾压局”，loss 更难降，梯度更大。Llama 3 发现放大量后收益递减，又去掉了——记住“margin 是可选插件”。

#Eq 5.8 一 prompt 多比较：除以 C(K,2)

原书 Eq 5.8（InstructGPT）
L ＝ −1/C(K,2)·E[logσ(rc−rr)]，C(K,2)＝K(K−1)/2

人话：一个 prompt 采 K 个回答，两两配对有 C(K,2) 对。若直接求和，K 大的 prompt 主导梯度（overfit 到这些 prompt）。除以对数＝“每 prompt 等权”。实现技巧：把同一 prompt 的 pairs 放同一 batch，自然平均。

#Eq 5.9 Plackett-Luce：K 个的排序概率

原书 Eq 5.9
P(σ|x,a0…aK−1) ＝ ∏k＝0K−1 exp(r(s,aσ(k)))/Σj＝kK−1 exp(r(s,aσ(j)))
前置 · 排序即连摔
想象 K 个人依次领奖：先从 K 人里按 softmax 选第一（分母 K 项），再从剩下 K−1 人里选第二……连乘即整排序概率。K＝2 时只剩一项＝BT。
  1. 验 K＝2：k＝0 项＝erσ0/(erσ0＋erσ1)＝σ(Δ)，k＝1 项＝er/er＝1，乘积＝BT。证毕。
  2. Starling 用它：一次给 K 个回答的完整排序，一条样本顶多对 pair，数据效率高，但标注贵。

#Eq 5.10 ORM：每 token 的二分类

原书 Eq 5.10
LCE ＝ −E[r·log pθ(s)＋(1−r)·log(1−pθ(s))]，r∈{0,1} 对错标签
前置 · BCE
二分类交叉熵：猜对（r＝1 时 p→1）loss→0；猜反 loss→∞。pθ＝sigmoid(logit)。ORM 把它搬到每个 token：整句对＝全 token 目标 1，错＝全 0。

与 BT 的区别：BT 要成对 (yc,yr) 做差；ORM 只要单句＋对错标签，loss 更像语言建模。代价：每 token 都给同标签，噪声大（第一 token 何辜）。代码即 BCEWithLogitsLoss(logits[mask], labels)，prompt token 用 −100 mask 掉。

#Eq 5.11 PRM：只在 step 末打分

原书 Eq 5.11
LPRM ＝ −E[ Σi＝1K yilog rθ(si|x)＋(1−yi)log(1−rθ(si|x)) ]，yi∈{0,1} 每步对错

人话：ORM 的求和在 token 上，PRM 的求和在推理步骤上。实现：只在分隔符（如双换行）处放 label，其余 token label＝−100 不算 loss。三分类变体（−1/0/1）把 BCE 换成 CE：CrossEntropy(logits[mask], labels)。

三者速查
BT：整句一个分，对比学；ORM：每 token 一个分，对错学；PRM：每 step 一个分，逐步学。Value 函数（Ch 6）外形像 ORM（每 token 回归未来回报），但目标是 E[回报] 而非对错概率。

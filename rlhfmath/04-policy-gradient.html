#Eq 6.1–6.4 回报与值：Gt、V、J

Eq 6.1
Gt ＝ Rt+1＋γRt+2＋… ＝ Σk＝0∞ γkRt+k+1
Eq 6.2 递推
Gt ＝ Rt+1＋γGt+1
Eq 6.3–6.4
V(s)＝E[Gt|St＝s]，J(θ)＝Σs dπ(s)Vπ(s)
  1. 6.1→6.2：把 6.1 第二项起提 γ：γ(Rt+2＋γRt+3＋…)＝γGt+1，剩首项 Rt+1。这是后面 TD、GAE 递推的源头。
  2. 6.3：V 是“从 s 出发的平均未来折扣和”。Q(s,a) 是“先强制做 a 再按 π 走”；A＝Q−V（好多少）。
  3. 6.4：J 按访问频率 dπ(s) 加权平均各状态值。实践中不枚举 s，改采样 B 条 (x,y) 取平均：Ĵ＝(1/B)ΣR(xi,yi)（bandit 版）或按步求和版——§0 蒙特卡洛。

#Eq 6.9–6.11 log-derivative trick（全章最重要 5 行）

Eq 6.9–6.11
∇J＝∫∇pθ(τ)R dτ；∇log p＝∇p/p ⇒ ∇p＝p∇log p；∴ ∇J＝E[∇log pθ(τ)·R(τ)]
前置 · 为什么能把 ∇ 塞进 E
∇J＝∇∫pR＝∫∇pR（R 与 θ 无关，∇ 只打 p）。再把 ∇p 换成 p∇log p，p 正好和积分凑成期望。这一步把“对分布求导”变成“对 log 概率求导再按分布平均”——采样就能算。
  1. 展开 log p(τ)：log p＝log p(s0)＋Σlog π＋Σlog p(s′|s,a)。前两项与 θ 无关（∇＝0），只剩 Σ∇log π(at|st)。
  2. 代回：∇J＝E[ (Σt∇log π(at|st))·R(τ) ]。直觉：整条轨迹分高（R 大），就把沿途每个动作的 log prob 都往上推；分低就往下推。
  3. 方差警告：用整条 R(τ) 给每一步记功，噪声极大——于是引入 baseline/优势（下一节）。

#Eq 6.12–6.13 Ψt 六兄弟＋语言模型版优势

Eq 6.12 通式
g＝E[ Σt ∇log π(at|st)·Ψt ]，Ψt 可取：①R(τ) ②Σt′≥trt′(＝Gt) ③Gt−b(st) ④Q ⑤A ⑥r＋V(s′)−V(s)(TD 残差)
Eq 6.13 LM 版
A(s,a)＝Q(s,a)−V(s)＝V(s+a)−V(s)＝r＋γV(s+a)−V(s)

② 比 ① 好：t 时刻前的奖励与当前动作无关，去掉降方差（因果性）。③–⑤ 再减 baseline（见下）。⑥ 是单步 TD 版。语言模型里 Q(s,a)＝V(s+a)（把“prompt＋continuation”看成新状态），故优势＝整句值减 prompt 值。

#Eq 6.14–6.18 baseline：为什么减个均值梯度不变

Eq 6.14 / 6.15 / 6.17 / 6.18
∇J＝E[Σ∇log π·Rt]；→ E[Σ∇log π·A]；REINFORCE: E[Σ∇log π·(Gt−b)]
Eq 6.16 REINFORCE 三件套
Δθ＝α(r−b)e（步长×中心化奖励×eligibility＝log prob 梯度）
前置 · baseline 无偏性
Ea∼π[∇log π(a|s)·b(s)]＝b(s)·Σ∇π＝b(s)·∇Σπ＝b(s)·∇1＝0。所以减任何只与 s 有关的 b(s)，期望梯度不变，但方差大降。记住：与 a 无关才能减。

最简 b＝batch 均值；更好 b＝V(s)（学出来的）。(G−b) 即优势 A 的蒙特卡洛版。Eq 6.16 的 e 在现代实现里就是 ∇log π。

#Eq 6.19–6.21 RLOO：leave-one-out 基线

Eq 6.19 / 6.20 / 6.21
b(s,ak)＝1/(K−1)·Σi≠kR(s,ai)；A＝Rk−b；＝K/(K−1)·(Rk−(1/K)ΣiRi)
  1. 做法：同一 prompt 采 K 个回答，给第 k 个的基线＝其他 K−1 个的均值（不用自己，避免 bias）。
  2. 6.21 推导：记均值 m̄＝(1/K)ΣRi。b＝(K·m̄−Rk)/(K−1)。A＝Rk−b＝Rk−(K·m̄−Rk)/(K−1)＝[Rk(K−1)−K·m̄＋Rk]/(K−1)＝K(Rk−m̄)/(K−1)。证毕。
  3. 例子：K＝4，R＝[3,1,1,1]，m̄＝1.5。对 k＝1：b＝(1+1+1)/3＝1，A＝2；用 6.21：4/3×(3−1.5)＝2。一致。
  4. 实现：同一 advantage 广播到该回答的所有 token（bandit 风格）；KL 是把每 token KL 求和后折进序列 reward 再算 A（与 PPO 的 per-token 扣减不同）。

#Eq 6.22–6.25 PPO：ratio＋clip＋min

Eq 6.22 / 6.23 / 6.25
J＝min( r·A, clip(r,1−ε,1＋ε)·A )，r＝πθ/πold
Eq 6.24 per-token LM 版
J＝(1/|a|)Σt min( rtAt, clip(rt)At )（1/|a| 是实现习惯，非原始推导）
前置 · 重要性采样一句话
想用旧策略采的数据估计新策略的期望，乘权重 r＝πnew/πold 纠偏。r＝1.2 表示新策略更喜欢这个样本，梯度放大 1.2 倍。
  1. r 从哪来：多步梯度时 πθ 已漂离采样时的 πold，期望须纠偏。首步 r＝1（还没动）。
  2. 正优势 A＞0（好动作，想加概率）：r＜1−ε→用 rA（正常推）；1−ε≤r≤1＋ε→用 rA；r＞1＋ε→用 (1＋ε)A（常数，梯度 0，不再推）。总结：只在 πnew≤(1＋ε)πold 时更新。
  3. 负优势 A＜0（坏动作，想降概率）：r＜1−ε→常数（梯度 0，不再踩）；中间→用 rA；r＞1＋ε→用 rA（继续降）。总结：只在 πnew≥(1−ε)πold 时更新。两表合起来＝“trust region 内＝普通 PG，之外梯度置零”。
  4. loss 符号：代码写 pg1＝−A·r，pg2＝−A·clip(r)，取 max（＝−min），再平均。value 另有一个 MSE loss（critic），见原书 6.2.4。

#Eq 6.26–6.28 GRPO：组内标准化＋loss 里加 KL

Eq 6.26 / 6.27 / 6.28
J＝(1/G)Σi[ min(riAi,clip(ri)Ai) −βDKL(π‖πref) ]；Ai＝(ri−mean)/std（per-token 版再除 |ai|）
  1. 与 PPO 两处不同：① 无 value 网络（省一份模型内存；value 难训）；② KL 不折进 reward，直接加在 loss 后（β·KL）。RLOO 把 KL 折进 reward 再算 A，GRPO 把 KL 单列——数值等价类不同，实现习惯不同。
  2. 优势：同 prompt 的 G 个回答算 mean/std，Ai 是“比组内平均好几个标准差”。std 小（全对/全错）时 A 被放大——这是 bias（简单题权重虚高），Dr.GRPO 要删 std（下节）。
  3. 例子：r＝[3,1,1,1]，mean＝1.5，std≈1.0，则 A≈[1.5,−0.5,−0.5,−0.5]。

#Eq 6.29–6.31 Dr.GRPO＝RLOO 的缩放版

Eq 6.29 / 6.30 / 6.31
Ãi＝ri−(1/G)Σrj（去 std）；ARLOOi＝ri−1/(G−1)Σj≠irj；G/(G−1)·Ãi＝ARLOOi
  1. 证：G/(G−1)·(ri−m̄)＝[G·ri−Σrj]/(G−1)＝[ (G−1)ri−Σj≠irj ]/(G−1)＝ri−Σj≠irj/(G−1)＝RLOO。证毕。
  2. 含义：常数缩放 G/(G−1) 可被学习率吸收，故两者等价（差个 lr）。去 std 后难样本（1 对多错）不再被 std 放大/缩小，学得更稳，但简单题信号变弱——tradeoff。

#Eq 6.32–6.37 重要性采样 → GSPO / CISPO

Eq 6.32 恒等式
Ep[f]＝Eq[ f·p/q ]，p＝πθ（想优化的），q＝πold（采样的）
Eq 6.33–6.35 GSPO
π(a|s)＝∏tπ(at|s,a<t)；ρi＝(π(ai|s)/πold(ai|s))1/|ai|＝exp((1/|ai|)Σlog(π/πold))；J＝(1/G)Σmin(ρiAi,clip(ρi)Ai)
Eq 6.36–6.37 CISPO
J＝(1/Σ|ai|)ΣΣ sg(ρ̂i,t)Ai,tlogπ(ai,t|·)，ρ̂＝clip(π/πold,1−εlow,1＋εhigh)
  1. 6.32 证（离散）：Ep[f]＝Σp·f＝Σq·(p/q)·f＝Eq[f·p/q]。异步训练（vLLM 采样 vs FSDP 训练权重不同步）与多步梯度都靠它纠偏。
  2. GSPO 动机：per-token ratio 长链连乘数值炸（MoE 更甚），且 reward 本是序列级，纠偏也该序列级。几何平均开 1/|a| 次方＝“平均每 token 的 ratio”，不同长度可比；实现时把同一 ρi 广播到该回答所有 token。
  3. CISPO 动机：PPO 的 clip 一旦越界梯度＝0（token dropping：稀有但关键的推理 token 学不出来）。CISPO 改 clip 权重本身（sg＝stop-gradient，只取值不求导），再乘回 REINFORCE 式的 A·logπ：越界也还有梯度，只是被限幅。非对称 εlow≠εhigh（clip-higher）允许往上走大步鼓励探索。

#Eq 6.38 单梯度步：r＝1，clip 消失

Eq 6.38
一步时 πθ＝πold，J＝(1/G)Σ( π/［π］∇·A −βKL )，［·］∇＝stop-gradient

r 恒 1，min/clip 无意义，PPO 退化成普通 PG＋KL。很多 LM 的 PPO/GRPO 只跑 1 步／batch，书里提醒此时“PPO 原生正则从未生效，起作用的全是 KL”——看 clip_frac 全 0 别慌。

#Eq 6.39–6.41 GAE：λ 加权的 telescoping

Eq 6.39 n 步 / 6.40 TD / 6.41 GAE
Â(n)t：n＝1: r＋γV′−V；n＝2: r＋γr′＋γ²V″−V；… n＝∞: 全回报−V
δt＝rt＋γVt+1−Vt；ÂGAE＝Σl＝0∞(γλ)lδt+l，λ＝0→TD，λ＝1→蒙特卡洛
  1. 6.41 推导梗概：ÂGAE＝(1−λ)(Â(1)＋λÂ(2)＋λ²Â(3)＋…)。把 Â(n) 写成 δ 之和（Â(2)＝δt＋γδt+1，以此类推），合并 δt 系数：(1−λ)(1＋λ＋λ²＋…)＝1；δt+1 系数：(1−λ)γ(λ＋λ²＋…)＝γλ；一般项 (γλ)l。证毕（几何级数 1/(1−λ)）。
  2. λ：0＝只信 value（bias 大方差小），1＝全信采样回报（反之），0.95 常用。LM 的 RLHF 常 γ＝1（短序列不折扣）。
  3. 代码：倒序循环 gae＝δ＋γλ·not_done·gae；terminal 处 not_done＝0 截断（可 pack 多序列）。targets＝adv＋values 训 value；adv.detach() 训 policy。

#无编号但必考：三种 loss 聚合除法

① per-sequence: (1/B)Σi(1/|ai|)Σtℓi,t（GRPO/部分 PPO，每句等权）
② per-token: ΣΣℓ/Σ|ai|（DAPO，每 token 等权）
③ fixed-length: (1/B)Σ(1/Lmax)Σℓ（Dr.GRPO，每 token 等梯度但长句总梯度大）

例子 seq1＝[1,1,1,1,10]（5 token 均值 2.8），seq2＝10 token 均值 1.9：① batch＝(2.8+1.9)/2＝2.35（短句每 token 梯度 0.25＞长句 0.14）；②＝(14+19)/15＝2.2（每 token 0.0909 拉平）；③ 除 Lmax＝10 得 1.4/1.9（梯度 0.1429 拉平但长句总量大）。MDP（token 级 advantage＋GAE）vs bandit（序列 advantage 广播）即聚合视角的两种建模，见原书 6.2.2 相关框。

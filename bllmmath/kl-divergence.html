KL 散度：从“分布”开始，一步步推出来

这一页只讲一件事：KL 散度是怎么定义的，为什么长成那个样子。不需要任何前置数学，每用一个概念就在这里现推。

路线：分布 → 期望 → 对数 → 自信息 → 熵 → 交叉熵 → KL。最后回到书里第 5 章的困惑度。

0. 分布：就是一张和为 1 的表

抛一个骰子，1~6 点各占多大概率？就是一个离散概率分布：

点数123456
概率 \(p_i\)1/61/61/61/61/61/6

合法只有两条：

\[ p_i \ge 0, \qquad \sum_{i} p_i = 1 \]

换到 LLM，只是把 6 面换成 50257 个 token：

\[ q = (q_1, \dots, q_{50257}), \quad \sum q_i = 1 \]

比如书 5.3.1 节 \(T=1\) 时：forward 0.5721，toward 0.3576，closer 0.0609，其余全是 0.00 几，加起来 =1。这就是模型分布 \(q\)。

而真实分布 \(p\)在训练时是确定的：答案是哪个词，哪个位置就是 1，其余 0。这叫 one-hot。比如目标是 forward：

词closerforwardtoward其余50254个
\(p\)0100
\(q\)（模型）0.06090.57210.3576≈0

预训练就是想让下面那行越来越像上面那行。KL 就是量“有多不像”的尺子。

为什么需要 softmax

模型的原始输出 logits 比如 \([4.51, 0.89, -1.90]\) 是可以为负、加起来不为 1 的，没法当概率。\(p_i = e^{z_i}/\sum_j e^{z_j}\) 的全部作用就是把它们变成合法的分布：分子 \(>0\) 保证非负，分母一除保证求和 =1。

1. 期望：加权平均

设 \(X\) 是“掷出几点”，取到 \(i\) 的概率是 \(p_i\)。长期平均值叫期望：

\[ \mathbb{E}[X] = \sum_i i \cdot p_i \]

例：\(p=(0.6,0.3,0.1)\) 对应取值 1,2,3：

\[ \mathbb{E}[X] = 1\times 0.6 + 2\times 0.3 + 3\times 0.1 = 1.5 \]

记住这个句式：\(p_i\) 是权重，加权的对象后面会换。后面熵就是把 \(i\) 换成 \(-\log p_i\)。

2. 对数：把乘法变加法

全章只用两条：

\[ \log(ab)=\log a+\log b, \qquad \log a^b = b\log a \]

外加单调性：\(a>b \iff \log a > \log b\)。所以“最大化概率”和“最小化 \(-\log\)概率”是同一件事。

为什么非取对数不可？书 5.1.2 节 6 个词的概率是 \(7\times 10^{-5}, 3\times 10^{-5}\dots\)，连乘得 \(10^{-23}\) 量级，32 个词连乘直接下溢到 0（float32 最小 \(1.2\times 10^{-38}\)）。取对数变成 \([-9.5,-10.3\dots]\) 相加，数值很健康。这步是必需的。

底的选择：\(\ln\)（自然对数）求导最方便，\(\log_2\) 读成“比特”最直观，两者差常数 \(\ln 2 = 0.6931\)。记住 \(\ln 50257 = 10.8249\)，后面会用。

3. 自信息与熵：有多“意外”

自信息（surprisal）：概率越小的事越意外：

\[ \mathrm{sp}(i) = -\log_2 p_i \]

\(p=1\) 必然发生，意外为 0；\(p=0.0001\) 很意外，值很大。

熵：把意外程度按 \(p\) 取期望：

\[ H(p) = \sum_i p_i (-\log_2 p_i) = -\sum_i p_i\log_2 p_i \]

均匀分布最意外：\(p_i=1/V\) 时 \(H=\log_2 V\)。代入 \(V=50257\) 得 15.62 比特。

一句话

熵 = 这个分布平均有多意外。分布越平，熵越大。

4. 交叉熵：用真实权重去量模型

不能用 \(q\) 自己的权重算熵，那是自说自话——模型自信地犯错时它会说自己很确定。正确做法：用真实 \(p\) 做权重，去量模型 \(q\) 有多意外：

\[ H(p,q) = -\sum_i p_i \log_2 q_i \]

训练时 \(p\) 是 one-hot，只剩一项。比如目标是 forward，\(p_{forward}=1\)：

\[ H = -\log q_{forward} = -\log 0.5721 = 0.81 \,\text{比特} \]

这就是书 figure 5.7 算的 \(-\log\) 再平均。\(q\) 给真实词的概率越高，交叉熵越小。

5. KL 散度：定义与手算

\[ \boxed{D_{KL}(p\|q) = \sum_i p_i \log_2 \frac{p_i}{q_i}} \]

读法：拿 \(q\) 去假装 \(p\)，平均每件事多花多少比特。权重永远是真实 \(p\)，里面是比值 \(p_i/q_i\)：猜准了比值=1，\(\log 1=0\) 不罚钱；低估了比值>1，罚钱。

手算一个：偏向硬币 vs 公平硬币

真实 \(p=(0.9,0.1)\)，模型以为 \(q=(0.5,0.5)\)：

\[ \begin{aligned} D &= 0.9\log_2\frac{0.9}{0.5} + 0.1\log_2\frac{0.1}{0.5} \\ &= 0.9\times 0.848 + 0.1\times (-2.322) \\ &= 0.531 \,\text{比特} \end{aligned} \]

拿公平硬币的假设去解释 9:1 的硬币，每抛一次多花 0.53 比特。若 \(q=p\)，比值全 1，\(D=0\)。

无穷大惩罚

若 \(p_i>0\) 但 \(q_i=0\)（模型说“不可能”，现实却发生了），那一项是 \(\log(p_i/0)=+\infty\)。所以训练时模型不敢把正确答案的概率压到 0。

关键恒等式（书 0.3 节的）

用 \(\log\frac{p_i}{q_i}=\log p_i-\log q_i\) 展开：

\[ \boxed{H(p,q) = H(p) + D_{KL}(p\|q)} \]

模型花掉的比特 = 文本本身的随机性（改不了）+ 模型浪费的比特（能优化）。所以最小化交叉熵 = 最小化 KL。困惑度就是它取指数：\(\mathrm{PPL}=2^{H(p)+D}\)。

为什么恒 ≥0（Gibbs 不等式，一行证完）

只用 \(\ln x \le x-1\)（等号仅 \(x=1\)）：

\[ -D = \sum p_i\ln\frac{q_i}{p_i} \le \sum p_i\left(\frac{q_i}{p_i}-1\right) = \sum q_i-\sum p_i = 0 \]

故 \(D\ge 0\)，仅 \(p=q\) 处处相等时为 0。

它不是距离

不对称：上面例子反过来 \(D(q\|p)=0.737\)，和正过来 0.531 不一样。预训练用的是 \(D(真实\|模型)\)，特点是模型不敢漏掉真实的任何可能。

## 本章数学路线

第 4 章的公式分成两条主线，依赖顺序如下：

1. 式 (4.1) 是「拿直线直接预测概率」的失败尝试，为整章提供动机。
2. 式 (4.2) 用 logistic 函数把取值范围修回 $(0,1)$；式 (4.3)、(4.4) 是它的两个等价改写——odds 与 logit。「线性」正是从 logit 走进来的。
3. 式 (4.5) 解决「参数怎么估」：伯努利似然 → 对数似然 → score 方程 → 无闭式解 → 牛顿法；同一块内容里还要推出 Fisher 信息矩阵与标准误。
4. 式 (4.6)、(4.7) 把 (4.4) 推广到 $p$ 个预测子；式 (4.8)、(4.9) 是把系数估计代回去后的两次预测。
5. 式 (4.10)–(4.14) 是 $K>2$ 类的多项逻辑回归（baseline 编码与 softmax 编码）。
6. 式 (4.15)（Bayes 定理）是**生成式**路线的唯一入口。LDA $p=1$ (4.16)–(4.22)、LDA $p>1$ (4.23)–(4.25)、QDA (4.28)、朴素贝叶斯 (4.29)、(4.30) 全都是「给 $f_k(x)$ 换一种假设」后重新算出来的 $p_k(x)$。
7. 式 (4.31)–(4.34) 把四种方法的 log-odds 统一成一张表，从而看清 LDA $\subset$ QDA、LDA $\subset$ 朴素贝叶斯。
8. 式 (4.35)–(4.38) 是 Poisson 回归；式 (4.39)–(4.42) 用 link function 把线性 / 逻辑 / Poisson 三个模型统一成 GLM（广义线性模型）。

> 最容易忘的三处计算：式 (4.5) 的 score 方程与海森矩阵、式 (4.24) 里二次项相消、式 (4.38) 的对数似然求导。下面逐条展开。

## 4.3 逻辑回归：模型形式

@src 原书 p.148 · [4.3.1 The Logistic Model](../isl/05-classification.html#s-4-3-1-the-logistic-model)

### (4.1) 线性概率模型及其失效 {#eq-4-1}

$$
p(X) = \beta_0 + \beta_1 X. \tag{4.1}
$$

**基础**：

- $p(X) = P(Y = 1 \mid X = x)$ 是 0/1 编码下的**后验概率**（posterior probability），按定义必落在 $[0,1]$ 内。
- 书里约定用通用的 0/1 编码：$Y\in\{0,1\}$，$X$ 暂取单个定量预测子。

**推导**（为什么这条直线一定会跑出 $[0,1]$）。$p(X)$ 是 $X$ 的仿射函数，斜率 $\beta_1$ 恒定：

$$
p(X) = \beta_0 + \beta_1 X, \qquad \frac{\mathrm{d}p}{\mathrm{d}X} = \beta_1
$$

若 $\beta_1 \ne 0$，它关于 $X$ 严格单调。取两端极限（设 $\beta_1>0$，$\beta_1<0$ 时方向相反）：

$$
X\to+\infty:\; p(X)\to+\infty, \qquad X\to-\infty:\; p(X)\to-\infty
$$

所以**无论** $\beta_0,\beta_1$ 取什么值，都存在一个 $X$ 使 $p(X)<0$、另一个 $X$ 使 $p(X)>1$。写出具体的区间更清楚（$\beta_1>0$）：

$$
p(X)<0 \iff X<-\frac{\beta_0}{\beta_1}, \qquad p(X)>1 \iff X>\frac{1-\beta_0}{\beta_1}
$$

**结论**：式 (4.1) 就是第 2 章的 $Y=f(X)+\epsilon$ 直接搬到二元响应上。它暴露的是一个**结构性**缺陷，不是样本量或拟合优度问题。Default 数据上用 balance 拟合，余额接近 0 时预测出负概率，余额很大时预测值超过 1——概率的定义不允许。

**易错点**：

- 不要以为「加个约束、截断到 $[0,1]$」就能救。截断之后 (4.1) 不再是线性模型，logit 的线性解释与系数解释也一并失效。
- 别把它和「训练误差高」混为一谈：这是模型**形式**与随机变量取值范围的矛盾。
- 左边是 $p(X)$（小写无帽，模型的均值/真值），与后面 $\hat p(x)$（估计值）严格区分。

### (4.2) logistic 模型 {#eq-4-2}

$$
p(X) = \frac{e^{\beta_0+\beta_1X}}{1+e^{\beta_0+\beta_1X}}. \tag{4.2}
$$

**基础**：$e^t$ 对一切实数 $t$ 取值于 $(0,+\infty)$；$1+e^t$ 恒大于 0，绝不为零，所以分母永远有定义。

**推导**（为什么它把值域锁死在 $(0,1)$）。记 $t := \beta_0+\beta_1X$。要证 $0<\dfrac{e^t}{1+e^t}<1$，只需两步：

1. 上下同除以正数 $e^t$：$p(X) = \dfrac{1}{e^{-t}+1}$。分母 $e^{-t}+1 > 1$，故 $p(X) < 1$。
2. 分子 $e^t>0$，分母 $1+e^t = e^t + 1 > e^t$，故 $p(X) > 0$。

端点极限：$t\to-\infty$ 时 $e^{-t}\to+\infty$，$p\to 0$；$t\to+\infty$ 时 $e^{-t}\to 0$，$p\to 1$。所以曲线是 S 形（sigmoid），从 0 升到 1 但**永远取不到**两个端点。

**单调性**（后面解释系数的前提）。设 $\eta := \beta_0+\beta_1X$：

$$
\frac{\mathrm{d}p}{\mathrm{d}X} = \frac{e^{\eta}\beta_1(1+e^{\eta}) - e^{\eta}\cdot e^{\eta}\beta_1}{(1+e^{\eta})^{2}} = \frac{\beta_1 e^{\eta}}{(1+e^{\eta})^{2}} = \beta_1\,p(X)\bigl(1-p(X)\bigr)
$$

因为 $0<p<1$ 故 $p(1-p)>0$，导数的符号完全由 $\beta_1$ 决定。

**结论**：式 (4.2) 修好了 (4.1) 的两个毛病——预测值恒在 $(0,1)$ 内，且是 $X$ 的光滑单调函数。书里 Figure 4.2 右图就是它的拟合：对低余额预测违约概率接近但不低于 0，对高余额接近但不高于 1。$\beta_0,\beta_1$ 未知，要用数据估计，这是 4.3.2 的内容（式 (4.5)）。

**易错点**：

- $p$ 在两个方向都**取不到** 0 和 1。这在完全可分（separation）的数据上会让 MLE 系数发散，见 (4.5) 的易错点。
- 别把 (4.2) 记成 $\dfrac{1}{1+e^{-(\beta_0+\beta_1X)}}$ 以外的形状。两种写法数学上等价，但只有 (4.2) 的形式让「分母恒正」这个论证一步到位。
- 这里的 $X$ 是大写（预测子的泛指），代入第 $i$ 个观测的具体取值才写小写 $x_i$。式 (4.5) 之后原书一律用小写 $x_i$。

### (4.3) odds（几率） {#eq-4-3}

@src 原书 p.149 · [4.3.1 The Logistic Model](../isl/05-classification.html#s-4-3-1-the-logistic-model)

$$
\frac{p(X)}{1 - p(X)} = e^{\beta_0+\beta_1X}. \tag{4.3}
$$

**基础**：

- **odds**（几率）：成功与失败之比 $p:(1-p)$，写成 $p/(1-p)$。
- 映射 $p\mapsto p/(1-p)$ 把 $(0,1)$ 双射到 $(0,+\infty)$。

**推导**（从 (4.2) 的定义式反解 odds）。先算分母，通分：

$$
1 - p(X) = 1 - \frac{e^{\eta}}{1+e^{\eta}} = \frac{(1+e^{\eta}) - e^{\eta}}{1+e^{\eta}} = \frac{1}{1+e^{\eta}}
$$

再作商，上下同乘 $(1+e^{\eta})$：

$$
\frac{p(X)}{1-p(X)} = \frac{\dfrac{e^{\eta}}{1+e^{\eta}}}{\dfrac{1}{1+e^{\eta}}} = \frac{e^{\eta}}{1+e^{\eta}}\cdot(1+e^{\eta}) = e^{\eta} = e^{\beta_0+\beta_1X}
$$

**反解**（做题时经常要用）。记 $o := p/(1-p)$，则 $o(1-p) = p \Rightarrow o - op = p \Rightarrow p = o - op \Rightarrow p(1+o) = o \Rightarrow$：

$$
p = \frac{o}{1+o} = \frac{e^{\beta_0+\beta_1X}}{1+e^{\beta_0+\beta_1X}}
$$

与式 (4.2) 一致，验证了两者互逆。

**结论**：odds 之所以有用，是因为它把「概率」这个**有界**量换成了**可乘的无界**量。$p=0.2$ 时 odds $=0.2/0.8 = 1/4$，即平均 5 人有 1 人违约；$p=0.9$ 时 odds $=0.9/0.1=9$，即 10 人有 9 人违约。取值可以任意接近 $0$ 或 $+\infty$，对应「概率极小」与「概率极大」。

**易错点**：

- **odds 不是概率**。odds $=4$ 对应 $p = 4/5 = 0.8$（80%），不是 40%。判别方法：$p<0.5 \Leftrightarrow$ odds $<1$；$p>0.5 \Leftrightarrow$ odds $>1$。
- odds 在赛马里常被使用（原书提到），因为「赢/输」的比值比概率更贴近下注策略。
- 原书这里写 $p(X)$，还没有引入第 4.4 节的 $p_k(x)$ 缩写。

### (4.4) 对数几率 logit {#eq-4-4}

$$
\log\left(\frac{p(X)}{1 - p(X)}\right) = \beta_0 + \beta_1 X. \tag{4.4}
$$

**基础**：**log odds** 也叫 **logit**，定义为 $\operatorname{logit}(p) := \log\frac{p}{1-p}$，把 $(0,1)$ 双射到 $\R$。

**推导**（一步）。对 (4.3) 两边取自然对数，用 $\log e^{t} = t$：

$$
\log\left(\frac{p(X)}{1-p(X)}\right) = \log\left(e^{\beta_0+\beta_1X}\right) = \beta_0 + \beta_1X
$$

反过来，$\log:(0,+\infty)\to\R$ 与 $e^{\cdot}:\R\to(0,+\infty)$ 互为反函数，所以 (4.4) $\iff$ (4.3) $\iff$ (4.2)。三者数学上完全等价，区别只在「线性」出现在哪一层。

**结论**：**logit 与 $X$ 之间是直线**。三个立刻可读的解释：

1. $X$ 增加 1 个单位，log odds 增加 $\beta_1$；
2. 等价地，odds 乘以 $e^{\beta_1}$（回到 (4.3)）；
3. 但 $p(X)$ 本身**不是**线性变化的——$X$ 加 1 让概率上升多少，取决于当前 $X$ 在 S 形曲线的哪一段。

用 (4.2) 的导数量化第 3 点：一阶近似 $\Delta p \approx \beta_1\,p(1-p)\,\Delta X$。注意 $p(1-p)$ 在 $p$ 接近 0 或 1 时趋于 0，所以同样的 $\beta_1$ 在曲线两端几乎不改变概率、在中段改变最大。

**易错点**：

- $\operatorname{logit}$ 的自变量是**概率** $p$，不是预测子 $x$。看到 $\log\frac{p(X)}{1-p(X)}$ 里的 $p$ 要立刻确认 $1-p>0$，对数才有实数定义。
- 不能写成 $\log\frac{p(X)}{p(X)-1}$：分母为负。
- 多变量版 (4.6) 里是 $\beta_0+\beta_1X_1+\cdots+\beta_pX_p$，$X_j$ 是第 $j$ 个预测子（大写），代入观测值时才写 $x_{ij}$。
- 本节最容易搞混的对比：第 3 章线性回归里 $\beta_1$ =「$X$ 加 1，$Y$ 平均变 $\beta_1$」；这里 $\beta_1$ =「$X$ 加 1，log odds 变 $\beta_1$」。二者不是一回事。

### (4.5) 最大似然估计与标准误 {#eq-4-5}

$$
\ell(\beta_0,\beta_1) = \prod_{i:\,y_i=1} p(x_i)\, \prod_{i':\,y_{i'}=0} \left(1 - p(x_{i'})\right) \tag{4.5}
$$

**基础**：

- $y_i\in\{0,1\}$ 是第 $i$ 个观测的响应，$x_i$ 是它的预测子取值，$i=1,\ldots,n$。
- **伯努利密度**可统一写成 $f(y_i) = p(x_i)^{y_i}\bigl(1-p(x_i)\bigr)^{1-y_i}$。
- 观测独立 $\Rightarrow$ 联合似然是各自似然之**积**。原书把两个 $\prod$ **按下标条件分组**
  并列写出（第一个乘积只取 $y_i=1$ 的下标，第二个只取 $y_{i'}=0$ 的下标）；
  它与上面那个统一写法完全等价，只是分组方式不同。

**推导 (1) 为什么是这个乘积**。先用统一写法：指数形式会自动为每个 $i$ 挑出该取的那一项（任何 $a^0=1$）：

$$
p(x_i)^{y_i}\bigl(1-p(x_i)\bigr)^{1-y_i} = \begin{cases} p(x_i)\bigl(1-p(x_i)\bigr)^{0} = p(x_i), & y_i=1\\[4pt] p(x_i)^{0}\bigl(1-p(x_i)\bigr)^{1} = 1-p(x_i), & y_i=0\end{cases}
$$

$n$ 个独立观测的联合概率是乘积 $\prod_i p(x_i)^{y_i}(1-p(x_i))^{1-y_i}$；
把它按「$y_i=1$ 的那些项」与「$y_i=0$ 的那些项」重新分组，就得到式 (4.5)
写成的样子——分组只是把同一个乘积里的因子重新排列，不改变结果。
（原书把似然本身记作 $\ell$，此处照抄；取对数后得到**对数似然**，
为与式 (4.5) 区分，下文记作 $\Lambda$。）

**推导 (2) 取对数，把乘积变求和**。记 $\Lambda := \log \ell$，用 $\log(ab)=\log a+\log b$ 与 $\log a^m = m\log a$：

$$
\Lambda = \sum_{i=1}^{n}\Big[\, y_i\log p(x_i) + (1-y_i)\log\bigl(1-p(x_i)\bigr) \,\Big]
$$

把 $p(x_i) = e^{\eta_i}/(1+e^{\eta_i})$、$\eta_i := \beta_0+\beta_1x_i$ 代入，两项各自化简：

$$
\log p(x_i) = \log\frac{e^{\eta_i}}{1+e^{\eta_i}} = \log e^{\eta_i} - \log(1+e^{\eta_i}) = \eta_i - \log(1+e^{\eta_i}), \qquad
\log\bigl(1-p(x_i)\bigr) = \log\frac{1}{1+e^{\eta_i}} = -\log(1+e^{\eta_i})
$$

代回并合并（两项的 $-\log(1+e^{\eta_i})$ 前系数为 $y_i+(1-y_i)=1$）：

$$
\Lambda = \sum_{i=1}^{n}\Big[\, y_i\eta_i - \log(1+e^{\eta_i}) \,\Big], \qquad \eta_i = \beta_0+\beta_1x_i
$$

推广到 $p$ 个预测子（$\eta_i = \beta_0+\sum_{j=1}^{p}\beta_jx_{ij}$）：

$$
\Lambda(\boldsymbol\beta) = \sum_{i=1}^{n}\Big[\, y_i\Big(\beta_0+\textstyle\sum_{j=1}^{p}\beta_jx_{ij}\Big) - \log\Big(1+e^{\beta_0+\sum_{j=1}^{p}\beta_jx_{ij}}\Big) \Big]
$$

**推导 (3) 求偏导，得到 score 方程**。三项分别求导：

1. $\dfrac{\partial}{\partial\beta_j}\sum_{i}y_i\Big(\beta_0+\sum_{m}\beta_mx_{im}\Big) = \sum_{i}y_ix_{ij}$（$j=0$ 时按 $x_{i0}\equiv 1$ 处理，结果是 $\sum_i y_i$）。
2. $\dfrac{\partial}{\partial\beta_j}\log(1+e^{\eta_i}) = \dfrac{e^{\eta_i}}{1+e^{\eta_i}}\,x_{ij} = p(x_i)\,x_{ij}$，整体带负号。
3. 令偏导为零：

$$
\frac{\partial \Lambda}{\partial\beta_j} = \sum_{i=1}^{n}\bigl(y_i - p(x_i)\bigr)x_{ij} = 0, \qquad j=0,1,\ldots,p
$$

矩阵形式：令 $\boldsymbol p = \bigl(p(x_1),\ldots,p(x_n)\bigr)^\top$、$\mathbf y=(y_1,\ldots,y_n)^\top$，$X$ 的第 $0$ 列取全 1，则

$$
\nabla_{\boldsymbol\beta}\Lambda = X^\top\bigl(\mathbf y - \boldsymbol p\bigr) = \mathbf 0
$$

**推导 (4) 为什么没有闭式解**。第 3 章的最小二乘解 $\hat{\boldsymbol\beta} = (X^\top X)^{-1}X^\top\mathbf y$ 来自解**线性**方程 $X^\top X\boldsymbol\beta = X^\top\mathbf y$。而这里把 $\boldsymbol p$ 移到右边：

$$
X^\top X\boldsymbol\beta = X^\top\bigl(\mathbf y - \boldsymbol p(\boldsymbol\beta)\bigr)
$$

$\boldsymbol\beta$ 同时出现在等号两边，且通过指数/logistic 非线性地耦合，方程对 $\boldsymbol\beta$ 不是线性的，消不掉。原书说「最大似然的数学细节超出本书范围」，指的就是这一步。

**推导 (5) 数值迭代与标准误**。实际用牛顿–拉夫森 / Fisher scoring。定义 **score** $U(\boldsymbol\beta) := X^\top(\mathbf y-\boldsymbol p)$，**Fisher 信息矩阵** $I(\boldsymbol\beta) := -\E_{\mathbf y}\!\left[\nabla^2_{\boldsymbol\beta}\Lambda\right]$。先算二阶导：

$$
\frac{\partial^2 \Lambda}{\partial\beta_j\,\partial\beta_m} = -\sum_{i=1}^{n} p(x_i)\bigl(1-p(x_i)\bigr)\,x_{ij}x_{im}
$$

（用到 $\frac{\mathrm{d}p}{\mathrm{d}\eta} = p(1-p)$ 与 $\frac{\mathrm{d}^2p}{\mathrm{d}\eta^2} = p(1-p)(1-2p)$ 的组合，$p$ 是 $x_{ij}x_{im}$ 的二次式，其余项二阶导为 0。）取负号并对 $\mathbf y$ 求期望（$\E[y_i-p_i] = 0$、$\mathrm{Var}(y_i) = p_i(1-p_i)$）得

$$
I(\boldsymbol\beta) = X^\top W X, \qquad W = \operatorname{diag}\bigl(p_1(1-p_1),\,p_2(1-p_2),\,\ldots,\,p_n(1-p_n)\bigr)
$$

牛顿迭代式（Fisher scoring）：

$$
\hat{\boldsymbol\beta}^{\,\text{new}} = \hat{\boldsymbol\beta}^{\,\text{old}} + \bigl(X^\top W X\bigr)^{-1} X^\top\bigl(\mathbf y - \boldsymbol p\bigr)
$$

标准误来自 $I^{-1}$ 的对角元：

$$
\hat{\mathrm{se}}(\hat\beta_j) = \sqrt{\Big[\bigl(X^\top W X\bigr)^{-1}\Big]_{jj}}, \qquad z_j = \frac{\hat\beta_j}{\hat{\mathrm{se}}(\hat\beta_j)}
$$

$z_j$ 就是表 4.1–4.3 的 z-statistic。Default 数据单变量拟合得 $\hat\beta_1 = 0.0055$、$\hat\beta_0 = -10.6513$，$z = 10.0$，p 值 $<0.0001$。

**结论**：式 (4.5) 是「让已观测到的数据最不像偶然发生」的那组参数的判据。它属于**判别式**（discriminant）方法——原书指出最小二乘其实是高斯误差下 MLE 的特例，所以「用最大似然拟合逻辑回归」与第 3 章的思路是连续的，只是似然从高斯密度换成了伯努利密度。

**易错点**：

- **完全可分（complete separation）**：若存在 $\boldsymbol\beta^{*}$ 使所有 $y_i=1$ 的观测都有 $\eta_i>0$、所有 $y_i=0$ 的观测都有 $\eta_i<0$，则 $\Lambda$ 沿 $\boldsymbol\beta^{*}$ 方向无上界，MLE 不存在（系数发散、$\hat p$ 贴住 0 或 1、标准误爆炸）。这正是 4.4 节开头说的「两类分离严重时逻辑回归参数估计出人意料地不稳定」。R 的 `glm` 会报 fitted probabilities are 0 or 1 警告。
- 左边是参数的函数 $\ell(\beta_0,\beta_1)$，不是 $\ell(\hat\beta_0,\hat\beta_1)$。
- $W$ 的对角元 $p_i(1-p_i)\le 1/4$，且 $p_i$ 越极端该观测权重越小——被「极端自信」的预测点自动降权。
- 共线性会让 $X^\top WX$ 接近奇异、标准误爆炸，与第 3 章 $X^\top X$ 的问题同源。
- 实现顺序：先算 $\boldsymbol p$ 再算 $W$，两步分开（否则退化成纯牛顿法，可能步长过大发散）。`glm(family = binomial())` 用的正是这套 Fisher scoring。
- 这里用正态分位数算 p 值（表头写 z-statistic），不像线性回归那样用 $t_{n-p}$。

## 4.3.3 用逻辑回归做预测

@src 原书 p.151 · [4.3.3 Making Predictions](../isl/05-classification.html#s-4-3-3-making-predictions)

### 无编号式：balance 为 1,000 美元时的预测概率 {#eq-4-u1}

$$
\hat{p}(X) = \frac{e^{\hat\beta_0+\hat\beta_1X}}{1+e^{\hat\beta_0+\hat\beta_1X}} = \frac{e^{-10.6513+0.0055\times 1{,}000}}{1+e^{-10.6513+0.0055\times 1{,}000}} = 0.00576,
$$

**基础**：表 4.1 给出 Default 数据用 balance 拟合逻辑回归的系数估计 $\hat\beta_0 = -10.6513$、$\hat\beta_1 = 0.0055$、标准误 0.3612 / 0.0002。

**推导**。把估计值代入 (4.2)，取 $X = 1{,}000$：

1. 指数部分（log odds）：$\hat\eta = -10.6513 + 0.0055\times 1000 = -10.6513 + 5.5 = -5.1513$。
2. $e^{-5.1513} \approx 0.0058$。
3. $p = \dfrac{0.0058}{1+0.0058} = \dfrac{0.0058}{1.0058} \approx 0.00576$。

对照余额 2,000 美元：$\hat\eta = -10.6513 + 11 = 0.3487$，$e^{0.3487}\approx 1.4172$，$p = 1.4172/2.4172 \approx 0.586$，即 58.6%。

**结论**：同样把余额从 1,000 美元增加到 2,000 美元，预测概率从 0.58% 跳到 58.6%。这正是 S 形曲线中段最陡的性质，也说明 $\hat\beta_1$ **不能**解释成「余额加 1 美元概率加 0.0055」。

**易错点**：

- 指数上的量是 log odds，不是概率。代入前先把它当「指数」处理。
- $\hat\beta_1 = 0.0055$ 的量纲是「每美元余额的 log odds 变化」。若想换成「每 1,000 美元余额」，系数应写成 $5.5$，log odds 变化是原来的 1000 倍。
- 左边写 $\hat p$（有帽）而不是 $p$：现在用的是估计的系数。

### 无编号式：学生（student = Yes）的违约概率 {#eq-4-u2}

$$
\widehat{\mathrm{Pr}}(\text{default}=\text{Yes}\mid \text{student}=\text{Yes}) = \frac{e^{-3.5041+0.4049\times 1}}{1+e^{-3.5041+0.4049\times 1}} = 0.0431,
$$

**基础**：表 4.2 给出只用 student 虚拟变量拟合的逻辑回归系数：截距 $\hat\beta_0 = -3.5041$、$\hat\beta_1 = 0.4049$（z = 4.02，p = 0.0001）。原书用 $\widehat{\mathrm{Pr}}$ 表示「估计的概率」。

**推导**。虚拟变量取值 1（学生）：

1. $\hat\eta = -3.5041 + 0.4049\times 1 = -3.0992$。
2. $e^{-3.0992}\approx 0.04512$。
3. $p = 0.04512/1.04512 \approx 0.0431$，即 4.31%。

**结论**：单变量模型里 $\hat\beta_1 = 0.4049 > 0$ 且 p 值很小，说明**在不做任何调整**的情况下学生的违约率更高。原书明确说这是 Table 4.2 的结论。

**易错点**：

- 这里的 $0.4049$ 只能读作「学生相对非学生，log odds 增加 0.4049，odds 乘 $e^{0.4049}\approx 1.50$ 倍」。绝不能读成「学生违约概率高 40.49%」。
- 原书在 4.3.4 节紧接着用 Table 4.3 推翻这个表面结论：一旦控制住 balance 与 income，学生系数变成 $-0.6468$。这是**混杂**（confounding）的教科书例子，别把两个结论混着引用。

### 无编号式：非学生（student = No）的违约概率 {#eq-4-u3}

$$
\widehat{\mathrm{Pr}}(\text{default}=\text{Yes}\mid \text{student}=\text{No}) = \frac{e^{-3.5041+0.4049\times 0}}{1+e^{-3.5041+0.4049\times 0}} = 0.0292.
$$

**基础**：同一套系数，虚拟变量取 0。

**推导**。

1. $\hat\eta = -3.5041 + 0.4049\times 0 = -3.5041$。
2. $e^{-3.5041}\approx 0.03008$。
3. $p = 0.03008/1.03008 \approx 0.0292$，即 2.92%。

**结论**：把上面两式相除，$\hat p_{\text{student}}/\hat p_{\text{non}} = 0.0431/0.0292 \approx 1.476$，与 $e^{0.4049} \approx 1.498$ 几乎一致（差异只来自四舍五入）——这正是 (4.3) 与 (4.4) 的直接推论：

$$
\frac{\hat p(X=1)}{1-\hat p(X=1)} \Big/ \frac{\hat p(X=0)}{1-\hat p(X=0)} = e^{\hat\beta_1}
$$

**易错点**：

- 0.0292 是 $\exp(\hat\eta)/(1+\exp(\hat\eta))$，不是 $\exp(\hat\eta)$。后者是 0.0301，即 odds。
- 两个概率的对比必须用 odds 比或 logistic 差，不能直接拿概率差（$4.31\%-2.92\%=1.39\%$）来对应系数 0.4049。

### 无编号式：4.3.3 → 4.3.4 的过渡公式框 {#eq-4-u4}

原书此处在两个 $\widehat{\mathrm{Pr}}$ 之后、小节标题 4.3.4 之前还排了一个**未编号的公式框**（切图为空白，只有上下留白）。它承接的是上两式背后的模型——只用虚拟变量 $S := \mathrm{student}[\mathrm{Yes}]$ 的单变量逻辑回归：

$$
\log\left(\frac{p(X)}{1-p(X)}\right) = \beta_0 + \beta_1 S, \qquad S = \mathrm{student}[\mathrm{Yes}] \in \{0,1\}
$$

**基础**：**虚拟变量 / 哑变量**（dummy variable）编码，见第 3.3.1 节。定性预测子 $S$ 被映射为 $1$（学生）与 $0$（非学生）。

**推导**（两个系数各自是什么）。代入 $S=0$ 与 $S=1$：

1. $S=0$：$\operatorname{logit}(p_0) = \beta_0$，即 $\beta_0 = \log\frac{p_0}{1-p_0}$ 是**非学生的 log odds**。
2. $S=1$：$\operatorname{logit}(p_1) = \beta_0+\beta_1$，相减得 $\beta_1 = \operatorname{logit}(p_1)-\operatorname{logit}(p_0)$，即**两类 log odds 之差**。
3. 指数化：$\dfrac{p_1/(1-p_1)}{p_0/(1-p_0)} = e^{\beta_1}$，即学生相对非学生的 **odds 倍数**。

代入表 4.2 的估计：$\beta_0 = -3.5041 \Rightarrow p_0 = e^{-3.5041}/(1+e^{-3.5041}) = 0.0292$；$\beta_0+\beta_1 = -3.0992 \Rightarrow p_1 = 0.0431$。与上面两条完全一致。

**结论**：虚拟变量模型是 (4.4)/(4.6) 在 $p=1$ 时的特例。它的截距不再是「$X=0$ 时的响应」，而是**基线类别**的 log odds——这是解释截距时最常见的错误来源。

**易错点**：

- 不要把 $\beta_0$ 说成「$X=0$ 时的期望响应」（那是线性回归的说法）。这里它是 log odds。
- 虚拟变量模型每多一个类别就要多一个系数（$K$ 个水平要 $K-1$ 个虚拟变量 + 截距），这就是第 6 章多项逻辑回归要解决的问题。
- 3.3.1 节的「虚拟变量 + 截距」有个陷阱：若把全部 $K$ 个水平都编码成虚拟变量，截距就不可识别。这里 $S$ 只有 0/1 两值，截距本身对应非学生类，所以没有这个问题。

## 4.3.4 多元逻辑回归

@src 原书 p.151 · [4.3.4 Multiple Logistic Regression](../isl/05-classification.html#s-4-3-4-multiple-logistic-regression)

### (4.6) 多元 logit 线性形式 {#eq-4-6}

$$
\log\left(\frac{p(X)}{1-p(X)}\right) = \beta_0 + \beta_1X_1 + \cdots + \beta_pX_p, \tag{4.6}
$$

**基础**：$X=(X_1,\ldots,X_p)$ 是 $p$ 个预测子（$X_1=\text{balance}$，$X_2=\text{income}$，$X_3=\mathrm{student}[\mathrm{Yes}]$）。

**推导**（为什么能这样推广）。逻辑回归 (4.4) 里「$X$」是一个占位符；把它换成向量的线性组合 $\beta_0+\sum_j\beta_jX_j$ 并不改变任何代数步骤：式 (4.1)→(4.2)→(4.3)→(4.4) 的推导里只用到「$\eta$ 是 $X$ 的某个线性函数」这一条。所以形式上的推广是免费的，参数数目从 2 个变成 $p+1$ 个。

把两边指数化可以立刻拿到一个有用的**分离**（separation）恒等式：

$$
\frac{p(X)}{1-p(X)} = e^{\beta_0}\, e^{\beta_1X_1}\cdots e^{\beta_pX_p} = e^{\beta_0}\prod_{j=1}^{p}e^{\beta_jX_j}
$$

**结论**：每个 $\beta_j$ 都可以单独读作「$X_j$ 加 1，其他不变时 log odds 增加 $\beta_j$」——这是**可加性**（additivity），不含任何交互项。

**易错点**：

- $\beta_j$ 的解释是**在其他预测子固定**的前提下。原书紧接着用这一点解释 Table 4.3 的混杂现象：控制住 balance 和 income 后 student 系数由 $+0.4049$ 翻成 $-0.6468$。
- 形式上「线性」指的是 logit 线性，不是 $p(X)$ 线性。
- 截距 $\beta_0$ 现在是「所有 $X_j=0$ 时的 log odds」。若 $X_1=\text{balance}$ 原点取 0，这个点没有实际意义（现实中不存在余额为 0 的人），所以 $\hat\beta_0 = -10.869$ 只是用来定位曲线，不能作经济解释。

### (4.7) 多元 logistic 模型 {#eq-4-7}

$$
p(X) = \frac{e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}}{1+e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}}. \tag{4.7}
$$

**基础**：$\eta := \beta_0+\beta_1X_1+\cdots+\beta_pX_p$ 称**线性预测子**（linear predictor）或 log odds。

**推导**（由 (4.6) 反解）。设 $o := p/(1-p) = e^{\eta}$，由 (4.3) 的反解式 $p = o/(1+o)$：

$$
p(X) = \frac{e^{\eta}}{1+e^{\eta}} = \frac{e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}}{1+e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}}
$$

**验证值域**。分母是 $1+$ 正数，恒 $>0$；同除 $e^{\eta}$ 得 $p = 1/(1+e^{-\eta}) \in (0,1)$。与单变量情形完全相同。

**结论**：式 (4.7) 是逻辑回归的**最终模型形式**——给定协变量代入式子即得概率。参数 $\beta_0,\beta_1,\ldots,\beta_p$ 用 4.3.2 的最大似然法（式 (4.5)）估计。原书强调：虽然也可以用（非线性）最小二乘去拟合 (4.7)，但最大似然的统计性质更好。

**易错点**：

- 分类时用 $\hat p(x) > 0.5$ 作为判别规则，等价于「把 $x$ 归到 log odds $>0$ 的一类」。
- 不要因为「$p(X)$ 是 $X$ 的非线性函数」就说这个模型「不线性」——判别边界是超平面，名字里的 linear 指的是 logit 线性（见 4.5.1 的 (4.32)）。
- $X$ 大写、$x$ 小写的约定在这里最容易被忽略：式 (4.7) 是「模型」，代入观测要写 $\hat p(x_i)$。

### (4.8) 学生的预测违约概率 {#eq-4-8}

$$
\hat{p}(X) = \frac{e^{-10.869+0.00574\times 1{,}500+0.003\times 40-0.6468\times 1}}{1+e^{-10.869+0.00574\times 1{,}500+0.003\times 40-0.6468\times 1}} = 0.058. \tag{4.8}
$$

**基础**：表 4.3 的系数估计（balance、income 以 1,000 美元为单位、student[Yes]）：

| 变量 | 系数 | 标准误 | z | p 值 |
| --- | --- | --- | --- | --- |
| Intercept | $-10.8690$ | 0.4923 | $-22.08$ | $<0.0001$ |
| balance | $0.0057$ | 0.0002 | 24.74 | $<0.0001$ |
| income | $0.0030$ | 0.0082 | 0.37 | 0.7115 |
| student[Yes] | $-0.6468$ | 0.2362 | $-2.74$ | 0.0062 |

**推导**。代入 $X_1=1500$（美元）、$X_2=40$（以 1,000 美元为单位）、$X_3=1$（学生）：

1. 逐项：$-10.869 + 0.00574\times 1500 = -10.869 + 8.61 = -2.259$。
2. $0.003\times 40 = 0.12$，累计 $-2.139$。
3. $-0.6468\times 1 = -0.6468$，累计 $\hat\eta = -2.7858$。
4. $e^{-2.7858}\approx 0.0617$。
5. $p = 0.0617/1.0617 \approx 0.058$。

**结论**：该学生（余额 1,500 美元、收入 40,000 美元）的估计违约概率是 5.8%。注意 income 的 p 值是 0.7115，统计上不显著——原书讨论的重点在 balance 与 student。

**易错点**：

- **income 必须乘 40 而不是 40,000**，因为模型是以 1,000 美元为单位拟合的。原书专门加了一句提醒。
- 各项是**相加后再取指数**，不是各自取指数再相乘（虽然由 (4.7) 的推导 $\prod_j e^{\beta_jX_j}$ 恰好等价，但直接写代码时容易写成连乘后忘记外层的 $+1$）。
- 截距 $-10.869$ 在这个模型里纯粹是「把曲线放到正确高度」的作用。

### (4.9) 非学生的预测违约概率 {#eq-4-9}

$$
\hat{p}(X) = \frac{e^{-10.869+0.00574\times 1{,}500+0.003\times 40-0.6468\times 0}}{1+e^{-10.869+0.00574\times 1{,}500+0.003\times 40-0.6468\times 0}} = 0.105. \tag{4.9}
$$

**基础**：与式 (4.8) 用**同一个模型、同一组系数估计**（Table 4.3），只有 dummy 变量
$X_3 = \mathrm{student[Yes]}$ 从 $1$ 变成 $0$。$X_1 = 1500$（balance）、$X_2 = 40$（income，
以 1,000 美元为单位）保持不变。模型形如 $\hat p(X) = \dfrac{e^{\hat\eta}}{1+e^{\hat\eta}}$，
其中 $\hat\eta = -10.869 + 0.00574X_1 + 0.003X_2 - 0.6468X_3$。

**推导**。只有最后一项改变：

1. $\hat\eta = -10.869 + 8.61 + 0.12 - 0 = -2.139$。
2. $e^{-2.139}\approx 0.1178$。
3. $p = 0.1178/1.1178 \approx 0.105$。

**结论**：同样余额 1,500 美元、同样收入 40,000 美元，学生的估计违约概率 5.8%、非学生 10.5%，**学生更低**。这与 Table 4.2 的单变量结论（学生更高，$0.4049$）方向相反。原书用 Figure 4.3 解释：学生倾向于持有更高余额，而高余额本身与高违约率相关；一旦把 balance 固定住，学生在任何余额水平上的违约率都不高于非学生。这个现象叫**混杂**（confounding）。

**易错点**：

- odds 倍数核对：$e^{-0.6468}\approx 0.524$，即「控制住 balance 和 income 后，学生的 odds 是非学生的 0.52 倍」。若用概率比：$0.058/0.105 \approx 0.55$，两数接近但不相等——**概率比 ≠ odds 比**，这是式 (4.3) 的直接后果。
- 结论的方向依赖于「控制了什么变量」。脱离模型谈「学生是否更容易违约」没有意义。
- 收入项在两式里完全相同，所以两式之差只来自 student 项：$\Delta\hat\eta = -0.6468$。

## 4.3.5 多项逻辑回归

@src 原书 p.154–155 · [4.3.5 Multinomial Logistic Regression](../isl/05-classification.html#s-4-3-5-multinomial-logistic-regression)

### (4.10) baseline 编码：非基准类的概率 {#eq-4-10}

$$
\mathrm{Pr}(Y = k\mid X = x) = \frac{e^{\beta_{k0}+\beta_{k1}x_1+\cdots+\beta_{kp}x_p}}{1 + \sum_{l=1}^{K-1} e^{\beta_{l0}+\beta_{l1}x_1+\cdots+\beta_{lp}x_p}} \tag{4.10}
$$

**基础**：$K>2$ 类，$k = 1,\ldots,K-1$。选第 $K$ 类作**基准**（baseline），不失一般性。记 $\eta_{ki} := \beta_{k0}+\beta_{k1}x_1+\cdots+\beta_{kp}x_p$（第 $k$ 类对观测 $i$ 的线性预测子）。

**推导**（为什么是「1 + 各项之和」）。设各类概率为 $p_1,\ldots,p_K$，唯一约束是 $\sum_{k=1}^{K}p_k = 1$。用 (4.7) 的技巧：把 $K$ 个「相对基准的 odds」乘积归一化。

1. 对每个 $k<K$ 造一个比值 $\dfrac{p_k}{p_K} = e^{\eta_k}$（这是 (4.3) 的多项版本，见 (4.12)）。
2. 代入 $p_K = 1 - \sum_{k=1}^{K-1}p_k$（归一化约束）。设 $S := \sum_{l=1}^{K-1}e^{\eta_l}$，则
$$
p_k = e^{\eta_k}\Bigl(1 - \sum_{l<K}p_l\Bigr) = e^{\eta_k}\bigl(p_K\bigr)
$$
3. 对 $k$ 求和：$\sum_{k=1}^{K-1}p_k = S\,p_K$，故 $S\,p_K = 1 - p_K$，即 $p_K(1+S) = 1$：

$$
p_K = \frac{1}{1+S} = \frac{1}{1+\sum_{l=1}^{K-1}e^{\eta_l}}
$$

4. 回代 $p_k = e^{\eta_k}p_K = \dfrac{e^{\eta_k}}{1+S}$，得式 (4.10)。

**验证归一化**。分子之和 $= \sum_{k<K}e^{\eta_k} = S$，分母 $= 1+S$，故 $\sum_{k=1}^{K}p_k = \dfrac{S}{1+S} + \dfrac{1}{1+S} = 1$。✓

**结论**：参数数目是 $(K-1)(p+1)$——每个非基准类一套自己的系数。$K=2$ 时退化回 (4.7)（此时只有一个非基准类，分母 $1+e^{\eta_1}$）。

**易错点**：

- 分母里的求和上限是 $K-1$，**不含**基准类。写成 $\sum_{l=1}^{K}$ 会让所有概率都变成 $e^{\eta_k}/\sum_l e^{\eta_l}$——那是 softmax 编码 (4.13)，两者数学上等价但参数识别方式不同。
- 下标是 $\beta_{k0},\beta_{k1},\ldots$（先类后系数），不是 $\beta_{0k}$。
- 原书用 $x_1,\ldots,x_p$（小写）而不是 $X_1,\ldots,X_p$，因为这里已经在写具体的观测值 $x$。这是原书在 (4.10) 之后的记号，与 (4.6) 的 $X_j$ 略有差别。

### (4.11) baseline 编码：基准类的概率 {#eq-4-11}

$$
\mathrm{Pr}(Y = K\mid X = x) = \frac{1}{1 + \sum_{l=1}^{K-1} e^{\beta_{l0}+\beta_{l1}x_1+\cdots+\beta_{lp}x_p}}. \tag{4.11}
$$

**基础**：沿用 (4.10) 的记号与归一化约束。

**推导**。这正是上面第 3 步解出的 $p_K$。也可以直接从式 (4.10) 与归一化推出：

$$
p_K = 1 - \sum_{k=1}^{K-1}p_k = 1 - \frac{\sum_{k=1}^{K-1}e^{\eta_k}}{1+S} = \frac{1+S-S}{1+S} = \frac{1}{1+S}
$$

两条路径给出同一结果，说明 (4.10) 与 (4.11) 不是两个独立假设，而是**一个**假设加归一化。

**结论**：$K$ 个概率由 $K-1$ 个类别的系数唯一决定，模型是**过度识别受限**的：换一组基准类会得到不同的系数估计，但**拟合值（预测概率）、任意两类之间的 log odds、以及其他关键输出完全相同**。原书用急诊室三分类（stroke / drug overdose / epileptic seizure）举例说明这一点。

**易错点**：

- 换基准类时系数会变，不要跨模型比较系数大小。原书明确说系数解释「与基准的选择绑定，必须小心」。
- $p_K$ 的表达式里没有 $e^{\eta_K}$：基准类没有自己的系数，它的系数被「归零」了。这就是 baseline 编码的本质——把一个冗余的自由度（$K$ 套系数共 $K(p+1)$ 个，但只有 $K-1$ 个可识别）拿掉。
- 数值上分母可能下溢（当所有 $\eta$ 都很负时）。软件通常先减去 $\max_k \eta_k$ 再取指数，$\log$-sum-exp 技巧保证至少有一项为 1。

### (4.12) baseline 编码的 log odds {#eq-4-12}

$$
\log\left(\frac{\mathrm{Pr}(Y = k\mid X = x)}{\mathrm{Pr}(Y = K\mid X = x)}\right) = \beta_{k0} + \beta_{k1}x_1 + \cdots + \beta_{kp}x_p. \tag{4.12}
$$

**基础**：式 (4.31) 是它的 $K$ 类推广（把 $K$ 换成任意参考类），这里先把 $K=2$ 版的 (4.4) 类推。

**推导**（一步，用比值约掉分母）。把 (4.10) 除以 (4.11)，分母 $1+S$ 精确相消：

$$
\frac{\mathrm{Pr}(Y=k\mid X=x)}{\mathrm{Pr}(Y=K\mid X=x)} = \frac{\dfrac{e^{\eta_k}}{1+S}}{\dfrac{1}{1+S}} = \frac{e^{\eta_k}}{1}\cdot\frac{1+S}{1+S} = e^{\eta_k}
$$

取对数，用 $\log e^{\eta_k} = \eta_k$：

$$
\log\frac{\mathrm{Pr}(Y=k\mid X=x)}{\mathrm{Pr}(Y=K\mid X=x)} = \eta_k = \beta_{k0}+\beta_{k1}x_1+\cdots+\beta_{kp}x_p
$$

**结论**：**任意一对类别之间的 log odds 都是特征的线性函数**。原书指出 (4.12) 与 (4.6) 「非常相似」。

**系数解释**（以 epileptic seizure 为基准为例，原书原文）：

- $\beta_{\text{stroke},0}$ 是在 $x_1=\cdots=x_p=0$ 处 stroke 相对 epileptic seizure 的 log odds。
- $X_j$ 增加 1 个单位，$\beta_{\text{stroke},j}$ 是 stroke 相对 epileptic seizure 的 log odds 的增加量。
- 换个说法：$X_j$ 增加 1，$\dfrac{\mathrm{Pr}(Y=\text{stroke}\mid X=x)}{\mathrm{Pr}(Y=\text{epileptic seizure}\mid X=x)}$ 乘以 $e^{\beta_{\text{stroke},j}}$。

**易错点**：

- log odds 里分子分母的顺序决定系数的符号。换成「epileptic 相对 stroke」时所有系数取负。
- 系数是**两两比较**的量，$K$ 个类别共 $\binom{K}{2}$ 对概率比，但只有 $K-1$ 组系数是自由的（其余由加和关系决定）。
- 不要把 $\beta_{k0}$ 说成「第 $k$ 类的 log odds」——它需要相对基准类来定义。

### (4.13) softmax 编码 {#eq-4-13}

$$
\mathrm{Pr}(Y = k\mid X = x) = \frac{e^{\beta_{k0}+\beta_{k1}x_1+\cdots+\beta_{kp}x_p}}{\sum_{l=1}^{K} e^{\beta_{l0}+\beta_{l1}x_1+\cdots+\beta_{lp}x_p}} . \tag{4.13}
$$

**基础**：**softmax 编码**不选基准类，$K$ 个类**对称**对待，$k=1,\ldots,K$ 都有自己的一整套系数。原文说它「与前面那种编码等价」（拟合值、任意两类的 log odds 等输出一致），但在机器学习文献里被广泛使用（第 10 章还会出现）。

**推导**（为什么这样就自动归一化）。分子分母同除以 $e^{\eta_k}$：

$$
\frac{e^{\eta_k}}{\sum_{l}e^{\eta_l}} = \frac{1}{e^{-\eta_k}\sum_l e^{\eta_l}} = \frac{1}{1 + \sum_{l\ne k}e^{\eta_l-\eta_k}}
$$

这与 (4.10) 的分母结构一致，只是「1」对应的类被换成了 $k$ 自己。

**与 (4.10) 的等价性**（重要结论，原书后面反复用到）。在 softmax 编码下对 $k$ 求和：

$$
\sum_{k=1}^{K}\mathrm{Pr}(Y=k\mid X=x) = \frac{\sum_k e^{\eta_k}}{\sum_l e^{\eta_l}} = 1
$$

因此它是合法的概率分布。更进一步，令 softmax 编码下的类别 $k$ 与 $k'$ 的概率比：

$$
\frac{\mathrm{Pr}(Y=k)}{\mathrm{Pr}(Y=k')} = \frac{e^{\eta_k}}{e^{\eta_{k'}}} = e^{\eta_k - \eta_{k'}}
$$

所以把 $K$ 类的系数都减去 $K$ 类的系数（即令 $\tilde\beta_{Kj} := \beta_{Kj}-\beta_{Kj}=0$），就得到 (4.10)/(4.11) 的 baseline 编码，而所有概率不变。

**结论**：softmax 多估了 $p+1$ 个参数（$K$ 套系数减去 $K-1$ 套），这 $p+1$ 个自由度是**不可识别**的（$X\to\boldsymbol\beta X + c\boldsymbol 1$ 给出同一个模型）。$p=1$ 时就是 2 个冗余参数。原书习题 4.5 就是在练这个换算。

**易错点**：

- 不可识别性只在**系数**层面存在，$\hat p(x)$ 层面是唯一的。所以「换编码系数不同但预测相同」不是矛盾。
- 数值实现里 $e^{\eta}$ 很容易溢出。标准做法是先减最大值：$\dfrac{e^{\eta_k-m}}{\sum_l e^{\eta_l-m}}$，$m := \max_l \eta_l$。
- 别把 softmax 与「多个独立的二分类器」混为一谈：softmax 的 $K$ 套系数是**联合**极大似然估计出来的，$\sum_k \hat p_k = 1$ 严格成立；独立二分类则没有这个约束。

### (4.14) softmax 编码下两类别的 log odds {#eq-4-14}

$$
\log\left(\frac{\mathrm{Pr}(Y = k\mid X = x)}{\mathrm{Pr}(Y = k'\mid X = x)}\right) = (\beta_{k0} - \beta_{k'0}) + (\beta_{k1} - \beta_{k'1})x_1 + \cdots + (\beta_{kp} - \beta_{k'p})x_p. \tag{4.14}
$$

**基础**：$k \ne k'$，$k$ 与 $k'$ 是任意两个类别（**不要求**其中一个是基准类）。原书写 $k'$（$k$ 带撇）。

**推导**（分子分母相除，分母消掉）。用 (4.13)：

$$
\frac{\mathrm{Pr}(Y=k\mid X=x)}{\mathrm{Pr}(Y=k'\mid X=x)} = \frac{\dfrac{e^{\eta_k}}{S}}{\dfrac{e^{\eta_{k'}}}{S}} = e^{\eta_k - \eta_{k'}}, \qquad S := \sum_{l=1}^{K}e^{\eta_l}
$$

取对数：

$$
\log e^{\eta_k-\eta_{k'}} = \eta_k - \eta_{k'} = \sum_{j=0}^{p}\beta_{kj}x_j - \sum_{j=0}^{p}\beta_{k'j}x_j = \sum_{j=0}^{p}\bigl(\beta_{kj}-\beta_{k'j}\bigr)x_j
$$

其中约定 $x_0 \equiv 1$，故常数项是 $\beta_{k0}-\beta_{k'0}$，得式 (4.14)。

**与 (4.12) 的关系**。当 $k'=K$ 时，(4.14) 就是 (4.12)——softmax 编码下系数差恰好是 baseline 编码的系数。这就是原书说「两种编码等价」的具体含义，也是 4.8 节习题 (c)(d) 的解法。

**结论**：log odds 总是**线性**的，与用哪种编码无关。编码只影响「用哪 $K-1$ 组系数来参数化」。

**易错点**：

- 下标 $k'$ 的撇在 LaTeX 里写作 `\beta_{k'0}`。注意它是**一个**下标（`k'0`），不是 `k'` 加上标 `0`。
- 系数差 $(\beta_{k0}-\beta_{k'0})$ 依赖于冗余参数的选取：给所有类别的系数同时加常数 $c$，每个概率都不变，但式 (4.14) 左边的常数项也会跟着变 $c-c=0$，所以 (4.14) 本身是**不变**的（这正是它可识别的原因）。而 (4.12) 依赖基准选择。
- $\log$ odds 与 $\log$ 概率比的区别见 (4.3) 的易错点；这里分母里是**概率**不是 $1-p$。

## 4.4 生成式模型：Bayes 定理

@src 原书 p.155–156 · [4.4 Generative Models for Classification](../isl/05-classification.html#s-4-4-generative-models-for-classification)

### (4.15) Bayes 定理 {#eq-4-15}

$$
\mathrm{Pr}(Y = k\mid X = x) = \frac{\pi_k f_k(x)}{\sum_{l=1}^{K} \pi_l f_l(x)} . \tag{4.15}
$$

**基础**：

- $\pi_k$：**先验概率**（prior probability），随机抽取一个观测它来自第 $k$ 类的概率，$\sum_k \pi_k = 1$。注意它是 $\pi$（希腊字母），**不是**圆周率 $3.14159$——原书在 (4.17) 后专门加了一条注释提醒这件事。
- $f_k(X) \equiv \Pr(X \mid Y=k)$：第 $k$ 类中 $X$ 的**密度函数**。若 $X$ 是定性的，$f_k(x)$ 直接读作 $\Pr(X = x \mid Y=k)$；若 $X$ 是定量的，$f_k(x)\,\mathrm{d}x$ 才是 $X$ 落在 $x$ 附近小区间的概率（原书脚注 1）。
- 约定简写 $p_k(x) = \Pr(Y = k \mid X = x)$，称为**后验概率**（posterior probability）。

**推导**（从条件概率定义出发）。全概率公式给出分母：

$$
\Pr(X = x) = \sum_{l=1}^{K}\Pr(X = x \mid Y = l)\Pr(Y = l) = \sum_{l=1}^{K} f_l(x)\,\pi_l
$$

再由条件概率的定义 $\Pr(Y=k\mid X=x) = \dfrac{\Pr(Y=k, X=x)}{\Pr(X=x)}$，而分子由乘法公式 $\Pr(Y=k,X=x) = \pi_k f_k(x)$，两式相除即得式 (4.15)。

**结论**：这是本章的**分水岭**。逻辑回归是**判别式**（discriminant）方法——直接建模 $\Pr(Y=k\mid X=x)$；式 (4.15) 是**生成式**（generative）方法——先建模 $X$ 在每个类里的分布 $f_k(x)$，再用 Bayes 定理「翻转」成 $\Pr(Y=k\mid X=x)$。原书强调这种做法「更间接」。

原书给出用生成式的三个理由：两类严重分离时逻辑回归的参数估计不稳定；$X$ 在各类内近似正态且样本量小时生成式可能更准；它能自然推广到两个以上的类。

**易错点**：

- **分母不能省**。式 (4.15) 给出的是概率（各类之和为 1），不是未归一化的「证据」（evidence）$\pi_kf_k(x)$。分类时因为分母对所有 $k$ 相同，可以只比较 $\pi_kf_k(x)$，但一旦要输出概率就必须除。
- $\pi_k$ 与 $f_k(x)$ 都可以低估。估计 $\pi_k$ 很容易（训练集中第 $k$ 类的比例）；估计 $f_k(x)$ 很难，必须对分布族做假设——这正是 LDA、QDA、朴素贝叶斯三者的分岔点。
- 第 2 章说「Bayes 分类器错误率最低」，前提就是式 (4.15) 里的**每一项都正确设定**。若 $f_k$ 假设错了，得到的不是 Bayes 分类器，只是它的近似。
- 密度与概率的混淆：定量预测子时 $f_k(x)$ 可以大于 1（密度不是概率），只有积分才是概率。

## 4.4.1 线性判别分析（LDA，$p=1$）

@src 原书 p.156–158 · [4.4.1 Linear Discriminant Analysis for p = 1](../isl/05-classification.html#s-4-4-1-linear-discriminant-analysis-for-p-1)

### (4.16) 一维高斯密度 {#eq-4-16}

$$
f_k(x) = \frac{1}{\sqrt{2\pi\sigma_k}}\exp\left(-\frac{1}{2\sigma_k^2}(x-\mu_k)^2\right), \tag{4.16}
$$

**基础**：$\mu_k$ 与 $\sigma_k^2$ 分别是第 $k$ 类的**均值**与**方差**参数。记号 $\sigma_k^2$ 是方差、$\sigma_k = \sqrt{\sigma_k^2}$ 是标准差。

**推导**（两部分）。分子分母的来历：

1. **指数部分**要「离均值越远越小、且总可积」。令 $z = (x-\mu_k)/\sigma_k$（标准化），取 $-\tfrac12 z^2 = -\frac{1}{2\sigma_k^2}(x-\mu_k)^2$。指数上的负号保证远离均值时衰减，单个 $\exp(-\tfrac{1}{2\sigma^2}(x-\mu)^2)$ 积分为 $\sqrt{2\pi}\sigma$，所以要除以它来归一化。
2. **归一化常数**：用换元 $u=(x-\mu_k)/\sigma_k$，$\mathrm{d}x = \sigma_k\,\mathrm{d}u$，
$$
\int_{-\infty}^{\infty}\exp\left(-\frac{(x-\mu_k)^2}{2\sigma_k^2}\right)\mathrm{d}x = \sigma_k\int_{-\infty}^{\infty}e^{-u^2/2}\mathrm{d}u = \sigma_k\sqrt{2\pi}
$$
故密度为 $\dfrac{1}{\sigma_k\sqrt{2\pi}}\exp(\cdots) = \dfrac{1}{\sqrt{2\pi\sigma_k}}\exp(\cdots)$——原书用的是后一种写法，分母写成根号套 $\sigma_k$。

**结论**：式 (4.16) 是 LDA 的第一条假设——**类内 $X$ 服从正态分布**。注意此时各类有自己的 $\sigma_k$；下一步还要进一步假设各类**共享**方差。

**易错点**：

- $\sqrt{2\pi\sigma_k}$ 与 $\sqrt{2\pi}\cdot\sigma_k$ 数值相同但不要混写，后者是 $\sqrt{2\pi}\,\sigma_k$。
- 分母里的 $\sigma_k$ 在根号**内**，所以「宽度 $\propto \sigma_k$」而不是 $\sigma_k^2$。
- 原书在 (4.17) 后提醒：这里的 $\pi_k$ 是先验概率，别与 $\pi \approx 3.14159$ 混淆。密度里的 $\pi$ 才是圆周率。

### (4.17) 共享方差下的后验概率 {#eq-4-17}

$$
p_k(x) = \frac{\pi_k \dfrac{1}{\sqrt{2\pi\sigma}}\exp\left(-\frac{1}{2\sigma^2}(x-\mu_k)^2\right)}{\sum_{l=1}^{K} \pi_l \dfrac{1}{\sqrt{2\pi\sigma}}\exp\left(-\frac{1}{2\sigma^2}(x-\mu_l)^2\right)} . \tag{4.17}
$$

**基础**：第二条假设 $\sigma_1^2 = \sigma_2^2 = \cdots = \sigma_K^2 =: \sigma^2$——各类**共享**一个方差。Bayes 分类器把 $X = x$ 归到 $p_k(x)$ 最大的那一类（原书脚注 2 强调：这是「分类规则」，与式 (4.15) 那个「可以操作条件分布的等式」不同）。

**推导**（纯代入）。把 (4.16) 中的 $\sigma_k$ 换成共享的 $\sigma$，代入 (4.15) 的分子与分母即可。

**结论**：式 (4.17) 揭示了为什么 LDA 的名字里有「线性」——下一步取对数后，公共的归一化常数 $\frac{1}{\sqrt{2\pi\sigma}}$ 会在分子分母中约掉，剩下的是 $x$ 的**二次式**的差，而这个二次项恰好在类间相消。

**易错点**：

- 共享方差是 LDA 的**关键**假设。放开它就变成 QDA (4.28)，判别边界变成二次曲线。
- 分母里 $\mu_l$ 的下标是 $l$（求和变量），分子的 $\mu_k$ 是固定类别。不要写成同一个下标。
- 式 (4.17) 里出现两处 $\pi$：分母 $\sqrt{2\pi\sigma}$ 中的 $\pi$ 是圆周率，$\pi_k$ 是先验。同一行公式里两种含义并存，这是原书特意加注释的原因。

### (4.18) 一维 LDA 判别函数 {#eq-4-18}

$$
\delta_k(x) = x\cdot\frac{\mu_k}{\sigma^2} - \frac{\mu_k^2}{2\sigma^2} + \log(\pi_k) \tag{4.18}
$$

**基础**：**判别函数**（discriminant function）$\delta_k(x)$。原书的结论是：把 $x$ 归到 $\delta_k(x)$ 最大的那一类，与归到 $p_k(x)$ 最大的那一类**等价**（原书脚注 3 把这一步留给习题 2）。

**推导（1）取对数**。因为 $\log$ 严格单调递增，$p_k(x)$ 的排序与 $\log p_k(x)$ 的排序相同。写 $A_k := \frac{\pi_k}{\sqrt{2\pi\sigma}}$，则

$$
\log p_k(x) = \log\left(\pi_k\right) - \frac{1}{2}\log(2\pi\sigma) - \frac{(x-\mu_k)^2}{2\sigma^2} - \log\left(\sum_{l}\pi_l\frac{1}{\sqrt{2\pi\sigma}}e^{-(x-\mu_l)^2/(2\sigma^2)}\right)
$$

最后那个对数项**对所有 $k$ 都一样**（它是常数），故比较时可以丢掉。剩下：

$$
\delta_k(x) := \log\pi_k - \frac{1}{2}\log(2\pi\sigma) - \frac{(x-\mu_k)^2}{2\sigma^2}
$$

**推导（2）展开平方项，暴露「线性」**。展开：

$$
(x-\mu_k)^2 = x^2 - 2x\mu_k + \mu_k^2
$$

代入：

$$
\delta_k(x) = \log\pi_k - \frac{1}{2}\log(2\pi\sigma) - \frac{x^2 - 2x\mu_k + \mu_k^2}{2\sigma^2} = \log\pi_k - \frac{1}{2}\log(2\pi\sigma) - \frac{x^2}{2\sigma^2} + \frac{x\mu_k}{\sigma^2} - \frac{\mu_k^2}{2\sigma^2}
$$

**两项与 $k$ 无关**：$-\frac{1}{2}\log(2\pi\sigma)$ 与 $-\frac{x^2}{2\sigma^2}$。把它们从 $\delta_k$ 里减掉（不改变跨 $k$ 的排序），得到原书的形式：

$$
\delta_k(x) = \underbrace{\frac{x\mu_k}{\sigma^2} - \frac{\mu_k^2}{2\sigma^2} + \log\pi_k}_{\text{原书式 (4.18)}}
$$

**结论**：$\delta_k(x)$ 是 $x$ 的**一次函数**，这就是「线性」二字的来源。若 $K=2$ 且 $\pi_1=\pi_2$，比较 $\delta_1(x) > \delta_2(x)$ 等价于

$$
2x(\mu_1-\mu_2) > \mu_1^2 - \mu_2^2
$$

**易错点**：

- $\delta_k(x)$ **不是**概率，甚至可以取任意实数值（可以 $>0$，也 $<0$）。它是「打分函数」。有些软件会再取 softmax 使其变成概率，但那不是原书的形式。
- 被丢掉的 $-x^2/(2\sigma^2)$ 是**二次**的，但因为与 $k$ 无关所以无害。**这一步只在共享方差时成立**——QDA 里 $k$ 相关的二次项消不掉。
- 判别比较用的是 $\delta_k$ 之间的差，不是 $\delta_k$ 的绝对值大小。
- 不要写成 $\log(\pi_k/\pi_1)$：原书 (4.18) 保留单个 $\log\pi_k$，$\log\pi_1$ 与 $\log\pi_k$ 的差在比较时自然出现。

### (4.19) 二类情形下的 Bayes 判别边界 {#eq-4-19}

$$
x = \frac{\mu_1^2-\mu_2^2}{2(\mu_1-\mu_2)} = \frac{\mu_1+\mu_2}{2}. \tag{4.19}
$$

**基础**：**判别边界**（decision boundary）是使 $\delta_k(x) = \delta_\ell(x)$ 成立的 $x$ 的集合。$K=2$ 时它是**一个点**。

**推导**。令 $\delta_1(x) = \delta_2(x)$：

$$
x\frac{\mu_1}{\sigma^2} - \frac{\mu_1^2}{2\sigma^2} + \log\pi_1 = x\frac{\mu_2}{\sigma^2} - \frac{\mu_2^2}{2\sigma^2} + \log\pi_2
$$

若 $\pi_1 = \pi_2$，对数项相消（$\log\pi_1-\log\pi_2 = \log 1 = 0$），移项：

$$
x\frac{\mu_1-\mu_2}{\sigma^2} = \frac{\mu_1^2-\mu_2^2}{2\sigma^2}
$$

两边同乘 $\sigma^2$（$\sigma^2>0$，不改变不等号方向）：

$$
x = \frac{\mu_1^2-\mu_2^2}{2(\mu_1-\mu_2)}
$$

**因式分解**分子：$\mu_1^2-\mu_2^2 = (\mu_1-\mu_2)(\mu_1+\mu_2)$，约去 $\mu_1-\mu_2$（$K=2$ 两类不同时 $\mu_1\ne\mu_2$，可约）：

$$
x = \frac{(\mu_1-\mu_2)(\mu_1+\mu_2)}{2(\mu_1-\mu_2)} = \frac{\mu_1+\mu_2}{2}
$$

**结论**：在等先验、等（共享）方差下，Bayes 判别边界恰是两个类均值的**中点**。原书的 Figure 4.4 左图：$\mu_1 = -1.25$、$\mu_2 = 1.25$、$\sigma_1^2=\sigma_2^2=1$、$\pi_1=\pi_2=0.5$，代入得边界 $= (-1.25+1.25)/2 = 0$；于是 $x<0$ 归第 1 类，$x\ge0$ 归第 2 类。

**易错点**：

- **先验不等时中点结论不成立**。一般情形下从 $\delta_1=\delta_2$ 解出的是
$$
x = \frac{\mu_1^2-\mu_2^2 - 2\sigma^2\log(\pi_1/\pi_2)}{2(\mu_1-\mu_2)}
$$
边界会朝**先验概率大**的那一类平移。例：$x$ 轴下方（类 1）先验大，则类 1 的地盘扩大，边界左移。
- $\mu_1=\mu_2$ 时不能约分。此时两个密度完全重合，$p_1=p_2$，Bayes 分类器退化为按先验多数类判别，没有边界。
- 这里的 $\mu$ 是**总体**参数。LDA 实际用的是样本估计 (4.20)，所以实际边界是 $(\hat\mu_1+\hat\mu_2)/2$，原书明确说它「略偏在」最优 Bayes 边界的左侧。

### (4.20) $\hat\mu_k$ 与 $\hat\sigma^2$ 的估计 {#eq-4-20}

$$
\hat\mu_k = \frac{1}{n_k}\sum_{i:y_i=k} x_i, \qquad \hat\sigma^2 = \frac{1}{n-K}\sum_{k=1}^{K}\sum_{i:y_i=k}(x_i - \hat\mu_k)^2 \tag{4.20}
$$

**基础**：$n$ 是训练观测总数，$n_k$ 是第 $k$ 类的观测个数（$\sum_k n_k = n$）。原书把它排成一个两行显示式，编号 (4.20) 标在第二行。

**推导（1）均值**。把第 $k$ 类的 $n_k$ 个值取算术平均。这与第 3 章样本均值的定义一致，只是样本被限制在第 $k$ 类内部——即用**类内**数据估**类内**均值。

**推导（2）共享方差：为什么是「合并的组内平方和」除以 $n-K$**。考虑总体残差平方和

$$
\mathrm{SS}_{\text{in}} = \sum_{k=1}^{K}\sum_{i:y_i=k}(x_i-\mu_k)^2
$$

分成两类项：

1. **类内**部分：把 $\mu_k$ 换成估计量 $\hat\mu_k$，
$$
\mathrm{SS}_{\text{within}} = \sum_{k=1}^{K}\sum_{i:y_i=k}(x_i-\hat\mu_k)^2
$$
每类消耗 $n_k-1$ 个自由度（估一个 $\mu_k$），共 $\sum_k(n_k-1) = n-K$ 个。
2. 用无偏性说明：$\E[\mathrm{SS}_{\text{within}}] = (n-K)\sigma^2$（每类 $\E[\sum(x_i-\bar x_k)^2] = (n_k-1)\sigma^2$，且 $p=1$ 时一维正态下这个结论不依赖正态性，只依赖二阶矩存在）。
3. 所以 $\hat\sigma^2 = \mathrm{SS}_{\text{within}}/(n-K)$ 是 $\sigma^2$ 的无偏估计。

**用「加权平均」理解**（原书原话）。各类单独的样本方差 $s_k^2 = \frac{1}{n_k-1}\sum_{i:y_i=k}(x_i-\hat\mu_k)^2$，把分子分母分别整理：

$$
\hat\sigma^2 = \frac{\sum_k (n_k-1)s_k^2}{\sum_k (n_k-1)} = \frac{\sum_{k=1}^{K}(n_k-1)s_k^2}{n-K}
$$

即以 $n_k-1$ 为权重的 $s_k^2$ 的加权平均。原书说 $\hat\sigma^2$「可以看作各类样本方差的加权平均」。

**结论**：LDA 需要估计 $K$ 个均值、$1$ 个共享方差、$K$ 个先验。总参数量是 $2K+1$（对比 QDA 的 $K\cdot\frac{p(p+1)}{2} + K(p+1)$）。

**易错点**：

- 分母是 $n-K$ 不是 $n-1$ 也不是 $n$。用 $n$ 会在 $n$ 小时**低估**方差（自由度多算了 $K-1$），边界变窄。
- 分子里减的是**各类自己的** $\hat\mu_k$，不是总均值 $\bar x$。减总均值得到的是总平方和（含类间差异），那是错的。
- $n_k = 0$ 的情形（某类在训练集里没出现）无法估计 $\hat\mu_k$；软件会报 warning。
- $p=1$ 时这是标量；$p>1$ 时换成矩阵（$p\times p$ 的 pooled covariance），构造方式见 4.4.2。

### (4.21) 先验概率的估计 {#eq-4-21}

$$
\hat{\pi}_k = n_k/n. \tag{4.21}
$$

**基础**：有时确实知道各类别的**真实**成员概率 $\pi_1,\ldots,\pi_K$（原书说这时可以直接用）；在没有额外信息时，LDA 用训练集里第 $k$ 类的**比例**来估。

**推导**。$\pi_k = \Pr(Y=k)$ 是「随机抽一个总体观测，它来自第 $k$ 类」的概率。训练集是从总体随机抽的 $n$ 个观测，$n_k$ 个落在第 $k$ 类。频率就是概率的估计：

$$
\hat\pi_k = \frac{\text{第 }k\text{ 类的观测数}}{\text{总观测数}} = \frac{n_k}{n}
$$

一致性检查：$\sum_{k=1}^{K}\hat\pi_k = \frac{\sum_k n_k}{n} = \frac{n}{n} = 1$，仍是一个合法的概率分布。

**结论**：这是**唯一**不需要任何分布假设的估计量。无论 LDA、QDA 还是朴素贝叶斯，$\hat\pi_k = n_k/n$ 都是默认做法。Default 数据里 $n_1 = 9667$、$n_2 = 333$、$n = 10{,}000$，所以 $\hat\pi_{\text{default}} = 0.0333$。

**易错点**：

- 类别极不平衡时（Default 数据 3.33% 违约）$\hat\pi$ 会非常小，使得 $\log\hat\pi$ 是个大负数，在 (4.18) 里给违约类的打分**系统性地拉低**。这正是原书后面要专门调阈值 (4.27) 的原因之一。
- 当 $K=2$ 且 $n_1=n_2$ 时，$\hat\pi_1=\hat\pi_2$，$\log\hat\pi$ 项在 $\delta_1-\delta_2$ 中相消，判别边界退化为 $(\hat\mu_1+\hat\mu_2)/2$（原书 Figure 4.4 右图正是这种情形）。
- 别把 $\hat\pi_k$ 写成 $\hat p_k$。前者是先验（只看 $Y$），后者是后验（看了 $X$ 之后）。

### (4.22) LDA 判别函数（估计量） {#eq-4-22}

$$
\hat{\delta}_k(x) = x\cdot\frac{\hat\mu_k}{\hat\sigma^2} - \frac{\hat\mu_k^2}{2\hat\sigma^2} + \log(\hat{\pi}_k) \tag{4.22}
$$

**基础**：LDA 把 (4.20)、(4.21) 的估计量代入 (4.18)，得到**可计算**的判别函数。

**推导**。逐项替换：$\mu_k\to\hat\mu_k$、$\sigma^2\to\hat\sigma^2$、$\pi_k\to\hat\pi_k$。这是一个**估计**量，因此带帽。原书明确说 LDA 分类规则是「把 $X=x$ 归到 $\hat\delta_k(x)$ 最大的那一类」。

**完整的 LDA 算法**（原书 4.4.1–4.4.2 汇总）：

1. 用 (4.20) 估 $\hat\mu_1,\ldots,\hat\mu_K$ 与 $\hat\sigma^2$（或 $\hat{\boldsymbol\Sigma}$）。
2. 用 (4.21) 估 $\hat\pi_1,\ldots,\hat\pi_K$。
3. 对新观测 $X=x$，计算 $K$ 个 $\hat\delta_k(x)$。
4. 取最大者为预测类别。

**结论**：「linear」一词指的就是 (4.22) 中 $\hat\delta_k$ 是 $x$ 的**线性函数**（原书原话：as opposed to a more complex function of $x$）。Figure 4.4 右图的实验：$n_1=n_2=20$，所以 $\hat\pi_1=\hat\pi_2$，LDA 判别边界就是 $(\hat\mu_1+\hat\mu_2)/2$，图上它略偏在 Bayes 边界 $0$ 的左侧。模拟实验中 Bayes 错误率 10.6%、LDA 测试错误率 11.1%——只差 0.5%。

**易错点**：

- $\hat\delta_k(x)$ 之间只比**大小**，不需要归一化成概率。若要输出概率，再通过 (4.17) 或 (4.15) 换算；实践中更常用 $\hat p_k \propto e^{\hat\delta_k}$（softmax）。
- 帽号不能省：$\hat\sigma^2$ 是估计量，$\hat\delta_k$ 也是。原书在 (4.22) 里给三个量都加了帽。
- 分类边界对**量纲**敏感：若把 $X$ 从米换成厘米，$\hat\mu_k$、$\hat\sigma^2$ 同步变换，$\hat\delta_k$ 只会整体平移同一个常数（因 $\log\hat\sigma^2$ 项与 $k$ 无关），所以**判别结果不变**。LDA 对单调线性重标定是稳健的。

## 4.4.2 线性判别分析（$p>1$）

### (4.23) 多元高斯（高维正态）密度 {#eq-4-23}

$$
f(x) = \frac{1}{(2\pi)^{p/2}|\boldsymbol{\Sigma}|^{1/2}}\exp\left(-\frac{1}{2}(x-\mu)^{T}\boldsymbol{\Sigma}^{-1}(x-\mu)\right). \tag{4.23}
$$

**基础**：$X \sim \mathcal N(\mu, \boldsymbol\Sigma)$，$\mu = \E(X)$ 是 $p$ 维均值向量，$\boldsymbol\Sigma = \Cov(X)$ 是 $p\times p$ 协方差矩阵，$|\boldsymbol\Sigma|$ 是**行列式**（determinant），$\boldsymbol\Sigma^{-1}$ 是逆矩阵。原文用粗体 $\boldsymbol\Sigma$，本节一律照此记号。

**性质**（原书 4.4.2 强调）：每个单独的预测子都服从一维正态（就是 (4.16)），但变量两两之间有**相关**。沿任一坐标轴切开曲面，截面是钟形；当 $\Var(X_1)=\Var(X_2)$ 且 $\Cor(X_1,X_2)=0$ 时是「钟形」，有相关或方差不齐时底部变成**椭圆**（Figure 4.5）。

**推导（1）为什么二次型里有 $\boldsymbol\Sigma^{-1}$**。先看 $p=1$：指数部分是 $-\frac{(x-\mu)^2}{2\sigma^2} = -\frac{1}{2\sigma^2}\left[1\cdot \frac{1}{\sigma^2}\cdot 1\right](x-\mu)$，即「$1/\sigma^2$ 是 $\sigma^2$ 的逆」。推广到 $p$ 维，「$1/\sigma^2$」的角色由 $\boldsymbol\Sigma^{-1}$ 承担，方括号里的「$1\cdot(\cdot)\cdot 1$」由 $z^\top\boldsymbol\Sigma^{-1}z$ 承担，其中 $z := x-\mu$。

**推导（2）归一化常数**。需要 $\int_{\R^p}\exp(-\frac12 z^\top\boldsymbol\Sigma^{-1}z)\,\mathrm{d}z = (2\pi)^{p/2}|\boldsymbol\Sigma|^{1/2}$。做法是先做线性换元 $w = \boldsymbol\Sigma^{-1/2}z$，其中 $\boldsymbol\Sigma^{1/2}$ 是 $\boldsymbol\Sigma$ 的「方根」（对称正定矩阵有唯一的正定方根，特征值逐个开方后重组）。雅可比是 $|\boldsymbol\Sigma^{1/2}| = |\boldsymbol\Sigma|^{1/2}$，于是

$$
\int e^{-\frac12 z^\top\boldsymbol\Sigma^{-1}z}\mathrm{d}z = |\boldsymbol\Sigma|^{1/2}\int_{\R^p}e^{-\frac12 w^\top w}\mathrm{d}w = |\boldsymbol\Sigma|^{1/2}(2\pi)^{p/2}
$$

**推导（3）分解成标准化正态**。令 $Z = \boldsymbol\Sigma^{-1/2}(X-\mu)$，则 $Z\sim\mathcal N(0, I_p)$，且

$$
X = \mu + \boldsymbol\Sigma^{1/2}Z
$$

这个表示法是后面所有 LDA 推导的发动机——凡是要「把 $k$ 相关的项和公共项分开」，都靠它。

**结论**：$|\boldsymbol\Sigma|^{1/2}$ 是「体积缩放因子」：$\boldsymbol\Sigma = cI_p$ 时椭球体积按 $c^{p/2}$ 缩放。$p=1$ 时 $(2\pi)^{1/2}|\sigma|^{1/2} = \sqrt{2\pi\sigma}$，正是 (4.16) 的分母——式 (4.23) 是式 (4.16) 的高维版本。

**易错点**：

- $|\boldsymbol\Sigma|$ 是行列式，**不是**绝对值也不是范数。写成 $\det\boldsymbol\Sigma$ 也可以（$\det$ 已在可用命令列表里）。
- 指数里是 $(x-\mu)^T\boldsymbol\Sigma^{-1}(x-\mu)$，结果是一个**标量**（这是 Mahalanobis 距离的平方）。它可正可负，**不是**距离本身。
- $\boldsymbol\Sigma$ 必须正定才能有逆。共线性（变量高度线性相关）会让 $\boldsymbol\Sigma$ 接近奇异，$|\boldsymbol\Sigma|^{1/2}\to 0$、$\boldsymbol\Sigma^{-1}$ 元素爆炸。
- $p=1$ 时 $\boldsymbol\Sigma$ 退化为标量 $\sigma^2$，$\boldsymbol\Sigma^{-1} = 1/\sigma^2$，(4.23) 精确回到 (4.16)。

### (4.24) 多元 LDA 判别函数 {#eq-4-24}

$$
\delta_k(x) = x^{T}\boldsymbol{\Sigma}^{-1}\mu_k - \frac{1}{2}\mu_{k}^{T}\boldsymbol{\Sigma}^{-1}\mu_k + \log \pi_k \tag{4.24}
$$

**基础**：LDA 假设第 $k$ 类的观测来自 $\mathcal N(\mu_k, \boldsymbol\Sigma)$——类特异均值 $\mu_k$，**所有 $K$ 类共享**的协方差 $\boldsymbol\Sigma$。原书称 (4.24) 是 (4.18) 的「向量/矩阵版本」。

**推导（1）代入**。把 $f_k(X=x) = f(x)$ 的第 $k$ 类版本代入 (4.15)：

$$
p_k(x) = \frac{\pi_k \dfrac{1}{(2\pi)^{p/2}|\boldsymbol\Sigma|^{1/2}}\exp\left(-\frac12(x-\mu_k)^\top\boldsymbol\Sigma^{-1}(x-\mu_k)\right)}{\sum_{l=1}^{K} \pi_l \dfrac{1}{(2\pi)^{p/2}|\boldsymbol\Sigma|^{1/2}}\exp\left(-\frac12(x-\mu_l)^\top\boldsymbol\Sigma^{-1}(x-\mu_l)\right)}
$$

**推导（2）取对数并丢掉公共项**。因为 $\log$ 单调，排序不变；分母那个对数项与 $k$ 无关，丢掉。剩下

$$
\tilde\delta_k(x) = \log\pi_k - \frac{1}{2}\log\big((2\pi)^{p/2}|\boldsymbol\Sigma|^{1/2}\big) - \frac12(x-\mu_k)^\top\boldsymbol\Sigma^{-1}(x-\mu_k)
$$

**推导（3）关键：二次项相消**。展开 $(x-\mu_k)^\top\boldsymbol\Sigma^{-1}(x-\mu_k)$。记 $A := \boldsymbol\Sigma^{-1}$（对称），逐步用 $(u+v)^\top = u^\top + v^\top$、$(A(u+v)) = Au+Av$、$(u+v)^\top w = u^\top w + v^\top w$：

$$
(x-\mu_k)^\top A (x-\mu_k) = x^\top A x - x^\top A\mu_k - \mu_k^\top A x + \mu_k^\top A\mu_k
$$

因为 $A$ 对称，$x^\top A\mu_k = (x^\top A\mu_k)^\top = \mu_k^\top A^\top x = \mu_k^\top A x$，两个交叉项相等：

$$
(x-\mu_k)^\top A(x-\mu_k) = x^\top A x - 2x^\top A\mu_k + \mu_k^\top A\mu_k
$$

代回 $\tilde\delta_k$：

$$
\tilde\delta_k(x) = \log\pi_k - \frac12\log\big((2\pi)^{p/2}|\boldsymbol\Sigma|^{1/2}\big) - \frac{x^\top A x}{2} + x^\top A\mu_k - \frac12\mu_k^\top A\mu_k
$$

现在做关键观察：前两项与 $k$ 无关，**第三项 $-x^\top\boldsymbol\Sigma^{-1}x/2$ 也与 $k$ 无关**（它只依赖共享的 $\boldsymbol\Sigma$）。所以比较 $\delta_k$ 时前两项可以整体减掉：

$$
\delta_k(x) = x^\top\boldsymbol\Sigma^{-1}\mu_k - \frac12\mu_k^\top\boldsymbol\Sigma^{-1}\mu_k + \log\pi_k
$$

**这就是「线性」的确切含义**：$x$ 只以 $x^\top\boldsymbol\Sigma^{-1}\mu_k$ 这个**一次**形式出现，二次型 $x^\top\boldsymbol\Sigma^{-1}x$ 被公共项吸收了。

**结论**：$\delta_k(x)$ 是 $x$ 的线性函数，判别规则（$p>1$）为 $\arg\max_k \delta_k(x)$。原书明确写：this is the reason for the word linear in LDA。$p=1$ 时把 $\boldsymbol\Sigma^{-1}$ 换成 $1/\sigma^2$、$x^\top\mu_k$ 换成 $x\mu_k$，即精确回到 (4.18)。

**易错点**：

- **共享协方差是可识别 $\delta_k$ 线性性的唯一原因**。若 $\boldsymbol\Sigma_k$ 随类变化，$-x^\top\boldsymbol\Sigma_k^{-1}x/2$ 就变成 $k$ 相关的，消不掉——那正是 QDA (4.28) 的二次来源。
- $\mu_k^\top\boldsymbol\Sigma^{-1}\mu_k$ 是标量，**不是** $\mu_k^\top\boldsymbol\Sigma^{-1}\mu_k$ 的向量形式，展开时不要多写一个 $\mu$。
- $\log\pi_k$ 在原书里是 $\log\pi_k$（无括号），(4.18) 里是 $\log(\pi_k)$。两者相同。
- 交叉项系数是 $-2$（来自 $\boldsymbol\Sigma^{-1}$ 的对称性），若误写成 $-1$ 会得到 $\delta_k$ 里多出 $x^\top A\mu_k/2$，形式就不再对称了。

### (4.25) 多元 LDA 的 Bayes 判别边界 {#eq-4-25}

$$
x^{T}\boldsymbol{\Sigma}^{-1}\mu_k - \frac{1}{2}\mu_{k}^{T}\boldsymbol{\Sigma}^{-1}\mu_k = x^{T}\boldsymbol{\Sigma}^{-1}\mu_l - \frac{1}{2}\mu_{l}^{T}\boldsymbol{\Sigma}^{-1}\mu_l \tag{4.25}
$$

**基础**：对 $k \ne \ell$。原书说明这里 $\log\pi_k$ 项消失了，**因为三个类在训练集里样本数相同**（即 $\pi_k$ 相同），对数项在等式两边相消。

**推导**。从 $\delta_k(x) = \delta_\ell(x)$ 出发：

$$
x^\top\boldsymbol\Sigma^{-1}\mu_k - \frac12\mu_k^\top\boldsymbol\Sigma^{-1}\mu_k + \log\pi_k = x^\top\boldsymbol\Sigma^{-1}\mu_\ell - \frac12\mu_\ell^\top\boldsymbol\Sigma^{-1}\mu_\ell + \log\pi_\ell
$$

若 $\pi_k = \pi_\ell$，则 $\log\pi_k - \log\pi_\ell = \log 1 = 0$，两项消去，得式 (4.25)。

**这条边界的几何形状**。它可以整理成

$$
x^\top\boldsymbol\Sigma^{-1}(\mu_k - \mu_\ell) = \frac12\bigl(\mu_k^\top\boldsymbol\Sigma^{-1}\mu_k - \mu_\ell^\top\boldsymbol\Sigma^{-1}\mu_\ell\bigr) = \frac12(\mu_k+\mu_\ell)^\top\boldsymbol\Sigma^{-1}(\mu_k-\mu_\ell)
$$

（最后一步用了 $\boldsymbol\Sigma^{-1}$ 对称。）所以边界是 $\{x : v^\top x = c\}$，其中 $v = \boldsymbol\Sigma^{-1}(\mu_k-\mu_\ell)$、$c = \frac12(\mu_k+\mu_\ell)^\top v$——**一个超平面**。它在 $\boldsymbol\Sigma^{-1}$ 度量的空间里垂直于 $\mu_k-\mu_\ell$，且过点 $\frac12(\mu_k+\mu_\ell)$。

**结论**：$K$ 个类别有 $\binom{K}{2}$ 对，因此最多有 $\binom{K}{2}$ 条边界，把 $p$ 维预测子空间切成若干区域。Figure 4.6 的三分类（$p=2$）给出 3 条线，切出 3 个区域。模拟实验里 Bayes 测试错误率 0.0746、LDA 0.0770。

**易错点**：

- $\log\pi$ 项消失是**因为等先验**，不是因为公式错了。一般情形下边界要平移（$p=1$ 的对应结论见 (4.19) 的易错点）。
- 边界垂直于 $\boldsymbol\Sigma^{-1}(\mu_k-\mu_\ell)$，**不是**垂直于 $\mu_k-\mu_\ell$。当 $\boldsymbol\Sigma \ne I$ 时两者不同——这就是为什么 Figure 4.5 右图（共线性 0.7）里的 LDA 边界不垂直于两个均值连线。
- 别把 (4.25) 当成「LDA 的判别规则」。规则是 (4.24) 的 $\arg\max$；(4.25) 只是**边界方程**，只在二分类的几何解释里用。
- 下标是 $\ell$（小写 L）不是 $1$（数字一）。原书用 $\ell$ 避免与 $1$ 混淆。

### (4.26) Bayes 分类器的 50% 阈值 {#eq-4-26}

$$
\mathrm{Pr}(\text{default} = \text{Yes}\mid X = x) > 0.5. \tag{4.26}
$$

**基础**：Bayes 分类器把观测归到后验概率 $p_k(X)$ 最大的那一类。二分类时这等价于「若违约的后验概率超过 0.5 就判违约」。

**推导**。设 $\mathrm{default}=\text{Yes}$ 是类 1、$\text{No}$ 是类 2。后验最大等价于

$$
p_1(x) > p_2(x) \iff p_1(x) > 1 - p_1(x) \iff 2p_1(x) > 1 \iff p_1(x) > \tfrac12
$$

（最后一步用了归一化 $p_1+p_2=1$。）

**用 log odds 看更清楚**。由 (4.4)，$p_1 > 0.5 \iff \operatorname{logit}(p_1) > \operatorname{logit}(0.5) = \log\frac{0.5}{0.5} = 0$。所以「50% 阈值」在 log odds 尺度上就是「阈值 0」。

**结论**：Bayes 分类器（以及它的近似 LDA）用的是 **50% 阈值**，这最小化**总体**错误率。原书用 Default 数据说明这在实践中不够：Table 4.4 的混淆矩阵里 LDA 只标出 104 人会违约，其中 81 人确实违约、23 人没违约；但真实的 333 个违约者里有 **252 个（75.7%）被漏掉**。灵敏度只有 24.3%，特异度 $(1-23/9667) = 99.8\%$。对信用卡公司来说 75.7% 的漏检不可接受。

**易错点**：

- 50% 阈值最小化的是**总体**错误率，不是某一类的错误率。类别不平衡时这两者差别巨大（Default 数据里 3.33% 违约，恒判「不违约」的错误率就只有 3.33%）。
- 别把「sensitivity 24.3%」和「overall error rate 2.75%」混为一谈。前者分母是 333（真实违约者），后者分母是 10,000。Table 4.7 专门列了这些指标的分母差别。
- $\mathrm{Pr}$ 里的 `default = Yes` 是响应取值，不是变量名；原书用等宽字体排版，LaTeX 里对应 `\text{default}`。

### (4.27) 调整阈值到 20% {#eq-4-27}

$$
\mathrm{Pr}(\text{default} = \text{Yes}\mid X = x) > 0.2. \tag{4.27}
$$

**基础**：如果真正在意的是「不要把会违约的人判成不违约」（提高**灵敏度**），就应该把阈值调低。

**推导**。阈值 $t$ 一般地写成 $\mathrm{Pr}(\text{default}=\text{Yes}\mid X=x) > t$。由 logit 单调，等价于

$$
x^\top\boldsymbol\Sigma^{-1}\mu_k - \frac12\mu_k^\top\boldsymbol\Sigma^{-1}\mu_k + \log\hat\pi_k > \log\frac{t}{1-t}
$$

即在 (4.22) 的判别分数上加一个与 $k$ 无关的常数——**决策规则的形式不变，只是边界平移**。$t=0.5$ 时 $\log\frac{t}{1-t} = 0$；$t=0.2$ 时 $\log\frac{0.2}{0.8} = \log 0.25 = -1.386$。

**结论**：Default 数据用 20% 阈值后（Table 4.5）：预测 430 人违约，其中 195 人确实违约（漏检从 252 降到 138，即从 75.7% 降到 41.4%），但误报从 23 升到 235，总体错误率从 2.75% 升到 3.73%。Figure 4.7 把这个权衡画成了三条曲线：总体错误率在 0.5 处最小；违约者的漏检率随阈值降低而单调下降；非违约者的误报率随阈值降低而单调上升。

**结论（阈值怎么定）**：这**不是**统计问题而是**决策**问题——必须靠领域知识（违约的代价）。Figure 4.8 的 **ROC 曲线**同时展示两类错误，AUC = 0.95。

**易错点**：

- 阈值可以在 0 到 1 之间任意取，50% 只是「最小化总体错误率」这一个特定目标下的选择。
- 把 $t$ 写成 $1/2$ 与 $0.5$ 等价；但别把 $t$ 与 odds 搞混：$t=0.2$ 对应 odds $=0.25$，不是 0.2。
- Table 4.6/4.7 的记号要分清分母：false positive rate $= \mathrm{FP}/N$（分母是真实负类总数），positive predictive value $=\mathrm{TP}/P^{*}$（分母是**预测**为正的总人数）。混淆这两者是读表时最常见的错误。

## 4.4.3 二次判别分析（QDA）

@src 原书 p.165–166 · [4.4.3 Quadratic Discriminant Analysis](../isl/05-classification.html#s-4-4-3-quadratic-discriminant-analysis)

### (4.28) QDA 判别函数 {#eq-4-28}

$$
\begin{aligned}
\delta_k(x) &= -\frac{1}{2}(x-\mu_k)^{T}\boldsymbol{\Sigma}_{k}^{-1}(x-\mu_k) - \frac{1}{2}\log|\boldsymbol{\Sigma}_{k}| + \log \pi_k\\[4pt]
&= -\frac{1}{2}x^{T}\boldsymbol{\Sigma}_{k}^{-1}x + x^{T}\boldsymbol{\Sigma}_{k}^{-1}\mu_k - \frac{1}{2}\mu_{k}^{T}\boldsymbol{\Sigma}_{k}^{-1}\mu_k - \frac{1}{2}\log|\boldsymbol{\Sigma}_{k}| + \log \pi_k
\end{aligned}\tag{4.28}
$$

**基础**：QDA 与 LDA 一样从生成式出发（高斯 + Bayes 定理），但**每类有自己的协方差矩阵** $\boldsymbol\Sigma_k$：第 $k$ 类观测服从 $\mathcal N(\mu_k, \boldsymbol\Sigma_k)$。LDA 里 $\boldsymbol\Sigma_1=\cdots=\boldsymbol\Sigma_K=\boldsymbol\Sigma$。

**推导 (1) 代入**。把 $f_k$ 的 QDA 版本（(4.23) 里 $\boldsymbol\Sigma\to\boldsymbol\Sigma_k$）代入 (4.15)：

$$
p_k(x) = \frac{\pi_k\,|\boldsymbol\Sigma_k|^{-1/2}\exp\!\left(-\frac12(x-\mu_k)^\top\boldsymbol\Sigma_k^{-1}(x-\mu_k)\right)}{\sum_{l=1}^{K}\pi_l\,|\boldsymbol\Sigma_l|^{-1/2}\exp\!\left(-\frac12(x-\mu_l)^\top\boldsymbol\Sigma_l^{-1}(x-\mu_l)\right)}
$$

**推导 (2) 取对数，丢掉公共分母**。丢弃与 $k$ 无关的那一项：

$$
\delta_k(x) = -\frac{1}{2}\log|\boldsymbol\Sigma_k| + \log\pi_k - \frac{1}{2}(x-\mu_k)^\top\boldsymbol\Sigma_k^{-1}(x-\mu_k)
$$

这就是式 (4.28) 的第一行。

**推导 (3) 展开平方项——这里消不掉**。用与 (4.24) 相同的展开（记 $A_k := \boldsymbol\Sigma_k^{-1}$，对称）：

$$
(x-\mu_k)^\top A_k(x-\mu_k) = x^\top A_k x - 2x^\top A_k\mu_k + \mu_k^\top A_k\mu_k
$$

代回并整理：

$$
\delta_k(x) = -\frac{1}{2}x^\top A_k x + x^\top A_k\mu_k - \frac{1}{2}\mu_k^\top A_k\mu_k - \frac{1}{2}\log|\boldsymbol\Sigma_k| + \log\pi_k
$$

这就是式 (4.28) 的第二行。

**与 LDA 的唯一差别**：$x^\top\boldsymbol\Sigma^{-1}x/2$ 在 LDA 里**与 $k$ 无关**，可以整体减掉；这里 $x^\top\boldsymbol\Sigma_k^{-1}x/2$ **依赖 $k$**，减不掉。于是 $x$ 以**二次**形式出现，QDA 得名。

**QDA 的判别边界（重点）**。对 $k\ne\ell$，令 $\delta_k = \delta_\ell$ 并把所有二次项移到左边：

$$
x^\top\Bigl(\boldsymbol\Sigma_\ell^{-1} - \boldsymbol\Sigma_k^{-1}\Bigr)x + 2x^\top\Bigl(\boldsymbol\Sigma_k^{-1}\mu_k - \boldsymbol\Sigma_\ell^{-1}\mu_\ell\Bigr) + \Bigl(\mu_\ell^\top\boldsymbol\Sigma_\ell^{-1}\mu_\ell - \mu_k^\top\boldsymbol\Sigma_k^{-1}\mu_k + \log|\boldsymbol\Sigma_k| - \log|\boldsymbol\Sigma_\ell| + 2\log\tfrac{\pi_k}{\pi_\ell}\Bigr) = 0
$$

用 $1 = x^\top x$ 配方：令 $A := \boldsymbol\Sigma_\ell^{-1}-\boldsymbol\Sigma_k^{-1}$、$b := \boldsymbol\Sigma_k^{-1}\mu_k - \boldsymbol\Sigma_\ell^{-1}\mu_\ell$、$c$ 为常数项，则

$$
x^\top A x + 2b^\top x + c = \bigl(x + A^{-1}b\bigr)^\top A\bigl(x + A^{-1}b\bigr) + c - b^\top A^{-1}b
$$

（用 $A$ 对称。）所以边界是以 $-A^{-1}b$ 为中心、$A$ 为形状矩阵的**二次曲面**（$p=2$ 时是圆锥曲线）。当 $\boldsymbol\Sigma_k = \boldsymbol\Sigma_\ell$ 时 $A = 0$，二次项消失，边界退化为直线——这正是 Figure 4.9 左panel 的情形。

**QDA 的参数量**（原书给的偏差–方差理由）。$p$ 个预测子时，估一个 $p\times p$ 协方差矩阵要估 $p(p+1)/2$ 个独立参数（对角线 $p$ 个 + 上三角 $p(p-1)/2$ 个）。QDA 每类一个矩阵：

$$
\text{QDA 参数量} = K\,\frac{p(p+1)}{2} + Kp + K \qquad (\text{均值 } Kp \text{ 个、先验 } K-1 \text{ 个})
$$

$p=50$ 时光是协方差就有 $50\times 51/2 = 1275$ 个，$K$ 类就是 $K$ 倍。LDA 假设共享矩阵后，判别函数线性、只有 $Kp$ 个线性系数要估（原书原话），**方差低得多**。

**结论**：$p$ 越大或 $n$ 越小，降方差越重要，选 LDA；训练集很大、或共享协方差假设明显不成立时，选 QDA。Figure 4.9：左panel 两类相关系数都是 0.7，Bayes 边界是**直线**，LDA 逼近得准、QDA 因「方差升高而偏差没降」而更差；右panel 橙色类相关系数 0.7、蓝色类 $-0.7$，Bayes 边界是**二次曲线**，QDA 更准。

**易错点**：

- $|\boldsymbol\Sigma_k|$ 是**各类自己的**行列式，QDA 里不能像 LDA 那样约掉——这正是 (4.28) 比 (4.24) 多出 $-\frac12\log|\boldsymbol\Sigma_k|$ 的原因。
- 原书写 $\log|\boldsymbol\Sigma_k|$，其量纲是 log（体积²），所以有系数 $-\tfrac12$。
- QDA 需要每类 $n_k \gtrsim p$ 才能稳定估 $\boldsymbol\Sigma_k$。$n_k < p$ 时 $\boldsymbol\Sigma_k$ 奇异，$\boldsymbol\Sigma_k^{-1}$ 不存在。
- 「二次」指的是 $\log$ 概率比里的 $x_jx_l$ 项，见 (4.33)。它**不是**说 $p_k(x)$ 本身是二次的。

### 无编号式：Figure 4.9 左图的坐标残片 {#eq-4-u5}

原书在 (4.28) 之后、Figure 4.9 之前排了一个**未编号公式框**，但切图显示的只是插图的下缘残片（$X_2$ 轴标签与散点、Bayes 虚线与 QDA 实线的一段、两侧的 $X_2$ 刻度文字）——它不是一条数学式子，而是 Figure 4.9 左panel 的重复裁切。这一框在页面上承担的是 QDA 公式与图的衔接，内容已在 (4.28) 的「二次判别边界」与「参数量」两段讲完。

$$
\Sigma_1 = \Sigma_2 \;\Longrightarrow\; \text{Bayes 判别边界是直线，且 LDA 逼近得比 QDA 准}
$$

**基础**：Figure 4.9 的读图约定——紫色虚线 = Bayes 边界，黑色点线 = LDA 边界，绿色实线 = QDA 边界，底色阴影 = QDA 判别规则。

**推导**（为什么 $\boldsymbol\Sigma_1=\boldsymbol\Sigma_2$ 时边界是直线）。回到上一节的边界方程：二次项的系数矩阵是 $A = \boldsymbol\Sigma_\ell^{-1}-\boldsymbol\Sigma_k^{-1}$。若两类共享 $\boldsymbol\Sigma$，则 $A = \boldsymbol\Sigma^{-1}-\boldsymbol\Sigma^{-1} = 0$，二次项整体消失，剩下 $2x^\top b + c = 0$，即一个超平面。这时 QDA 的**额外灵活性完全没有用武之地**，只贡献方差——这正是原书说「QDA suffers from higher variance without a corresponding decrease in bias」的原因。

**结论**：QDA 在 $\boldsymbol\Sigma_1=\boldsymbol\Sigma_2$ 时退化为 LDA（系数上 $c_{kjl}=0$，见 (4.33)），但参数估计多用了 $K\frac{p(p+1)}{2}$ 个，所以更差。

**易错点**：

- 「Bayes 边界线性」是**数据生成过程**的性质（正态 + 共享协方差），不是算法选对了的结果。LDA 之所以好是因为它**假设对了**。
- 判别边界与 $\hat p_k(x) = 0.5$ 的等高线**不是**同一条曲线，只有在 $K=2$ 时才重合（因为 $\arg\max$ 与「$p_1>p_2$」等价）。

### 无编号式：Figure 4.9 右图的坐标残片 {#eq-4-u6}

原书在 Figure 4.9 图注之后紧接着又有一个**未编号公式框**，切图同样只是插图残片（两侧的 $X_1$ 轴标签与空白）。它对应 Figure 4.9 右panel：橙色类相关系数 $0.7$、蓝色类相关系数 $-0.7$，即 $\boldsymbol\Sigma_1 \ne \boldsymbol\Sigma_2$。

$$
\Sigma_1 \neq \Sigma_2 \;\Longrightarrow\; \text{Bayes 判别边界是非线性（二次）的，QDA 逼近得比 LDA 准}
$$

**基础**：$\boldsymbol\Sigma_1$ 与 $\boldsymbol\Sigma_2$ 是两类各自的**总体协方差矩阵**
（$p\times p$，第 $(j,l)$ 元是第 $j$、$l$ 个变量的类内协方差）。QDA 允许
$\boldsymbol\Sigma_k$ 逐类不同，LDA 则假设它们都等于同一个 $\boldsymbol\Sigma$。
读 Figure 4.9 的约定与左panel 相同：紫色虚线 = Bayes 边界，黑色点线 = LDA 边界，
绿色实线 = QDA 边界；本panel 两类的相关系数符号相反（$+0.7$ 与 $-0.7$），
意思就是两个协方差矩阵的**非对角元不同**。

**推导**。此时 $A = \boldsymbol\Sigma_2^{-1}-\boldsymbol\Sigma_1^{-1} \ne 0$，$x^\top A x$ 无法消掉，Bayes 边界就是上面推出的二次曲面。LDA 因为强行把 $\boldsymbol\Sigma_2$ 换成 $\boldsymbol\Sigma_1$，$A$ 变成 0，只能用一条直线去近似一条曲线——这就是它的**偏差**来源。

**结论**：两个 panel 合起来就是「QDA 何时值得用」的完整答案：QDA 在**各类协方差矩阵确实不同**时才划算。原书用词很克制——QDA「has the potential to be more accurate」，不是一定更好。

**易错点**：

- 判别边界是二次的**不代表** $p_k(x)$ 是二次的。$p_k(x) = \pi_k|\boldsymbol\Sigma_k|^{-1/2}e^{-\frac12 Q_k(x)}/\sum_l(\cdots)$ 里指数的指数才是二次的。
- 两类相关系数符号相反（$+0.7$ 与 $-0.7$）时，两类的概率密度曲面一个「沿对角拉长」一个「沿反对角拉长」，它们的交线必然弯曲——这是 QDA 边界的直观来源。

## 4.4.4 朴素贝叶斯

@src 原书 p.167–169 · [4.4.4 Naive Bayes](../isl/05-classification.html#s-4-4-4-naive-bayes)

### (4.29) 类内独立的假设 {#eq-4-29}

$$
f_k(x) = f_{k1}(x_1) \times f_{k2}(x_2) \times \cdots \times f_{kp}(x_p), \tag{4.29}
$$

**基础**：原书把唯一的假设单独排成一行斜体：**「Within the $k$th class, the $p$ predictors are independent.」**（第 $k$ 类内，$p$ 个预测子是独立的。）$f_{kj}$ 是第 $k$ 类中第 $j$ 个预测子的密度函数。原文说 $k = 1,\ldots,K$。

**推导**（为什么这个假设「威力」这么大）。估计一个 $p$ 维密度需要两样东西：

1. 各个预测子的**边缘分布**（marginal distribution）——单独看每个变量；
2. 变量之间的**联合分布**（joint distribution）——变量间的关联结构。

在多元正态里，第 2 项由协方差矩阵的非对角元概括，所以 LDA 只需估 $K$ 个均值 + 1 个矩阵。但在一般分布里，关联结构可能非常难刻画，$p(p+1)/2$ 之外的信息（偏度、尾巴形状等）根本无法用一个矩阵概括。朴素贝叶斯**直接假设没有关联**：

$$
f_k(x) = \Pr(X = x \mid Y=k) = \prod_{j=1}^{p}\Pr(X_j = x_j \mid Y = k) = \prod_{j=1}^{p} f_{kj}(x_j)
$$

这样只要分别估 $K\times p$ 个**一维**密度就够了。

**结论**：「naive（朴素）」这个名字就来自这个假设——它显然是错的（大多数设定下预测子之间确实相关），但换来了巨大的方差下降。原书明确说：naive Bayes assumption introduces some bias, but reduces variance。这正是第 2 章式 (2.7) 偏差–方差权衡的又一次上演。

**结论（与 QDA 的关系）**：若再用 $X_j \mid Y=k \sim \mathcal N(\mu_{jk}, \sigma_{jk}^2)$ 来估每个 $f_{kj}$，那么 $f_k$ 是一个协方差矩阵为**对角**的多元正态——即「QDA 再加一条 $\boldsymbol\Sigma_k$ 是对角阵的假设」（原书原话）。

**易错点**：

- 独立是**类内**（conditional on $Y=k$）的假设，不是全局独立。全局独立会推出 $Y$ 与 $X$ 无关，分类就毫无意义了。
- 这里的 $f_{kj}$ 是**一维**密度（$x_j$ 的函数），不是 $p$ 维密度的第 $j$ 个分量。
- 独立 $\ne$ 不相关。反过来成立，正过来不成立。原书在 4.5.2 的 Scenario 2 里指出：相关系数为 $-0.5$ 的情形下朴素贝叶斯表现很差——因为「不相关」在正态下才蕴含独立。
- 估计 $f_{kj}$ 的三选一（原书列的三条）：定量变量用一维正态 / 定量变量用直方图或核密度估计 / 定性变量直接数比例。三种都可以，结果差别见 Table 4.8。

### (4.30) 朴素贝叶斯的后验概率 {#eq-4-30}

$$
\mathrm{Pr}(Y = k\mid X = x) = \frac{\pi_k \times f_{k1}(x_1) \times f_{k2}(x_2) \times \cdots \times f_{kp}(x_p)}{\sum_{l=1}^{K} \pi_l \times f_{l1}(x_1) \times f_{l2}(x_2) \times \cdots \times f_{lp}(x_p)} \tag{4.30}
$$

**基础**：把 (4.29) 代入 (4.15)。对 $k = 1,\ldots,K$。

**推导**（纯代入）。分子按 (4.15) 应为 $\pi_k f_k(x)$，用 (4.29) 把 $f_k(x)$ 展开成乘积；分母同理，对 $l$ 求和。

**为什么这个形式在计算上很友好**。取对数（分类只需要比较大小）：

$$
\log\frac{\mathrm{Pr}(Y=k\mid X=x)}{\mathrm{Pr}(Y=\ell\mid X=x)} = \log\frac{\pi_k}{\pi_\ell} + \sum_{j=1}^{p}\log\frac{f_{kj}(x_j)}{f_{\ell j}(x_j)}
$$

右端是 $p+1$ 个标量之和——完全**可加**、没有交互项。这就是式 (4.34) 与第 7 章广义可加模型（GAM）的接口。

**朴素贝叶斯 = 条件独立下的逻辑回归**（重要结论）。设每个 $f_{kj}$ 都用一维正态 $\mathcal N(\mu_{kj},\sigma_j^2)$（**各类共享** $\sigma_j^2$，这才是与 LDA 对齐的版本），则

$$
\log\frac{f_{kj}(x_j)}{f_{\ell j}(x_j)} = -\frac{(x_j-\mu_{kj})^2}{2\sigma_j^2} + \frac{(x_j-\mu_{\ell j})^2}{2\sigma_j^2} = \frac{2x_j(\mu_{kj}-\mu_{\ell j}) - \mu_{kj}^2+\mu_{\ell j}^2}{2\sigma_j^2} = \underbrace{\frac{\mu_{kj}-\mu_{\ell j}}{\sigma_j^2}}_{=:b_{kj}}x_j + \underbrace{\text{常数}}_{a_{kj}}
$$

是 $x_j$ 的**线性**函数。求和后 log odds 对 $x$ 线性，与 (4.32) 的 LDA 形式完全一致。这就是原书在 4.5.1 说的「naive Bayes 实际是 LDA 的特例，$\boldsymbol\Sigma$ 被限制为对角阵」。

**结论**：式 (4.30) 兼顾了 (4.15) 的概率形式与 (4.29) 的可分解性。Table 4.8（Default 数据，$p=2$，阈值 0.5）：朴素贝叶斯预测 135 人违约，89 人确实违约、46 人没违约；漏检 244/333 = 73%。与 LDA 的 Table 4.4 相比「结果喜忧参半」（原话：our findings are mixed）——LDA 总体错误率略低，但朴素贝叶斯正确识别了更多真实违约者。

**易错点**：

- 不要在取对数之前比较。$f_{kj}(x_j)$ 可能极小（尾部），连乘会**数值下溢**。标准做法是取 $\log$ 后比较。
- 分母不能省（与 (4.15) 相同的理由）；但**分类时**可以省，因为分母对所有 $k$ 相同。
- 「朴素贝叶斯」在不同文献里指不同的实现：$p$ 是类别数还是预测子个数容易混。本章的 $K$ 是类别数、$p$ 是预测子数（第 4.7 节用 KNN 时特意提醒「不要与类数混淆」）。
- 条件独立假设带来的偏差方向是**不一致**的：若 $X_1,X_2$ 在类内正相关，独立假设会**高估** $f_k$ 在两个都大的区域的值，从而偏向「两个预测子同时极端」的观测。

### 无编号式：定性预测子的经验密度（频率估计） {#eq-4-u7}

$$
\hat{f}_{kj}(x_j) = \begin{cases} 0.32 & \text{if } x_j = 1\\ 0.55 & \text{if } x_j = 2\\ 0.13 & \text{if } x_j = 3. \end{cases}
$$

**基础**：原书的例子——$X_j \in \{1,2,3\}$，第 $k$ 类有 100 个训练观测，其中 $X_j$ 取 1、2、3 的分别有 32、55、13 个。

**推导**（为什么就是频率）。定性变量的 $X_j \mid Y = k$ 服从一个离散分布，$f_{kj}(x_j) = \Pr(X_j = x_j \mid Y = k)$。用经验频率估计：

$$
\hat f_{kj}(x_j) = \frac{\#\{i : y_i = k,\ x_{ij} = x_j\}}{\#\{i : y_i = k\}} = \frac{\text{第 }k\text{ 类中 }X_j\text{ 取 }x_j\text{ 的个数}}{n_k}
$$

代入：$32/100 = 0.32$、$55/100 = 0.55$、$13/100 = 0.13$。

**验证是合法概率**：$0.32+0.55+0.13 = 1.00$。✓ 一般地对每个 $j$ 都有 $\sum_{v}\hat f_{kj}(v) = 1$。

**结论**：这是**非参数**估计（不需要假设分布族）。原书还提到定量变量的两个对应版本：直方图估计（$\hat f_{kj}(x_j)$ = 第 $k$ 类中与 $x_j$ 落在同一个箱里的观测比例）与**核密度估计**（kernel density estimator，直方图的光滑版本）。

**易错点**：

- 频率估计在某个水平上没有观测时会取 $\hat f_{kj}=0$，于是该水平的后验概率变成 0，**永远无法被分到这一类**。定量变量也有同样问题（直方图尾部）。实践中用**拉普拉斯平滑**：$\hat f_{kj}(x_j) = \dfrac{n_{kj}+1}{n_k+M}$，$M$ 是水平数。定性变量的朴素贝叶斯（categorical naive Bayes）默认就做这个平滑。原书正文没有展开平滑，但这是实现时必做的。
- 分母是 $n_k$（**该类**的样本数），不是 $n$。用 $n$ 会得到一个每类加起来只有 $1/K$ 的「密度」。
- 三个数之和为 1 是因为它们是**同一个** $k$、**同一个** $j$ 下所有水平的频率。不要把不同 $k$ 的频率放在一个分布里。

### 无编号式：Figure 4.10 上排的密度标签 {#eq-4-u8}

原书在 Figure 4.10 的上排（标题 *Density estimates for class $k=1$*）之后跟了一个**未编号公式框**，切图是插图残片，只有三个密度估计的标签 $\hat f_{11}$、$\hat f_{12}$、$\hat f_{13}$。它对应玩具例子中第 1 类、三个预测子的密度估计（Figure 4.10 上排）：前两个是直方图（定量），第三个是三根柱子（定性，三水平）。

**基础**：玩具例子的设定是 $p=3$ 个预测子、$K=2$ 个类别；前两个定量，第三个定性且有三个水平；$\hat\pi_1 = \hat\pi_2 = 0.5$。待分类的观测是 $x^{*} = (0.4,\,1.5,\,1)^T$。

**推导**（本条是图内标注，没有可推过程——说明这个约定）。切图里只有 $\hat f_{11}$、$\hat f_{12}$、$\hat f_{13}$ 三个密度标签，没有别的式子。原书把 $K\times p = 2\times 3 = 6$ 个一维密度排成上下两排：上排固定 $k = 1$、$j = 1,2,3$，下排固定 $k = 2$。所以约定这样读：

\hat f_{kj} \;=\; \text{第 } k \text{ 类中第 } j \text{ 个预测子的一维估计密度}\quad(\text{先类 } k\text{，后变量 } j)

$\hat f_{kj}$ 的定义沿用 (4.29)/(4.30)：$f_{kj}$ 是第 $k$ 类的 $f_k(x)$ 在第 $j$ 个坐标上的边缘密度，帽号表示它是估计量。三条标签对应 Figure 4.10 上排的三个 panel：$X_1$、$X_2$ 用直方图（定量），$X_3$ 用三根柱子（定性，水平 $1,2,3$）。

**结论**：上排给出 $k=1$ 的三个一维密度。原书说这些正是朴素贝叶斯公式 (4.30) 需要的全部输入：$K\times p = 2\times 3 = 6$ 个密度，外加 2 个先验。

**易错点**：

- 帽号 $\hat f$ 表示估计量；Figure 4.10 里画的是**直方图/柱状图**（非参数估计），不是正态曲线（参数估计）。原书在 Table 4.8 的注释里说「在这个朴素贝叶斯实现里，我们假设每个定量预测子服从高斯分布」——那是 Default 数据的另一组实验，与这个玩具例子用的估计方式不同。
- 朴素贝叶斯一共只需估 $K + Kp$ 个标量或一维密度；对比 LDA 的 $K$ 个均值 + 1 个矩阵。这才是它在 $p$ 大、$n$ 小时受欢迎的原因。

### 无编号式：Figure 4.10 下排的密度标签 {#eq-4-u9}

### 无编号式：$x^{*}$ 属于第 2 类的后验概率 {#eq-4-u10}

$$
\mathrm{Pr}(Y = 2\mid X = x^{*}) = 0.056.
$$

**基础**：原文里这句的上半部分是 $\mathrm{Pr}(Y = 1\mid X = x^{*}) = 0.944$（切图正好截到这一行的上缘），两式合起来是完整的分解。

**推导**（用 (4.30) 代入 Figure 4.10 的六个密度值）。原书给出的值是 $\hat f_{11}(0.4)=0.368$、$\hat f_{12}(1.5)=0.484$、$\hat f_{13}(1)=0.226$，$\hat f_{21}(0.4)=0.030$、$\hat f_{22}(1.5)=0.130$、$\hat f_{23}(1)=0.616$，且 $\hat\pi_1=\hat\pi_2=0.5$。

1. **分子（第 1 类）**：
$$
0.5\times0.368\times0.484\times0.226 = 0.5\times0.368 = 0.184;\quad 0.184\times0.484 = 0.08906;\quad 0.08906\times0.226 = 0.020127
$$
2. **分母里第 2 类那一项**：
$$
0.5\times0.030\times0.130\times0.616 = 0.015\times0.130 = 0.00195;\quad 0.00195\times0.616 = 0.0012012
$$
3. **归一化**：
$$
\mathrm{Pr}(Y=1\mid X=x^{*}) = \frac{0.020127}{0.020127+0.0012012} = \frac{0.020127}{0.0213282} \approx 0.9437 \approx 0.944
$$
$$
\mathrm{Pr}(Y=2\mid X = x^{*}) = \frac{0.0012012}{0.0213282} \approx 0.0563 \approx 0.056
$$

**验证归一化**：$0.944 + 0.056 = 1.000$。✓

**结论**：$x^{*} = (0.4, 1.5, 1)^T$ 有 94.4% 的后验概率属于第 1 类（原书 Figure 4.10 的图注也是这个数）。

**易错点**：

- 三个密度必须**全部相乘**——这正是「朴素」假设在做的事。若 $X_1,X_2$ 在类内相关，正确做法是乘联合密度，而不是把边缘密度相乘。
- $\hat\pi_1 = \hat\pi_2 = 0.5$ 时先验在比值里约掉，所以即使先验不等，上述计算只需在分子分母各乘一个 $\hat\pi$。
- 这里得到的 0.056 是**后验概率**，不是 $\hat f_{23}(1) = 0.616$（后者是单个预测子的边缘密度）。两者数量级差 10 倍，正是「三个密度相乘再归一化」造成的。

## 4.5 分类方法的解析比较

@src 原书 p.170–172 · [4.5.1 An Analytical Comparison](../isl/05-classification.html#s-4-5-1-an-analytical-comparison)

### (4.31) 以基准类为参照的 log 后验比 {#eq-4-31}

$$
\log\left(\frac{\mathrm{Pr}(Y = k\mid X = x)}{\mathrm{Pr}(Y = K\mid X = x)}\right) \tag{4.31}
$$

**基础**：$K$ 个类，做**分析式**（analytical）比较。设第 $K$ 类为基准，对 $k = 1,\ldots,K$ 计算上式，取最大的类为预测（与式 (2.10) 的 Bayes 分类器等价）。

**推导**（为什么可以只看两两之比）。目标是比较 $\mathrm{Pr}(Y = 1),\ldots,\mathrm{Pr}(Y=K)$ 的大小。取 $K$ 为参照，对每个 $k$ 计算比值 $\frac{\Pr_k}{\Pr_K}$：

1. 若上式的最大值 $>1$，则第 $k$ 类的概率大于基准类，取它。
2. 若所有 $k<K$ 的比值都 $<1$，则基准类最大。
3. 更一般地，$\frac{\Pr_k}{\Pr_K} > \frac{\Pr_\ell}{\Pr_K} \iff \Pr_k > \Pr_\ell$，所以「比值的排序」与「概率的排序」一致。
4. 再取 $\log$：$\log$ 严格单调，排序不变。

所以式 (4.31) 与「比较后验概率」是等价的。

**结论**：式 (4.31) 是**统一比较四种方法的框架**。原书的做法是：分别假设 LDA / QDA / 朴素贝叶斯的 $f_k$，把式 (4.31) 化简成 $x$ 的具体函数，看它是几次式。

**易错点**：

- 式 (4.31) 本身只是一个待计算的目标，没有任何模型假设。**必须**先用 (4.15) 把 $\mathrm{Pr}(Y=k\mid X=x)$ 换成 $\pi_kf_k(x)$ 形式才能继续。
- 换基准类会改变式子的具体值，但不改变「取最大值」的分类结果（$K$ 个比值同时除以同一个数或取负号）。
- 上式 $k$ 的范围在原书 (4.31) 里写的是 $k = 1,\ldots,K$（含 $K$，此时比值为 1，即 $\log 1 = 0$）。

### (4.32) LDA 情形：log odds 线性 {#eq-4-32}

$$
\begin{aligned}
\log\left(\frac{\mathrm{Pr}(Y = k\mid X = x)}{\mathrm{Pr}(Y = K\mid X = x)}\right) &= \log\left(\frac{\pi_k f_k(x)}{\pi_K f_K(x)}\right)\\[4pt]
&= \log\left(\frac{\pi_k \exp\left(-\frac{1}{2}(x-\mu_k)^T\boldsymbol{\Sigma}^{-1}(x-\mu_k)\right)}{\pi_K \exp\left(-\frac{1}{2}(x-\mu_K)^T\boldsymbol{\Sigma}^{-1}(x-\mu_K)\right)}\right)\\[4pt]
&= \log\left(\frac{\pi_k}{\pi_K}\right) - \frac{1}{2}(x-\mu_k)^T\boldsymbol{\Sigma}^{-1}(x-\mu_k) + \frac{1}{2}(x-\mu_K)^T\boldsymbol{\Sigma}^{-1}(x-\mu_K)\\[4pt]
&= \log\left(\frac{\pi_k}{\pi_K}\right) - \frac{1}{2}(\mu_k+\mu_K)^T\boldsymbol{\Sigma}^{-1}(\mu_k-\mu_K) + x^T\boldsymbol{\Sigma}^{-1}(\mu_k-\mu_K)\\[4pt]
&= a_k + \sum_{j=1}^{p} b_{kj}x_j,
\end{aligned}\tag{4.32}
$$

**基础**：原书在式后给出 $a_k$ 与 $b_{kj}$ 的定义：

$$
a_k = \log\left(\frac{\pi_k}{\pi_K}\right) - \frac{1}{2}(\mu_k+\mu_K)^T\boldsymbol{\Sigma}^{-1}(\mu_k-\mu_K), \qquad b_{kj} = \Big[\boldsymbol{\Sigma}^{-1}(\mu_k-\mu_K)\Big]_j
$$

**推导（第 1→2 行）**。用 Bayes 定理 (4.15)：$\mathrm{Pr}(Y=k\mid X=x) = \pi_kf_k(x)/\sum_l\pi_lf_l(x)$，分母相除时消掉。再用 LDA 的高斯假设 (4.23)（**类特异均值 $\mu_k$，共享协方差 $\boldsymbol\Sigma$**）代入 $f_k$。注意 $(2\pi)^{p/2}|\boldsymbol\Sigma|^{1/2}$ 在分子分母里约掉了。

**推导（第 2→3 行）**。对分式取对数，用 $\log\frac{a}{b} = \log a - \log b$、$\log e^u = u$、$\log(ab)=\log a+\log b$。$\frac12$ 前后的负号因此变成「减第 $k$ 项、加第 $K$ 项」。

**推导（第 3→4 行，本行的关键代数）**。记 $A := \boldsymbol\Sigma^{-1}$（对称）。要证明

$$
-(x-\mu_k)^\top A(x-\mu_k) + (x-\mu_K)^\top A(x-\mu_K) = -(\mu_k+\mu_K)^\top A(\mu_k-\mu_K) + 2x^\top A(\mu_k-\mu_K)
$$

按 $x$ 的次数分组（用 $\boldsymbol\Sigma^{-1}$ 的对称性 $x^\top A\mu = \mu^\top A x$）：

1. **二次项**：$-x^\top Ax + x^\top Ax = 0$。**相消**（这与 (4.24) 是同一个机制）。
2. **一次项**：$-\big(-x^\top A\mu_k - \mu_k^\top Ax\big) + \big(-x^\top A\mu_K - \mu_K^\top Ax\big) = 2x^\top A\mu_k - 2x^\top A\mu_K = 2x^\top A(\mu_k-\mu_K)$。
3. **常数项**：$-\mu_k^\top A\mu_k + \mu_K^\top A\mu_K$。用恒等式 $a^\top Aa - b^\top Ab = (a+b)^\top A(a-b)$（把右边展开：$(a+b)^\top A(a-b) = a^\top Aa - a^\top Ab + b^\top Aa - b^\top Ab = a^\top Aa - b^\top Ab$，用 $a^\top Ab = b^\top Aa$），取 $a = \mu_k$、$b = \mu_K$：
$$
\mu_k^\top A\mu_k - \mu_K^\top A\mu_K = (\mu_k+\mu_K)^\top A(\mu_k-\mu_K)
$$
所以常数项等于 $-(\mu_k+\mu_K)^\top\boldsymbol\Sigma^{-1}(\mu_k-\mu_K)$。

**推导（第 4→5 行）**。$x^\top\boldsymbol\Sigma^{-1}(\mu_k-\mu_K)$ 是 $x$ 与常向量 $\boldsymbol\Sigma^{-1}(\mu_k-\mu_K)$ 的内积，即 $\sum_{j=1}^{p}\big[\boldsymbol\Sigma^{-1}(\mu_k-\mu_K)\big]_j x_j$。定义 $b_{kj}$ 为该向量的第 $j$ 个分量，得式 (4.32)。

**结论**：log odds 是 $x$ 的**一次**函数。原书原话：Hence LDA, like logistic regression, assumes that the log odds of the posterior probabilities is **linear in $x$**。

**与 (4.24) 的关系**。式 (4.32) 就是在 (4.24) 的 $\delta_k$ 基础上**减去 $\delta_K$**（并把 log odds 的常数整理成 $a_k$）。所以两个判别函数的差就是式 (4.32) 的右端。

**易错点**：

- 二次项相消**依赖共享 $\boldsymbol\Sigma$**。$K$ 个类若各有 $\boldsymbol\Sigma_k$，第 1 步就不成立——这正是 (4.33) 多出 $c_{kjl}x_jx_l$ 的原因。
- $\log\frac{\pi_k}{\pi_K}$ 的负号要小心：原书 (4.18)/(4.22) 写 $\log\pi_k$，(4.32) 写 $\log\frac{\pi_k}{\pi_K}$。两者只差一个与 $k$ 无关的常数。
- 常数项的「$\frac12$」很容易被合并进 $a_k$ 而忘掉。$a_k$ 不只是先验的对数比。
- $b_{kj}$ 是 $\boldsymbol\Sigma^{-1}(\mu_k-\mu_K)$ 的第 $j$ 个**分量**，不是 $\Sigma^{-1}_{jk}$。

### (4.33) QDA 情形：log odds 二次 {#eq-4-33}

$$
\log\left(\frac{\mathrm{Pr}(Y = k\mid X = x)}{\mathrm{Pr}(Y = K\mid X = x)}\right) = a_k + \sum_{j=1}^{p} b_{kj}x_j + \sum_{j=1}^{p}\sum_{l=1}^{p} c_{kjl}x_j x_l, \tag{4.33}
$$

**基础**：原书说 $a_k, b_{kj}, c_{kjl}$ 是 $\pi_k, \pi_K, \mu_k, \mu_K, \boldsymbol\Sigma_k, \boldsymbol\Sigma_K$ 的函数（具体表达式留给习题 4.2）。**注意 $c$ 的下标是 $kjl$**（原书题面把它写成 $b_{kjl}$，是笔误，正文用 $c_{kjl}$）。

**推导**。与 (4.32) 同法，只是现在 $\boldsymbol\Sigma_k$ 依赖 $k$。第 3→4 行那次「二次项相消」不再成立：

1. **二次项**：$-x^\top\boldsymbol\Sigma_k^{-1}x + x^\top\boldsymbol\Sigma_K^{-1}x = x^\top(\boldsymbol\Sigma_K^{-1}-\boldsymbol\Sigma_k^{-1})x$。这个矩阵**依赖 $k$**，减不掉。展开成标量：
$$
x^\top A x = \sum_{j=1}^{p}\sum_{l=1}^{p} A_{jl}x_jx_l = \sum_j A_{jj}x_j^2 + 2\sum_{j<l}A_{jl}x_jx_l
$$
所以它提供了全部 $c_{kjl}x_jx_l$，其中含**平方项**（$j=l$）与**交互项**（$j\ne l$）。
2. **一次项**（照 (4.32) 的算法）：$x^\top(\boldsymbol\Sigma_k^{-1}\mu_k - \boldsymbol\Sigma_K^{-1}\mu_K)$，即 $\sum_j b_{kj}x_j$。
3. **常数项**（含行列式）：$-\frac12\mu_k^\top\boldsymbol\Sigma_k^{-1}\mu_k + \frac12\mu_K^\top\boldsymbol\Sigma_K^{-1}\mu_K - \frac12\log|\boldsymbol\Sigma_k| + \frac12\log|\boldsymbol\Sigma_K|$，全部并入 $a_k$。

**结论**：log odds 对 $x$ 是**二次**的——名字里的「quadratic」正来自此。原书由此得出关系图（4.5.1 的四条观察）：

- **LDA 是 QDA 的特例**（$c_{kjl} = 0$）。这与「LDA 是 $\boldsymbol\Sigma_1=\cdots=\boldsymbol\Sigma_K$ 的 QDA」完全一致。
- **任何线性边界的分类器都是朴素贝叶斯的特例**（$g_{kj}(x_j) = b_{kj}x_j$）。特别地，**LDA 是朴素贝叶斯的特例**。
- 若 $f_{kj}$ 用 $\mathcal N(\mu_{kj},\sigma_j^2)$ 建模，得 $g_{kj}(x_j) = b_{kj}x_j$、$b_{kj} = (\mu_{kj}-\mu_{Kj})/\sigma_j^2$，此时朴素贝叶斯是「$\boldsymbol\Sigma$ 限制为对角阵（对角元为 $\sigma_j^2$）的 LDA」。
- **QDA 与朴素贝叶斯互不包含**。朴素贝叶斯更灵活（$g_{kj}$ 可任意选），但**只加不乘**（纯可加）；QDA 含 $c_{kjl}x_jx_l$ 这种**乘性**项，所以当预测子间的交互对分类重要时 QDA 有优势。

**易错点**：

- $c_{kjl}x_jx_l$ 里 $j=l$ 的项是 $x_j^2$（非线性），$j\ne l$ 的是**交互项**。只有后者能表达「两个变量联合起来才有信息」。
- 朴素贝叶斯的「可加」限制来自 $f_k(x) = \prod_jf_{kj}(x_j)$：log 之后乘积变求和，所以只能加。
- QDA 参数量 $K\frac{p(p+1)}{2}$ 远大于朴素贝叶斯的 $K(p+2)$，所以它方差更高。
- 交互项 $c_{kjl}x_jx_l$ 中的常数 $c_{kjl}$ 依赖 $k$；不同类的 $c$ 不同，这一点与 $b_{kj}$ 类似。

### (4.34) 朴素贝叶斯情形：log odds 可加 {#eq-4-34}

$$
\begin{aligned}
\log\left(\frac{\mathrm{Pr}(Y = k\mid X = x)}{\mathrm{Pr}(Y = K\mid X = x)}\right) &= \log\left(\frac{\pi_k f_k(x)}{\pi_K f_K(x)}\right)\\[4pt]
&= \log\left(\frac{\pi_k \prod_{j=1}^{p} f_{kj}(x_j)}{\pi_K \prod_{j=1}^{p} f_{Kj}(x_j)}\right)\\[4pt]
&= \log\left(\frac{\pi_k}{\pi_K}\right) + \sum_{j=1}^{p}\log\left(\frac{f_{kj}(x_j)}{f_{Kj}(x_j)}\right)\\[4pt]
&= a_k + \sum_{j=1}^{p} g_{kj}(x_j),
\end{aligned}\tag{4.34}
$$

**基础**：原书给出 $a_k = \log\frac{\pi_k}{\pi_K}$、$g_{kj}(x_j) = \log\frac{f_{kj}(x_j)}{f_{Kj}(x_j)}$。

**推导**。用 (4.29) 把 $f_k(x) = \prod_jf_{kj}(x_j)$ 代入 (4.31) 的 Bayes 形式；再对分式取对数，第 2→3 行用两条对数法则：

1. $\log\frac{a_1a_2\cdots a_p}{b_1b_2\cdots b_p} = \sum_j\log\frac{a_j}{b_j}$（逐项拆开 $\frac{a_1a_2}{b_1b_2} = \frac{a_1}{b_1}\cdot\frac{a_2}{b_2}$，再对乘积取对数）。
2. $\log\frac{\pi_k}{\pi_K}$ 单独拆出，定义为 $a_k$；剩余项定义成 $g_{kj}(x_j)$。

**结论**：式 (4.34) 的右端是**广义可加模型**（generalized additive model, GAM）的形式——原书明确指出这一点并指向第 7 章。$g_{kj}$ 可以是**任意**一元函数（正态的 log odds 是线性的，但直方图/核密度估计得到的 $g$ 可以是任意形状）。

**与逻辑回归的关系**。原书接着写：多项逻辑回归的形式是 $a_k + \sum_j\beta_{kj}x_j$，与 LDA 的线性形式 (4.32) **完全一样**。区别只在系数的来源：LDA 的系数是 $\hat\pi_k,\hat\pi_K,\hat\mu_k,\hat\mu_K,\hat{\boldsymbol\Sigma}$ 的函数（这些估计来自「类内正态」的假设），逻辑回归的系数是**直接最大化似然 (4.5)** 得到的。所以「正态假设近似成立时 LDA 会更好；不成立时逻辑回归更好」。

**易错点**：

- 朴素贝叶斯可以给出比 LDA 更灵活的拟合（$g_{kj}$ 任选），但**永远给不出交互项**。这是它与 QDA 的分水岭。
- 换用不同的 $f_{kj}$ 估计方式（正态 / 直方图 / 核密度 / 频率）会给出**不同**的 $g_{kj}$，从而不同的边界。原书 Table 4.8/4.9 的结果依赖所用的估计方式。
- 严格说 $\log\frac{\pi_k}{\pi_K}$ 应该写成 $\log\pi_k - \log\pi_K$；$a_k$ 不含数据项。

### 无编号式：多项逻辑回归的 log odds（对照式） {#eq-4-u11}

$$
\log\left(\frac{\mathrm{Pr}(Y = k\mid X = x)}{\mathrm{Pr}(Y = K\mid X = x)}\right) = \beta_{k0} + \sum_{j=1}^{p} \beta_{kj}x_j.
$$

**基础**：原书在这里回顾式 (4.12)，用它把逻辑回归塞进 (4.32)–(4.34) 的统一框架。

**推导**。与 (4.12) 完全相同：把 (4.10) 除以 (4.11)，分母 $1+S$ 精确相消，得 $\frac{\mathrm{Pr}_k}{\mathrm{Pr}_K} = e^{\eta_k}$，取对数得 $\eta_k = \sum_{j=0}^{p}\beta_{kj}x_j$（约定 $x_0\equiv1$，常数项写成 $\beta_{k0}$）。

**与 (4.32) 的对照**。两式形式完全一致，所以 $a_k$ 对应 $\beta_{k0}$、$b_{kj}$ 对应 $\beta_{kj}$。原书原话：This is identical to the linear form of LDA (4.32)。

**两者的本质差异**（原书给出的实践指南）：

| 方法 | 系数怎么来 | 何时更好 |
| --- | --- | --- |
| LDA | 由 $\hat\pi_k,\hat\pi_K,\hat\mu_k,\hat\mu_K,\hat{\boldsymbol\Sigma}$ 推出，依赖「类内正态 + 共享协方差」 | 正态假设（近似）成立时 |
| 逻辑回归 | 直接最大化似然 (4.5)，只要求 $\log$ odds 线性 | 正态假设不成立时 |

在二分类里，$K=2$、基准类取类 2，则

$$
\frac{p(x)}{1-p(x)} = e^{\beta_0 + \sum_j\beta_jx_j}
$$

这就是式 (4.3)/(4.4) 的多元版。**对比 LDA**：由 (4.32) 取 $k=1,K=2$，

$$
\log\frac{\mathrm{Pr}(Y=1\mid X=x)}{\mathrm{Pr}(Y=2\mid X=x)} = a_1 + \sum_j b_{1j}x_j
$$

两边同取指数：$\dfrac{\mathrm{Pr}_1}{\mathrm{Pr}_2} = e^{a_1}\prod_j e^{b_{1j}x_j}$。所以「LDA 与逻辑回归在二分类下系数不同」的根源是：LDA 的系数里含 $\boldsymbol\Sigma^{-1}$（对变量的**尺度**敏感）以及 $\mu_k^2$ 那一项（对变量的**原点**敏感），逻辑回归的系数只依赖 $x$ 的尺度而不依赖原点平移。

**结论**：这条对照式是第 4 章 4.5 节的收口：它把逻辑回归的 log 后验比写成
「一个常数 + 预测子的线性组合」，从而与 (4.32) 的 LDA、（4.33）的 QDA、（4.34）的
朴素贝叶斯并排成一行。原书用它做的是**形式上的归类**——四个方法的 log odds 对 $x$
分别是二次、二次、可加、线性，差别只在次数与可加性，而不在「是否用比值比较」。
再取指数就回到式 (4.3)/(4.4)：$\dfrac{p(x)}{1-p(x)} = e^{\beta_0+\sum_j\beta_jx_j}$，
即逻辑回归的模型假设本身就是「log odds 线性」，不需要任何分布假设。
所以原书随后才说：正态假设成立时 LDA 更高效，不成立时逻辑回归更稳健。

**易错点**：

- 「形式相同」不等于「系数相同」。原书强调的是 log odds 的**函数形式**相同，系数来源不同。
- 原书说「in both cases, $\log\frac{\Pr(Y=k\mid X=x)}{\Pr(Y=K\mid X=x)}$ is a linear function of the predictors」——比较的永远是**比值**，不是单个概率。
- 不要以为逻辑回归的形式简单就一定更好。原书 4.5.2 的 Scenario 1–3 显示：边界真为线性时 LDA 与逻辑回归都不错；若数据非正态（Scenario 3 用 $t$ 分布），逻辑回归明显胜出。
- 6.2 节还提到一个折中办法：给 LDA 加上所有二次项与交叉乘积，模型形式就与 QDA 相同（但参数估计方式不同），从而在 LDA 与 QDA 之间连续移动。

### 无编号式：对响应取对数后的线性模型 {#eq-4-u12}

$$
\log(Y) = \sum_{j=1}^{p} X_j\beta_j + \epsilon.
$$

**基础**：Bikeshare 数据的响应 `bikers` 是**计数**（非负整数），既非定性也非定量。4.6.1 用线性回归直接拟合有两个问题：9.6% 的拟合值为**负**；方差随均值增大（异方差）——凌晨 2 点大雨的十二月平均 5.05 人、标准差 3.73，而上午 7–10 点晴天的四至六月平均 243.59 人、标准差 131.7。

**推导**（为什么「直接线性」不行、为什么「先取对数」也不够好）。**问题 1（负预测）**：$Y = \beta_0 + \sum_jX_j\beta_j + \epsilon$ 是一条无界的直线，$X$ 落在某个区域时 $X^\top\beta$ 可以为负。**问题 2（异方差）**：线性模型假设 $\Var(\epsilon) = \sigma^2$ 是**常数**，但数据里均值大的时候方差也大（Figure 4.14 左panel）。

取对数 $\log Y$ 修好了这两点：$\log Y$ 在 $Y>0$ 时单调且无界，负预测被排除；$\log$ 变换压缩了尺度，异方差大幅缓解（Figure 4.14 右panel）。

**但还有两个问题（原书明确列出）**：

1. **预测与推断都是针对 $\log Y$ 的**，解释很别扭：「$X_j$ 增加 1 个单位，$\log Y$ 的均值增加 $\beta_j$」。
2. **$Y=0$ 时无法取对数**。而计数数据里 0 非常常见（Bikeshare 数据里凌晨时段就有大量 0）。

**结论**：式 (4.u12) 揭示了**把响应做变换再线性回归**这条折中路的两个硬伤，从而引出 Poisson 回归。原书原话：it often leaves something to be desired。

**易错点**：

- 原书这一式**没有截距项**（写作 $\sum_{j=1}^p X_j\beta_j$），与前文的 $Y = \beta_0 + \sum_jX_j\beta_j + \epsilon$ 略不同；对照第 3 章时注意这个差别。
- $\log Y$ 的「线性」是均值层面的：模型是「$\log Y$ 的条件均值是 $X$ 的线性函数」，并不是「$\log Y = $ 线性函数 + 独立同分布的 $\epsilon$」严格成立（除非误差正态）。
- 取对数改变的是**响应的尺度**，不改变预测子。所以它能修值域与异方差，但修不了「响应本身是离散计数」这一点。

### (4.35) Poisson 分布 {#eq-4-35}

$$
\mathrm{Pr}(Y = k) = \frac{e^{-\lambda}\lambda^{k}}{k!} \qquad \text{for } k = 0,1,2,\ldots \tag{4.35}
$$

**基础**：$Y \in \{0,1,2,\ldots\}$ 取非负整数值，$\lambda > 0$ 是唯一参数，$k! = k\times(k-1)\times\cdots\times 3\times2\times1$（原书特别说明 $0! = 1$ 按约定）。

**推导 (1) 归一化**（概率之和必须是 1）。用 $e^\lambda = \sum_{k\ge0}\frac{\lambda^k}{k!}$（指数函数的泰勒级数）：

$$
\sum_{k=0}^{\infty}\mathrm{Pr}(Y=k) = e^{-\lambda}\sum_{k=0}^{\infty}\frac{\lambda^k}{k!} = e^{-\lambda}\,e^{\lambda} = 1
$$

**推导 (2) 均值**。用幂级数求导技巧 $\sum_{k\ge0}k\lambda^k = \lambda\sum_{k\ge0}k\lambda^{k-1} = \lambda\cdot\lambda e^{\lambda} = \lambda^2e^{\lambda}$：

$$
\E[Y] = \sum_{k\ge0} k\,\frac{e^{-\lambda}\lambda^k}{k!} = e^{-\lambda}\sum_{k\ge1}\frac{k\lambda^k}{k!} = e^{-\lambda}\sum_{k\ge1}\frac{\lambda^k}{(k-1)!} = e^{-\lambda}\lambda\sum_{m\ge0}\frac{\lambda^m}{m!} = e^{-\lambda}\lambda e^{\lambda} = \lambda
$$

（第三步用 $k/k! = 1/(k-1)!$，第四步换元 $m = k-1$。）

**推导 (3) 方差 = 均值**。先算二阶矩：

$$
\E[Y^2] = \sum_{k\ge0}k^2\frac{e^{-\lambda}\lambda^k}{k!} = e^{-\lambda}\sum_{k\ge1}k\frac{\lambda^k}{(k-1)!}
$$

用 $k = (k-1)+1$ 拆开：$k^2 = k(k-1)+k$，而 $k(k-1)/k! = 1/(k-2)!$，所以

$$
\E[Y^2] = e^{-\lambda}\left[\sum_{k\ge2}\frac{\lambda^k}{(k-2)!} + \sum_{k\ge1}\frac{\lambda^k}{(k-1)!}\right] = e^{-\lambda}\left[\lambda^2e^{\lambda} + \lambda e^{\lambda}\right] = \lambda^2 + \lambda
$$

于是

$$
\Var(Y) = \E[Y^2] - \bigl(\E[Y]\bigr)^2 = (\lambda^2+\lambda) - \lambda^2 = \lambda = \E[Y]
$$

**结论**：原书明确写出 $\lambda = \E(Y) = \Var(Y)$。这个「均值–方差关系」是 Poisson 分布的签名，也是它对计数数据如此自然的原因：**均值大的地方方差自动也大**，正好对上 Bikeshare 数据的异方差形态。

**具体数值**（原书例子，$\lambda = 5$）：

$$
\mathrm{Pr}(Y=0) = \frac{e^{-5}5^0}{0!} = e^{-5} = 0.0067, \qquad
\mathrm{Pr}(Y=1) = \frac{e^{-5}5^1}{1!} = 5e^{-5} = 0.034, \qquad
\mathrm{Pr}(Y=2) = \frac{e^{-5}5^2}{2!} = \frac{25e^{-5}}{2} = 0.084
$$

**易错点**：

- **方差等于均值**是 Poisson 的性质，不是所有分布都这样。若实际数据的方差**远大于**均值（$\Var \gg \E$），这叫**过度离散**（overdispersion）——原书脚注 5 指出 Bikeshare 数据正是这种情况，会使表 4.11 的 z 值被**高估**（过于显著），需要更仔细的分析（如负二项回归）。这是 Poisson 回归最常见的诊断。
- $k!$ 是阶乘，$0! = 1$ 是**约定**。分母不能省。
- $\mathrm{Pr}(Y=k)$ 的峰值在 $k \approx \lfloor\lambda\rfloor$ 附近，分布右偏。$\lambda=5$ 时 $\Pr(Y=0)$ 只有 0.67%，所以「整点无人」虽然可能但不罕见。
- Poisson 假设 $Y$ 是**计数**：非负整数。它不能给负数，所以 Poisson 回归「不可能有负预测」。

### (4.36) Poisson 回归：对数均值线性 {#eq-4-36}

$$
\log\left(\lambda(X_1,\ldots,X_p)\right) = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p \tag{4.36}
$$

**基础**：原书把均值写成 $\lambda(X_1,\ldots,X_p)$ 以强调它是协变量的函数，$\lambda = \E(Y)$。

**推导**（为什么对 $\lambda$ 取对数）。要求 $\lambda(X) \ge 0$ 对一切 $X$ 成立，有两个办法：

1. 硬约束 $\lambda = \max\{0, \beta_0+\sum_j\beta_jX_j\}$——不可导、优化困难。
2. **软约束**：取 $\log\lambda = \beta_0+\sum_j\beta_jX_j$，两边指数化得 $\lambda = e^{\beta_0+\sum_j\beta_jX_j} > 0$ **恒成立**（指数函数值域 $(0,+\infty)$）。

原书明确说：we take the log of $\lambda(X_1,\ldots,X_p)$ to be linear in $X_1,\ldots,X_p$, rather than having $\lambda$ itself be linear; this ensures that $\lambda$ takes on nonnegative values for all values of the covariates。

**对比 (4.2)（logistic）**。两个模型的思路完全平行：

| | logistic 回归 | Poisson 回归 |
| --- | --- | --- |
| 值域约束 | $0 < p < 1$ | $\lambda > 0$ |
| 「线性」的那一层 | $\log\frac{p}{1-p}$（logit） | $\log\lambda$（log） |
| link function | $\eta(\mu) = \log\frac{\mu}{1-\mu}$ | $\eta(\mu) = \log\mu$ |

**结论**：这正是**对数链接**（log link）。它的代价是 $\beta_j$ 的解释方式变了：$X_j$ 增加 1，$\E(Y) = \lambda$ **乘以** $e^{\beta_j}$，而不是「加 $\beta_j$」。

**易错点**：

- 系数是在 **log 尺度**上线性，不是在 $\lambda$ 上线性。用 $\lambda = \beta_0+\sum_j\beta_jX_j$（identity link）会给出负的 $\lambda$，而 $\lambda = \E(Y) \ge 0$。
- Poisson 回归是**乘性**模型：预测均值随 $X$ 指数增长。$X$ 很大时 $\lambda$ 会爆炸，模型没有上界。
- 截距 $\beta_0$ 的解释是「所有 $X_j=0$ 时 $\lambda = e^{\beta_0}$」。Bikeshare 里 $\hat\beta_0 = 4.12$，即基准情形（$X=0$）下每小时约 $e^{4.12}\approx 61$ 人。若 $X_j$ 是 0/1 虚拟变量，截距对应**基线水平**。

### (4.37) Poisson 回归：均值形式 {#eq-4-37}

$$
\lambda(X_1,\ldots,X_p) = e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}. \tag{4.37}
$$

**基础**：原书说「or equivalently」，它与 (4.36) 是**同一个**模型。

**推导**（指数与对数互逆）。对 (4.36) 两边取指数，用 $e^{\log a} = a$（$a>0$）：

$$
e^{\log\lambda(X_1,\ldots,X_p)} = e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p} \;\Longrightarrow\; \lambda(X_1,\ldots,X_p) = e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}
$$

**系数的解释**（原书的核心段落）。设 $X_j$ 增加 1 个单位（其他不变），记 $\lambda_1$ 为变化后的均值、$\lambda_0$ 为变化前：

$$
\frac{\lambda_1}{\lambda_0} = \frac{e^{\beta_0 + \beta_1X_1 + \cdots + \beta_j(X_j+1) + \cdots + \beta_pX_p}}{e^{\beta_0 + \beta_1X_1 + \cdots + \beta_jX_j + \cdots + \beta_pX_p}} = \frac{e^{\beta_j}\,e^{\beta_0+\beta_1X_1+\cdots+\beta_jX_j+\cdots+\beta_pX_p}}{e^{\beta_0+\beta_1X_1+\cdots+\beta_jX_j+\cdots+\beta_pX_p}} = e^{\beta_j}
$$

所以 $\beta_j = \log\frac{\lambda_1}{\lambda_0}$，即**均值变化的倍数**的对数。

**原书的具体解读**（Table 4.11）：

- 天气从晴到多云：$\hat\beta = -0.08$，$\lambda$ 乘以 $e^{-0.08} = 0.923$——平均只有晴天的 92.3%。
- 再恶化到雨雪：系数 $-0.58$（相对多云），$\lambda$ 进一步乘以 $e^{-0.58} = 0.560$（原书正文用 $e^{-0.5}=0.607$ 举例说明原理），即雨天的平均用车量只有多云天的 60.7%。

**结论**：式 (4.37) 是 Poisson 回归的**预测式**。给定 $x$，代入即得期望计数 $e^{\hat\beta_0+\sum_j\hat\beta_jx_j}$。原书列出 Poisson 回归相对线性回归的三个优势：

1. **解释**：系数是「倍数」（见上）。
2. **均值–方差关系**：隐含 $\lambda = \E(Y) = \Var(Y)$，自动处理 Bikeshare 那种「均值大方差也大」的形态。
3. **非负拟合值**：不会有负预测（对比线性回归的 9.6%）。

**易错点**：

- **不要用「$\Delta\lambda = \beta_j$」的加法解释**。若 $X_j$ 增加 1，$\lambda$ 从 $e^{\cdots}$ 变成 $e^{\cdots+\beta_j}$，差值是 $e^{\cdots}(e^{\beta_j}-1)$，与当前水平有关。乘性解释才是对的。
- 与逻辑回归的对比很值得记：logistic 里 $\beta_j$ 是「odds 乘 $e^{\beta_j}$ 倍」，Poisson 里 $\beta_j$ 是「**均值**乘 $e^{\beta_j}$ 倍」。后者更直接，因为均值本身就是我们要预测的量。
- 虚拟变量的 Poisson 系数解释成「倍数变化」：多云 $-0.08$ 是相对晴天的 0.923 倍，雨 $-0.58$ 是相对多云的 0.560 倍。若要「雨天相对晴天」，要把两个系数**相加**（$-0.08-0.58=-0.66$，$e^{-0.66}=0.517$）。

### (4.38) Poisson 回归的似然 {#eq-4-38}

$$
\ell(\beta_0,\beta_1,\ldots,\beta_p) = \prod_{i=1}^{n} \frac{e^{-\lambda(x_i)}\lambda(x_i)^{y_i}}{y_i!}, \tag{4.38}
$$

**基础**：$n$ 个**独立**观测。注意原书左端写的是 $\ell$（对数似然的记号）而右端是**乘积**形式——原书明确称之为「the likelihood takes the form」。

**推导 (1) 似然是乘积**。每个观测的 pmf 是 (4.35)（$\lambda$ 换成依赖协变量的 $\lambda(x_i)$）：

$$
f(y_i;\boldsymbol\beta) = \mathrm{Pr}(Y = y_i \mid X = x_i) = \frac{e^{-\lambda(x_i)}\,\lambda(x_i)^{y_i}}{y_i!}
$$

$n$ 个独立观测的联合概率是乘积，得式 (4.38)。其中 $\lambda(x_i) = e^{\beta_0+\beta_1x_{i1}+\cdots+\beta_px_{ip}}$（由 (4.37)）。

**推导 (2) 取对数（真正要最大化的对象）**。原书说要「maximize the likelihood $\ell(\beta_0,\beta_1,\ldots,\beta_p)$」，实际实现中取对数：

$$
\ell(\boldsymbol\beta) = \log L = \sum_{i=1}^{n}\left[-\lambda(x_i) + y_i\log\lambda(x_i) - \log y_i!\right]
$$

逐项的来历：$\log\frac{e^{-\lambda}\lambda^{y}}{y!} = \log e^{-\lambda} + \log\lambda^{y} - \log y! = -\lambda + y\log\lambda - \log y!$。

**推导 (3) 代入 $\log\lambda(x_i) = \beta_0+\sum_j\beta_jx_{ij}$（由 (4.36)）**。注意 $\lambda(x_i)$ 本身是指数形式，$-\lambda(x_i) = -e^{\beta_0+\sum_j\beta_jx_{ij}}$：

$$
\ell(\boldsymbol\beta) = -\sum_{i=1}^{n}e^{\beta_0+\sum_{j=1}^{p}\beta_jx_{ij}} + \sum_{i=1}^{n}y_i\Big(\beta_0+\sum_{j=1}^{p}\beta_jx_{ij}\Big) - \sum_{i=1}^{n}\log y_i!
$$

**推导 (4) 求偏导得 score 方程**。最后一项与 $\boldsymbol\beta$ 无关，导数为 0；第一项的导数是 $-x_{ij}e^{\beta_0+\sum_m\beta_mx_{im}} = -x_{ij}\lambda(x_i)$：

$$
\frac{\partial\ell}{\partial\beta_j} = -\sum_{i=1}^{n}x_{ij}\lambda(x_i) + \sum_{i=1}^{n}y_ix_{ij} = \sum_{i=1}^{n}x_{ij}\big(y_i - \lambda(x_i)\big) = 0, \qquad j = 0,1,\ldots,p
$$

（$j=0$ 时按 $x_{i0}\equiv1$ 处理。）

**与逻辑回归的平行**。比较 (4.5) 的 score 方程 $\sum_i (y_i - p(x_i))x_{ij} = 0$：形式**完全一样**，只是「预测均值」从 $p(x_i)\in(0,1)$ 换成 $\lambda(x_i) > 0$。Fisher 信息矩阵是 $X^\top W X$，其中 $W = \operatorname{diag}(\lambda_1,\ldots,\lambda_n)$（注意**没有** $1-p$ 因子，因为 Poisson 的方差就是 $\lambda$）。

**结论**：式 (4.38) 与 (4.5) 是同一套极大似然框架在两个不同「指数族」成员上的应用。原书明确说「we use the same maximum likelihood approach that we adopted for logistic regression」。参数估计在软件里用 IRLS（迭代重加权最小二乘），仍是牛顿法家族。

**易错点**：

- **原书式 (4.38) 左边写 $\ell$（log-likelihood 记号）但右边是乘积**——这是原书的记号瑕疵。严格说右边是 $L$，$\ell = \log L$。实现时最大化 $\ell$（对数）更稳定，因为乘积在 $n$ 大时数值下溢。
- $\log y_i!$ 与 $\boldsymbol\beta$ 无关，求导时直接丢掉；但**不能**在似然里丢掉（它影响 $L$ 的绝对值，只是不影响 argmax）。
- 残差 $y_i - \lambda(x_i)$ 是「观测值减期望值」，与逻辑回归同构。这让 Poisson 回归的诊断、影响点分析都可以照搬 GLM 的标准工具。
- Poisson 回归**没有闭式解**（$-\sum_ie^{\eta_i}$ 项是非线性的），必须迭代。
- 过度离散时 (4.38) 的似然不再是数据的正确似然，标准误被低估、z 值被高估。原书脚注 5 明确提醒。

### (4.39) 线性回归的均值形式 {#eq-4-39}

$$
\E(Y\mid X_1,\ldots,X_p) = \beta_0+\beta_1X_1+\cdots+\beta_pX_p, \tag{4.39}
$$

**基础**：原书在 4.6.3 列出三种回归的共同点：(1) 给定 $X_1,\ldots,X_p$，$Y$ 服从某个分布族——线性回归是**高斯**、逻辑回归是**伯努利**、Poisson 回归是 **Poisson**；(2) 每种方法都把 $Y$ 的**均值**建模为预测子的函数。式 (4.39)–(4.41) 就是第 2 点。

**推导**。高斯误差下 $Y = \beta_0+\sum_jX_j\beta_j+\epsilon$、$\E[\epsilon\mid X]=0$，故 $\E[Y\mid X] = \beta_0+\sum_jX_j\beta_j$。

**结论**：三个模型的结构完全平行，只是「均值」取的形式不同：

| 模型 | 响应分布族 | 均值形式 | 式号 |
| --- | --- | --- | --- |
| 线性回归 | 高斯 $\mathcal N$ | $\beta_0+\sum_j\beta_jX_j$ | (4.39) |
| 逻辑回归 | 伯努利 $\text{Bernoulli}$ | $\dfrac{e^{\beta_0+\sum_j\beta_jX_j}}{1+e^{\beta_0+\sum_j\beta_jX_j}}$ | (4.40) |
| Poisson 回归 | Poisson | $e^{\beta_0+\sum_j\beta_jX_j}$ | (4.41) |

**易错点**：

- 逻辑回归的 $\E(Y\mid X) = \mathrm{Pr}(Y=1\mid X)$ 这一等式**只在 $Y\in\{0,1\}$ 时成立**（因为 $0\cdot(1-p)+1\cdot p = p$）。$Y$ 取别的编码（如 $-1/+1$）时等式不成立。
- 线性回归的均值形式就是模型本身，没有变换；后两个都经过了变换（logit / log）。这个差别就是 link function 存在的原因。
- 原书用的是**无条件**记号 $\E(Y\mid X_1,\ldots,X_p)$，括号里没有 $\Pr$。

### (4.40) 逻辑回归的均值形式 {#eq-4-40}

$$
\begin{aligned}
\E(Y\mid X_1,\ldots,X_p) &= \mathrm{Pr}(Y = 1\mid X_1,\ldots,X_p)\\[4pt]
&= \frac{e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}}{1 + e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}},
\end{aligned}\tag{4.40}
$$

**基础**：**伯努利**分布：$Y\mid X \sim \text{Bernoulli}(p)$，即 $\Pr(Y=1\mid X) = p$、$\Pr(Y=0\mid X) = 1-p$。

**推导**（为什么期望等于「取 1 的概率」）。$Y$ 只有两个取值，用离散期望的定义 $\E[Y] = \sum_y y\Pr(Y=y)$：

$$
\E[Y\mid X] = 0\cdot\Pr(Y=0\mid X) + 1\cdot\Pr(Y=1\mid X) = 0\cdot(1-p) + 1\cdot p = p = \mathrm{Pr}(Y=1\mid X)
$$

再由式 (4.7) 代入 $p$ 的 logistic 形式即得第二行。

**结论**：式 (4.40) 表明逻辑回归就是「$Y\mid X$ 服从伯努利分布 + 均值用 logit 链接」的模型。GLM 的三个要素在这里齐了：分布族 = 伯努利、link = logit、线性预测子 = $\beta_0+\sum_j\beta_jX_j$。

**易错点**：

- $\mathrm{Pr}(Y=1\mid X)$ 里的 $1$ 依赖 0/1 编码。用 $Y\in\{-1,+1\}$ 编码时 $\E[Y] = 2p-1$，不再是 $p$。
- 伯努利分布的**方差也等于均值**：$\Var(Y) = p(1-p) = \E[Y](1-\E[Y])$。这解释了为什么逻辑回归的标准误里有 $p_i(1-p_i)$ 这个权重（见 (4.5)）。
- 原书写 $\mathrm{Pr}(Y=1\mid X_1,\ldots,X_p)$，用的是 $\mathrm{Pr}$ 而非 $\Pr$，与前面一致。

### (4.41) Poisson 回归的均值形式 {#eq-4-41}

$$
\E(Y\mid X_1,\ldots,X_p) = \lambda(X_1,\ldots,X_p) = e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}. \tag{4.41}
$$

**基础**：伯努利的推广——伯努利是「$\E = \Var$、$Y\in\{0,1\}$」的最简单情形，Poisson 是「$\E = \Var$、$Y\in\mathbb N_0$」的版本。

**推导**（三步，每步都对应前面已证的事实）。设 $Y\mid X \sim \text{Poisson}(\lambda(X))$：

1. 由 (4.35) 的推导 (2)，Poisson 的均值就是它的参数：$\E(Y\mid X) = \lambda(X)$。
2. 由 (4.37)，$\lambda(X_1,\ldots,X_p) = e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}$。
3. 三者用等号串起来。

**结论**：三个式子 (4.39)、(4.40)、(4.41) 分别是三个 GLM 的「均值方程」。它们的右侧都不是 $X$ 的线性函数——这就是为什么需要 link function。

| 模型 | 分布族 | 均值 $\mu$ | 需要 $\eta(\mu)$ 变成线性的 link |
| --- | --- | --- | --- |
| 线性回归 | 高斯 | $\mu = \beta_0+\sum_j\beta_jX_j$ | $\eta(\mu) = \mu$ |
| 逻辑回归 | 伯努利 | $\mu = \dfrac{e^{\sum_j\beta_jX_j}}{1+e^{\sum_j\beta_jX_j}}$ | $\eta(\mu) = \log\frac{\mu}{1-\mu}$ |
| Poisson | Poisson | $\mu = e^{\sum_j\beta_jX_j}$ | $\eta(\mu) = \log\mu$ |

**易错点**：

- 原书这一行把三个等号连起来写，视觉上容易误以为 $\E(Y\mid X)$ 与 $\lambda(X)$ 是两回事。**它们是同一个东西**——$\lambda$ 只是 Poisson 分布参数的记号，而 Poisson 分布的参数恰等于其均值。
- Poisson 分布的方差也等于均值（(4.35) 的推导 (3)），所以 $\Var(Y\mid X) = \lambda(X)$。这就是为什么 (4.38) 的信息矩阵里权重就是 $\lambda_i$ 而没有额外的因子。
- 逻辑与 Poisson 的 link 都是 $\log$（作用于不同对象：$\log\mu$ vs $\log\frac{\mu}{1-\mu}$）。所以 $\log\lambda$ 与 logit $p$ 都是**乘性**解释：$e^{\beta_j}$ 倍。

### (4.42) link function {#eq-4-42}

$$
\eta\left(\E(Y\mid X_1,\ldots,X_p)\right) = \beta_0+\beta_1X_1+\cdots+\beta_pX_p. \tag{4.42}
$$

**基础**：**link function**（链接函数）$\eta$ 对 $\E(Y\mid X_1,\ldots,X_p)$ 施加一个变换，使得**变换后的均值**是预测子的线性函数。原书给出三个例子：

$$
\eta(\mu) = \mu \quad(\text{线性回归}), \qquad \eta(\mu) = \log\frac{\mu}{1-\mu} \quad(\text{逻辑回归}), \qquad \eta(\mu) = \log\mu \quad(\text{Poisson})
$$

**推导（1）为什么 logit 是逻辑回归的 link**。把 (4.40) 的均值代入 $\eta$：

$$
\eta(\mu) = \log\frac{\mu}{1-\mu} = \log\frac{\dfrac{e^{\eta_0}}{1+e^{\eta_0}}}{\dfrac{1}{1+e^{\eta_0}}} = \log\frac{\dfrac{e^{\eta_0}}{1+e^{\eta_0}}}{\dfrac{1}{1+e^{\eta_0}}} = \log e^{\eta_0} = \eta_0 = \beta_0+\beta_1X_1+\cdots+\beta_pX_p
$$

（第一步用到前面 (4.3) 算过的 $1-p(X) = dfrac{1}{1+e^{\eta_0}}$。）**link 存在的原因一目了然**：把非线性的 $\mu$ 拉回线性。

**推导（2）为什么 log 是 Poisson 的 link**。由 (4.41)：

$$
\eta(\mu) = \log\mu = \log\left(e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}\right) = \beta_0+\beta_1X_1+\cdots+\beta_pX_p
$$

**推导 (3) 为什么 $\eta(\mu)=\mu$ 对线性回归成立**。由 (4.39) 直接得（$\mu$ 本来就是线性的，link 是恒等变换）。

**link 的取值范围约束**。link 必须把 $\mu$ 的定义域映到 $\R$：

| 模型 | $\mu$ 的值域 | link | link 的值域 |
| --- | --- | --- | --- |
| 线性回归 | $\R$ | $\mu$ | $\R$ |
| 逻辑回归 | $(0,1)$ | $\log\frac{\mu}{1-\mu}$ | $\R$ |
| Poisson | $(0,\infty)$ | $\log\mu$ | $\R$ |

反过来，**canonical link**（典范链接）指让「参数 = link 的逆像」的那个 link。伯努利族的自然参数是 $\log\frac{\pi}{1-\pi}$，Poisson 族的自然参数是 $\log\mu$，所以这两者就是各自的典范链接（**canonical link**），也是 GLM 理论里唯一能同时给出标准 IRLS 权重的选择。

**结论**：原书把高斯、伯努利、Poisson 归入更大的**指数族**（exponential family），其他成员还有指数分布、Gamma 分布、负二项分布。凡是「选一个指数族成员 + 用 link function 把均值线性化 + 用极大似然估参数」的回归方法，都叫**广义线性模型**（generalized linear model, GLM）。线性回归、逻辑回归、Poisson 回归是三个例子。

**GLM 的标准形式**（把三条实例统一，本书未正式给出但这是式 (4.42) 的直接一般化）：

$$
f(y;\boldsymbol\beta) = h(y)\,\exp\Big\{\eta_i a(y) - b(\eta_i) \Big\}
$$

- **逻辑回归（伯努利族）**：取 $a(y) = y$、$b(\eta) = \log(1+e^{\eta})$、$h(y) = 1$、$\eta = \beta_0+\sum_j\beta_jX_j$。于是
$$
f(y;\boldsymbol\beta) = \exp\Big\{y\big(\beta_0+\textstyle\sum_j\beta_jx_j\big) - \log\Big(1+e^{\beta_0+\sum_j\beta_jx_j}\Big)\Big\} = p(x)^y\big(1-p(x)\big)^{1-y}
$$
正是式 (4.5) 的单观测因子。取对数后 $\ell = \sum_i\{y_i\eta_i - b(\eta_i)\}$，与 (4.5) 推导出的 $\sum_i[y_i\eta_i-\log(1+e^{\eta_i})]$ 逐字相同。✓
- **Poisson 回归**：取 $a(y) = \log y!$、$b(\eta) = e^{\eta}$、$h(y) = 1$、$\eta = \beta_0+\sum_j\beta_jx_j$。于是
$$
f(y;\boldsymbol\beta) = \exp\{\log(y!)\eta_i - e^{\eta_i}\} = y!^{\,\eta_i}e^{-e^{\eta_i}} = e^{-e^{\eta_i}}e^{\eta_i\log y!}
$$
而 (4.35) 给出 $\mathrm{Pr}(Y=y)=\dfrac{e^{-\lambda}\lambda^{y}}{y!} = e^{-e^{\eta_i}}\dfrac{e^{y\eta_i}}{y!}$，与上式**逐字相同**。✓（其中 $\lambda = e^{\eta_i}$ 由 (4.37)。）

**易错点**：

- **link ≠ identity 不是随意的**：它必须保证 $\eta$ 在 $\mu$ 的整个值域上有定义（log 需要 $\mu>0$，logit 需要 $0<\mu<1$）。选错 link 会让某些 $\eta$ 无定义。
- link 的选择**不影响**参数估计的公式形式（都走同一个 IRLS 迭代），但**影响**系数的解释（identity link 下 $\beta_j$ 是「加 $\beta_j$」）和**影响**拟合值的合理性（identity link 可能给出负的 $\hat\mu$，违背分布的值域）。
- 不要把 (4.42) 的右边「$\beta_0+\beta_1X_1+\cdots$」叫做「均值」——它是**线性预测子**（linear predictor）/ 链接后的均值。
- GLM 理论还有第三个要素：$\Var(Y\mid X) = \psi(\mu)$（V(a) 法则）。伯努利 $\psi(\mu) = \mu(1-\mu)$，Poisson $\psi(\mu)=\mu$。**只有当 link 恰好是典范链接时，$\Var$ 才是 $\mu$ 的某个简单函数**，这解释了 (4.5) 的 $p(1-p)$ 与 (4.38) 的 $\lambda$ 这两个权重来源。
- 原书的 GLM 讨论是概念性的：它没有给出指数族的一般定义，只说「The Gaussian, Bernoulli and Poisson distributions are all members of a wider class of distributions, known as the exponential family」。上面的标准形式是把它补全。

### 无编号式：baseline 编码的二元逻辑回归 {#eq-4-u13}

$$
\widehat{\mathrm{Pr}}(Y = \text{orange}\mid X = x) = \frac{\exp(\hat\beta_0 + \hat\beta_1x)}{1+\exp(\hat\beta_0+\hat\beta_1x)}.
$$

**基础**：习题 4.3 (b)：把观测分进 `apples` 与 `oranges`，用 baseline（默认基准类）编码拟合逻辑回归。$X \in \R$ 是单个定量预测子。

**推导**。这是式 (4.7) 在 $K=2$、以 `apples` 为基准（$Y=1$ 代表 orange）时的写法。三个细节：

1. **分子分母的指数形式**：原书写 $\exp(\hat\beta_0+\hat\beta_1x)$ 而不是 $e^{\hat\beta_0+\hat\beta_1x}$——同一个东西，只是 $\exp$ 更适合较长的指数。
2. **$\exp$ 里面加了括号**：$\exp(\hat\beta_0+\hat\beta_1x)$，比 $\exp\hat\beta_0+\hat\beta_1x$ 少一对括号但含义相同（$\exp$ 的参数是紧随其后的整个原子式）。
3. **左边是 $\widehat{\mathrm{Pr}}$**（帽号在 $\mathrm{Pr}$ 上）而不是 $\hat p$——原书在这一组习题里用 $\widehat{\mathrm{Pr}}$，与 4.3.3 节的写法一致。

**配套的 log odds**（习题 (a) 问的就是这个）：

$$
\log\frac{\widehat{\mathrm{Pr}}(Y=\text{orange}\mid X=x)}{\widehat{\mathrm{Pr}}(Y=\text{apple}\mid X=x)} = \hat\beta_0 + \hat\beta_1x
$$

**结论**：这是式 (4.7) 在二分类下的原型。由 (4.40)，$\widehat{\mathrm{Pr}}(Y=\text{orange}\mid X=x)$ 就是 $\E(Y\mid X=x)$（以 $Y=1$ 表示 orange）。

**易错点**：

- 基准类（这里是 apple）**没有**自己的系数。$\hat\beta_0$ 是「$x=0$ 处 orange 相对 apple 的 log odds」。
- 用概率比而不是 odds 比会得到错误答案：$\dfrac{\hat p}{1-\hat p} = e^{\hat\beta_0+\hat\beta_1x}$，而 $\hat p$ 本身不是这个形式。

### 无编号式：softmax 编码的二元逻辑回归 {#eq-4-u14}

$$
\widehat{\mathrm{Pr}}(Y = \text{orange}\mid X = x) = \frac{\exp(\hat\alpha_{\text{orange}0} + \hat\alpha_{\text{orange}1}x)}{\exp(\hat\alpha_{\text{orange}0} + \hat\alpha_{\text{orange}1}x) + \exp(\hat\alpha_{\text{apple}0} + \hat\alpha_{\text{apple}1}x)}.
$$

**基础**：习题 (c) 问：用式 (4.13) 的 softmax 编码拟合**同一份数据**，会得到什么系数？

**推导（1）两类的 log odds**。用 (4.14)，取 $k = \text{orange}$、$k' = \text{apple}$：

$$
\log\frac{\widehat{\mathrm{Pr}}(Y=\text{orange}\mid X=x)}{\widehat{\mathrm{Pr}}(Y=\text{apple}\mid X=x)} = (\hat\alpha_{\text{orange}0}-\hat\alpha_{\text{apple}0}) + (\hat\alpha_{\text{orange}1}-\hat\alpha_{\text{apple}1})x
$$

**推导 (2) 系数换算**。两式都表示**同一个**模型（同一份数据、同一批拟合值），所以 log odds 相等，逐项比较系数：

$$
\boxed{\ \hat\beta_0 = \hat\alpha_{\text{orange}0}-\hat\alpha_{\text{apple}0}, \qquad \hat\beta_1 = \hat\alpha_{\text{orange}1}-\hat\alpha_{\text{apple}1}\ }
$$

反过来 $\hat\alpha_{\text{orange}j} = \hat\beta_j + \hat\alpha_{\text{apple}j}$。习题 (d) 给 $\hat\alpha_{\text{orange}0}=1.2$、$\hat\alpha_{\text{orange}1}=-2$、$\hat\alpha_{\text{apple}0}=3$、$\hat\alpha_{\text{apple}1}=0.6$，代入得 $\hat\beta_0 = 1.2-3 = -1.8$、$\hat\beta_1 = -2-0.6 = -2.6$。

**推导 (3) 一个平移自由度**。若把两类的 $\alpha$ 系数**同时**加一个常数 $c$（$\hat\alpha_{\text{orange}j}\mapsto\hat\alpha_{\text{orange}j}+c$、$\hat\alpha_{\text{apple}j}\mapsto\hat\alpha_{\text{apple}j}+c$），则分子分母同乘 $e^{c}$，比值不变——所以 $\hat\alpha$ 有 $2$ 个冗余参数（$p=1$ 时）。这正是 (4.13) 说的「估计全部 $K$ 个类的系数」比 baseline 多 $p+1$ 个参数的原因。

**预测一致的理由**（习题 (e) 问「预测标签会有多大比例一致」）。把上面的换算代回 softmax 公式：

$$
\frac{e^{\hat\alpha_{\text{orange}0}+\hat\alpha_{\text{orange}1}x}}{e^{\hat\alpha_{\text{orange}0}+\hat\alpha_{\text{orange}1}x}+e^{\hat\alpha_{\text{apple}0}+\hat\alpha_{\text{apple}1}x}}
$$

分子分母同除以 $e^{\hat\alpha_{\text{apple}0}+\hat\alpha_{\text{apple}1}x}$：

$$
= \frac{e^{(\hat\alpha_{\text{orange}0}-\hat\alpha_{\text{apple}0})+(\hat\alpha_{\text{orange}1}-\hat\alpha_{\text{apple}1})x}}{1 + e^{(\hat\alpha_{\text{orange}0}-\hat\alpha_{\text{apple}0})+(\hat\alpha_{\text{orange}1}-\hat\alpha_{\text{apple}1})x}} = \frac{e^{\hat\beta_0+\hat\beta_1x}}{1+e^{\hat\beta_0+\hat\beta_1x}}
$$

与式 (4.u13) 逐字相同。**所以两个模型的预测标签 100% 一致**（除了恰好落在决策边界 $\hat\beta_0+\hat\beta_1x = 0$ 上的样本，那里两边都「平局」，标签由 tie-breaking 规则决定，可能不同）。

**结论**：这是 4.3.5 节「两种编码等价」这一论断的完整证明。原书在 (4.13) 后说「the fitted values, log odds between any pair of classes, and other key model outputs will remain the same, regardless of coding」。

**易错点**：

- softmax 编码**不**要求每个类的系数有意义——它们只有差值可识别（原书习题 (c) 特意问「Be as specific as possible」，就是提醒要指出这一点）。
- 换算时别把 $\alpha$ 的下标搞反：$\hat\beta_0 = \hat\alpha_{\text{orange}0} - \hat\alpha_{\text{apple}0}$，分子是目标类、分母是基准类。反过来会得到 $(\hat\beta_0,\hat\beta_1) = (1.8,\,1.4)$，符号全错。
- 数值上：softmax 编码在二分类时 $K=2$，分母是两项之和；这与 logistic 的 $1+\exp(\cdot)$ 差一个归一化因子，正是「概率 vs odds」的差别。

| 公式 | 内容 | 关键手段 |
| --- | --- | --- |
| (4.1) | 线性概率模型 $p(X)=\beta_0+\beta_1X$ | 反例：$X\to\pm\infty$ 跑出 $[0,1]$ |
| (4.2) | logistic 模型 | $e^t>0$、$1+e^t>0$ ⇒ $p\in(0,1)$；$p'=\beta_1p(1-p)$ |
| (4.3) | odds $=e^{\beta_0+\beta_1X}$ | 由 (4.2) 算 $1-p=\frac{1}{1+e^{\eta}}$ 后作商 |
| (4.4) | logit 线性 | 对 (4.3) 取 $\log$；$\operatorname{logit}(p)=\log\frac{p}{1-p}$ |
| (4.5) | 伯努利似然（MLE） | $L=\prod p^{y}(1-p)^{1-y}$ → $\ell=\sum[y_i\eta_i-\log(1+e^{\eta_i})]$ → $\sum_i(y_i-p_i)x_{ij}=0$；无闭式解 ⇒ 牛顿法 + $I=X^\top WX$ |
| (4.6) | 多元 logit 线性 | 把 (4.4) 的 $X$ 换成 $\sum_j\beta_jX_j$ |
| (4.7) | 多元 logistic 模型 | 由 (4.6) 用 $p=o/(1+o)$ 反解 |
| (4.8) | 学生的 $\hat p$ | 代入 $\hat\eta=-2.7858$ |
| (4.9) | 非学生的 $\hat p$ | 代入 $\hat\eta=-2.139$；差异只来自 student 项 |
| (4.10) | baseline 编码（$k<K$） | 用 $p_k=e^{\eta_k}p_K$ 与 $\sum p_k=1$ 解出 $p_K$ |
| (4.11) | baseline 编码（$k=K$） | 归一化约束 $S p_K = 1-p_K$ |
| (4.12) | baseline 的 log odds | (4.10)$\div$(4.11)，分母精确相消 |
| (4.13) | softmax 编码 | 归一化 + 系数平移不改变概率 |
| (4.14) | softmax 的两类 log odds | 分母相消 ⇒ 系数逐项相减 |
| (4.15) | Bayes 定理 | 全概率公式作分母；生成式路线的入口 |
| (4.16) | 一维高斯密度 | 标准正态换元求归一化常数 $\sqrt{2\pi}\sigma$ |
| (4.17) | 共享方差下的后验 | 代入 (4.16)，假设 $\sigma_1^2=\cdots=\sigma_K^2$ |
| (4.18) | 一维 LDA 判别函数 | 取 $\log$ 丢公共项 + 展开平方；$-x^2/(2\sigma^2)$ 与 $k$ 无关 |
| (4.19) | 二类 Bayes 边界 | $\delta_1=\delta_2$ ⇒ 因式分解 $\mu_1^2-\mu_2^2$ ⇒ 中点 |
| (4.20) | $\hat\mu_k$、$\hat\sigma^2$ | 类内均值 + 组内平方和除以自由度 $n-K$ |
| (4.21) | $\hat\pi_k=n_k/n$ | 频率即概率的估计 |
| (4.22) | LDA 判别函数（估计） | 把 (4.20)(4.21) 代入 (4.18) |
| (4.23) | 多元高斯密度 | 换元 $w=\boldsymbol\Sigma^{-1/2}z$，雅可比 $|\boldsymbol\Sigma|^{1/2}$ |
| (4.24) | 多元 LDA 判别函数 | 取 $\log$ 丢公共项；$-x^\top\boldsymbol\Sigma^{-1}x/2$ 与 $k$ 无关 ⇒ 线性 |
| (4.25) | 多元 Bayes 边界 | $\delta_k=\delta_\ell$，等先验时 $\log\pi$ 相消；超平面 |
| (4.26) | 50% 阈值 | $p_1>p_2\iff p_1>0.5\iff$ log odds $>0$ |
| (4.27) | 20% 阈值 | $\hat\delta_k > \log\frac{t}{1-t}=-1.386$；只平移边界 |
| (4.28) | QDA 判别函数 | 二次项 $x^\top\boldsymbol\Sigma_k^{-1}x$ 依赖 $k$，消不掉 |
| (4.29) | 类内独立假设 | $f_k(x)=\prod_jf_{kj}(x_j)$；省掉联合密度估计 |
| (4.30) | 朴素贝叶斯后验 | (4.29) 代入 (4.15)；取 $\log$ 后可加 |
| (4.35) | Poisson pmf | 指数级数归一化；$\E=\Var=\lambda$ |
| (4.36) | $\log\lambda$ 线性 | 指数值域 $(0,\infty)$ 保证 $\lambda>0$ |
| (4.37) | $\lambda=e^{\beta_0+\sum_j\beta_jX_j}$ | 对 (4.36) 取指数；系数是「倍数」 |

| (4.39) | 线性回归均值 | $\E(Y\mid X)=\beta_0+\sum_j\beta_jX_j$ |

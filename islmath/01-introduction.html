本章数学路线#

第 1 章本身不做统计推导，它做的事是约定记号。但这些记号后面每章都在用， 而且几个约定（向量默认列向量、xij​ 的下标顺序、矩阵乘法的维度约束）如果不看清楚， 后面每一章的公式都会读错。所以本章的重点是把记号讲透，并说明每个记号为什么这样定。

本章 1.5 节的形式化记号只有 1 个编号公式 (1.1)，其余是无编号的记号定义。 这些定义本身没有「推导」，但每个都有一个为什么和一个易错点，是本章的主要内容。

样本与变量：X 的形状#

原书 p.19–20 · 1.5 Notation and Simple Matrix Algebra

观测矩阵 X#

X=​x11​⋮xn1​​⋯⋯​x1p​⋮xnp​​​∈Rn×p

基础：X 是 n×p 的实矩阵，n 是观测个数、p 是变量个数， xij​∈R 是第 i 行第 j 列的那个数。n×p 是矩阵的维度 （shape）：行数乘列数，与矩阵里元素的总个数 np 不同。

推导（为什么先定 n 与 p）。原书用 Wage 数据举例：n=3,000 个人、 p=11 个变量，于是 X 是 3000×11 的表；有些数据 p 很大 （如基因表达 p∼104），所以算法必须能处理 n、p 相差悬殊的情形。

结论：X 有 n 行 p 列，第 i 行第 j 列的数记作 xij​。 下标约定：i 索引样本（1..n），j 索引变量（1..p）。

易错点：xij​ 与 xji​ 一般不是同一个数（X 一般不对称）。

(1.1) 第 i 个观测的行向量#

(1.1)xi​=​xi1​xi2​⋮xip​​​∈Rp

基础：书里「把 X 想成一张电子表格」——行是观测、列是变量。 第 i 行是第 i 个人的全部测量值。

推导（为什么写成列向量而不是行向量）。xi​ 实际上是 X 的第 i 行（1×p）， 但书里写成 p×1 的列向量，原书在此处加了旁注「向量默认按列表示」。 原因是后续所有表达式要求它必须竖着：Xβ 中 X 是 n×p， 只有 β 取 p×1 时乘积才等于 n×1 的响应向量； 若把 xi​ 横着放，就无法把「逐行乘同一组系数」写成矩阵乘法。

结论：xi​ 是第 i 个个体的全部测量值，p×1。 例：Wage 数据里 xi​ 是长度 11 的向量，含 year、age、race 等。 响应变量单独记作 y=(y1​,…,yn​)⊤（见下文）。

易错点：x1​ 在两种说法里含义不同——按行说时它是第一个观测， 按列说时它是第一个变量（见下一条）。原书靠字体区分（斜体小写 vs 粗体小写）， 读的时候必须结合上下文。另一个坑是 xij​ 的下标顺序不能反。

转置 X⊤：把行列对调#

X⊤=​x11​⋮x1p​​⋯⋯​xn1​⋮xnp​​​

基础：转置把行列互换，(A⊤)ij​=Aji​。A 是 r×s 则 A⊤ 是 s×r。

推导（逐项核对，不跳步）。按定义，X 的第 j 行第 i 列是 xij​（i=1,…,n 索引观测、j=1,…,p 索引变量），故

(X⊤)ij​=Xji​=xji​

其中第一个等号是转置定义，第二个等号是 X 的元素写法。取 i 固定、j=1,…,p，得 X⊤ 的第 i 行为 (xi1​,…,xip​)，正是 X 的第 i 行；取 j 固定、i=1,…,n，得 X⊤ 的第 j 列为 (x1j​,…,xnj​)⊤，正是 X 的第 j 列。逐项对照即得上面的显示式。维度也一致：X 是 n×p，X⊤ 是 p×n，共 np 个元素，两边相同。

含义：上式不是一条需要证明的定理，而是记号约定——定义「把行列对调」后逐项写出来就是它。这样写是为了让读者一眼看到：转置把「行 = 观测」翻成「列 = 观测」，因此 X⊤ 的行对应变量、列对应观测。

结论：由 (X⊤)ji​=xij​ 知 X⊤ 的第 j 行就是变量 xj​ 的全部 n 个取值。 所以「X 的行 = 观测」「X 的列 = 变量」这件事，转置后就互换角色。 另外 (xi⊤​)⊤=xi​、(X⊤)⊤=X、(AB)⊤=B⊤A⊤。

易错点：(AB)⊤=B⊤A⊤ 的顺序会反。这条在推导 β^​1​ 的 分母 ∑i​(xi​−xˉ)2 时直接用到（见第 3 章式 (3.6)）。

列向量 xj​#

xj​=​x1j​x2j​⋮xnj​​​∈Rn,j=1,…,p

基础：xj​ 是 n 维向量，收集第 j 个变量的全部观测。n 维 = n×1 列向量。

推导（从 X 的定义逐列取出）。X 的第 j 列按下标读是

(X)1j​, (X)2j​, …, (X)nj​=x1j​, x2j​, …, xnj​

（i 索引行/观测，j 固定）。把这 n 个数按列排成一个 n×1 的矩阵，就是显示式里的 xj​。j 从 1 取到 p，共得到 p 个这样的列向量。

结论：由此 X=(x1​,x2​,…,xp​)，即 X 是 p 个 n 维列向量拼成的。 注意维度约定：X 是 n×p，xj​ 是 n×1。

易错点：书里说「长度 n 的向量用粗体小写，n 维」；而 xi​ 是 p 维。 同一个字母家族在两处维度不同，只有下标能区分。

响应向量 y 与观测对#

y=​y1​y2​⋮yn​​​,数据={(x1​,y1​),(x2​,y2​),…,(xn​,yn​)}

基础：yi​ 是第 i 个观测的响应值（标量，属于 R）。一次观测 = 一个 (xi​,yi​) 对；训练集就是 n 个这样的对。

推导（为什么数据必须成对）。线性模型 f(X)=β0​+∑j​βj​Xj​ 只吃预测子，所以它对每个 xi​ 只能给出一个数 f^​(xi​)。要拿它和实际观测比较，就必须有同样编号的 yi​——编号错了，比较的就不是同一件事了。所以「i 索引观测」这条约定同时用在 xi​ 和 yi​ 上：把 n 个标量响应按观测顺序竖排，得 n×1 的 y；再把 n 对 (xi​,yi​) 并列，就是显示式里的数据集合。

维度上，yi​ 是 1 个数而 xi​ 是 p 个数（见前一条），所以一对 (xi​,yi​) 的两部分长度不同，写成集合元素时用逗号分隔而不是转置。

结论：y 是 n×1 向量。注意 xi​ 是 p 维、yi​ 是 1 维，所以 xi​ 与 yi​ 维度不同，不能写成 (xi​,yi​)⊤ 这样一个「同维向量对」——它们是两个不同 长度的东西，通常写成列并排 (xi⊤​yi​​)。 这在第 4 章写「响应与预测子矩阵」时需要注意。

易错点：(p=1) 时 xi​ 退化为标量，X 是 n×1 列向量， Rn×p 变 Rn。很多公式里 p=1 的特例要单独检查。

字体约定#

原书 p.21 · 同上节

字体约定：标量 / 向量 / 矩阵 / 随机变量#

a（标量）,a（向量）,A（矩阵）,A（随机变量）,Σ（协方差矩阵）

基础：书的字体规则——实数标量用斜体小写（a），向量用粗体小写（a）， 矩阵用粗体大写（A），随机变量用普通大写（A）。

推导（本条是约定，没有推过程——说明为什么这样约定）。这条式子不是定理， 而是原书 1.5 节明确写下的排版规则：同一个字母的字体承载它属于哪一类对象。 它要解决的实际问题是：书里反复出现同一个符号的两种身份。

  1. X：写成 X 时是已经观测到的数据矩阵（n×p，每个元素都是确定的实数）； 写成 X 时是随机变量（取一个向量值，服从某个联合分布）。第 3 章开头 「Xi​ 是随机变量」与后面「X 的第 i 行」讲的是两件事，靠字体分开。
  2. β 与 β^​：β 是真参数（固定、未知），β^​ 是由样本算出的 随机量。第 3 章推标准误时，Var[β^​1​] 有意义而 Var[β1​] 无意义。
  3. Σ：Σ 是 p×p 的协方差矩阵（非对角元可正可负）， 与标量形式的方差 σ2 区分开。

为什么值得专门定规则：全书的「预测 vs 推断」「真参数 vs 估计量」两处关键区分都靠它。 如果字体不承载信息，读者在 (2.7) 里无法判断 Var[f^​(x0​)] 究竟是对训练集还是对 Y 取的。

结论：这条约定是「X（数据矩阵，粗体大写）」与「X（随机变量，普通大写）」 不混淆的原因。第 2 章式 (2.1) 里 Y 是随机变量、X 是随机向量， 而式 (2.4) 里 β 是参数向量——字体直接告诉你对象是「随机的」 还是「固定的」。第 3 章 β^​ 是估计量（随机），β 是真参数（固定）， 这个区别在推导标准误时必须清楚。

易错点：正态分布写作 N(μ,σ2)，其中 σ2 是方差； 而 sd=σ。第 3 章 σ^=RMSE、第 2 章 Var(ϵ)=σ2 是同一件事。

矩阵乘法的维度约束 AB#

r×sA​​⋅s×mB​​=r×mC​​

基础：内维度必须相等：A 的列数 = B 的行数 =s。C=AB 的第 (i,j) 项定义为 Cij​=∑k​Aik​Bkj​——先沿 A 的列取下标 k、沿 B 的行取下标 k， 两者都必须在 1,…,s 上取遍，求和才有定义。

推导（为什么必须是这个形状）。代入 Aik​（i 固定、k=1..s）与 Bkj​（k 固定、j 固定）：

  1. 自由下标：A 侧只有 i 未被求和吃掉，B 侧只有 j 未被吃掉。所以结果矩阵的 行由 i 标记（i=1,…,r，共 r 个）、列由 j 标记（j=1,…,m，共 m 个）， 即 C 是 r×m。
  2. 被求和吃掉的下标只有 k。求和 ∑k=1s​Aik​Bkj​ 要求 k 的取值范围在 A 与 B 中一致：Aik​ 需要 k≤sA​（A 的列数），Bkj​ 需要 k≤sB​ （B 的行数）。k 从 1 数到 min(sA​,sB​) 之外就会有一侧越界，所以必须 sA​=sB​=s。
  3. 反过来，若 sA​=sB​，对任意 i≤r、j≤m，(i,j) 项都是 s 个实数的和， 都有定义。乘法恰好在这些条件下有定义，不多不少。

结论：这条约束是所有矩阵代数推导的第一道检查。后面几乎每个公式都要先用它验一遍：

  • Xβ：X 是 n×p、β 是 p×1，得 n×1，与 y 匹配。
  • X⊤X：p×n 乘 n×p，得 p×p，与 β 匹配。
  • X⊤y：p×n 乘 n×1，得 p×1，与 β 匹配。
  • 1⊤β：1×p 乘 p×1，得标量（截距项）。

易错点：Xy 不合法（p=n 时）。XX⊤y 也不合法 （y 是 n 维但要乘的矩阵要求 p 维输入）。这类错误在推导 y⊤Xβ 与 (X⊤y)⊤β 的关系时最容易犯。

本章数学路线#

第 2 章的公式不多，但它们是全书的纲领。依赖关系是：

  1. 式 (2.1) 给出数据生成模型 Y=f(X)+ϵ，这是所有后续建模的出发点。
  2. 式 (2.3) 把预测误差拆成可约 + 不可约，说明「为什么有一个下界」。
  3. 式 (2.7) 进一步把可约部分拆成平方偏差 + 方差，这是全书反复引用的结论。
  4. 式 (2.10)–(2.12) 把这套语言搬到分类问题，引入 Bayes 分类器与 Bayes 错误率。
  5. KNN 的式 (2.12) 是第一个具体算法，也是第 3 章对比线性回归的基准。

式 (2.7) 的推导是本章最需要动手的部分，也是第 6、7、9 章反复引用的定理。

估计 f 的两种路线#

原书 p.25、p.30 · 2.1 What Is Statistical Learning?

(2.1) 数据生成模型#

2.1Y=f(X)+ϵ

基础：X=(X1​,…,Xp​) 是输入（预测子）向量，Y 是定量响应。 f 是未知的真实函数，把 X 映射到 Y 的系统部分均值。 ϵ 是误差项，捕获 X 解释不了的部分。

推导（为什么必须写成这个形式）。设我们对一个新观测 (X,Y) 关心预测。 「最好的可能预测」是在给定 X 时的条件期望：

E[Y∣X=x]=∫yfY∣X​(y∣x)dy

把 Y 按「系统部分 + 随机部分」拆开：取任意函数 g，记 ϵ:=Y−E[Y∣X]，则 E[ϵ∣X]=E[Y∣X]−E[E[Y∣X]∣X]=0 （用全期望公式，E[Y∣X]=E[E[Y∣X]∣X]）。 又因为 E[Y∣X] 只依赖 X，把它命名为 f(X)，就得到 Y=f(X)+ϵ， 且 E[ϵ∣X]=0。

结论：式 (2.1) 不是「假设」，而是对任何 (X,Y) 都成立的分解—— f(X)=E[Y∣X] 是唯一的、使得残差条件均值为零的那个函数。 不可约性随之而来：即使知道 f 精确，Y 本身仍是随机的。

(2.4) 参数化：线性模型#

2.4f(X)=β0​+β1​X1​+β2​X2​+⋯+βp​Xp​

基础：参数化方法分两步——先假定 f 的形状，再估这 p+1 个系数。 非参数方法不给形状加约束，直接让拟合尽量贴近数据、同时保持光滑。

推导（为什么假定形状就简化了问题）。Rp 上的任意连续函数有无穷多个自由度， 「估计 f」是一个无穷维问题，无法用有限样本定解。假定为 (2.4) 后， f 被 p+1 个实数完全确定，搜索空间从函数空间降到 Rp+1—— 一个有限维问题，有限样本就够用。

结论：参数化的代价是模型错配风险——若真实 f 离 (2.4) 很远，估计就差。 非参数方法避免了这一点，但需要多得多的样本才能达到同等精度。 书里 Figure 2.4（线性拟合）与 Figure 2.5（薄板样条）的对比正说明这两难。

易错点：式 (2.4) 写的是 f 而不是 Y，也不含 ϵ。真正的随机性来自 式 (2.1)。第 3 章的式 (3.1) 才把 ϵ 补回去，并且用 ≈ 表示 「这条线只是条件期望的近似」。

为什么估计 f#

原书 p.27–28 · 2.1.1 Why Estimate f?

易错点：E[ϵ]=0（无条件均值为零）比 E[ϵ∣X]=0 弱得多。 书中 Figure 2.2 说「误差整体上均值为零」指的是前者；推导式 (2.3)、(2.7) 需要的是后者。 区别在于：E[ϵ]=0 只保证残差图不整体偏移，但可能与 X 有关（漏变量时的典型情形）， 此时 f 并不是真正的条件期望，整个偏差–方差分解的形式要重新推。

原书 p.27–28 · 2.1.1 Why Estimate f?

(2.2) 预测视角：Y^=f^​(X)#

2.2Y^=f^​(X)

基础：f^​ 是用训练数据估出的函数，Y^ 是对应的预测值。 帽号 ⋅^ 统一表示「估计量或预测值」。

推导（为什么只写 X 不写 x）。把式 (2.1) 的 Y 换成一个我们愿意输出的数。 式 (2.1) 说 Y=f(X)+ϵ，其中 ϵ 与 X 无关、无法预测； 而条件期望是「在只知 X 时 Y 的最好猜测」：

E[Y∣X]=f(X)⟹用 f(X) 代替 Y 时误差只剩 ϵ

所以预测值按定义取「条件均值在估计量处的取值」Y^:=f^​(X)，误差是 Y−Y^=ϵ+(f(X)−f^​(X))——可约部分来自 f^​ 不够好， 不可约部分来自 ϵ。式 (2.3) 与 (2.7) 都是对这一个残差展开平方得到的。

这里写大写 X 而不是小写 x：式 (2.1) 里 X 本身就是随机变量（普通大写）， Y 是 X 的函数，所以 Y^ 也是随机变量；写成 f^​(X) 而不是 f^​(x) 正是要强调「这个预测是在随机的新观测 X 处做出的」，而不是在某个固定的 x 处。

结论：预测问题里 f^​ 是黑箱，只关心输出准不准。这与推断问题 （关心 f^​ 的具体形式，例如何变量与 Y 相关）形成对比，两种目标可能导向不同方法。

易错点：f^​ 是随机变量（依赖训练集 D），f 是固定函数。 后面式 (2.7) 里 Var[f^​(x0​)] 就是对 D 求的。 把 f^​ 当常数会让偏差–方差分解失去意义——这是本章最容易出错的地方。

(2.3) 误差的分解：可约与不可约#

2.3E[(Y−Y^)2]=Reducible[E(f^​(X)−f(X))2]​​+IrreducibleVar(ϵ)​​

基础：设 f^​ 与 X 都固定，唯一变动来自 ϵ。 期望 E(⋅) 是对「同一个 X 上重复取 Y」求的。

推导。记 b:=f^​(X)−f(X)（偏差，对固定的 f^​ 是常数）。 把 Y−Y^=f(X)+ϵ−f^​(X)=ϵ−b 展开：

E[(ϵ−b)2]=E[ϵ2]−2bE[ϵ]+b2

用 E[ϵ]=0（书上此处假设的正是这个较弱的条件），中间项消失； 再用 E[ϵ2]=Var(ϵ)+(Eϵ)2=Var(ϵ)， 得 E[(Y−Y^)2]=b2+Var(ϵ)=[E(f^​(X)−f(X))]2+Var(ϵ)， 即式 (2.3)（式子里的平方是 (⋅)2 作用于括号整体）。

结论：三项含义——b2 是估计的偏差造成的，只要改进方法就能降； Var(ϵ) 是 Y 自身的随机性，任何方法都无法降低， 所以它是测试 MSE 的下界。书中说可约误差「原则上总是非负」正是这个 b2。

易错点

  • Var(ϵ) 是条件方差 Var(ϵ∣X) 的某个平均。 若 ϵ 的方差随 X 变化，严格来说式 (2.3) 应写成期望下的平均。 书里把 X 视为已定，读者知道结论对随机 X 取期望后仍成立即可。
  • 若 E[ϵ]=0（例如漏了变量），上式多出一项 E[ϵ]2， 而且「不可约误差」不再等于 Var(ϵ)。此时应先把模型改对。
  • f^​ 与 ϵ 相关时（例如 f^​ 用同一批数据拟合）， E[(Y−Y^)2] 还要对训练集取期望才能得到式 (2.7)。式 (2.3) 假设 f^​ 固定， 所以只出现偏差不出现方差——两个式子的差别正在于此。

偏差与方差的定义#

Bias=ED​[f^​(x0​)]−f(x0​),Variance=VarD​[f^​(x0​)]

基础：两个期望/方差都对训练集 D 取（即「如果换一批训练数据， 估计会怎样」）。

推导（为什么这两个量刻画「换数据会怎样」）。设重复 B 次实验， 每次抽一份大小为 n 的训练集 D(b)，得到 f^​(b)(x0​)，b=1,…,B。 考虑这 B 个值的二阶中心矩：

B1​b=1∑B​(f^​(b)(x0​)−f^​(b)(x0​))2B→∞​VarD​f^​(x0​)

而均值 B1​∑b​f^​(b)(x0​) 收敛到 ED​f^​(x0​)。所以 「重复实验结果的波动程度」= 方差，「重复实验结果的中心位置偏离真值多少」= 偏差。

结论：这两句定义是全书的核心区分。偏差反映模型形式错没错（系统性错误）， 方差反映估计稳不稳（对数据的敏感度）。灵活性增加会同时降低偏差、升高方差。

易错点：偏差可正可负（书里常说「低偏差」而不说「偏差小」正是这个原因）， 但平方偏差 Bias2 非负。式 (2.7) 里出现的是平方偏差。

拟合质量的度量#

原书 p.38–45 · 2.2 Assessing Model Accuracy

(2.5) 均方误差#

2.5MSE=n1​i=1∑n​(yi​−f^​(xi​))2

基础：yi​ 是实际观测，f^​(xi​) 是预测值。取平方有两个作用： 消除符号、加重惩罚大误差。

推导（为什么训练 MSE 不是我们关心的量）。训练 MSE 衡量的是拟合优度。 一个极端例子：取 f^​ 为常数 c=n1​∑i​yi​，训练 MSE 可能很大； 反过来，若参数足够多（如多项式插值），可以让 f^​(xi​)=yi​ 对所有 i 成立， 训练 MSE =0，但这样的 f^​ 对新观测的预测极差（过拟合）。 所以训练 MSE 小只说明模型有足够的自由度记住训练数据。

结论：真正要看的是测试 MSE，用未参与训练的 (x0​,y0​) 计算。 式 (2.6) 给出总体测试误差 E[(y0​−f^​(x0​))2]， 式 (2.7) 把它按训练集再取期望，这就是下面要推的核心结论。

易错点：MSE 有量纲（单位的平方），因此不能直接跨响应变量比较 （预测工资的 MSE 和预测销量的 MSE 不可比）。第 5 章用标准化 MSE 解决； 分类问题则用错误率，两者量纲无关。

期望测试 MSE 与偏差–方差分解#

2.7Ey0​,D​[(y0​−f^​(x0​))2]=Bias2[f^​(x0​)]+Var[f^​(x0​)]+Var(ϵ)

基础：Ey0​,D​ 表示双重期望——先对训练集 D 取， 再对测试点的响应 y0​ 取。这正是「重复多次：换训练集、换测试点，各测一次」的平均。 前提：y0​ 与 D 独立（测试点没参与训练）。

推导。以下对 D 与 y0​ 的期望省略下标，固定 x0​。记

m:=E[f^​(x0​)],u:=f^​(x0​)−m(E[u]=0),b:=m−f(x0​)

关键一步是把 y0​−f^​(x0​) 拆成三块：

y0​−f^​(x0​)=ϵ(f(x0​)+ϵ−f(x0​))​​−u(f^​(x0​)−m)​​−b(m−f(x0​))​​=ϵ−u−b

（这个减法是恒等式，没有任何近似。）现在逐项展开 E[(ϵ−u−b)2]。 用 (α+β+γ)2=α2+β2+γ2+2αβ+2αγ+2βγ：

E[ϵ2]+E[u2]+b2−2E[ϵu]−2bE[ϵ]+2bE[u]

三个交叉项逐一消失：

  • E[u]=0（u 是中心化后的随机量，按定义），故 2bE[u]=0。
  • E[ϵ]=0（数据生成模型），故 −2bE[ϵ]=0。
  • E[ϵu]=E[ϵ]E[u]=0：因为 y0​（从而 ϵ）与训练集 D （从而 u）独立，期望可分离，两个因子其一为零。这一步是 x0​ 固定、y0​ 新的意义所在。

剩下的三项各自化简：

E[ϵ2]=Var(ϵ)+(Eϵ)2=Var(ϵ)
E[u2]=E[(f^​−m)2]=Var(f^​(x0​))

b2=(E[f^​(x0​)]−f(x0​))2=Bias2[f^​(x0​)]。 三项相加即得式 (2.7)。

结论：期望测试 MSE = 平方偏差 + 方差 + 不可约误差。三者都非负， 所以 E[(y0​−f^​(x0​))2]≥Var(ϵ)——这重新证明了式 (2.3) 的下界， 而且更强：即使 f^​ 恰好无偏，仍要付方差的钱。要最小化测试 MSE， 就要在平方偏差与方差之间找平衡，这正是「灵活性」的含义： 越灵活的模型偏差越小、方差越大（图 2.12）。

易错点

  • 必须有 E[ϵ∣X]=0，不只是 E[ϵ]=0。推导里 E[ϵ] 与 E[ϵu] 的消失靠的是 u 与 ϵ 的独立性/零均值组合； 若 ϵ 与 X 相关，f 就不等于条件期望，分解要重推。
  • b 是常数（对 D 与 y0​ 都是），u 是随机。平方偏差里不含方差， 不要写成 Var(f^​)−⋯ 之类的形式。
  • 式 (2.7) 是「总体」结论：Var(ϵ) 通常未知，实践中用测试集 MSE 或交叉验证（Chapter 5）来估计。
  • 书里强调 Var(ϵ) 是下界，实际中几乎总未知—— 所以模型选择只能在偏差与方差之间做相对权衡。

分类问题#

(2.8) 训练与测试错误率#

2.8Training error rate=n1​i=1∑n​I(yi​=y^​i​),Test error rate=m1​i=1∑n+m​I(yi​=y^​i​)

基础：I(⋅) 是示性函数（指示函数）：

I(命题)={10​命题为真命题为假​

推导（为什么求和除以 n 就是「错误比例」）。对每个 i，I(yi​=y^​i​) 取值 0 或 1。把它们加起来：每个被误分类的观测贡献 1，分类正确的贡献 0。 所以 ∑i=1n​I(yi​=y^​i​) 恰好是误分类的个数，再除以总个数 n 得比例。 这个量在 [0,1] 之间。

结论：式 (2.8) 给出训练错误率；式 (2.9) 把同一公式用于 n+m 个训练+测试观测， 得到总体错误率，其中 m 是测试样本量。分类问题里我们不能用平方误差—— 因为 yi​=y^​i​ 已经包含了全部错误信息，再平方没有增益。

易错点

  • 示性函数与 Kronecker delta 记号 1{⋅} 是同一个东西， 书里两种都用。
  • 错误率对类别不平衡极敏感：99% 的样本是负类时， 永远预测负类的错误率只有 1%。所以第 4 章引入灵敏度、特异度等指标。
  • 式 (2.9) 里分子是 n+m 项、分母也是 n+m，如果只写测试集那部分， 得到的才是纯测试错误率。书里两式一起给，是为了对照。

(2.10) Bayes 分类器#

2.10y^​=argjmax​P(Y=j∣X=x0​)

基础：Y 取值于 {1,…,K}（K 个类别），x0​ 是一个新观测的预测子取值。 P(Y=j∣X=x0​) 是条件概率：已知 X 恰好等于 x0​ 时 Y 属于第 j 类的概率。 argmaxj​ 返回使后面表达式取到最大值的那一个 j（下标），不是最大值本身。

推导（为什么取 argmax）。给定 x0​，任何分类器都输出某个类 j，猜测正确的概率就是 P(Y=j∣X=x0​)，所以应该选最大的那个——这就是 (2.10)。它需要联合分布， 实践中通常未知，因此无法直接实现。

写成不等式更明确：对任意与 X 无关的选类规则 g 与任意权重 πj​≥0、∑j​πj​=1，

P(g(x0​)=Y)=j=1∑K​πj​I(g(x0​)=j)≤1≤j≤Kmax​ πj​P(Y=j∣X=x0​)

因为求和中至多有一项（I 为 1），其余为 0；取 πj​=1 得左边就是 P(g(x0​)=Y)， 右边是各条件概率的最大值。要让正确概率最大，就该输出使 P(Y=j∣X=x0​) 最大的那个 j， 即 y^​=argmaxj​P(Y=j∣X=x0​)。二类时它退化成「P(Y=1∣X=x0​)>0.5 判 1，否则判 2」（见式 (4.26) 的 50% 阈值）。

结论：式 (2.10) 是逐点最优的分类规则：它在每个 x0​ 处都把该点的正确概率取到最大， 所以也使测试错误率取到最小（式 (2.11)）。它同时是第 4 章 LDA / QDA / 逻辑回归 / 朴素贝叶斯四种方法的共同目标——那些方法都是在给 P(Y=j∣X=x0​) 找可计算的近似。 代价是需要联合分布知识，实践中通常未知，所以它是理论基准而不是可直接实现的算法。

易错点：式 (2.10) 是条件概率 P(Y=j∣X=x0​)，不是 P(Y=j)。 用先验（边缘）概率分类等价于忽略所有预测子，在有信号时一定更差。

逐点 Bayes 错误概率（原书未编号）#

P(Y=Y^∣X=x0​)=1−jmax​P(Y=j∣X=x0​)

基础：左边是「用 Bayes 分类器时在 x0​ 处犯错的概率」，右边是该点上的最大正确概率。

推导。对固定的 x0​，∑j​P(Y=j∣X=x0​)=1（条件分布归一）。 y^​ 取 argmaxj​ 后，只有一个 j 有贡献，所以

P(Y=y^​∣X=x0​)=1−P(Y=y^​∣X=x0​)=1−jmax​P(Y=j∣X=x0​)

结论：这是逐点的 Bayes 错误率，仍依赖 x0​。式 (2.11) 再对 X 的分布取平均， 得到总体 Bayes 错误率（原书此式未编号，是正文里的内联推导）。

易错点：1−maxj​(⋅) 里的 max 在条件概率内部——先固定 x0​ 选类。 若写成 maxj​(1−P(Y=j∣X=x0​)) 就变成选最差的类了。

(2.12) KNN 估计的条件概率#

(2.12)P^(Y=j∣X=x0​)=K1​i∈N0​∑​I(yi​=j)

基础：N0​ 是训练集中离 x0​ 最近的 K 个观测的索引集合， K 是邻居数，I(yi​=j) 是「yi​ 是否属于第 j 类」的示性函数。

推导（为什么是频率计数）。公式右边对 N0​ 中每个邻居： 若它属于第 j 类贡献 1，否则贡献 0。求和得第 j 类的邻居个数， 除以 K（邻居总数）得比例。若 K 个邻居中有 mj​ 个属于第 j 类， 则结果为 mj​/K，且 ∑j​mj​/K=K/K=1——是一个合法的概率分布。 再把它代回 (2.10) 的 argmax，就得到 KNN 分类器： 预测 x0​ 属于邻居中数量最多的那一类。

结论：KNN 用「局部频率」估计条件概率。这是第 3 章对比线性回归的基准模型， 也是 4.6 节 KNN 与朴素贝叶斯比较的起点。

易错点：公式是估计的 P^，不是真的 P。帽号不能省—— 它提醒我们这只是一次频率统计，受 K 与局部样本量影响很大。

(2.11) Bayes 错误率#

2.11Bayes error rate=1−E[jmax​P(Y=j∣X=x0​)]

基础：P(Y=j∣X=x0​) 是条件概率——已知预测子取值为 x0​ 时， 响应属于第 j 类的概率。E[⋅] 是对 X 的分布取期望。

推导（为什么取 argmax）。给定 x0​，任何分类器都输出某个类 j，猜测正确的概率就是 P(Y=j∣X=x0​)。要最大化「猜对的概率」，就选最大的那个。形式化地， 对任意分类规则 g 与任何 D 无关的先验权重 πj​：

P(g(x0​)=Y)=j∑​πj​I(g(x0​)=j)≤jmax​πj​P(Y=j∣X=x0​)

（每个 πj​≥0、∑j​πj​=1，加权和不超过最大值）。取 πj​=P(Y=j)， 再对 x0​ 取期望，Bayes 分类器达到测试错误率的最小可能值。

Bayes 错误率就是「已经做到最好时仍然会犯的错」：对固定的 x0​，最优错误概率是 1−maxj​P(Y=j∣X=x0​)；再对 X 的随机性取平均：

Bayes error=EX​[1−jmax​P(Y=j∣X=x0​)]=1−E[jmax​P(Y=j∣X=x0​)]

最后一步用期望的线性性。

结论：二类问题里 Bayes 分类器就是「若 P(Y=1∣X=x0​)>0.5 判 1，否则判 2」。 Bayes 错误率是分类问题的不可约误差——与式 (2.3) 的 Var(ϵ) 地位相同。 书中模拟数据的 Bayes 错误率是 0.133，因为两类在总体中重叠， 某些 x0​ 处 maxj​P(Y=j∣X=x0​)<1。

易错点

  • 式 (2.11) 的期望在 max 外面。E[maxj​⋅] 一般不等于 maxj​E[⋅]—— 前者是「先对每个 x0​ 选最优类再平均」，后者是「先平均再选类」， 后者会给出过于乐观（更小）的错误率。这是最常见的记号陷阱。
  • P(Y=j∣X=x0​) 用的是条件概率，需要联合分布知识，实践中通常未知。 所以 Bayes 分类器是理论基准，不能直接实现——这正是 KNN、LDA、逻辑回归存在的理由。

KNN 分类与 K 的选择（原书未编号）#

f^​k​(x0​)=j∈{1,…,K}argmax​ i∈N0​∑​I(yi​=j)

基础：式 (2.12) 给出概率估计，下面这条是把 (2.10) 的 argmax 代进去之后的最终分类规则 （原书此式未编号，是正文里的推论）。 注意书里两个 K 含义不同：K 是类别总数，k 是邻居数。

推导（为什么下面这条等价于「选邻居中最多的一类」）。式 (2.12) 里除以 K（邻居数） 是公共的正因子，argmax 对它不敏感，所以 argmaxj​ 可以直接作用在分子上： 分子 ∑i∈N0​​I(yi​=j) 就是第 j 类的邻居计数，取最大即得众数类。

结论：K（邻居数）控制灵活性：K 小 → 边界起伏大、方差大； K 大 → 平滑、偏差大。这是式 (2.7) 在分类场景的重演， 书中用图 2.17 说明邻居数与偏差–方差的权衡。 「最近」的度量用欧氏距离 ∥xi​−x0​∥2​=∑j​(xij​−x0j​)2​。

易错点

  • 距离要用标准化的变量（原书在 Advertising 例子里先标准化）， 否则量纲大的变量主导了「最近」的判断，Figure 2.15–2.16 说明了这一点。
  • K 一般取奇数（偶数时平局无决断规则）。K=n 时退化为「总是预测训练集中最多的类」。
  • 式 (2.12) 是估计的 P^。书里特意用帽号区分它与真正的条件概率 P。
